## 经验（重要，写进下次操作）

### 1. 飞书发文件：必须用 `media` 参数，不能用 `attachments`
- 用 `attachments:[{type:"file", media:"...", name:"..."}]` 发，飞书侧收到的是 **post 纯文本**，MEDIA 行还会被当正文原样渲染 + 末尾追加一行 `📎 路径`——等于文件没发出去
- 正确用法：`message(action="send", media="/abs/path.zip", filename="x.zip", mimeType="application/zip", message="说明")`
- 校验方法：返回 receipt 里 `parts[].kind` 应为 `media`（attachments 方式返回 `text`）
- 二次校验：用 tenant_access_token 调 `im/v1/messages?container_id_type=chat&container_id=<chat_id>`，msg_type 应为 `file`

### 3. GitHub 直连不通时的两条可用通道
- 仓库源码：`https://api.github.com/repos/<owner>/<repo>/tarball`（200，走 codeload，能通）
- Release 附件：`https://api.github.com/repos/<owner>/<repo>/releases/assets/<asset_id>`，加 `-H "Accept: application/octet-stream"` + curl -L（200，能在 github.com 不通时下载 release 文件）
- 附件的 asset_id 从 `https://api.github.com/repos/<owner>/<repo>/releases` 里取
- 本次成果：官方 EPUB 999KB（38 章、含封面目录）已发逸凡；同 release 还有 PDF 7.2MB、离线 HTML 2.1MB
