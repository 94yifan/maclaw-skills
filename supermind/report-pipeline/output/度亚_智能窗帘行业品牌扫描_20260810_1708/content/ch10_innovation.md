# 创品策略

## P0（立刻启动）

免打孔快装方案：打开2亿租房增量市场，伸缩杆式导轨+强力气压支撑+锂电池电机，定价499-699元。技术验证可行，6-9个月推出。

场景化内容矩阵：围绕8个核心生活场景制作短视频——早起光照管理、午睡遮光、宝宝午睡、观影模式、隐私保护、节能隔热、远程控制、起夜安全。借鉴扫地机器人行业从参数竞争到场景叙事的转型路径。

## P1（6-12个月内启动）

安装服务品牌化：借鉴九牧星管家服务体系。统一工装+无尘打孔+安装后48小时回访+安装师傅分级体系。从成本中心转品牌溢价来源。

三四线城市渠道下沉：借鉴凯迪仕渠道铁三角（品牌旗舰店+授权经销商+社区体验店）。三四线城市精装房窗帘配套率仅5%-8%（vs一线25%-30%），但改装意愿更强。

## P2（长期储备）

离线语音控制方案：科大讯飞/思必驰离线语音芯片单颗成本已降至15-25元。覆盖WiFi不稳定场景，纽扣电池续航12-18个月。

窗帘面料订阅制：电机+导轨+季度面料换新订阅方案，年费形式。将低频窗帘消费变高频订阅。

SaaS酒店运营：设备免费+年费服务模式（每间房199-299元/年）。中国1500万间客房×1%渗透=3750万ARR。
