# 复盘修改建议 Skill

## 定位

针对已经完成的投放复盘报告（PPTX/飞书文档），逐页输出结构化的修改建议。输出格式为修改意见文档，清晰标注每条建议的改动位置、改动内容、改动理由。

区别于 `data-report-review`（通用报告质量检查清单）和 `proposal-review`（提案结构性审查），本skill专注复盘报告的场景：用数据说话、结论有数据支撑、建议在客户约束内可执行。

## 核心原则

**不了解约束的建议 = 无效建议。** 在出任何修改建议之前，必须先完成前置三问。

## 前置三问（必须执行，不跳过）

在开始逐页审查之前，先回答这三个问题。答不上来的标记"待确认"，不推测。

### 问1：当前投放状态

- 信息流/搜索/口碑通是否仍在跑？
- 是否有预算冻结或已停投的渠道？
- 投放账户是否有操作权限限制？

**为什么问：** 如果信息流已停投，"建议信息流放量到X万"就是无效建议。建议的有效性取决于渠道是否还在运作。

### 问2：客户不可妥协项

- 品牌词防守是否不可动摇？（多数成熟品牌是）
- 核心竞品占位是否有硬性要求？
- 客户汇报偏好是什么？（数据先行 vs 结论先行？PPT标注 vs 文档详述？）

**为什么问：** 品牌词对瑞幸是防守底线，但对外部视角只是一个可优化的成本项。不了解客户底线出的建议会被直接驳回。

**场景化提醒：** 品牌词防守只在有搜索投放的项目才适用。纯信息流+视频流的项目（如热点借势）没有搜索，这条直接跳过，别机械套用。

### 问3：操作空间

- 预算有调整空间吗？还是只能在已有预算内优化分配？
- 内容团队配合度如何？（能做新素材还是只能优化已有素材？）
- 方案交付时间窗口是多久？（一天内改完还是有一周？）

**为什么问：** "建议新拍一组达人素材"和"建议从已有素材中选最优组合"是两条完全不同的建议路径，取决于内容团队的实际产能。

## 修改建议输出规范

### 格式要求

每条建议包含四个字段：

```
页面：[页码/板块名]
动作：[新增 / 改写 / 扩展 / 重写 / 不改]
问题：[当前版本有什么问题]
修改方向：[具体怎么改，给方向不给填空]
约束：[这条建议需要确认的前置条件，如果前置三问没答上来标"待确认"]
```

### 优先级标注

- 🔴 必须改：数据错误、逻辑矛盾、结论无支撑
- 🟡 建议改：数据不完整、表达不清、缺关键对比
- ⚪ 锦上添花：排版优化、措辞调整

### 不改的页面也要标注

如果某页当前版本已达标，标注"不改"并说明理由。避免团队猜测"这一页是没看到还是觉得没问题"。

## 常见失败模式（瑞幸案例教训）

| 错误 | 表现 | 根因 |
|------|------|------|
| 给已停投渠道出放量建议 | 信息流已停投，建议放量到3-4万 | 没问投放状态 |
| 动客户底线 | 建议缩减品牌泛词匹配 | 没问不可妥协项 |
| 忽略客户汇报偏好 | 建议执行摘要前置 | 没问汇报风格 |
| 建议超出执行能力 | 建议大规模新素材 | 没问内容团队产能 |

## 与 data-report-review 的分工

`data-report-review` 做的是通用质量检查（数据准确、逻辑连贯、结论有支撑）。本skill在其基础上叠加了客户约束层和操作可行性层。两个skill可以串行使用：先用 data-report-review 跑一遍质量，再用本skill做客户适配。

## 复盘独有检查项（补充通用审查）

除了通用质量检查外，复盘报告额外检查：

- [ ] 每个核心结论是否指向一个可执行的8月动作？
- [ ] 环比数据是否完整？（只看绝对值不知道算好算坏）
- [ ] 归因是因果性还是相关性？（"投放点位切换导致下降"需要更多证据链）
- [ ] 竞品分析是否有收口页？（9页竞品分析没有一页汇总=读者要在脑内做跨页对比）
- [ ] 热点洞察是否有投放桥梁？（热梗和投放分析是两条平行线=读者不知道怎么用）
- [ ] 策略建议和执行备注是否混在一起？（"优质词优先精准匹配"是操作流程不是策略）
- [ ] 渠道完整性：是否覆盖 KOL、信息流、视频流、搜索四块？（渠道分工漏搜索是高频遗漏）
- [ ] 小红书口径：阅读=点击，CPC=每阅读成本=每点击成本，CTR=阅读率，别把阅读率和点击率当成矛盾报出来
- [ ] 前置三问场景化：品牌词防守只在有搜索投放的项目适用，纯信息流+视频流项目不适用

## 代码工具

`scripts/review_check.py` 是复盘完整性检查脚本，出建议前先跑一遍：

```bash
python3 scripts/review_check.py <复盘文档路径>
```

- 渠道完整性：自动检查 KOL、信息流、视频流、搜索四块是否齐全，缺哪块报 MISSING。
- 口径一致性：同时出现"点击率"和"阅读率"时提示统一口径。
- 前置三问场景化：无搜索投放时提示品牌词防守不适用。
