# 小红书平台口径知识库

固化小红书投放的基础口径，遇到指标对不上先查这里，查不到就标待验证，别用通用认知硬套。

## 核心口径（最容易搞混的）

- 阅读 = 点击。用户点进笔记就是阅读，是同一个动作、同一个指标。
- CPC = 每阅读成本 = 每点击成本。消耗 ÷ 阅读（点击）。
- CTR = 阅读率 = 点击率。阅读（点击）÷ 曝光。
- CPM = 每千次曝光成本。消耗 ÷ 曝光 × 1000。
- CPE = 每互动成本。消耗 ÷ 互动。

## 指标层级

- 曝光：用户刷到（impression）
- 阅读 / 点击：用户点进笔记（view = click，同一个）
- 互动：点赞、评论、收藏、转发

## 重要提醒

- 阅读率和点击率是同一个指标的两个叫法，同时出现不算混用，别当成数据矛盾报出来。
- 别把阅读和点击当成两个不同指标去对比，它们是一个东西。
- CPC 0.03 这种低值，意味着消耗 ÷ 阅读，是每阅读成本，不是每点击成本，两者一致。

## KFS 结构

- K = KOL（达人）
- F = Feeds（信息流）
- S = Search（搜索）
- 复盘渠道分工必须覆盖 KOL、信息流、视频流、搜索四块，漏搜索是高频错误。

## 曝光口径

- 项目投放曝光：投放本身带来的曝光。
- 话题词关联曝光：话题词在站内的整体关联曝光，含自然流量。
- 两者不是一回事。话题词关联曝光 > 投放曝光，说明内容溢出到自然流量场域（如 334 万 vs 151 万，溢出 2.2 倍）。
