## 用词规则

- 对外署名：`曼拾·社交媒体整合营销`
- 英文名：`MEANSPLUS`（连写，不写 MEANS PLUS）
- 法律/投标/公函：`上海曼拾文化传播有限公司`
- logo 中间是**五叶草**（象征幸运的传播），**禁止写蒲公英**
- 五心：感恩心 GRATITUDE·感恩并回馈 / 利他心 ALTRUISM·成人达己 / 创意心 CREATIVITY·创意破局 / 成长心 GROWTH·每日精进 / 成事心 IMPACT·结果说话；根茎＝积极乐观不放弃的恒心
- 三个可复用说法：择善而栖 / 和鸣而传 / 浴火新生（不用「浴火重生」，且避开含「卒」的字：淬、粹、翠）
