## 一、Skill 核心方法论

### 1.1 激活口令
ms-review-report、曼拾复盘

### 1.2 前置问询（执行任何复盘任务前必须完成）

1. 客户是否有指定模板？有→按客户结构走但用GRARI五模块做内容完整性校验；无→直接用GRARI+Part 1-4
2. 复盘目的？对客交付→走完整Part 1-4+视觉呈现；内部沉淀→重点Analysis+Insight
3. 报告读者是谁？客户品牌总监→趋势判断+策略方向；客户媒介执行→可操作参数+优化方法；内部团队→坦诚真实+经验萃取

### 1.3 GRARI五模块框架（OnePage是出品基准）

| 模块 | 权重 | 对应内容 |
|------|------|----------|
| G-Goal | 10% | 项目目的/预算分配/为什么这么设定/核心阶段可量化目标 |
| R-Result | 10% | 目标完成情况/差距对比/亮点和不足/KPI三层分级 |
| A-Analysis | 40% | 做得好的（亮点+三力拆解）+ 做得不好的（问题+三力拆解+客观原因）|
| R-Review | 10% | 最早目的是否完成+为什么（资源分配/执行/情景变动）|
| I-Insight | 30% | 做得好的萃取为可复用方法论 + 做的不好的提炼提升经验 |

### 1.4 策略型分析三段式（结论优先）

格式：一句话总结结论 → 两到三句话量化数据论证 → 一句话未来建议

示例：本次投放CPE优于行业基准60%。信息流CPE均值2.0，对比行业benchmark 6.15-9.27处于最低值以下；其中都市活力女性人群CPE仅0.7，互动成本全组最优。后续情感向内容应对该人群加大投放权重至40%。

### 1.5 结论写作五条红线

1. 数据与结论必须有因果关系——CPM反映系统出价竞争力非人群精准度，精准看CTR和CPC；进店UV大说明跑量好非引流高效，效率看进店率
2. 最小暴露负面原则——热度下降做外部归因，占比恒定此消彼长是自然现象
3. 每个数据都要有So-What——不写仅供参考的数据
4. 结论落点准确具体——追到成功机理层面
5. 五问法深挖根因——不止于"转化率低因为人群不对"，追问到内容卖点与流量错配

### 1.6 平台特有指标关系

小红书双列信息流是用户选择逻辑——CTR高说明封面标题打中精准人群→系统给更多曝光→CPM升高。CPM高+CTR高是人群精准的正向信号，不是成本问题。SEM卡位场景下CPC与SOV/C成反比。

### 1.7 整合的外部Skill方法

**data-report-review（五维审查）：**
- 检查模式：同事已写好报告，查缺补漏。输出三步——指出问题位置、给出修改后内容、标注修改理由。不是检查自己写的东西。
- 重写模式：报告大面积崩了直接按playbook框架重写。
- 五维：数据准确性、逻辑连贯性、结论质量、受众适配、表达质量
- 嵌入位置：执行流程第11步质检

**creative-performance-diagnoser2：**
- 动态诊断SOP：数据不全时主动切换分析框架，不强行输出薄报告
- 创造衍生指标：标准指标缺失时主动创造替代指标
- 关键词与业务结果挂钩
- 双重美德论：报告正文用亚里士多德美德论（如实标注数据缺失），单独review建议层用康德义务论作启发

**greko三层追问：**
- 书写规范层：苏格拉底层（数据口径和参照物对吗？）→ 柏拉图层（数据背后核心矛盾是什么？）→ 亚里士多德层（有反例吗？）
- 质检review链层：替代简单的"论证链是否完整"
- Prompt要求层：三段式写完后追加三层自问

### 1.8 吸黏拽模型（蓝氏SEM选词策略专用）

三层递进，只用于搜索投放分析，不是全报告框架：
- 吸（30%预算）：场景词+兴趣词+痛点词→关注CTR和种草力，不追求SOV
- 粘（品牌20%+品类40%=60%预算）：品牌/品类核心词→首位SOV→品牌词回搜率→TI流转率
- 拽（10%预算）：竞品比较词→前三位SOV→拦截竞品流量
