# 产品迭代决策框架：三个评估维度

## 框架概述

当品牌面临一个产品反馈时，该不该改、值不值得投入资源？本框架从三个主维度拆解判断标准，适用于消费品场景。

## 评估表格

### 1. 改善后转化用户的真实规模

| 子维度 | 消费品判断方式 | 关键数据来源 |
|---|---|---|
| **痛点用户基数及痛点行为数据验证** | 社媒讨论、电商退货、客服/评论提及率三个信号同时指向一个问题才算"有规模"，任何一个信号缺失都需要谨慎 | 小红书/微博搜索密度 + 天猫/京东售后数据 + 客服工单系统 |
| **痛点频率与持续度** | 同类型投诉是否连续出现 ≥ 2 个季度，而非季节性/批次性偶发；持续度不足的痛点权重减半 | 以季度为周期的客诉/差评趋势拉取 |
| **沉默用户偏差对冲** | 三个交叉信号：避雷类内容互动量是否远大于吐槽量、痛点是否初次使用即暴露、竞品是否已在这个方向上动过 | 社媒互动指标 + 产品使用场景分析 + 竞品对标跟踪 |

### 2. 组织可执行性

评估改动属于包装/说明书/配方/渠道哪个层面，对应工时和跨部门依赖的门槛要准；超过门槛（如8周）不在此框架评，单独立项。

| — | 消费品判断方式 | 关键数据来源 |
|---|---|---|
| | 耗时在合理周期内的改动纳入本框架评估；需大幅重构的产品迭代单独评估 | 研发/供应链/品控工时评估 |

### 3. 品牌战略相关性

| — | 消费品判断方式 | 关键数据来源 |
|---|---|---|
| | 这个问题卡住的是不是品牌当前阶段最核心要赢的用户场景；修复它对品牌心智的修复价值是否能清晰描述，不能用"用户体验更好了"笼统概括 | 品牌年度策略对齐 + 竞品在该场景的优势差距 |

## 综合判断逻辑

三个主维度各自独立打分：

1. **真实规模强 + 可执行性强 + 战略相关性强** → 果断执行，优先级最高
2. **真实规模强 + 可执行性强 + 战略相关性弱** → 可以作为运营优化推进，但不是品牌战役级别
3. **真实规模弱 + 可执行性强 + 战略相关性强** → 等规模信号更强后再动，现在不值得投入
4. **只有一个维度得分** → 先放着，持续观察
