# 品牌概览（报告开头三章）

## 项目信息
- 品牌：养生堂
- 行业：保健品/膳食补充剂
- 报告类型：品牌竞品研究咨询报告

## 写作规范

- 首句=独立判断结论（不能说「XX有几个特征」）
- 中间=具体数字+可验证事实
- 末句=这个判断对竞品意味着什么
- 禁止星号强调（**）、破折号列表体（- xxx - yyy）、填充词（本质上/整体而言/值得注意的是）
- 人群收入跨度不得超过2个档位（如5000-8000 ok，5000-50000 rejected）

- 所有表格用 Markdown 表格格式
- 数字必须标注来源或推算依据
- 不作排名、不排序、纯信息陈列

## 一、品牌概览

### 1.1 基础信息
表格：品牌全称/公司主体/创始人/联合创始人/总部/工厂/品牌定位/核心品类/品牌使命
- 来源：前置调研
- QA：基础信息≥8维度

### 1.2 品牌发展里程碑
时间线表格：时间|事件|意义，≥8个事件
- 来源：前置调研+深度稿件

### 1.3 规模判断
核心锚点+增速轨迹+规模区间+判断依据≥3条
- 来源：Step 6 本品五维扫描

## 二、产品与品类矩阵

### 2.1 核心品类
表格：品类/推出时间/产品形态/市场地位
- 来源：前置调研+电商数据
- QA：核心品类表≥4个品类且标注市场地位

### 2.2 定价带与客单价
表格：品类/价格区间/定位(入门/中端/高端)
- 来源：电商数据(天猫+京东)
- QA：定价带有具体数字

### 2.3 季节性品类结构
分析季节依赖+平滑策略+全品类消费日历覆盖度
- 来源：品类数据+行业趋势

## 三、渠道与供应链

### 3.1 渠道演变路径
表格：阶段/时间/核心渠道/特征，≥4个阶段
- 来源：前置调研+企业公开信息

### 3.2 供应链能力
表格：维度/详情 + 供应链评估(优势/风险/原料进口依赖度)
- 来源：企业公开信息+行业对标

## 输出要求
1. 直接输出品牌概览正文，从 ## 品牌概览 开始
2. 所有子节按上述格式输出，表格用 Markdown 表格
3. 缺失数据标注 [待补充]，不编造
4. 规模判断不给单一数字，给锚点数字+侧面证据+范围区间

请直接输出品牌概览内容。
