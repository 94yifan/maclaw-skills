## B. 规避方案（写进 memory 的铁律）

1. **样本时效门槛（对应 A5，今日最高优先级，新）**：任何效果类判断，先确认样本的可观察时间。可观察 <1h 只能报事实（发了什么、多少互动），不能下结论（自嗨/没跑起来/效果好）。落地后可拦截 SC 今日 2 条错误结论
2. **MEMORY 写入方式改造（对应 A2，升级自 9/15 的「归档」）**：不只是切分文件，是收敛写入量——缝合条目保留判断主干 + 最少证据句，详细推导留在 `dreaming-YYYY-MM-DD.md`（两份文件本来就在同一天生成，主干进 MEMORY、细节进 dreaming，天然分层）。目标：单日 MEMORY 增量 ≤5KB
3. **缝合条目数由知识量决定，不硬凑 5 条（新）**：SC 今日只有 4 条行业信号，SP 硬凑第 5 条会产生与昨日同源的重复条目。规则改为主干判断不足 5 条就写 3-4 条，同源判断合并成承接位
4. **挂起项执行纪律（沿用 9/14）**：所有需主 session/逸凡执行的待办，显式标注「仅主 session 执行，cron run 内禁止尝试」
5. **外部系统状态口径（沿用 9/15）**：引用分身状态区分「本次成功」与「根因已除」，写「今日 ok（根因未除，高危窗口 X）」
6. **跨日一致性检查（沿用 9/15）**：缝合前对同一产品/活动的跨日数字做比对，不一致且无法从 raw 确认的标「待验证」（库迪 Duo 口味数 4 vs 3 今日第 3 天挂起）
7. **去重比结论主干（对应 A6，新）**：写缝合前扫最近 2-3 天缝合条目的结论主干，同一主干不重开条目
