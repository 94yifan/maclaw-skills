## 引言: 复盘的双重价值

复盘不为应付客户, 更不为走完流程。

复盘有两个核心目的:

对内: 经验沉淀。你踩过的坑、发现的规律、验证的方法, 如果不写下来, 下一个项目还会再踩一次。好的复盘能让一个项目的经验变成整个团队的能力。

对外: 专业交付。客户花了钱, 需要看到钱花在哪、花得怎么样、下次怎么花更好。一份好的复盘报告能让客户信任你的专业判断, 愿意把下一期的预算也交给你。

复盘的难点不在收集数据, 而在从数据中提取洞察。数据谁都能拉, 但能从数据里看出为什么好、为什么不好、下次怎么做的, 才是专业。

这份手册帮你做到这一点。

## 第一部分: 通用基础

无论你是哪个角色, 以下基础规则必须掌握。

### 1.1 数据准备三确认

在开始任何分析之前, 先确认三件事:

确认1: 数据口径
问自己: 这个数据里的流量是总流量还是广告流? 自然流有没有混进来? 信息流包含视频内流吗?
如果数据口径不一, 任何对比都没有意义。比如你用聚光的广告流CPM去对比蒲公英的总流量CPM, 得出的结论是错的。

确认2: 数据周期
问自己: 这个数据是汇总值还是按天的? 投放开始日期和数据回传日期一致吗? 有没有数据延迟?
比如淘宝联盟数据可能比投放晚回传3-7天, 如果你用不同周期的数据做对比, 会得出错误趋势。

确认3: 数据粒度
问自己: 这个数据能下钻到什么程度? 能拆到单篇笔记吗? 能拆到单个人群包吗? 能拆到单个关键词吗?
如果粒度不够, 你只能看到表现好不好, 但看不到为什么好。粒度不够的分析就是"知道有问题但不知道问题在哪"。

### 1.2 数据分析方法

三种基本分析方法, 每种都要会用:

方法1: 数据对比
一个数据本身没有意义, 对比之后才有意义。四种对比参照物:
- 对比大盘: 和行业benchmark比, 判断是高于还是低于平均水平
- 对比竞品: 和竞品同期数据比, 判断相对竞争力
- 对比本品历史: 和上一期/去年同期比, 判断是进步还是退步
- 对比内部: 拆分不同内容方向/人群包/词包, 看内部哪个好哪个差

好的分析至少用两种对比参照物交叉验证。只用一种对比容易得出片面结论。

方法2: 异动分析
先找到异常, 再定位原因。步骤:
1. 对比找出异常指标(偏离正常范围)
2. 下钻到能下钻的最细粒度(笔记/人群包/关键词/计划)
3. 定位到具体原因

注意: 异常不一定是问题。高CTR+高CPM是正向异常(人群精准), 低CTR+低CPM才是负向异常(泛流量)。

方法3: 趋势分析
看指标的变化趋势, 不是只看最终值。by-day趋势图能看出来:
- 是持续异常还是某几天异常(某天异常可能是偶然事件)
- 异常是否与投放动作相关(放量后指标变好还是变差)
- 趋势是否与外部事件相关(大促/竞品动作/热搜事件)

### 1.3 结论写作原则

每条你写进报告的结论, 必须同时满足以下五条。缺一条就是不合格的结论。

原则1: 数据与结论必须有因果关系
你写的结论必须能被你的数据直接证明, 不能是联想或推测。

常见错误对照表:
- "CPM低, 说明人群精准" -- 错误。CPM低只能说明系统竞价竞争力低。人群精准看CTR和CPC。
- "进店UV大, 说明引流高效" -- 错误。进店UV大只能说明跑量好。引流效率看进店率(进店UV/曝光)。
- "进店率和转化率高于大盘, 说明GMV更高" -- 错误。进店率和转化率高只能说明性价比高。GMV取决于钱能不能花够花完。
- "引流率和转化率高, 说明市场竞争力和心智占有率高" -- 错误。引流率和转化率高表明点击人群精准+电商价格机制符合需求, 不等于心智占有率。
- 如果要论证与电商节奏正相关, 必须放大盘搜索趋势做参照。

做结论前自问: 我这个结论的因果链条能倒推回去吗? 如果不能, 说明因果关系不成立。

原则2: 最小暴露负面原则
不是所有下降都是问题。判断之前先想:
- 占比恒定时, A升B降是自然现象(饼就那么大), 不用当问题提
- 热度下降优先做外部归因: 大盘是否在降? 是否有季节性因素? 竞品是否有大动作?
- 不要一看到下降就说执行出了问题

原则3: 每个数据都要有 So-What
不要只陈列数据。数据是什么不重要, 数据意味着什么才重要。

错误写法: "本期CPE为2.3元, 较上期下降15%"
正确写法: "本期CPE降至2.3元(较上期-15%), 互动效率提升主要来自笔记封面优化后CTR上升带来的互动量放大效应。建议将高CTR封面模板作为后续内容制作的基准样式。"

如果数据下降但你不知道为什么下降, 追问: 提升/下降的原因是什么? 做对了/做错了什么?
如果答案是"笔记铺量+投流放量", 这不够 -- 所有代理商都能做这件事。追问: 曼拾做对了什么独特的动作?

原则4: 结论落点准确具体
用五问法深挖根因, 直到不能再追问为止。

示例:
初始观察: 本期进店率提升了
一问: 为什么进店率提升? -- 因为信息流CTR提升
二问: 为什么信息流CTR提升? -- 因为封面点击率高
三问: 为什么封面点击率高? -- 因为使用了场景化封面(非产品图)
四问: 为什么场景化封面有效? -- 因为场景图降低了用户的认知门槛, 从"这是什么东西"变成"这跟我有什么关系"
五问: 为什么这个品类需要降低认知门槛? -- 因为这个品类属于高认知门槛品类, 用户需要场景带入才能理解产品价值

最终的结论不是"进店率提升了", 而是"高认知门槛品类通过场景化封面降低用户认知门槛, 使进店率提升"。

自检: 如果你的结论可以套用在另一个项目上, 说明结论不够具体。

原则5: 下一步动作必须回溯到前文
你的每一条建议都必须能在分析部分找到依据。不能凭空说"建议加大投放"。
建议的结构: 因为分析发现了X, 所以建议做Y, 预期达到Z效果。

### 1.4 呈现原则

写好内容只是第一步, 呈现方式决定客户能不能看懂。

原则1: 最大程度可视化
字数越少越好。能用一个图表说清楚的事, 不要用一段文字。逻辑越清晰越好, 客户不需要猜你想表达什么。

原则2: 可视化图表标记重点
- 对比类图表: 格式一致, 降序排列
- 关键数字: highlight(加粗/变色/放大)
- 四象限图: XY轴明确标注, 每个象限写总结标签

原则3: PPT中各模块内容加总 = 标题
标题应该是一个结论, 不是话题描述。
错误标题: "投放效果分析"
正确标题: "精准人群圈选驱动CTR提升37%, 进店率超行业2倍"

原则4: 使用四象限图分析
当你有两个关键维度需要同时分析时, 优先用四象限:
- 人群四象限: 高/低消耗 x 高/低点击或转化
- 笔记四象限: XY轴匹配客户目标(回搜/进店成本/转化率/CTR/TI种草)
- 行业四象限: 高/低阅读 x 高/低搜索

### 1.5 策略型分析三段式格式

凡是策略型结论(非单纯数据陈列), 使用以下结构:

第一句: 一句话总结结论 -- 最核心的判断, 放在最前面
第二到四句: 通过量化数据论证结论 -- 用了什么对比参照物, 什么数据支撑, 从最重要到次要排列
最后一句: 未来建议和方向 -- 基于此结论的下一步做什么

这个格式的核心逻辑是: 让客户第一眼就知道你想说什么, 然后用数据证明你说的对, 最后告诉他因为这个发现接下来该怎么做。

### 1.6 受众适配

**在开始写报告之前, 先确认这份报告是写给谁看的。受众不一样, 写法就不一样。**

从本版手册开始, 受众适配正式列入复盘前置问询的必问项。确认后, 报告全篇的术语深度、数据粒度、结论颗粒度、叙事方式均据此校准。

三种典型受众及适配规则:

**受众A: 客户品牌总监/CMO**
- 你需要回答的是战略问题: 我们做对了什么策略决策? 这个策略能不能复用到下一个产品/下一场战役?
- 术语: 可正常使用营销专业术语, 不需要解释基本概念
- 数据: 只保留关键指标, 不逐条笔记展开。用1-2个数字说明趋势, 不用大篇幅的数据陈列
- 结论: 聚焦策略层的判断 -- "场景化内容是这个品类最高效的种草方式"比"第3篇笔记CPM 28元"更重要
- 叙事: 金字塔结构, 先给结论再给证明。不要让总监在报告里找"你想说什么"
- 篇幅: 精简, 每个核心观点控制在3页以内

**受众B: 客户媒介执行/投放负责人**
- 你需要回答的是战术问题: 哪个方向好, 哪个方向不好, 下次具体怎么调
- 术语: 专业术语需简要解释或附术语表。如果客户是媒介执行但不一定熟悉灵犀体系, 解释AIPS和TI
- 数据: 需要详细到可操作粒度 -- 具体到笔记方向、人群包、关键词、计划层级的拆解
- 结论: 聚焦操作层建议 -- "场景化内容笔记的封面用产品场景图(人物+场景+产品), CTR均值3.5%"
- 叙事: 分类分层展开, 每类数据单独讲清楚。媒介执行拿到报告后能直接照着改下一期的投放设置
- 篇幅: 可以较长, 确保每条操作建议都可直接落地

**受众C: 曼拾内部团队**
- 你需要完整复现整个分析过程, 并萃取可复用/可改进的方法
- 术语: 无障碍, 可用曼拾内部用语
- 数据: 最细粒度, 包含所有原始数据和计算过程
- 结论: 完整分析 + 方法论萃取 + 失败经验记录。不做客户汇报叙事包装, 直给问题和教训
- 篇幅: 不限

**多读者层处理:**
如果同一份报告有多个读者, 以最高决策层为正文受众。执行层信息以附录或标注形式补充。
比如: 品牌总监过目 + 媒介执行落地 → 正文按总监标准写, 媒介执行需要的详细数据放在附录"执行参考数据"中。

### 1.7 三层追问内置法

**三层追问是 greko 方法论在复盘场景的落地。这套方法帮你把"数据是什么"升级为"数据意味着什么"。**

三条规则, 操作简单:

**规则1: 写每条结论时过三层**

苏格拉底层(数据真实性):
- 这个数据的计算口径确认过没有? 有没有口径陷阱?
- 对比参照物选对了吗? 换了参照物结论还变吗?
- 数据的表面含义之外, 有没有被数据表象误导?

常见的被数据表象误导案例:
- "CPM降低了, 所以成本优化了" -- 表层。CPM降低可能是因为流量变泛了(低CTR+低CPM), 是负向信号。
- "搜索指数上升了, 所以种草有效" -- 表层。需要排除自然搜索增长和外部事件(明星同款/热搜话题)。
- "转化率提升了, 所以内容优化到位了" -- 表层。可能只是因为人群精准了, 不是内容本身的功劳。

柏拉图层(本质矛盾):
- 这组数据放在一起反映的核心矛盾是什么?
- 如果去掉所有数字, 这个问题的本质是什么?
- 数据背后代表的东西是什么?

常见的数据组合及其本质矛盾:
- 高曝光+低互动 → 内容触达了人但没有打动人。本质: 内容与受众需求不匹配。
- 高互动+低转化 → 内容好但购买动机弱。本质: 种草深度够但转化路径断裂(价格/渠道/时机)。
- 搜索指数升+进店率降 → 品牌被记住了但购买决策在别处发生了。本质: 电商落地页或价格机制有问题。

亚里士多德层(逻辑验证):
- 这个结论有没有反例? 有哪个指标跟这个结论方向相反?
- 换一个时间周期(比如只看前两周 vs 后两周), 这个结论还成立吗?
- 换一个人群包(比如只看女性 vs 只看男性), 这个结论还成立吗?

常见逻辑漏洞:
- "本期CPE较上期优化25%" -- 拆分到不同笔记方向后, 是全面优化还是某个方向拉动的均值?
- "搜索SOV达到45%, 心智占位良好" -- 拆分到品牌词和品类词后, 品牌词SOV可能60%但品类词只有15%。

**规则2: 替别人检查报告时, 用三层追问替代"论证链是否完整"**

接到同事的复盘报告做质量检查时, 问三个问题代替模糊的"论证链完整吗":

1. 苏格拉底层: 这个结论依赖的数据前提是否成立? 数据的计算口径、采集周期、对比参照物可靠吗?
2. 柏拉图层: 数据的本质矛盾是否被识别出来了? 同事的结论是停留在描述数据, 还是触及了数据背后的规律?
3. 亚里士多德层: 反例是否被排除了? 有没有指标跟结论方向相反? 拆分不同子维度后结论还成立吗?

**规则3: 写完三段式后做无声自检**

写完三段式策略分析后, 不是把三个问题的答案写进报告, 而是在心里过一遍:
- 苏格拉底自问: 数据口径对吗? 参照物可靠吗? 有没有被表象误导?
- 柏拉图自问: 本质矛盾是什么? 去掉数字后问题的本质是什么?
- 亚里士多德自问: 有反例吗? 换时间或人群, 结论还成立吗?

这三个问题不写进报告。但它们是你结论靠谱的最后一道防线。如果三个问题中任何一个答不上来, 那条结论需要回去重新写。

### 1.8 表达质量规范

**内容再深刻, 表达混乱, 客户的信任会打折扣。**

**书写时三条强制规则:**

规则1: 每段一个中心论点
一个段落只讲一件事。段落第一句是中心论点, 后文展开论证。
不要把多个论点挤在一个段落里。

反例(违反): 
"本期CPE 1.2元较上期下降15%, CTR提升至3.5%, 搜索指数增长320%, 整体投放效果超出预期。"
问题: 四件事挤在一段, 读者不知道核心是什么。

正例:
"本期互动效率显著提升。CPE降至1.2元(较上期-15%), 根因在场景化封面驱动CTR从2.1%提升至3.5%, 互动量随之放大。
搜索心智同步建立。搜索指数较投前提升320%, 品牌词SOV达65%, 表明场景化内容不仅驱动了浅层互动, 也有效建立了品牌搜索习惯。"

规则2: 段落间有逻辑衔接
上一段的落点和下一段的起点有承接关系。三种衔接方式:
- 因果衔接: "以上数据解释了互动效率的提升, 接下来看这些互动是否转化为了生意结果。"
- 递进衔接: "场景化内容解决了触达效率, 但触达之后的转化需要价格和渠道的配合。"
- 转折衔接: "搜索指数整体上升, 但拆分品类词和品牌词后发现, 品类词的心智建设明显滞后。"

如果两个段落之间没有逻辑关系, 重新组织内容顺序。

规则3: 不用模糊措辞
你不需要在每一句前面加"应该""大概""可能""看起来""似乎""好像""差不多""也许"。

有精确数据就用精确数据: "CPE从2.3元降至1.95元, 优化幅度15%"
没有精确数据就标注: "该维度缺少精确数据, 不在此处做定量判断。建议补充X数据后做二次分析。"
不在两者之间打太极。

**检查时逐项对照四维度:**

接到同事报告检查表达质量(或用 data-report-review 自检报告)时, 按以下四维逐项扫描:

维度1: 表达清晰度
- 每个句子有明确的主谓宾吗?
- 是否有连续3个以上长句(超过40字)? 有就拆短。
- 是否有专业术语未解释(取决于受众)? 有就加解释。
- 是否有指代不明("这个""那个""其")? 有就改成具体名词。

维度2: 段落焦点
- 每个段落有明确的中心句吗?
- 段落内其他句子都在支撑中心句吗?
- 是否有段落包含了互不相关的两个观点?
- 段落长度合理吗(不超过5-6行)?

维度3: 过渡自然度
- 段落间是否存在逻辑跳跃?
- 关键结论的转场是否有衔接句?
- 从一个模块过渡到另一个模块是否有总括或预告?

维度4: 格式一致性
- 同层级标题的格式统一吗?
- 数字的呈现格式一致吗(百分比统一到小数点几位? 金额单位统一)?
- 表格格式一致吗(对齐方式/表头样式)?
- 标注和脚注的格式统一吗?

### 1.9 动态诊断: 数据不全时的正确做法

**核心原则: 数据不全时不强行输出薄报告。主动切换分析框架, 并在报告中明确标注数据的局限性。**

#### 1.9.1 数据可用性评级

数据拉回来后, 先评级再动手:

A级(完整): 六大分析流所需数据齐全。用标准 GRARI 框架正常执行。

B级(部分缺失): 某个或某几个分析流缺少关键数据。对缺失维度执行 fallback, 对可分析维度正常执行。

C级(严重缺失): 多个分析流缺少关键数据。不强行做 GRARI, 基于已有数据创建精简框架。报告中明确标注"受限于数据可用性, 本次分析侧重X维度, Y和Z维度建议补充数据后做二次分析"。

D级(仅最基础数据): 基本只有消耗和曝光数据。做趋势分析和结构分析, 不做因果归因。明确告知客户数据完整度不足, 结论置信度相应降级。

#### 1.9.2 Fallback 路径速查

**内容策略维度:**
- 缺笔记维度互动/转化 → 仅分析内容方向分布和封面/标题结构, 做定性判断不给定量的效果排序
- 缺竞品内容数据 → 用行业大盘内容趋势做参照, 标注"缺少竞品参照, 判断基于行业均值"
- 缺评论区数据 → 从笔记标题和内容文本提取关键词做内容方向聚类, 标注"缺少用户反馈验证"

**人群分析维度:**
- 缺人群包维度数据 → 仅做整体画像分析, 不做分人群包效果对比, 标注"人群包颗粒度缺失, 精细化优化建议暂不可提供"
- 缺P/TI人群对比 → 仅做TI人群画像, 用行业通用人群画像做粗对比, 标注"缺乏本品牌P人群基线, 差异分析降级为参考性判断"
- 缺灵犀AIPS → 用投放前后搜索指数变化间接推断人群资产变化, 标注"AIPS数据缺失, 人群资产判断基于间接指标"

**竞价策略维度:**
- 缺计划/单元层级数据 → 仅分析场域级别的效率差异, 不做计划间赛马对比, 标注"计划颗粒度缺失, 无法识别最优/最差计划特征"
- 缺人群包消耗和效果 → 用整体人群画像和内容偏好匹配度做间接判断, 标注"人群包数据缺失, 人群圈选效果判断为推测性结论"
- 缺分阶段投放数据 → 全周期做整体分析, 不做测试期/放量期/转化期的阶段性判断, 标注"缺少时段拆解, 投放节奏优化建议暂不可提供"

**搜索维度:**
- 缺关键词维度数据 → 仅做整体搜索趋势分析, 不做关键词效率排序, 标注"关键词颗粒度缺失, 词包优化建议降级"
- 缺直客全品牌SOV → 用聚光后台数据做内部趋势对比, 不做绝对值行业对标, 标注"SOV数据为代子账号维度, 非品牌全维度"

**生意结果维度:**
- 缺GMV/ROI → 用灵犀AIPS增长和搜索指数变化间接论证效果, 标注"缺少生意结果验证, 效果判断基于品牌指标而非生意指标"
- 缺淘宝联盟后链路 → 用蒲公英组件点击量趋势做电商意向间接判断, 标注"缺少后链路验证, 电商转化能力无法评估"

#### 1.9.3 衍生指标创造

**标准指标缺失时, 主动创造替代指标。不把"数据没有"当成"不能分析"。**

创造步骤:
1. 确认标准指标因什么数据缺失而无法计算
2. 用已有数据构造一个与标准指标正相关的替代指标
3. 标注"此为衍生指标, 局限性为X"

已验证可用的衍生指标:

| 标准指标 | 缺失数据 | 衍生替代 | 计算公式 | 注意 |
|---------|---------|---------|---------|------|
| ROI | GMV | RPV(单次观看价值) | 总成交金额 / 总观看次数 | 不含自然成交和复购 |
| ROI | GMV | 估计ROI | (进店转化率 x 客单价估算) / CPUV | 客单价估算有误差 |
| 回搜率 | 搜索行为日志 | 搜索指数变化率 | (投后搜索指数-投前)/投前 | 不排除自然增长 |
| 人群渗透率 | 全品类人群基数 | TI增速 | 投放周期内TI新增/周数 | 不反映相对竞争位置 |
| 内容渗透率 | 类目总阅读量 | 笔记阅读增量率 | (投后-投前)阅读量/投前 | 不反映在类目份额 |

衍生指标铁律:
- 每个衍生指标必须在报告中标注"衍生指标"和局限性
- 衍生指标的结论强度降一级: "X呈现向好趋势"而非"X效果优秀"
- 一个方向的判断至少用两个衍生指标交叉验证

### 1.10 data-report-review 的正确用法

**data-report-review 技能有两个模式, 场景不同用法不同。用错模式的代价: 花了时间做了错误的操作。**

#### 检查模式: 同事已写好报告, 你帮检查

适用场景: 同事已经写完一版报告, 把文件给你做质量检查。你不是从零写, 而是查缺补漏。

三步输出:

第一步: 指出具体问题位置
定位到具体段落/数据/图表。标注维度和一句话问题描述。
示例: "[位置: A模块 第3段第2句] [维度: 因果关系] CPM低不能直接说明人群精准。"

第二步: 给出修改后的内容
不是"建议改成XX", 是直接把替换后的完整段落写出来。同事可以直接复制粘贴使用。
示例: "替换为: 在人群精准度上, 本期CTR达3.5%(行业2.0%), 且高CTR伴随高CPM(较行业+15%), 说明封面和标题有效打中精准人群。在双列信息流用户选择逻辑下, 精准人群更高的CTR使系统分配了更多曝光, CPM随之上升。"

第三步: 标注修改理由
每条修改后加一句理由: 为什么原写法不对, 新写法为什么更对。
示例: "理由: 原写法犯了因果倒置(红线1)。在小红书双列信息流中, CPM受CTR正向影响 -- 精准人群CTR更高, CPM反而更高。改为CTR+CPM联合判断, 逻辑更严谨。"

#### 重写模式: 同事报告大面积崩坏

触发条件(满足任一即触发):
- 结构混乱: GRARI五模块不全或顺序错乱, 客户读不出完整故事
- 逻辑断裂: 多个关键结论因果不成立, 需要修改的量超过全文50%
- 数据错误过多: 数据口径/计算/参照物错误超过全文30%

不修缮原报告。以原报告提供的原始数据为基础, 按 GRARI 框架从头重建。

重写流程:
1. 通读原报告, 提取所有可用原始数据(剔除错误数据)
2. 与各角色同事确认原始数据准确性
3. 按 OnePage GRARI 标准流程从零构建
4. 原报告遗漏的维度按 fallback 路径处理
5. 重写完成后, 执行一遍自写报告的质量检查
6. 交付时标注: "报告基于同事原版数据重新构建, 结构调整和结论优化由[执行人]完成"

判断技巧: 不确定是否触发重写时, 把报告每个模块的核心结论读一遍。如果超过一半的结论经不起五条红线检查, 触发重写。

#### 不要混淆: 自己写报告不需要单独走检查模式

你写报告的过程中, 每写一条结论就过一遍红线+三层追问。写完就是 review 完了。不需要写完后再把自己的报告丢给 data-report-review, 那是在重复你已经做过的事。

## 第二部分: 策略同事篇

### 2.1 职责定位

你是复盘报告的总导演。你的核心任务是:

1. 搭建报告的总体叙事框架
2. 设定 KPI 层级(P0/P1/P2), 并据此判断项目成败
3. 将各角色的分析结论串联成一个完整的故事
4. 执行三力拆解, 把成败归因到可操作的层面
5. 萃取可复用的方法论和改进经验
6. 确保每条结论都通过五条红线检验
7. 确保每条策略型结论内置三层追问
8. 确保报告正文遵守亚里士多德美德论(如实), 并在 review 层用康德义务论给出假设验证方向

你不对具体数据取数负责(那是PM/媒介/竞价的工作), 但你对数据解读的质量负最终责任。一份报告里如果出现了错误的因果归因, 首先是你策略同事的问题。

### 2.2 关注数据

以下数据你不需要自己取, 但必须理解其含义并能在结论中使用:

KPI 目标 vs 实际:
- 所有 P0/P1/P2 指标的达成情况
- 重点关注 P0 北极星指标: 这是判断项目成败的核心依据
- P1 过程指标帮你理解"为什么P0达成/未达成"
- P2 参考指标是辅助证据, 不要单独用P2指标下重要结论

行业和市场数据:
- 大盘趋势(从灵犀洞察和直客数据获取)
- 竞品投放规模和效果(从千瓜和灵犀获取)
- 行业 benchmark(从直客获取)
- 你的角色是把项目数据放到更大的市场语境中解读

三力拆解需要的数据:
- 策略力: 目标设定逻辑、KFS分配比例、人群策略、内容策略的原始方案 -- 对照实际执行看偏差
- 执行力: 各环节的交付质量和时效 -- 从PM和媒介获取
- 管理力: 跨部门协作的流畅度、反馈时效、异常响应速度 -- 从你自己的项目管理记录中提取
- 客观原因: 预算变动、平台政策变化、竞品大动作、市场环境变化 -- 主动收集

### 2.3 如何写好你的板块

你负责的板块是报告的灵魂。写得好不好, 直接决定报告的档次。

板块一: Goal 目标回顾(G模块, 占10%)

要点: 分清目的和目标。

目的是"为什么做这件事", 目标是"做到什么程度"。

错误写法:
"本次投放目标为GMV 500万, ROI 2.0。"
这是目标, 不是目的。

正确写法:
"本次投放目的是通过精准种草建立品牌在新锐白领人群中的认知, 为618大促蓄水。
基于此目的, 我们设定了三个层次的目标: P0为TI人群新增50万(蓄水效果的核心度量);
P1为回搜率0.8%(种草深度的过程验证); P2为CPE 1.5元(互动效率参考)。
预算分配KOL 40%/Feeds 35%/Search 25%, 其中Search占比高于常规水平,
原因是该品类搜索心智尚未建立, 需要通过搜索卡位培养用户的主动搜索习惯。"

好的目标回顾回答了三个问题:
1. 为什么要这么做(目的)
2. 为什么目标是这个数(设定逻辑)
3. 为什么资源这样分配(策略起点)

板块二: Analysis 分析原因(A模块, 占40%)

这是报告的核心, 你的主场。拆分为亮点分析和问题分析。

亮点分析的要领:
每个亮点必须回答: 做了什么, 为什么好, 做对了什么, 能不能复制。

不要写成:
"亮点1: CPE低于预期。实际CPE 1.2元, 目标1.5元, 达成率125%。"

要写成:
"亮点1: 场景化内容策略使互动效率超出预期25%。
我们以用户真实使用场景替代产品功能罗列, 3篇场景笔记的平均CTR为4.7%(常规笔记2.1%),
驱动CPE降至1.2元(目标1.5元)。三力拆解: 策略上, 我们在选题阶段识别到该品类的高认知门槛特征,
主动选择场景化降低理解成本; 执行上, PM筛选了有生活场景拍摄能力的博主, 而非纯产品测评类博主;
管理上, 我们在审稿环节引入了场景还原度检查点, 确保每篇笔记的场景感达标。
该方法论可复用至高认知门槛品类的种草内容制作。"

问题分析的要领:
每个问题必须回答: 发生了什么, 和预期差距多大, 哪个环节出问题, 下次怎么避免。

不要写成:
"问题1: 搜索SOV未达标。实际35%, 目标50%。"
这只是描述现象, 不是分析。

要写成:
"问题1: 搜索SOV仅达35%(目标50%), 根因在搜索预算分配滞后。
投放前3周搜索预算仅执行了计划的40%, 而竞品同期加大了搜索投放(千瓜数据显示竞品A搜索笔记量环比+60%)。
三力拆解: 策略上, 搜索预算的阶段性释放节奏偏保守, 没有在前两周快速抢占SOV;
执行上, 竞价同事反馈搜索词包的否定词设置过于激进, 导致部分长尾词无法竞价;
管理上, 预算调整决策链条过长, 从发现SOV不足到追加预算用了10天。
客观原因: 竞品同期加大了搜索投放力度, 推高了搜索竞价成本。
后续建议: 搜索预算前置于投放开局阶段, 前两周集中释放50%以上的搜索预算快速卡位;
建立SOV周度监控机制, 当SOV低于目标值80%时自动触发预算追加讨论。"

三力拆解实操指南:

策略力归因: 问自己"策略上这个决策是对的还是错的"。好的判断来自对市场/用户/竞品的准确理解, 坏的判断来自信息不足或假设错误。

执行力归因: 问自己"执行中哪个具体动作导致了成败"。不是笼统的"执行不到位", 而是"达人选号标准中的场景拍摄能力权重不够, 导致入选达人不适合场景化内容方向"。

管理力归因: 问自己"流程上哪个环节出了问题"。常见的管理力问题包括: 审稿反馈周期过长、跨部门信息不对称、异常预警机制缺失、预算审批流程僵化。

客观原因: 问自己"如果外部环境不同, 结果会变吗"。客观原因不能作为推卸责任的借口, 但必须如实记录。它同时也帮助判断方法论的可复用性: 如果成功高度依赖客观原因, 说明方法论的可复用性有限。

板块三: Review 目的回顾(R模块, 占10%)

回到最初的目的, 判断是否完成。

三个维度解释为什么:
1. 资源分配: 预算够不够? 人力和时间是否匹配目标?
2. 执行: 团队有没有把该做的事做到位?
3. 情景变动: 外部环境有没有发生变化? 如果有, 对结果产生了什么影响?

这一部分的目的是让你跳出KPI数字, 从更高的视角审视项目。有时候KPI超预期完成但目的没有达到(比如GMV达标但人群资产没有建立, 下一期生意不可持续), 有时候KPI没完成但目的部分达成(比如虽然没有达到GMV目标, 但建立了一个可复用的内容模型)。

板块四: Insight 规律总结(I模块, 占30%)

这是最有价值的部分, 也是最容易被敷衍的部分。

可复用方法论: 从成功的部分萃取出来的规律, 必须包含三个要素:
1. 什么方法(具体的操作步骤, 不是抽象概念)
2. 什么条件下适用(不能适用于所有情况的方法论才是真的方法论)
3. 预期什么效果(可量化的参考值)

示例:
"方法: 高认知门槛品类的内容冷启动策略。
适用条件: 产品功能复杂、用户需要教育才能理解价值的品类。
操作步骤: (1)先以场景化笔记建立认知(占比60%), 封面用真实使用场景而非产品图;
(2)再以KOL测评笔记建立信任(占比30%), 内容重点在效果对比而非功能罗列;
(3)最后以UGC晒单笔记完成转化闭环(占比10%)。
预期效果: CTR可提升至行业均值的1.5倍以上, 进店率提升50%+。"

改进经验: 从失败的部分提炼出来的教训, 必须包含:
1. 什么问题
2. 根因是什么(五问法)
3. 怎么改进(具体措施, 不是"下次注意")

### 2.4 常见错误

错误1: 目的和目标混淆
"本次投放的目的是实现ROI 2.0" -- ROI 2.0是目标, 不是目的。目的是"为什么投", 目标是"投到什么程度"。

错误2: 数据陈列代替分析
"本期CPM 35元, CTR 2.1%, CPC 1.6元" -- 这串数字客户自己也能看。你要说的是这些数字组合在一起说明了什么。

错误3: 因果关系不成立
"CPM降低说明我们找到了更精准的人群" -- 如前所述, CPM和人群精准没有因果关系。

错误4: 方法论太虚
"建议后续加强内容质量" -- 什么叫加强? 怎么加强? 谁来加强? 没有操作性的建议等于没建议。

错误5: 没有So-What
"本期搜索热度环比提升23%" -- 然后呢? 这个提升是因为你做了什么还是外部趋势? 对生意有什么影响?

错误6: 问题分析避重就轻
所有问题都归因于"预算不够"或"大盘不好"。偶尔确实如此, 但如果每个项目都这样归因, 说明你没有认真找内部原因。

错误7: 不区分受众写报告
给品牌总监写一页一页的笔记拆解, 给媒介执行写抽象的策略方法论。受众错了, 报告白写了。

错误8: 数据不全时强行输出薄报告
某个维度数据不全, 就把能写的部分凑成一份报告交差。正确做法: 标注数据局限, 给出 fallback 分析框架, 明确告知哪些结论是降级后的推断。

错误9: 不区分正文和 review 层
把"如果补充数据, 可能存在XX假设"写进报告正文。正文是被客户看到的, 只放已经验证的结论。假设性的优化方向放在 review 层, 是内部策略团队看的。

### 2.5 自查清单

在每个复盘报告交付前, 策略同事必须逐条自检:

[ ] P0/P1/P2 指标层级划分是否合理? 每个指标的定位是否清晰?
[ ] 受众类型是否已在写报告前确认? 术语/粒度/叙事是否匹配受众?
[ ] 每条分析结论是否数据与结论具有因果关系?
[ ] 每个数据陈列是否都有 So-What?
[ ] 每个问题是否用五问法深挖了根因?
[ ] 每条策略型结论写完后是否在内心过了三层追问(苏格拉底/柏拉图/亚里士多德)?
[ ] 三力拆解是否覆盖了策略力/执行力/管理力+客观原因?
[ ] 亮点的方法论是否包含适用条件?
[ ] 问题的改进建议是否具体可执行?
[ ] 下一步动作是否回溯到了前文分析发现?
[ ] 报告正文是否如实标注了每个数据维度的置信度(不缺数据→肯定语气, 缺数据→降级标注)?
[ ] 缺失数据维度是否在报告中明确列出, 并说明影响哪些分析?
[ ] review层建议是否独立于正文, 标注了"[review层建议]", 且针对内部策略团队?
[ ] 报告中是否每段只有一个中心论点?
[ ] 段落间是否有逻辑衔接(因果/递进/转折)?
[ ] 是否有模糊措辞(应该/大概/可能/看起来/似乎/好像/差不多/也许)?
[ ] 是否有AI化表达(emoji/装饰引号/装饰破折号)?
[ ] 是否最小暴露了负面(热度下降做外部归因, 占比恒定的此消彼长不当问题)?
[ ] 如果数据有缺失, 是否执行了 fallback 路径, 创建了衍生指标并标注了局限性?

## 第三部分: PM同事篇

### 3.1 职责定位

你是内容策略的负责人。你的核心任务是:

1. 管理并分析所有达人/笔记的数据
2. 拆解内容策略的执行效果
3. 从内容维度回答"什么内容有效, 为什么有效"
4. 分析竞品的内容策略和效果
5. 从评论区/UGC中提取用户真实反馈
6. 为策略同事的内容分析板块提供数据和分析初稿

你的工作成果直接决定了报告中"内容策略分析"部分的质量。你不是数据搬运工 -- 你拉出蒲公英投后数据后, 要自己先分析一遍, 而不是把原始数据丢给策略同事。

### 3.2 关注数据

你的主场数据来自蒲公英和商业内容中心。

达人/笔记基础数据:
- 笔记曝光量、阅读量、互动量(点赞/收藏/评论/转发)、组件点击量
- 按笔记方向(产品测评/场景种草/教程攻略/开箱体验等)分类汇总
- 按博主量级(KOL/KOC/素人)分类汇总
- 按内容形式(图文/视频)分类汇总

需要你手动分类的数据:
- 笔记内容方向: 每篇笔记的核心内容角度是什么? 不是看博主标签, 而是看内容本身在说什么。
  示例分类: 产品测评 / 场景种草 / 使用教程 / 对比评测 / 开箱 / UGC晒单
- 封面类型: 产品图 / 场景图 / 人物图 / 文字卡片 / 对比图
- 标题类型: 痛点类 / 好奇类 / 教程类 / 清单类 / 对比类

这些分类决定了你后续能分析出什么差异化洞察。如果你不分方向, 就只能说"本期笔记平均互动量500" -- 这和没说一样。

竞品内容数据(从千瓜获取):
- 竞品商单笔记数、预估投放金额
- 竞品笔记的曝光/阅读/互动量
- 竞品的内容方向分布
- 竞品使用的博主类型和量级
- 竞品的搜索热度趋势

评论区数据(逐条阅读关键笔记的评论区):
- 用户在问什么(高频问题 = 内容没有覆盖到的信息缺口)
- 用户在讨论什么(讨论热点 = 用户真正关心的话题)
- 用户在抱怨什么(负面反馈 = 产品/内容/品牌的改进方向)
- 用户之间的互动(用户帮回答 = 已经产生认知的用户在帮你种草)

UGC 数据:
- 投放周期内UGC笔记的数量(自然产生的用户笔记)
- UGC笔记的内容方向(用户自发在说什么)
- UGC笔记中的关键词和品牌词关联度
- 品牌词云 vs UGC讨论核心的关联度

### 3.3 如何写好你的板块

板块一: Overall 内容效果概览

建立一个清晰的笔记数据总表:

| 笔记方向 | 笔记数 | 曝光量 | 阅读量 | 互动量 | 组件点击 | CPE | CTR |
|---------|--------|--------|--------|--------|---------|-----|-----|
| 场景种草 | 12 | xxx | xxx | xxx | xxx | x.x | x.x% |
| 产品测评 | 8 | xxx | xxx | xxx | xxx | x.x | x.x% |
| ... | ... | ... | ... | ... | ... | ... | ... |

表格不只是陈列数据, 每行后面必须有总结性表达:
"场景种草类笔记CTR最高(3.2%), 且CPE最低(1.1元), 是该品类最高效的内容方向。"
"产品测评类笔记互动量最高但组件点击率最低, 说明用户对产品有兴趣但购买意愿转化不足。"

然后补充博主量级分析:
"KOL(5-10w粉)贡献了45%的总互动量但仅占25%的预算, 性价比最高。
KOC(1-5w粉)在场景种草方向表现突出, CPE仅为KOL的60%。
头部博主(10w+)在品类背书效应上不可替代, 但其CPE显著高于中小博主。"

板块二: 优质笔记分析

核心原则: 不以爆文定义好坏, 以客户目标定义好坏。

如果你的客户P0目标是回搜率: 你的XY轴可能是"互动量 x 回搜率"。第一象限是互动量高且回搜率高的笔记 -- 这是真正优质的内容。

如果你的客户P0目标是进店成本: 你的XY轴可能是"曝光量 x 进店成本"。第一象限是曝光量高且进店成本低的笔记。

如果你的客户P0目标是TI种草: 你的XY轴可能是"互动量 x TI深度种草人数"。

每一篇落在第一象限的笔记, 你要分析:
- 这篇笔记的封面是什么样的(类型/构图/文字)
- 标题是怎么写的(结构/关键词/情绪)
- 内容结构是怎样的(开头/正文/结尾的节奏)
- 博主有什么特点(人设/风格/粉丝画像)

从中提取共性, 形成优质内容特征清单。这是最有价值的部分 -- 它不是一次性的分析, 而是可以指导下一期内容制作的标准。

板块三: 评论区洞察

这是最容易被忽视但最有价值的分析。

你要做三件事:

第一, 提炼用户真实关注点。用户在问什么? 担心什么? 对比什么? 这些直接告诉你内容策略应该怎么调整。

示例:
"评论区高频问题集中在(1)敏感肌是否适用(出现23次); (2)与其他品牌的区别(出现18次); 
(3)使用步骤(出现15次)。建议下期内容增加敏感肌实测和品牌对比专题。"

第二, 找到用户自发的好评点和差评点。好评点是你可以放大传播的方向, 差评点是需要提醒客户改进的方向。

第三, 发现品牌可升级改进的方向。评论区里用户提的建议, 有些可以直接反馈给客户作为产品改进参考。

板块四: UGC 洞察

UGC的数量和质量直接反映了种草效果。

分析维度:
- UGC数量趋势: 是否与你的投放动作正相关? 某篇笔记发布后UGC是否有明显增长?
- UGC内容方向: 用户自发在说什么? 和你的品牌核心信息是否一致? 如果不一致, 差异在哪里?
- 品牌词关联度: 用户讨论的内容和品牌关键词的关联度。如果UGC很多但跟品牌词没关系, 说明你的种草没有形成品牌心智。
- 新建议: 基于UGC讨论方向, 品牌应该强化哪些传播信息, 弱化哪些。

板块五: 竞品内容 Case Study

选定2-4个竞品(优先客户指定的死对头), 从以下维度分析:

浅层指标:
- 商单笔记数量 x 互动量(判断竞品的内容投入规模)
- 内容方向分布(竞品在主打什么方向, 跟我们的差异在哪)
- 博主合作策略(竞品偏好什么类型/量级的博主)
- 高频关键词和话题

深层指标:
- 人群渗透率(竞品在品类人群中的占比)
- 阅读渗透率(竞品内容阅读量在类目中的占比)
- 搜后曝光渗透率(竞品搜索场景的曝光份额)

品牌动作:
- 竞品有没有做品牌广告或线下活动
- 竞品在电商侧的动作
- 这些动作对竞品的正向影响
- 我们可以复用什么

### 3.4 常见错误

错误1: 不分方向, 只看总量
"本期发布笔记30篇, 总互动量15万" -- 30篇里可能有25篇表现一般, 5篇爆了。不分方向你根本不知道哪种内容有效。

错误2: 优质笔记判断标准错误
"这篇笔记互动量10万, 是爆文" -- 如果客户的目标是进店转化, 互动量10万但进店率=0的笔记是无效内容。好坏由客户目标定义。

错误3: 评论区分析缺失
完全不看评论区或者只看一眼说"评论都是好评" -- 评论区是免费的用户调研, 不看等于浪费了最重要的策略信息源。

错误4: 竞品分析变成数据罗列
"竞品A发了20篇笔记, 总互动量30万" -- 然后呢? 竞品的内容方向是什么? 和我们的差异是什么? 哪篇笔记值得深入研究? 我们能学到什么?

错误5: UGC 分析缺失
完全不看投放周期内产生的UGC -- UGC是种草效果的直接验证。UGC多且与品牌相关 = 种草成功; UGC少或与品牌无关 = 种草失败。

错误6: 数据不全时给模糊判断
缺少笔记维度的互动/转化数据, 就凭着"感觉"或"印象"说某类内容好。正确做法: 标注缺少什么数据, 给出在当前数据条件下能做的最大程度分析, 建议补充数据后做二次分析。

### 3.5 自查清单

[ ] 笔记是否按内容方向和博主量级做了分类汇总?
[ ] 每类笔记是否标注了总结性判断?
[ ] 优质笔记的判断标准是否匹配客户P0目标?
[ ] 优质笔记是否提取了共性特征(封面/标题/内容结构/博主特征)?
[ ] 评论区的用户高频问题是否已提炼?
[ ] 评论区的用户好评点和差评点是否已归纳?
[ ] UGC数量和方向是否已分析?
[ ] 竞品内容Case Study是否覆盖了浅层和深层指标?
[ ] 竞品分析是否包含可复用的发现?
[ ] 所有结论是否都有 So-What?
[ ] 分析文字中是否有模糊措辞(应该/大概/可能/看起来)?
[ ] 每个段落是否只讲了一个观点?
[ ] 如果某个维度数据缺失, 是否标注了数据局限和替代分析方案?

## 第四部分: 媒介同事篇

### 4.1 职责定位

你是投放执行和效果度量的负责人。你的核心任务是:

1. 提供投放全链路数据(从曝光到转化的每个环节)
2. 分析 KFS 分配的实际执行效果
3. 分析搜索指标(SOV/SOC/搜索指数/回搜率)
4. 分析口碑指标(CPE/CPC/CPM/CTR/渗透率)
5. 拉取行业 benchmark 和竞品消耗数据
6. 管理品牌广告资源的数据达成

你的角色非常关键: 你的数据是策略同事下结论的基础。数据不准确, 整个报告的结论都不可靠。数据不全, 策略同事只能做不完整的分析。

### 4.2 关注数据

你的主场数据来自聚光后台、灵犀度量模块和直客。

聚光后台/千帆推广报表:
- 竞价广告曝光到转化的全链路数据
- 按场域拆分: 信息流 / 视频流 / 搜索(必须分开, 不能混在一起看)
- 按计划/单元/创意层级的数据
- 消耗金额、曝光量、点击量、互动量、转化量

灵犀度量模块:
- AIPS 人群资产数据: 各层级人群的数量和结构
- 口碑数据: 正向/中性/负向评论占比
- 一方/三方数据的对接

直客拉取:
- 行业 benchmark: CPM/CPC/CTR/CPE/进店成本/ROI等的行业均值
- 竞品消耗数据: 竞品的投放规模
- 大盘趋势数据

搜索指标:
- SOV(Share of Voice): 某关键词下品牌广告曝光量 / 该关键词所有广告曝光量
  注意: 聚光后台只能看到代子账号的数据, 不是全品牌维度。正确数据需要找直客拉取全品牌数据。
- SOC(Share of Click): 某关键词下品牌广告点击量 / 该关键词所有广告点击量
- 搜索指数: 品牌词 + 品牌SPU词至少两个, 以聚光为准, 蒲公英后台辅助
- 回搜率: 用户看过广告流量笔记后48小时内搜索特定词的比率
  计算公式: 点击广告后48小时内搜索过回搜词的用户去重人数 / 点击广告用户去重人数
  回搜率是 by 笔记维度, 不是 by 关键词维度
  行业均值约为0.5%, 低于0.5%说明种草深度不足

口碑/浅层指标:
- CPE = 消耗 / 总互动(内容互动效果, 越低越好)
- CPC = 消耗 / 点击量(点击成本)
- CPM = 消耗 / 总曝光 x 1000(千次曝光成本)
- CTR = 阅读量 / 曝光量(封面和标题的表现, 越高越好)

深度/渗透指标:
- 人群渗透率 = 品牌人群在品类人群中的占比
  注意: 每个客户取数逻辑不同, 先和客户对齐取数口径。提高方法包括: 人群圈精准、笔记数量加量、投放以新增种草+深度种草为核心目标、客户加预算。
- 内容渗透率 = 品牌内容阅读量在该类目所有内容阅读量中的占比
  提高方法: 笔记质量拔高关注CTR、加笔记数量、客户加预算。
- 搜后曝光渗透率 = 搜索后品牌内容曝光量在该类目所有内容曝光量中的占比
  提高方法: 投手关注搜索笔记CTR、增加搜索预算、投流中对词的匹配模式优化。

生意指标(如可获取):
- 全店GMV、ROI(GMV/消耗成本)、进店成本(消耗成本/UV)
  ROI和进店成本需要行业benchmark, 找直客拿。

品牌广告数据(如适用):
- IP资源包数据达成
- 惊喜盒子数据
- 品专数据
- 火焰话题数据

**数据完整性自我诊断(新增):**

拉完数据后在进入分析之前, 先做一次快速诊断:
问自己: 我这六个分析维度(生意指标/搜索指标/口碑指标/内容策略/人群分析/竞价策略)的数据够不够?
- 如果某个维度只有基础数据(比如只有消耗和曝光, 没有转化), 对照本文 1.9.2 的 fallback 路径, 确认在有限数据下能做什么分析
- 把各维度的数据完整度向策略同事同步, 让策略同事知道哪些结论可以做, 哪些需要降级

### 4.3 如何写好你的板块

板块一: 投放成果总览

核心原则: 大标题+总括句highlight+数据化表达。

开头用一个大表展示投前投后的对比:

| 指标 | 投前(或上期) | 投后(本期) | 变化 | 行业benchmark | 判断 |
|------|-------------|-----------|------|-------------|------|
| SOV  | x% | x% | +x% | x% | 高于/低于行业 |
| 搜索指数 | x | x | +x% | - | 趋势判断 |
| 回搜率 | x% | x% | +x% | 0.5% | 高于/低于参考线 |
| CPE | x元 | x元 | -x% | x元 | 高于/低于行业 |
| CTR | x% | x% | +x% | x% | 高于/低于行业 |
| ... | ... | ... | ... | ... | ... |

表格后面跟一段总结性文字, 用策略型三段式:
第一句: 整体效果的判断
中间: 关键数据支撑
最后: 未来方向

搜索指标分析要点:
- SOV/SOC要对比行业, 不能只看绝对值。SOV 20%看起来低, 但如果行业高度分散第一名也就25%, 那20%是很强的。
- 搜索趋势和投放节奏的相关度: 搜索指数是否随笔记发布+投流呈正相关趋势? 如果是, 说明投放有效驱动了搜索心智。
- 回搜率趋势: 哪篇笔记的回搜率最高? 为什么这篇的种草深度好?

口碑指标分析要点:
- CPE/CPC/CPM/CTR 四个指标要放在一起看, 不能孤立分析。
- 小红书双列信息流中, CPM高+CTR高不是坏事, 是人群精准的信号(用户选择逻辑下, CTR高说明封面标题打中精准人群, 系统给更多曝光, CPM自然上升)。
- 如果CTR高但CPM很低, 反而要警惕: 可能流量太泛, 大量非目标用户点击。
- 渗透率看趋势, 不止看绝对值。即使绝对值不高, 只要趋势向好就是正面信号。

板块二: 策略执行方法论

三个关键信息: 策略是什么 + 用了什么抓手 + 达成了什么效果。

示例:
"策略: KFS分配比例为KOL 40%/Feeds 35%/Search 25%, 其中搜索占比高于常规水平, 
目的是在新品类中快速建立搜索心智。
抓手: KOL侧采用金字塔结构(2头部+8腰部+20KOC), 头部负责品类背书, 腰部负责深度种草, KOC负责铺量;
Feeds侧以场景化笔记为主投素材, 重点投放20-35岁一二线女性;
Search侧锁定品牌词+品类词+场景词三类关键词, 品牌词保第一, 品类词争前3。
效果: 搜索指数较投前提升320%, 品牌词SOV达到65%, CTR高于行业均值37%, CPE为行业均值的72%。"

板块三: 人群分析

四象限人群分析:
XY轴为消耗和效果(点击或转化, 根据客户目标选择)。四个象限的判断:

高消耗+高点击/转化: 主力人群。检查是否与策略设定的人群方向一致。如果一致, 说明策略正确; 如果不一致, 说明实际有效人群和策略人群有偏差, 需要修正策略认知。

高点击/转化+低消耗: 潜力人群。这是最值得关注的人群 -- 效率高但花钱少。建议拓展预算到这个方向。

低点击/转化+高消耗: 需要优化的人群。先尝试换素材(可能人群对但是素材不对), 如果换素材仍然低效, 战略性放弃。如果是策略核心人群但表现差, 这是一个需要深入分析的问题。

低点击/转化+低消耗: 边缘人群。如果是策略覆盖范围外的自然触达, 可以忽略。如果是策略希望覆盖但表现差, 考虑换素材或放弃。

P人群 vs TI人群对比:
对比P人群(泛品类人群)和TI人群(种草/购买意向人群)的表现差异。共性说明什么? 差异说明什么?

举例:
"P人群和TI人群的共性: 性别都是女性为主(85%), 年龄集中在25-35岁。
差异: TI人群的消费水平TGI比P人群高40%, 说明高消费力用户更容易从品类认知转化到品牌种草。
建议: 后续人群圈选时提升消费水平的权重, 同时针对不同消费水平用户做差异化内容。"

人群画像三维度:
1. 基础信息(性别/年龄/婚恋/母婴/消费水平/固定资产/地域/城市/消费档次) -- 反映基本形象和消费能力。占比反映整体特点, TGI反映偏好程度。
2. 消费偏好(行业品类偏好/品牌偏好/消费金额/手机价格/品牌型号) -- 反映消费习惯和态度。
3. 内容偏好(内容兴趣偏好/内容关键词偏好/搜索词偏好/热点关注偏好/博主偏好) -- 反映内容行为习惯。

**衍生指标创建(当标准指标缺失时):**

如果你负责的指标因为数据缺失无法直接计算, 创建替代指标。核心场景:

场景1: 客户没有提供GMV, 无法计算ROI
→ 用 RPV(单次观看价值)替代: 总成交金额(如有) / 总观看次数
→ 或用 估计ROI: (进店转化率 x 类目均客单价) / CPUV(投放)
→ 在报告中标注: "本次ROI使用衍生指标估算, 客单价基于类目均值, 与实际ROI存在偏差。建议客户补充GMV数据做精确计算。"

场景2: 缺少回搜率数据(没有搜索行为日志)
→ 用 搜索指数变化率替代: (投后搜索指数 - 投前) / 投前搜索指数
→ 标注: "搜索指数变化率为衍生指标, 反映搜索心智的变化趋势, 不区分主动搜索和被动搜索。"

场景3: 缺少全品类人群基数, 无法计算人群渗透率
→ 用 TI人群增长速度替代: TI新增人数 / 周数
→ 标注: "TI增速为渗透率的衍生替代指标, 反映品牌人群资产的绝对增长速度, 不反映在品类中的相对位置。"

衍生指标使用铁律:
- 必须在报告中标注"衍生指标"
- 必须说明局限性(和标准指标的差异)
- 结论强度降一级: 不说"效果优秀", 说"呈现向好趋势"

### 4.4 常见错误

错误1: 搜索指标用聚光后台数据
聚光后台的SOV/SOC只是代子账号维度的数据, 不是品牌全维度。有偏差。必须找直客拉取全品牌维度的搜索数据。

错误2: CPM高就说是成本问题
小红书双列信息流是用户选择逻辑, CPM受CTR影响。高CTR+高CPM是人群精准的正向信号, 不是成本高的问题。

错误3: 不对比 benchmark
"本期CPM 35元" -- 35元是高是低? 没有行业benchmark, 数据没有判断依据。

错误4: 人群画像只列数据不分析
"人群画像: 女性85%, 25-35岁占70%, 一线城市占45%" -- 然后呢? 这些数据说明什么? 和策略预期一致吗? 有没有发现新的机会人群?

错误5: 渗透率取数口径不一致
每个客户的渗透率取数逻辑可能不同。拿数据前必须和客户对齐取数口径, 否则数据没有可比性。

错误6: 品牌广告数据缺失
如果项目包含品牌广告(IP资源包/惊喜盒子/品专/火焰话题等), 数据必须完整收录。不能因为是品牌部门的事情就忽略。

错误7: 数据不全时给模糊结论
"这个月整体效果还不错" -- 不错在哪? 用衍生指标给出定量判断, 同时标注局限性。不能因为数据不全就退回到主观判断。

### 4.5 自查清单

[ ] 搜索指标(SOV/SOC/搜索指数/回搜率)是否使用了直客全品牌数据而非聚光后台数据?
[ ] 所有指标是否都标注了行业benchmark?
[ ] 分析中是否正确理解了平台指标关系(CPM高+CTR高是正向信号)?
[ ] CPE/CPC/CPM/CTR是否放在一起综合分析而非孤立看?
[ ] 人群分析是否包含了四象限/P-TI对比/画像三维度?
[ ] 渗透率取数口径是否已和客户对齐?
[ ] 品牌广告数据(如有)是否完整收录?
[ ] KFS策略执行情况是否清楚描述?
[ ] 和行业benchmark对比后是否给出了明确判断?
[ ] 数据是否按场域(信息流/视频流/搜索)分开而非混在一起?
[ ] 如果某个维度数据缺失, 是否执行了 fallback 路径, 创建了衍生指标并标注了局限性?
[ ] 是否在分析前做了数据完整性自我诊断, 并将各维度数据完整度同步给了策略同事?
[ ] 分析文字中是否有模糊措辞(应该/大概/可能/看起来)?
[ ] 每个段落是否只讲了一个观点?

## 第五部分: 竞价同事篇

### 5.1 职责定位

你是投放优化的执行者。你的核心任务是:

1. 提供竞价投放的精细化数据(按计划/单元/笔记/人群包/关键词/广告位)
2. 分析竞价投放的三阶段节奏(测试期/放量期/转化期)
3. 分析人群包的表现和优化方向
4. 分析广告位的效率差异
5. 分析搜索词和关键词的投放效果
6. 提供具体的竞价优化建议

你的数据是最细粒度的。其他同事的分析都在宏观层面, 你的分析必须能解释"为什么这个计划好, 那个计划不好"。如果你只能给出总消耗和总转化的数据, 你的分析就没有价值。

### 5.2 关注数据

聚光竞价投放数据(最细粒度):

按计划维度:
- 每个投放计划的消耗/曝光/点击/互动/转化
- 计划的出价策略(自动出价/手动出价/最大转化量等)
- 计划的定向设置(人群包/地域/年龄/兴趣等)

按人群包维度:
- 曝光人群: CPM对比benchmark
- 互动人群: CPE对比benchmark
- 每个包的转化成本

按广告位维度:
- 信息流: 曝光/CTR/CPC/CPE/转化率(高效触达层)
- 视频流: 曝光/CTR/CPC/CPE/转化率(深度互动层)
- 搜索: 曝光/CTR/CPC/CPE/转化率(精准转化层)
必须分开分析, 不同广告位的用户行为和效率完全不同。

按关键词维度(搜索):
- 品牌词/品类词/场景词的SOV和CPA
- 关键词的匹配模式(广泛/短语/精确)
- 否定词设置的效果
- SEM卡位场景下CPC与SOV/C的关系(成反比, SOV/C越高CPC越低)

按投放阶段维度:
- 测试期: 赛马测试数据(不同素材/人群/出价的A/B对比)
- 放量期: 成本变化趋势(放量后CPM/CPC/CPE是升是降)
- 转化期: 转化成本趋势和TI人群积累速度

**动态诊断: 竞价数据不全时的分析策略(新增):**

你的分析依赖最细粒度的数据。当数据粒度不够时, 调整分析框架而非强行输出。

场景1: 缺分阶段投放数据(没有测试期/放量期/转化期的区分)
→ 不要硬拆三阶段。改为: 将全周期数据按时段分段(如按周), 分析效率变化趋势。
→ 如果有效率的趋势变化, 结合投放日志回顾当时做了什么调整, 做定性归因。
→ 标注: "因缺少投放阶段的明确划分, 三阶段分析暂不可做。以下分析基于全周期按周拆解的趋势判断。"

场景2: 缺人群包维度的消耗和效果数据
→ 不要逐个分析人群包。改为: 用整体人群画像和主流内容方向做匹配度分析。如果素材是场景化的, 而整体人群的内容偏好也与场景内容高度匹配, 则间接判断人群圈选合理。
→ 标注: "因缺少人群包维度数据, 无法对人群圈选的精细化效果做量化评估。建议后续投放补充该维度数据, 以识别最优/最差人群包特征。"

场景3: 缺计划/单元层级的详细数据
→ 仅做场域级别(信息流/视频流/搜索)的效率对比。不做计划间的赛马分析。
→ 标注: "因缺少计划层级数据, 无法识别最优/最差计划的素材和定向特征。场域分析结论为粗粒度判断。"

场景4: 只有消耗和曝光数据, 缺转化数据
→ 用曝光效率(CPM)和互动效率(CPE)作为核心分析维度。不做转化归因。
→ 标注: "因缺少转化数据, 当前分析限于曝光和互动层效率。转化效果待补充数据后评估。"

**衍生指标: RPV 的使用场景(新增):**

当你的客户只提供了总成交金额和总观看次数, 但没有GMV的完整拆解时, 用 RPV(单次观看价值)做投放效率的替代判断:

RPV = 总成交金额 / 总观看次数

RPV 的意义: 每次用户观看带来的成交价值。它不等于ROI, 但反映了流量的商业价值密度。

使用方法:
- 对比不同笔记方向的RPV: 场景化笔记RPV 0.8元 vs 测评类笔记RPV 0.3元 → 场景化笔记的单次观看商业价值更高
- 对比不同人群包的RPV: 竞品人群RPV 1.2元 vs 泛人群RPV 0.5元 → 竞品人群的流量商业密度更高
- 标注: "RPV为衍生指标, 不含自然成交和复购, 且受客单价影响较大。判断需结合其他指标交叉验证。"

### 5.3 如何写好你的板块

板块一: 投放策略三段论

把你的投放过程拆成三个阶段, 每个阶段说明做了什么、为什么这么做、数据验证结果。

测试期(通常投放前1-2周):
"目标: 赛马测试, 找出低成本潜力笔记, 建立搜索端露出。
动作: 上线15篇笔记同时投放, 每篇初始预算均分。测试维度包括:
(1)内容方向(场景vs测评vs教程); (2)封面类型(场景图vs产品图);
(3)出价策略(自动vs手动)。监控指标: CTR和CPE。
结果: 场景类笔记CTR均值3.8%(测评类2.1%), CPE均值1.1元(测评类2.3元)。
场景方向确定为放量主力。搜索端锁定品牌词+3个高转化品类词, SOV首周即达到55%。"

放量期(通常投放第3-6周):
"目标: 放大测试期验证的低成本笔记, 优化出价和定向。
动作: 将测试期CTR>3%且CPE<1.5元的笔记预算翻倍;
出价策略从手动切换为自动出价(目标CPE设定为1.5元);
定向从初始的泛人群切换为测试期表现最好的3个人群包。
结果: 在预算翻倍的情况下CPE仅上升8%(从1.1元到1.2元), 说明放量效率健康。
CTR保持在3.5%以上, 说明内容疲劳度可控。"

转化期(通常投放第7周后):
"目标: 集中高转化人群, 放大粉丝定向, 降低TI成本。
动作: 缩小定向范围至测试和放量期验证的转化率前20%人群;
加大粉丝定向比例(从10%提升至25%);
搜索端将精确匹配关键词预算集中到转化率最高的3个品牌词。
结果: TI成本较放量期下降18%, 转化率提升至行业均值的1.5倍。"

**如果缺少三阶段数据(新增):**
如果数据没有按测试期/放量期/转化期区分, 改用按周拆解趋势分析:
"因各投放阶段的明确划分数据不可获取, 以下分析基于全周期按周拆解。
第1-2周: CPE均值2.3元, CTR 2.1%, 处于探索期, 多方向测试中。
第3-5周: CPE降至1.4元, CTR升至3.2%, 场景化内容方向跑通后开始放量。
第6-7周: CPE保持1.3元, CTR稳定在3.5%, 放量效率未随预算增加而衰减。
趋势判断: 场景化内容方向在整个周期保持效率优势, 放量后未出现内容疲劳。"
标注: "注意: 以上按周分段基于数据趋势推断, 非投放后台记录的明确阶段划分。阶段间的效率变化归因需结合投放操作日志做进一步验证。"

板块二: 渗透策略分析

人群圈选+数据验证两步走:

第一步: 说明你圈了哪些人群, 为什么圈这些人群。
"人群圈选逻辑: 基于品牌目标人群(25-35岁一线城市女性, 高消费力, 美妆兴趣),
圈选了三组人群进行测试: A组(泛美妆兴趣人群), B组(竞品互动人群), C组(品牌搜索人群)。
圈选依据: A组量大但精准度低, B组竞品对标, C组精准但量级小。"

第二步: 用数据验证圈选效果。
"验证结果(CTR/CPE对比行业benchmark):
A组: CTR 1.8%(行业2.0%), CPE 2.5元(行业2.0元) -- 泛人群效率低于行业, 需缩量。
B组: CTR 3.2%(行业2.0%), CPE 1.3元(行业2.0元) -- 竞品人群效率显著高于行业, 建议放量。
C组: CTR 5.1%(行业2.0%), CPE 0.8元(行业2.0元) -- 品牌人群效率极佳但量级有限, 作为种子包。

基于验证结果, 后续建议: B组放量至当前2倍, C组作为种子包拓展向量相似人群。"

板块三: 广告位策略分析

三个广告位分开分析, 每个位置说明哪项指标最优+原因。

信息流(高效触达层):
"信息流贡献了65%的总曝光, CPM 28元(行业35元)。CTR 3.5%显著高于行业(2.0%),
原因是场景化封面在双列信息流中更具点击吸引力。
不足: 转化率1.2%低于搜索(3.8%), 说明信息流在激发即时购买意愿上弱于搜索。
结论: 信息流适合做人群触达和内容种草, 不适合直接做转化。"

视频流(深度互动层):
"视频流贡献了20%的总曝光, 互动率8.5%(信息流为3.2%)。CPE 0.9元, 是所有广告位中最低的。
原因是视频形式的内容承载量更大, 用户停留时间更长, 互动意愿更强。
但视频流的进店率仅1.0%, 低于信息流(1.8%), 说明视频内容在引导点击购物上不如图文直接。
结论: 视频流适合做深度种草和品牌建设, 配合信息流做人群分层触达。"

搜索(精准转化层):
"搜索贡献了15%的总曝光但贡献了35%的总转化。转化率3.8%, 是信息流的3倍。
CPC 2.5元高于行业(2.0元), 原因是SEM卡位场景下为保证品牌词SOV第一竞价力度较大。
但搜索的转化质量最高, 单次转化成本(CPA)反而是所有广告位中最低的。
结论: 搜索是转化效率最高的广告位, 建议下期增加搜索预算占比, 通过提升SOV/C自然降低CPC。"

板块四: 人群包分析

对每个人群包做以下分析:

曝光人群分析: CPM对比行业benchmark
"人群包A(泛美妆): CPM 30元(<行业35元), 跑量能力强但人群偏泛。
人群包B(竞品互动): CPM 38元(>行业35元), CPM偏高但结合CTR看效率不差。
人群包C(品牌搜索): CPM 42元(>行业35元), CPM最高但转化率也最高(4.2%)。"

互动人群分析: CPE对比行业benchmark
"人群包A: CPE 2.5元(>行业2.0元), 互动效率低于行业, 内容匹配度不足。
人群包B: CPE 1.3元(<行业2.0元), 互动效率显著高于行业, 内容与竞品人群的需求匹配度高。
人群包C: CPE 0.8元(<行业2.0元), 品牌人群互动意愿最强。"

总结分类:
"好的(建议放量): 人群包B(竞品互动), 人群包C(品牌搜索)
需优化的(换素材再试): 人群包A, 尝试换用场景化素材替代产品图素材
需停投的: 人群包D(泛兴趣), CTR<1%且CPE>行业2倍, 建议放弃"

### 5.4 常见错误

错误1: 投放阶段混在一起分析
把测试期的数据和放量期的数据放在一起算均值 -- 测试期的CPE可能很高(测新方向), 放量期的CPE很低(跑通的才放量)。混在一起均值没有意义。

错误2: 广告位不分
信息流/视频流/搜索混在一起看CTR和CPC -- 搜索天然CPC高但转化好, 信息流天然CPC低但转化弱。混在一起得不出有效结论。

错误3: 只给出"建议放量"但没有数据依据
"建议对这个人群包放量" -- 为什么? CTR多少? CPE多少? 对比基准是多少? 放量到多少? 没有数据支撑的建议没有说服力。

错误4: SEM分析不看CPC与SOV/C的关系
搜索广告的分析如果只看CPC绝对值, 忽略了SOV/C对CPC的反向影响(SOV/C越高CPC越低), 就会错误判断成本。如果CPC高, 先看SOV/C是否够高 -- 如果SOV/C不够, 需要加大搜索预算而不是降低出价。

错误5: 人群包分析只有平均值
"本期所有人群包平均CPM 35元" -- 不同人群包差异巨大, 平均值掩盖了差异。必须分人群包分析, 找到每个包的具体表现。

错误6: 下一步建议和前面分析脱节
前面分析说人群包B好, 后面建议说"建议增加搜索预算" -- 这两个完全没关系。建议必须回溯到分析发现。

错误7: 数据粒度不够时强行做精细分析
缺人群包维度数据还硬写"A组表现好于B组" -- 你都不知道A组B组各自的表现, 这个结论从哪来的? 数据粒度不够就降级分析框架, 标注局限性。

### 5.5 自查清单

[ ] 投放是否按测试期/放量期/转化期三阶段分开分析?
  → 如果缺少三阶段数据, 是否已改用按周趋势分析并标注局限性?
[ ] 每个阶段是否说明了动作/逻辑/数据验证?
[ ] 广告位是否按信息流/视频流/搜索分开分析?
[ ] 每个广告位是否标注了哪项指标最优+原因?
[ ] 人群包是否分开展示而非算平均值?
[ ] 每个人群包是否有CPM/CPE对比行业benchmark?
[ ] SEM分析是否考虑了CPC与SOV/C的反比关系?
[ ] 人群圈选逻辑是否有数据验证?
[ ] 渗透策略是否包含人群圈选+数据验证两步?
[ ] 优化建议是否有具体数据支撑并回溯到前文分析?
[ ] 如果某个维度数据缺失, 是否执行了 fallback 路径并标注了局限性?
[ ] 标准指标缺失时, 是否创建了衍生指标(如RPV)并标注了局限性和计算公式?
[ ] 分析文字中是否有模糊措辞(应该/大概/可能/看起来)?

### E. 报告版本管理

每次复盘完成后, 在内部做以下归档:

1. 复盘报告最终版: 保存在曼拾内部共享盘, 按"客户名/年月"归档
2. 方法论更新: 如果本次复盘萃取了新的可复用方法论, 更新到方法论库
3. 失败经验记录: 如果本次复盘发现了新的失败模式, 更新到避坑指南
4. 行业benchmark更新: 如果本次获取了新的行业数据, 更新到benchmark库

四次归档做齐全, 一个项目的经验才能真正变成整个团队的能力。
