## B. 规避方案

**B1（对 A1，最高优先，本 run 已执行）**：交付失败两形态——①收尾工具污染（101–142s）②真超时（300s）。共同兜底＝「系统查询全部前置到写文件之前 + 收尾轮纯文本零工具调用」。本 run：所有 sqlite/文件实测在写产物前完成；写完 MEMORY 与复盘后仅输出纯文本。

**B2（对 A2）**：需外部授权的事项，**只认配置层落地（`updated_at` 变化 / sqlite 实读），不认 dreaming 日记的重复记录**。判定标准一句话：改完查 `updated_at` 是否变化——变了才算落地。据此今日把「timeout」拍板项从台账关闭，不再重复挂。

**B3（对 A3）**：缝合区压缩**只动证据层**——每条只留 1 句证据 + 判据句，推导移入 dreaming D 节；核心框架条目数保留（判据不可虚化，B2 处置）。

**B4（对 A4）**：跨日去重执行规则十——缝合与引用前先按帖子发布时间筛掉落在昨日窗口内的条目，再核对昨日 BM 缝合区是否已入档。
