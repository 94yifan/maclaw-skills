# 瑞幸即享 · 新品共创洞察服务 报价方案

日期：2026-08-19
服务主体：燃创（品牌咨询/服务设计）
项目周期：三个月，至少3轮"趋势洞察报告 + workshop"

## 一、项目概述

瑞幸即享（预包装咖啡）拟委托燃创做"新品共创洞察"服务，周期三个月，至少3轮洞察分享，最终目标为共创出一款新品方向（含命名、包装视觉方向、饮用场景等）。

## 二、三档服务结构与报价总览

**第一档：洞察分享（燃创）— 报价 50-60万**
三个月3轮趋势洞察 + 机会点提炼 + 3场洞察分享workshop

**第二档：创品跟进（燃创，含第一档）— 报价 80-90万**
在第一档基础上，加产品命名、包装视觉方向、饮用场景定义、概念共创workshop、口味/风味方向、价格带建议

**第三档：设计落地（暂缓，独立评估）**
产品设计落地、平面设计、CMF设计、商详页设计等执行层，由逸凡另行评估报价，本期不并入燃创报价

## 三、第一档：洞察分享（燃创）

### 3.1 服务内容（每轮）

1. 社交趋势扫描：小红书/抖音/微博声量、热搜、爆款笔记，捕捉咖啡与泛消费赛道的声量变化
2. 异业品类趋势扫描：跨品类（零食/美妆/酒饮等）爆品逻辑借鉴，找可迁移的趋势
3. 本品+竞品矩阵拆解：瑞幸即享现有产品矩阵 + 三顿半/永璞/隅田川/雀巢/星巴克等竞品拆解
4. 目标人群画像与需求洞察
5. 饮用/情绪场景洞察
6. 趋势机会点提炼（核心交付）：从趋势中提炼"瑞幸即享该押什么方向"的判断
7. 洞察分享workshop：每轮1场，向瑞幸团队分享洞察并共创讨论

### 3.2 交付物

- 3轮趋势洞察报告（含机会点判断）
- 3场workshop（设计+引导+纪要）
- 每轮汇报材料

### 3.3 工时明细（3轮）

- 社交趋势扫描：9人天（采集4.5 + 分析4.5）
- 异业品类趋势扫描：6人天
- 本品+竞品矩阵拆解：5人天
- 人群画像与需求洞察：5人天
- 饮用/情绪场景洞察：4.5人天
- 趋势机会点提炼（核心）：6人天
- 报告撰写：6人天
- 洞察分享workshop：9人天
- 项目管理与汇报：3人天

**第一档合计：约54人天**
人员结构：合伙人/总监级18人天，资深顾问27人天，分析师9人天

### 3.4 报价

对外报价 **50-60万**，锚定55万

## 四、第二档：创品跟进（燃创）

### 4.1 服务内容（在第一档基础上新增）

1. 产品命名：多套方案供选，含商标可注册性初查
2. 包装视觉方向：设计语言/风格方向定义，含竞品包装视觉拆解
3. 饮用场景定义与内容跟进
4. 概念共创workshop：2场深化共创
5. 口味/风味方向建议
6. 价格带建议
7. 概念测试（对接调研公司）

### 4.2 新增工时

- 产品命名：4人天（核心创意，合伙人级）
- 包装视觉方向：6人天
- 饮用场景定义与内容跟进：4人天
- 概念共创workshop：6人天
- 口味/风味方向建议：3人天
- 价格带建议：2人天
- 概念测试：3人天

**第二档新增：约28人天**
**第二档总计：约82人天**

### 4.3 报价

对外报价 **80-90万**，锚定85万

**命名+包装视觉方向是核心溢价资产，单独在第二档加价，不放第一档。**

## 五、第三档：设计落地（暂缓）

由逸凡独立评估，本期不并入燃创报价。可能涉及：

- 产品设计落地：产品外观/结构（瓶型、罐型、包装结构）
- 平面设计：包装平面、VI延展、海报、物料
- CMF设计：颜色（Color）、材质（Material）、表面处理（Finishing）方案
- 商详页设计：电商详情页
- 延伸：产品拍摄、短视频

## 六、价值定价逻辑（对外口径，不讲工时）

对外讲三个锚点：

1. **决策确定性**：我们卖的不是信息罗列，是"该押哪个方向"的判断。对标君智卖决策确定性，年费2000-3000万，本季度项目是其合理切片。
2. **试错成本对冲**：瑞幸即享自推一个新品类，从洞察到上市投入百万级，押错方向的沉没成本远高于服务费。我们的服务帮它把"押注"变成"有依据的选择"。
3. **市场对标**：同类"趋势洞察+共创"服务，顶级设计咨询（frog/IDEO）单项目100-200万，专业调研公司单模块20万+。燃创50-60万是同等质量、boutique价格，本身是合理低估。

## 七、内部成本盘账（仅逸凡内部，不外发）

对外日费口径（市场对标）：合伙人/总监 12000-15000，资深顾问 8000，分析师 4000-5000
内部人力成本（盘账）：合伙人约5000，资深顾问约3000，分析师约2000

第一档（54人天）：
- 对外口径人天价 ≈ 47万
- 内部人力成本 ≈ 19万
- 直接费用（数据工具/调研/差旅/workshop场地）5-8万
- 总成本 ≈ 24-27万
- 报价55万 → 毛利率约50-55%

第二档（82人天）：
- 对外口径人天价 ≈ 76万
- 内部人力成本 ≈ 29万
- 直接费用8万
- 总成本 ≈ 37万
- 报价85万 → 毛利率约56%

## 八、谈判要点

1. 主推第二档85万，第一档55万做下探，第三档暂缓
2. scope写死：几轮汇报、几版报告、workshop人数上限、命名方案套数
3. 命名+包装方向是溢价核心，不降价
4. 人天成本只在内部盘账用，绝不出现在客户材料里
5. 比稿前先确认预算区间，低于50万只做第一档
