## 1. 为什么写复盘

### 1.1 复盘的双重目的

| 维度 | 内部视角 | 对客视角 |
|------|----------|----------|
| 核心目标 | 经验沉淀（好的萃取、不好的避坑） | 证明专业能力 + 拿增购/续约 |
| 输出姿态 | 坦诚、真实、可复现 | 自信、有洞察、有下一步 |
| 判断标准 | 是否能指导下一次投放 | 客户看了会不会说"专业" |

### 1.2 复盘≠数据罗列

| 错误： 错误操作 | 正确： 正确操作 |
|------------|------------|
| 把后台数据截图贴上去 | 用数据讲一个"因为…所以…"的故事 |
| 只说"ROI 1:3" | 说"ROI 1:3，环比上期提升20%，主要因为X策略调整" |
| 表格塞满不总结 | 大标题 + 一句话总括句 + 数据化表达 |
| 只有结果没有原因 | 每个结果都要有归因分析 |

### 1.3 什么时候用

- **常规周报/月报：** 不用全GRARI，用Analysis + Insight两模块即可
- **项目结案：** 全流程GRARI + 总-分-总，作为对客交付物
- **内部复盘会：** 重点在Review + Insight，少放Data多讲方法论
- **报奖案例包装：** 提炼Insight中的可复用方法论，弱化细节数据

## 2. 复盘框架总览：GRARI + 总-分-总

### 2.1 GRARI 五模块逻辑流

```
G ── -  R ── -  A ── -  R ── -  I
目标回顾  结果比对  分析原因  目的回顾  规律总结
  10%      10%       40%      10%      30%
```

**为什么这五个模块缺一不可？**

| 模块 | 回答的问题 | 占分 | 新手常见坑 |
|------|-----------|------|-----------|
| **G - Goal 目标回顾** | 当初定了什么目标、为什么定这个 | 10% | 抄Brief上的数字，不思考"为什么是这个数" |
| **R - Result 结果比对** | 实际做到了什么、差距在哪 | 10% | 只报喜不报忧，或者只报忧不分析 |
| **A - Analysis 分析原因** | 做得好/不好，分别因为什么 | 40% | 只列动作不归因，或者归因太主观 |
| **R - Review 目的回顾** | 最早做这件事的目的达成了吗 | 10% | 完全跳过，不知道做这件事的初心 |
| **I - Insight 规律总结** | 以后可以怎么复用/怎么避免 | 30% | 写得太虚（"下次继续努力"），没有可操作SOP |

### 2.2 GRARI 详细说明

#### G - Goal 目标回顾（10%）

**写什么：**
- **目的 vs 目标区分**
  - 目的 = 为什么要做这件事（如：加强品牌在xx人群的渗透 / 提升新品生意）
  - 目标 = 实际量化的结果指标（如：CPUV < 3元 / ROI > 1:2.5）

- **KPI 三层分级**

| 层级 | 名称 | 数量 | 举例 |
|------|------|------|------|
| **P0** | 北极星指标 | 2-3个 | 整体提升销量 - 看转化率/CPUV/长效ROI；人群资产提升 - 看CPTI/特定人群渗透率；心智占位 - 看SOV/C |
| **P1** | 核心过程指标 | 2-4个 | TI人群效率与互动 - 看CPE、回搜 |
| **P2** | 参考指标 | 1-2个 | CPC、CTR等浅层指标 |

> 注意： **注意：** 浅层指标（P2）可能与核心指标（P0）冲突。例如CTR很高但转化率很低，说明标题党，这时候要优先保P0。

**模板格式：**
```
【项目目的】加强xx品牌在Z世代人群中的心智渗透
【项目目标】P0: CPTI < 5元, 长效ROI > 1:3 | P1: CPE < 2元, 回搜率 > 0.8% | P2: CTR > 5%
【预算分配】K: 60% | F: 30% | S: 10%
```

**错误： 错误示范：** 直接写"ROI>1:2"，没有说明是什么的ROI、什么时间周期、什么口径。

**正确： 正确示范：** "投放期间（6.1-6.30）全店GMV ROI > 1:2.5（以聚光回传口径为准），其中S场ROI > 1:4"

#### R - Result 结果比对（10%）

**写什么：**

| 要素 | 说明 |
|------|------|
| 目标完成情况 | KPI达标率，表格呈现 |
| 差距对比 | 实际 vs 目标的差距，用绿色（达标）/红色（未达标）标注 |
| 亮点和不足 | 亮点最多3个，不足最多2个（坦诚但有策略） |
| 目标变更 | 投放过程中是否新增/减少了目标，为什么 |

**模板格式（表格）：**
| KPI | 目标值 | 实际值 | 达成率 | 状态 |
|-----|--------|--------|--------|------|
| ROI | ≥1:3 | 1:3.5 | 117% | 正确： |
| CPTI | ≤5元 | 4.2元 | 116% | 正确： |
| CPE | ≤2元 | 3.1元 | 64% | 错误： |

#### A - Analysis 分析原因（40%） --  全文最核心模块

**三力拆解法：**

| 维度 | 含义 | 问题清单 |
|------|------|----------|
| **策略力** | 方向对不对、打法对不对 | KFS配比是否合理？人群圈选是否精准？关键词策略是否正确？ |
| **执行力** | 落地的质量和速度 | 内容质量是否达标？投流出价是否有节奏？审稿轮次是否过多？ |
| **管理力** | 流程和协同效率 | 内部SOP是否顺畅？客户对接是否及时？反馈时效是否满足？ |
| **客观原因** | 不可控的外部因素 | 大盘变化？竞品投放加量？品牌限流？目标临时修改？预算降低？ |

**正确： 做得好的：亮点事件 + 关键动作**

模板：
```
【亮点事件】xx笔记在投放后48小时跑出10w+曝光
【关键动作】
  · 策略力：精准命中"xx"话题热点，与品牌卖点强关联
  · 执行力：运营在热点出现2小时内完成笔记修改+重投
  · 管理力：审稿SOP前置，样稿提前3天确认，无卡点
  · 客观原因：当天行业大盘流量+15%
```

**正确： 做得不好的：问题事件 + 有差距的关键动作**

模板：
```
【问题事件】第三周CPE从1.8元飙升至3.5元
【有差距的关键动作】
  · 策略力：人群圈选过窄，曝光触达量不够
  · 执行力：二轮笔记质量下降，CTR从6%降到3%
  · 管理力：客户审批延迟2天，错过节日高峰窗口
  · 客观原因：竞品在同期大幅加量，品牌SOV从15%降到8%
```

#### R - Review 目的回顾（10%）

**三个维度回溯：**

| 维度 | 问自己 |
|------|--------|
| 资源分配 | 预算花在刀刃上了吗？有没有不必要的浪费？ |
| 执行 | 过程管控是否到位？有没有可以提前预警的？ |
| 情景变动 | 外部环境变化了多少？目标是否需要据此调整？ |

**模板：**
```
【最早目的】提升xx品牌在精致妈妈人群中的渗透率
【是否完成】正确： 完成。基准期渗透率8%  -  当期15%
【为什么能完成】资源集中在核心种草方向上，执行端笔记质量达标率高
【如果没完成】原因：xx竞品同期做了大型IP联动，分散了目标人群注意力
```

#### I - Insight 规律总结（30%） --  拉开差距的地方

**做得好的  -  萃取为可复用方法论**

| 维度 | 可输出成果 |
|------|-----------|
| 策略 | 媒介选K方法论、KFS分配模型、人群反漏斗模型 |
| 执行SOP | 内容制作流程、审稿SOP、投流节奏SOP |
| 管理 | 机动响应机制、客户对接SOP、周报模板 |

**做得不好的  -  提炼为提升经验**

| 维度 | 可输出成果 |
|------|-----------|
| 策略 | 目标设定避坑、人群圈选红线 |
| 执行 | SOP优化清单、内容质检标准 |
| 管理 | 预警机制、人员配置优化建议 |

**错误： 错误示范：**
> "下次要做得更好"  --  没有任何操作价值

**正确： 正确示范：**
> "【可复用方法论】高CTR > 8%的笔记，统一特征是封面采用'产品+使用场景'二合一构图。建议纳入后续所有项目的Brief模板中。"

### 2.3 总-分-总结构（对客交付专用）

```
┌──────────────────────────────────────────────────┐
│  总 ── 投放成果（Part 1）                          │
│       核心结论先行，给客户一个"一句话总结"           │
├──────────────────────────────────────────────────┤
│  分 ── 内容策略分析（Part 2）                       │
│       竞价策略分析（Part 3）                       │
│       两个维度平行展开，互为印证                    │
├──────────────────────────────────────────────────┤
│  总 ── 后续投放建议（Part 4）                       │
│       "所以下一步怎么做"                             │
└──────────────────────────────────────────────────┘
```

## 3. 数据准备：确认三件事 + 来源地图

### 3.1 数据准备三确认

> 在做任何分析之前，先做这三个确认。**这是新手最容易翻车的地方。**

#### 正确： 确认①：数据口径

| 口径类型 | 要确认的问题 | 踩坑案例 |
|----------|-------------|----------|
| 总流量 vs 自然流 vs 广告流 | 报告中用的是什么口径？ | 把自然流+广告流混在一起算CPC，数据失真 |
| 信息流是否含视频内流 | 聚光推广中"信息流"的配置 | 默认设置不同，数据会差30%以上 |
| 品牌广告 vs 竞价广告 | 两个数据源是否分离 | 混在一起做ROI计算，客户不认 |

#### 正确： 确认②：数据周期

| 要素 | 要确认 |
|------|--------|
| 汇总 vs by-day | 客户要的是汇总还是趋势？ |
| 周期一致性 | 对比期间和本期周期是否一致（天数/时间范围） |
| 特殊日期标注 | 大促期间、节假日期间需标注 |

#### 正确： 确认③：数据粒度

| 粒度层级 | 说明 | 什么时候用 |
|----------|------|------------|
| 达人×笔记ID | 每篇笔记维度 | 内容分析、优质笔记筛选 |
| 账户×场域×计划×笔记×创意 | 投放层级 | 竞价策略分析、计划级优化 |
| 关键词 | 搜索投放维度 | SOV/SOC分析、搜索词优化 |
| 人群包 | 人群维度 | 人群画像、人群包效果分析 |

### 3.2 数据来源地图

| 来源 | 能看什么 | 不能看什么 | 什么时候优先用 |
|------|---------|-----------|---------------|
| **蒲公英投后数据** | 达人数据+总流量数据 | 竞价分场域数据 | 内容分析、达人效果评估 |
| **商业内容中心** | 笔记投放数据 | 人群画像 | 笔记效果概览 |
| **聚光/千帆推广报表** | 竞价广告曝光 - 转化全链路 | 自然流量数据 | 竞价策略分析、ROI计算 |
| **灵犀度量模块** | AIPS/口碑/一方三方数据 | 实时数据（有延迟） | 人群资产分析、品牌心智 |
| **千瓜** | 竞品笔记/花费/博主数据 | 聚光内部数据 | 竞品分析、内容洞察 |
| **蒲公英创意中心-内容广场** | 竞品关键词+商业笔记分类 | 仅30天内数据 | 快速查竞品近期动作 |
| **直客拉取** | 大盘数据/benchmark/竞品消耗 | 非公开数据 | 做竞品对标/行业benchmark |

### 3.3 灵犀 vs 聚光/蒲公英  --  核心区别

| 对比维度 | 灵犀 | 聚光/蒲公英 |
|----------|------|-------------|
| 覆盖流量 | 全部流量场景（自然流+效果广告+品牌广告+薯条） | 仅广告流量 |
| 数据加工 | 经过加工，更具目的性 | 原始数据 |
| 适用场景 | 过程度量+结果度量+品牌度量 | 投放优化、执行管理 |
| 跨平台数据 | 支持（种草-购买-复购闭环） | 不支持 |

**灵犀三大复盘场景：**
1. **过程度量：** AIPS全链路，看人群如何从A - I - P - S流转
2. **结果度量：** 跨平台交易+全渠道数据，看种草 - 购买 - 复购闭环
3. **品牌度量：** 品牌心智+品牌口碑，看搜索趋势、SOV、回搜率

## 4. Part 1 投放成果怎么写

### 4.1 什么时候用

- **对客结案报告的开篇**（一上来先给客户"看结果"）
- 别跟Part 2/3/4搞混 -- Part 1是"结果展示"，Part 2/3是"为什么"
- 客户可能先看Part 1，如果Part 1没有说服力可能就不看后面的了

### 4.2 怎么写

**核心原则：** 大标题 + 总括句Highlight + 数据化表达

#### 4.2.1 投放亮点

**格式：** 投前投后对比，表格 + 趋势图

| 亮点 | 投前/基准 | 投后 | 提升 |
|------|-----------|------|------|
| SOV | 12% | 25% | +108% |
| 回搜率 | 0.3% | 0.9% | +200% |
| 全店GMV | 50w/月 | 85w/月 | +70% |

**注意：** 每个数据都要有来源标注（聚光 / 灵犀 / 蒲公英）

##### 搜索指标

| 指标 | 定义 | 数据来源 | 注意事项 |
|------|------|---------|----------|
| **SOV** | 品牌广告曝光量 / 该关键词所有广告曝光量 | 直客拉取全品牌数据 | 聚光后台是代子账号维度，有偏差 |
| **SOC** | 品牌广告点击量 / 该关键词所有广告点击量 | 直客拉取全品牌数据 | 同上 |
| **搜索指数** | 品牌词+品牌SPU词至少两个 | 以聚光为准，蒲公英后台辅助 | 至少选两个词，避免以偏概全 |
| **回搜率** | 用户看过广告流量笔记后48小时内搜索特定词的比率 | 蒲公英后台 | by笔记维度，不是by关键词维度；无行业均值默认0.5% |

> **回搜率公式：** 点击广告后48小时内搜索过回搜词的用户去重人数 / 点击广告用户去重人数

##### 生意指标

| 指标 | 说明 | 注意点 |
|------|------|--------|
| **全店GMV** | 投放期间店铺总成交额 | 需要去客户拉后台数据 |
| **ROI** | GMV / 消耗成本 | 行业benchmark问直客 |
| **进店成本** | 消耗成本 / UV | 行业benchmark问直客 |

**淘宝联盟维度**（看站外引流到淘宝的效果）：

| 指标 | 说明 | 好/坏判断 |
|------|------|-----------|
| 内容互动率 | 浅层种草程度 | 越高越好 |
| 引流率 | 人群精准+内容吸引度 | 越高越精准 |
| 店铺新访客率 | 引流新客多 | 越高越好 |
| 收藏加购率 | 需考虑价格/竞争优势因素 | 结合价格判断 |
| 转化率 | 实际下单转化 | 越高越好 |
| 店铺新客率 | 新客已成功下单 | 越高越好 |

##### 口碑指标

**搜索趋势与投放节奏相关性：** 热度随笔记发布+投流呈正相关趋势

**浅层指标：**

| 指标 | 公式 | 反映什么 |
|------|------|---------|
| CPE | 价格 / 总互动 | 内容互动效果 |
| CPC | 消费 / 点击量 | 点击成本 |
| CPM | 价格 / 总曝光 × 1000 | 系统竞争力 |
| CTR | 阅读量 / 曝光量 | 封面&标题表现 |

**深层指标：**

| 指标 | 定义 | 提高方法 |
|------|------|----------|
| **人群渗透率** | 品牌人群在品类人群中的占比（每个客户取数逻辑不同，先和客户对齐） | ①人群圈精准 ②笔记数量加量+核心种草方向 ③投放以新增种草+深度种草为核心目标 ④让客户加预算 |
| **内容渗透率** | 品牌内容阅读量在该类目所有内容阅读量中占比 | ①笔记质量拔高关注CTR ②加笔记数量 ③客户加预算 |
| **搜后曝光渗透率** | 搜索后品牌内容曝光量在该类目所有内容曝光量中占比 | ①投手关注搜索笔记CTR ②增加搜索预算 ③投流中对词的匹配模式 |
| **人群资产** | AIPS各层级人群数量 | 见灵犀模块（第9章） |
| **品牌广告数据** | IP资源包、惊喜盒子、品专、火焰话题等 | 按品牌广告实际交付统计 |

### 4.3 怎么分析客户在乎什么

**动作清单：**
1. 先看客户行业（美妆看回搜和AIPS，电商看GMV和ROI，汽车看渗透率）
2. 先看客户在项目启动时反复强调的是什么
3. 把客户最在乎的指标放在Part 1的第一屏

### 4.4 错误： 常见错误

| 错误 | 说明 | 正确做法 |
|------|------|----------|
| 只有数据没有结论 | 贴了一张CPM趋势图，说"CPM在第二周升高了" | 要追一句："CPM升高是因为高峰期竞争加剧，竞价成本上升" |
| 数据和客户无关 | 客户是看重ROI的电商品牌，你放了大量CPE分析 | 把客户关心的放前面，支撑性指标放后面 |
| SOV拿聚光数据就算 | 聚光后台是代子账号维度有偏差 | 找直客拉全品牌数据 |
| 回搜率按关键词维度报 | 回搜率是by笔记维度 | 蒲公英后台按笔记导出 |
| 回搜率报0.3%说"低" | 无行业基准 | 默认基准0.5%，低于再判断 |

## 5. Part 2 内容策略分析怎么写

### 5.1 什么时候用

- 需要向客户证明"内容的钱没白花"
- 客户想看到"什么样的内容有效/为什么有效"
- 尤其是种草型项目，内容策略分析是核心

### 5.2 Overall 内容效果

**笔记数据概览总表（按笔记方向归纳）：**

| 笔记方向 | 笔记数 | 总曝光 | 总互动 | CPE | CTR | 优质笔记数 |
|----------|--------|--------|--------|-----|-----|-----------|
| 品类科普 | 15 | 120w | 8w | 1.5 | 6.2% | 3 |
| 使用教程 | 10 | 85w | 5.2w | 1.3 | 7.1% | 4 |
| 口碑种草 | 12 | 95w | 6.8w | 1.8 | 5.8% | 2 |

**博主量级/数量/内容分配篇数/数据达成：**
- 头部KOL：2人×3篇  -  总曝光50w，整体CPE 2.1
- 腰部达人：8人×5篇  -  总曝光120w，整体CPE 1.3
- KOC：20人×3篇  -  总曝光80w，整体CPE 0.9

### 5.3 优质笔记分析

> 注意： **不用行业爆文定义好坏，用客户目标定义好坏。**

**方法：** XY轴四象限分析

**X/Y轴选择（匹配客户目标）：**

| 客户最关心 | X轴用 | Y轴用 |
|-----------|-------|-------|
| 种草效果 | 回搜率 | CPE |
| 引流电商 | 进店成本 | 转化率 |
| 品牌曝光 | CTR | 互动量 |
| 深度种草 | 回搜率 | TI深度种草人数 |

**四象限分析结构：**
```
                    Y轴（高）
                    │
          低X高Y    │    高X高Y
          ──────────┼──────────
          低X低Y    │    高X低Y
                    │
                    X轴（高）
```

- **高X高Y：** 好内容，可复用类型
- **高X低Y：** 内容有亮点但投放可优化
- **低X高Y：** 投放精准但内容不够好
- **低X低Y：** 放弃

**注意：** 有定量取数范围值，不要只看相对位置。

### 5.4 评论区洞察

**目的：** 发现用户真实关注点

| 维度 | 分析内容 | 输出 |
|------|---------|------|
| 正向评论高频词 | 用户喜欢什么 | 品牌可放大卖点 |
| 负向/疑问评论 | 用户的顾虑/疑问 | 品牌可优化改进的方向 |
| 竞争品牌提及 | 用户在对比哪些品牌 | 竞品定位参考 |

**模板：**
```
【评论区洞察】
· 高频正向词：质地轻薄（35次）、不刺激（28次）、包装好看（15次）
· 高频疑问词：会不会过敏（22次）、适合油皮吗（18次）、哪里买（12次）
· 品牌建议：①下期内容增加"敏感肌可用"的认证背书 ②完善购买链路引导
```

### 5.5 UGC 洞察

| 分析维度 | 操作方法 | 输出 |
|----------|---------|------|
| UGC数量 | 搜索品牌词，统计自然UGC发文量变化 | 判断种草外溢效果 |
| 讨论内容 | 随机采样100条UGC评论，归类 | 洞察用户自发讨论的热点 |
| 品牌词云 vs UGC核心关联度 | 对比品牌官方内容词云和UGC词云 | 找到品牌沟通和用户认知的gap |

### 5.6 竞品分析 Case Study

**竞品选定三原则：**
1. 优质赛道品牌（赛道有增长潜力）
2. 花钱多的（愿意投入的，有学习价值）
3. 产品类似的（直接竞品，对标意义大）

>  **如果客户有"死对头"，优先选那个。**

**浅层指标分析：**

| 指标 | 说明 |
|------|------|
| 商单笔记数 | 竞品投放了多少篇商业笔记 |
| 预估投放金额 | 根据达人量级×行业均价估算 |
| 笔记曝光/阅读/互动量 | 竞品内容表现 |
| 搜索热度趋势 | 竞品品牌词搜索热度变化 |
| 笔记内容规划 | 竞品的内容方向和切入点 |

**深度指标分析：**

| 指标 | 数据来源 | 说明 |
|------|---------|------|
| 人群渗透 | 灵犀 | 竞品在品类人群中的渗透率 |
| 阅读渗透 | 灵犀 | 竞品内容阅读占比 |
| 搜后曝光渗透 | 灵犀 | 竞品搜索端曝光占比 |
| AIPS（含TI人数） | 灵犀 | 竞品的人群资产量级 |

**品牌广告分析：**
- 竞品做了什么品牌广告（IP联名/线下活动/电商大促）
- 这些动作对竞品数据的正向影响
- 可复用的点（但不是照抄，要适配自身品牌调性）

## 6. Part 3 竞价策略分析怎么写

### 6.1 什么时候用

- 竞价消耗占比高的项目（F场+S场占大头）
- 客户关注投放效率（CPUV/CPE/ROI）
- 需要向客户证明"投流的钱花得值"

### 6.2 投放策略三段论

| 阶段 | 时间 | 核心任务 | 操盘动作 |
|------|------|----------|----------|
| **测试期** | 第1-2周 | 赛马测试 | ①多条素材同时测试 ②挖掘低成本潜力笔记 ③搜索端露出，占住核心词位 |
| **放量期** | 第3-5周 | 放量优化 | ①CPE低成本笔记加大预算 ②出价定向优化 ③扩大人群覆盖 |
| **转化期** | 第6周起 | 收割转化 | ①集中高转化人群 ②放大粉丝定向 ③TI成本降低，深层人群累积 |

### 6.3 渗透策略

```
人群圈选  -  数据验证  -  优化迭代
```

**验证标准：**

| 指标 | 对比基准 | 判断 |
|------|---------|------|
| CTR | 行业benchmark | 高于基准 - 人群精准 |
| CPE | 行业benchmark | 低于基准 - 互动效率高 |

### 6.4 广告位策略

| 广告位 | 定位 | 哪项指标最优 | 原因 |
|--------|------|-------------|------|
| **信息流** | 高效触达层 | CPM | 曝光成本低，覆盖面广 |
| **视频流** | 深度互动层 | CPE/完播率 | 视频内容停留时间长，适合深度种草 |
| **搜索** | 精准转化层 | CTR/SOV | 搜索用户意图明确，转化率高 |

> **每层分析：** 该场域哪项指标最优 + 为什么最优

### 6.5 人群包分析

| 人群包类型 | 对比指标 | 基准 | 判断 |
|-----------|---------|------|------|
| **曝光人群** | CPM | 行业benchmark | 高 - 需优化；低 - 效果好 |
| **互动人群** | CPE | 行业benchmark | 高 - 需优化；低 - 效果好 |

**总结维度：**
- 正确： **好的：** 哪些人群包效果好，可复用
- 注意： **需优化的：** 哪些人群包效果一般，需要调整
- 错误： **需停投的：** 哪些人群包完全无效，建议停投

### 6.6 错误： 常见错误

| 错误 | 正确做法 |
|------|----------|
| 只说"信息流CPE为1.5" | 加上"比行业benchmark 2.0低25%，说明信息流触达效率高" |
| 不区分场域分析 | 信息流/视频流/搜索三个场域分开分析 |
| 人群包分析只有数据没有结论 | 每个数据后面跟一句话建议 |
| 三段论只写阶段名称 | 每个阶段配上具体数据验证，证明阶段划分有效 |

## 7. Part 4 后续投放建议怎么写

### 7.1 什么时候用

- 所有对客结案的结尾
- 客户想看到"做完这一轮，下一轮怎么办"
- 增购/续约的钩子

### 7.2 行业洞察数据源地图

| 来源 | 功能 | 优缺点 |
|------|------|--------|
| **蒲公英创意中心-内容广场** | 竞品关键词+上下游词+商业笔记分类+博主量级 | 正确： 方便操作 错误： 只支持30天内 |
| **千瓜品牌/品类搜索** | 博主/笔记/花费/数据/行业/画像/舆情 | 正确： 操作简单 错误： 第三方平台口径不一致/维度局限 |
| **灵犀洞察-行业-市场机会** | 品牌赛道表现/搜索量/SOV/渗透排名/SPU竞争格局 | 正确： 数多且全 错误： 使用不顺畅/部分品牌未开通 |
| **直客拉取** | 大盘数据/benchmark/竞品消耗 | 正确： 准确 错误： 依赖直客配合 |

### 7.3 四象限行业格局分析

```
                    搜索量（高）
                     │
           高阅读    │    高阅读
           低搜索    │    高搜索
           ──────────┼──────────
           低阅读    │    低阅读
           低搜索    │    高搜索
                     │
                    搜索量（低）
```

| 象限 | 诊断 | 策略建议 |
|------|------|----------|
| **高阅读 高搜索** | 品牌已有声量和心智 | 保持优势，加大预算投入 |
| **高阅读 低搜索** | 内容好但搜索引导不足 | 优化关键词策略，内容中增加搜索引导 |
| **低阅读 低搜索** | 品牌整体声量不足 | 综合提升，KFS全部上阵，加大投入量 |
| **低阅读 高搜索** | 用户搜索但内容不够 | 优化内容质量，拉大笔记量，提高CTR |

### 7.4 下一步建议三维度

| 维度 | 建议方向 | 问题清单 |
|------|----------|----------|
| **内容** | 角度放大/放弃、笔记数量形式配比、热点追踪 | 哪些角度效果好要继续放大？哪些角度放弃？图文vs视频配比？ |
| **竞价** | 人群圈选、投放目标、搜索词优化 | 人群包要不要换？投放目标是否调整？搜索词要不要加否定？ |
| **执行对接** | SOP对接、审稿对齐、反馈时效 | 审稿流程怎么优化？反馈时效能不能缩短？ |

## 8. 策略型结论怎么写

### 8.1 结论优先三段式（原始版）

**公式：** ①细节数据成果  -  ②结论（好不好+量化）  -  ③什么策略导致  -  ④后续动作建议

**操作步骤：**
1. 把所有动作和数据列出来（草稿状态，不急着写）
2. **语句升维** -- 从"我们做了A"变成"A策略导致B效果"
3. **做减法** -- 删掉那些"说了也白说"的数据

**错误： 非策略写法：**
> "我们有15篇笔记，其中3篇CTR超过8%，CPE平均1.2元。"

**正确： 策略写法：**
> "我们验证了'生活场景化封面+卖点化标题'的内容组合效果最优。3篇采用该组合的笔记CTR全部超过8%（平均33%），CPE仅1.2元（低于整体均值50%）。建议后续项目将上述组合纳入标准Content Brief模板。"

### 8.2 五条红线 -- 数据与结论必须有因果关系

> **这是最容易被客户/领导怼的地方。每条红线都是一次'你确定吗'的检验。**

#### 错误： 红线①：CPM≠人群精准

| 错误说法 | 为什么错 | 正确说法 |
|----------|----------|----------|
| "CPM低说明我们人群圈得准" | CPM只能反映系统竞争力（出价和流量竞争），不能反映触达人群是否精准 | 精准要看CTR和CPC -- CTR高说明封面+标题对目标人群有吸引力，CPC低说明点击成本低 |

#### 错误： 红线②：进店UV量≠引流高效

| 错误说法 | 为什么错 | 正确说法 |
|----------|----------|----------|
| "进店UV高说明引流效率好" | 进店UV量只能说明跑量好，不能说明引流效率高 | 引流效率要看进店率（进店UV / 引流UV） |

#### 错误： 红线③：进店率和转化率优于大盘≠GMV更高

| 错误说法 | 为什么错 | 正确说法 |
|----------|----------|----------|
| "进店率和转化率优于大盘，所以这一波带来的GMV更高" | 只能说明性价比高，GMV同时取决于钱能不能花够花完 | 应该分两个论点：①转化效率好（性价比）②消耗是否到位（花钱能力） |

#### 错误： 红线④：本身体质差异不能直接对比

| 错误说法 | 为什么错 | 正确说法 |
|----------|----------|----------|
| "我们搜索量涨了20%，是因为投放做得好" | 如果搜索量与电商大促节奏正相关，要先放大盘搜索趋势做对照 | "6月整体大盘搜索趋势上涨30%，我们的搜索量上涨20%，增幅略低于大盘" |

#### 错误： 红线⑤：引流率+转化率高≠市场竞争力强

| 错误说法 | 为什么错 | 正确说法 |
|----------|----------|----------|
| "引流率和转化率双高，说明品牌自带心智优势" | 引流率和转化率高表明点击人群精准+电商价格机制符合需求，与品牌市场竞争力和心智占有率无关 | 只论证"投放效率好"，不延伸到"品牌力强" |

### 8.3 最小暴露负面原则

| 原则 | 说明 | 示例 |
|------|------|------|
| **占比恒定时的此消彼长** | 某一时段该指标占比下降但总量上升  -  是自然现象而非投放问题 | "搜索SOV从25%降到20% - 同期整体搜索量翻倍，投放搜索量也增长60%，只是没有大盘快" |
| **热度下降做外部归因** | 竞品做了什么？大盘是否下行？节日/热点是否消退？ | "品牌搜索热度下降主要因为xx竞品同期做了IP联动，分流了品类关注度" |

### 8.4 数据结果必须有结论 + So What

**错误： 只有数据：**
> "本轮投放总曝光500w，CPC 0.8元，CPE 1.5元，CTR 6%，CPUV 3.2元，ROI 1:2.8。"

**正确： 有结论+So What：**
> "核心发现：CPE（1.5元）优于行业benchmark 30%，但CPUV（3.2元）偏高。  
> 原因：高互动率说明内容种草力强，但ROI转化链路中出现了用户从笔记到商品页的流失。  
> So What：下轮在笔记中增加「直接加购引导」+「限时利益点」，缩短种草 - 转化路径。"

#### 缺失归因时要追问

> **如果客户问"为什么提升"而你回答不出，是因为你没有往深处挖。**

**追问链条示例：**
```
问：CPE下降了30%，为什么？
答：因为笔记互动变高了。
再问：为什么笔记互动变高了？
答：因为用了"xx话术"的笔记占比从20%提升到了60%。
再再问：为什么"xx话术"效果好？
答：因为xx话术击中目标人群的在护肤上的核心痛点。
 -  最终结论：CPE下降30%根因是内容策略调整 -- 放大"xx话术"方向，该话术精准击中xx人群的护肤痛感，互动意愿更强。
```

#### 展示差异化动作

> **笔记铺量+投流放量，所有代理商都能做 -- 客户为什么要选你？**

| 错误： 非差异化 | 正确： 差异化 |
|------------|----------|
| "我们铺了50篇笔记" | "我们通过笔记方向测试，发现'xx风格'内容CPE比'yy风格'低40%，于是集中资源放大了xx方向" |
| "我们投了信息流" | "我们设计了三阶段投放节奏：测试期验证CPE模型 - 放量期按CPE梯队分配预算 - 转化期聚焦TI成本最低的人群包" |

### 8.5 五问法 -- 深挖根因

**方法：** 连续追问5个"为什么"，直到找到可操作的根因。

**示例：CPUV高**

| 追问 | 回答 |
|------|------|
| Q1：为什么CPUV高？ | 因为进店转化率低 |
| Q2：为什么进店转化率低？ | 因为用户只对IP感兴趣，对产品无购买意图 |
| Q3：为什么内容吸引这类用户？ | 因为素材过于侧重IP，未突出产品功能 |
| Q4：那根因是什么？ | 内容卖点与IP流量错配 -- IP引流来了但产品没接住 |
| Q5：怎么解决？ | 【根因结论】IP类内容需要做到"IP引流 - 产品承接"的完整链路，在笔记中明确产品卖点+直接购买指引 |

**再示例：搜索量低**

| 追问 | 回答 |
|------|------|
| Q1：为什么搜索量低？ | 因为用户没有搜我们 |
| Q2：为什么用户不搜？ | 可能不知道这个品牌，或知道了但没有搜索动机 |
| Q3：那是搜索占位的问题吗？ | 和搜索占位无关 -- 我们SOV已经到25%了，排在前三 |
| Q4：所以根本原因是什么？ | 用户缺乏搜索动机 -- 看了笔记觉得"还行"但没到"要去搜一下"的程度 |
| Q5：怎么解决？ | 【根因结论】搜索量低不是搜索占位的问题，而是要激发用户搜索行为 -- 在笔记中增加"搜索引导利益点"（如：搜xx领优惠券） |

**用结果解释结果的大忌：**

| 错误： 错误 | 正确： 正确 |
|----------|----------|
| "转化率低是因为价格太贵" | "转化率低指向用户对高客单价价格敏感  -  尝试叠加消费能力人群投放测试" |
| "搜索量低是因为搜索SOV不够" | "搜索量低与我们搜索占位无关  -  要做的是激发用户搜索行为" |

### 8.6 好的结构 vs 不好的结构

| 错误： 不好的结构 | 正确： 好的结构 |
|-------------|-------------|
| 只有事实数据（ROI 1:3，CPE 1.2） | 有事实数据 + 有洞察结论 + 有投放建议 |
| 数据和结论拼凑（CPM低 - 人群精准） | 数据和结论有因果关系（CTR高 - 人群精准） |
| 只说问题不给解法 | 每个问题后面跟So What |
| 避重就轻只报喜 | 负面用"最小暴露"原则，坦诚+归因 |

## 10. 视觉怎么呈现

### 10.1 呈现三原则

| 原则 | 解释 | 检查清单 |
|------|------|----------|
| **最大程度可视化** | 字数越少越好，逻辑越清晰越好 | ①每页能不能少写50个字？②这页是不是一张图就说明白了？ |

## 附录：速查卡片

### 速查①：回搜率定义

> 用户看过广告流量笔记后48小时内搜索过特定词的比率。  
> **计算公式：** 点击广告后48小时内搜索过回搜词的用户去重人数 / 点击广告用户去重人数  
> **注意：** by笔记维度，不是by关键词维度。无行业benchmark默认0.5%。

### 速查②：SOV/SOC

> **SOV（声量占比）：** 品牌广告曝光量 / 该关键词所有广告曝光量  
> **SOC（点击占比）：** 品牌广告点击量 / 该关键词所有广告点击量  
> **来源：** 找直客拉全品牌数据 -- 聚光后台只是代子账号维度，有偏差。

### 速查③：KPI三层分级

| 层级 | 说明 | 数量 |
|------|------|------|
| P0 | 北极星指标，与目的最相关 | 2-3个 |
| P1 | 核心过程指标 | 2-4个 |
| P2 | 参考指标（浅层） | 1-2个 |

### 速查④：三力拆解法

| 力 | 含义 |
|----|------|
| 策略力 | 方向对不对、打法对不对 |
| 执行力 | 落地的质量和速度 |
| 管理力 | 流程和协同效率 |
| 客观原因 | 大盘变化/竞品投放/品牌限流等不可控因素 |

### 速查⑤：分析型句子公式

```
① 细节数据成果（🟢好/🔴不好/🟣策略动作）
 -  ② 结论（好不好 + 量化）
 -  ③ 什么策略导致
 -  ④ 后续动作建议
```

### 速查⑥：五问法

```
现象  -  Q1为什么  -  Q2为什么  -  Q3为什么  -  Q4为什么  -  Q5为什么  -  根因
```
不是"用结果解释结果"，而是追到可操作的根因。

### 速查⑦：人群画像三维度

| 维度 | 内容 | 反映什么 |
|------|------|----------|
| 基础信息 | 性别/年龄/婚恋/母婴/消费水平/固定资产/地域/城市/消费档次 | 基本形象+消费能力 |
| 消费偏好 | 行业品类偏好/品牌偏好/消费金额/手机价格/品牌型号 | 消费习惯和态度 |
| 内容偏好 | 内容兴趣偏好/内容关键词偏好/搜索词偏好/热点关注偏好/博主偏好 | 内容行为习惯 |

> **占比**反映整体特点，**TGI**反映偏好程度

### 速查⑧：四象限场景汇总

| 使用场景 | X轴 | Y轴 | 产出 |
