# 第一章 核心发现与咨询窗口

## 1.1 核心发现

发现一：猫哆哩是酸角食品品类的绝对领导者，品类独占性是其最不可复制的核心资产。 从2003年首创酸角糕至今20年，猫哆哩在酸角食品品类建立了从种质资源（自有品种猫哆哩1号/2号）到种植基地（3200亩）到加工产能（20000吨）到品牌认知（中国驰名商标）到全国渠道的全链条壁垒。酸角食品全国年消费规模约10-15亿元 [mapped]，猫哆哩占品类认知份额约80% [mapped]，品类独占地位在全国零食行业中极为罕见。这意味着猫哆哩的增长不是零和博弈，品类扩张的收益几乎全部归属于猫哆哩。

发现二：溜溜梅以16.16亿营收（2024年）和100亿HKD估值（2026年）验证了品类聚焦+单品突破的可资本化路径，但核心品类已现衰退信号。 溜溜梅从梅干零食做起，通过梅冻开辟第二增长曲线，成功完成了从小品类到百亿市值的跨越。但2025年梅干零食收入同比下滑14.8%，营收增速从22.24%骤降至5.86%，显示出品类天花板的现实压力。溜溜梅的革命性创新——梅冻（天然果冻市占率45.7%）为猫哆哩提供了品类扩张的最佳参考案例。

发现三：猫哆哩的B端业务夜草生物科技是集团利润的重要支撑但被严重低估。 罗望子多糖市场价约150-200元/kg [mapped]，远高于酸角果泥产品，估测B端贡献集团30-40%的利润 [mapped]。烟草行业客户提供了稳定的利润池，但B端与C端几乎没有战略协同——这既是猫哆哩的财务稳定器，也可能是战略分散的根源。

发现四：酸角食品赛道的竞争格局极其友好，但品类自身的天花板正在制约猫哆哩的增长。 酸角食品赛道呈现一超多零的格局，猫哆哩在品类内几乎没有成规模的竞争者。但品类天花板约10-15亿元严重限制了猫哆哩的增长想象空间。中国果类零食市场已达520亿元（2024年），酸角食品仅占约2-3% [mapped]，品类扩张的空间巨大但亟需主动的品类教育投入。

发现五：猫哆哩的内容体系建设严重缺位，这是制约品牌全国化的最大瓶颈。 与溜溜梅的成熟内容体系（明星代言+社媒运营+新品发布）相比，猫哆哩在内容端几乎处于空白状态。品类独占意味着品类教育的收益1:1归属于猫哆哩，内容体系的投资回报率在食品行业中可能最高。品类教育的内容缺口也是猫哆哩增长确定性最强的方向。

发现六：云南超级食物（酸角/多依果/姜黄）的功能化产品创新是猫哆哩从地域品牌到全国健康零食品牌的战略跳板。 减糖化升级、酸角益生菌软糖、酸角罗汉果润喉糖等创品方向具有高趋势契合度和高能力匹配度。猫哆哩的自有供应链和品类独占地位为产品创新提供了独特的竞争优势——在酸角食品领域的任何创新都具有先天的消费者信任基础。

发现七：猫哆哩的供应链垂直整合程度在食品行业中极其罕见，既是壁垒也是增长约束。 自有种质资源圃、3200亩种植基地、20000吨产线的配置更像农业科技公司而非零食品牌。酸角树5-8年的挂果周期意味着任何新进入者需要至少5年时间才能开始追赶猫哆哩的供应链。但这种重资产模式也决定了猫哆哩的增长节奏无法像溜溜梅那样轻快。

## 1.2 咨询窗口

窗口一：品类扩张窗口。 酸角食品的品类认知仍局限于云南，但健康零食趋势正在为酸角食品打开百亿级的市场空间。猫哆哩的品类独占地位意味着当前是投入品类教育的最佳时机——品类教育的成本全部由猫哆哩承担，但品类扩张的收益也全部由猫哆哩享受。燃创咨询可提供品类扩张策略（品类延伸路径+产品创新管线+消费者测试），帮助猫哆哩制定从15亿品类到50亿+品类的路线图 [speculation]。

窗口二：品牌升级窗口。 猫哆哩的品牌定位需要从云南伴手礼升级为全国健康零食，这需要品牌视觉升级、品类教育内容体系建设、渠道升级三个维度的系统化改造。燃创咨询可提供品牌战略升级方案（定位重塑+视觉升级+内容体系建设），帮助猫哆哩完成从地域品牌到全国品牌的跨越。

窗口三：资本化窗口。 溜溜梅的百亿港元估值验证了品类聚焦+单品突破的资本化路径。猫哆哩的品类独占地位和全产业链壁垒在资本市场上可能获得比溜溜梅更高的估值溢价。但猫哆哩当前缺乏资本化的战略规划——B端和C端的业务结构需要梳理，品牌故事和增长叙事需要重新构建。燃创咨询可提供集团战略梳理和资本化路径规划，帮助猫哆哩为未来的资本化做好准备。

## 1.3 研究方法与数据来源说明

本报告的研究方法以电商平台一手数据为基石，辅以上市公司公开财报、行业研报交叉验证和公开信息推断，综合采用五维扫描法和创品策略框架。

核心数据来源包括：天猫和京东平台的产品详情页数据（价格、销量、评论数、付款人数、评分等），在统一的搜索条件下采集，数据采集日期为2026年7月。溜溜果园集团（06658.HK）2025年度财报和招股书数据属于公开可查证的confirmed层级。行业研报数据来自华信人研究院、艾瑞咨询等公开报告，属于reported层级。其余基于电商数据推算的市场规模、品牌认知份额等数据属于mapped层级，基于趋势判断的增长预测属于speculation层级。

研究框架采用V4五维扫描法，对每个深度品牌从市场渠道、品牌力、产品力、趋势适配、人群画像五个维度进行系统分析。创品策略基于云南超级食物功效研究（酸角、多依果、姜黄三种物种）和中医归经理论，结合零食消费趋势进行产品创新方向研判。本报告的输出格式以段落为核心单元，每个段落遵循"结论先行→数据支撑→收尾判断"的结构规范，避免关键词碎片和对读者的段落理解负担。
