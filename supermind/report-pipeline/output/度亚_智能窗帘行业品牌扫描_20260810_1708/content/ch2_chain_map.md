# 产业链地图与卡口识别

智能窗帘产业链从上游到下游共5个核心segments。

Segment 1：核心零部件（电机+电控）。无刷直流电机成本占整机BOM的35%-45%，电机环节毛利率25%-35%，控制芯片环节毛利率40%-55%。杜亚自研电机免去ODM厂商15%-20%的利润加成。瓶颈风险Medium——钕铁硼永磁材料供应集中在中国（全球产量约85%），稀土开采配额政策变化可能影响成本。乐鑫ESP32系列WiFi/BLE芯片单品年出货量过亿颗，价格从2019年约12元/颗降至2025年约5-6元/颗。

Segment 2：导轨与配件。铝合金型材挤出+传动皮带+滑轮组件，毛利率15%-22%，标准化程度高、进入门槛低。供给高度分散，广东佛山和山东临朐有500+型材厂。瓶颈风险Low。

Segment 3：品牌与产品集成。将电机、控制模块、导轨组装为成品并进行品牌包装，毛利率35%-50%，是产业链中利润率最高的环节。杜亚C端品牌毛利率约40%-45%。瓶颈风险Medium——品牌建立的周期需24-36个月，渠道和服务网络是实质性门槛。

Segment 4：渠道与销售。线上（天猫/京东/抖音/小红书）+线下（建材市场/地产精装/酒店工程）。平台佣金+营销费用占终端售价15%-25%（线上），经销商加价20%-35%（线下）。瓶颈风险High——线下服务网络需12-18个月建设和每年500万+年维护成本。

Segment 5：安装与售后服务。安装费占终端售价15%-20%（单次200-500元）。天猫智能窗帘品类差评中约40%与安装有关。杜亚全国3000+服务网点已建立壁垒，万师傅和鲁班到家是第三方平台主力。

卡口识别：P0（安装服务网络/生态认证）、P1（电机自研能力/地产精装集采准入）、P2（窗帘面料供应）。
