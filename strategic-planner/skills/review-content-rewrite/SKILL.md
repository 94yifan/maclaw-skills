# 复盘内容重写 Skill

## 定位

根据上游 `review-revision` 输出的修改方向，将复盘报告的指定页面/段落重写为可直接使用的目标格式内容。输出是重写后的文字段落，不是修改建议。

## 核心原则

**重写的质量 = 格式匹配度 × 数据准确度 × 衔接完整度。** 三者缺一不可。

## 三步前置（开始重写前必执行）

### 第一步：确认输出格式

重写前明确目标载体，不同载体对应不同的约束：

| 格式 | 每页字数上限 | 结构要求 | 额外约束 |
|------|-------------|----------|----------|
| PPTX slide | 150-200字 | 标题一句话结论 + 2-3个要点 | 标题本身承担结论功能，不需要在正文重复标题 |
| 飞书文档 | 300-500字/板块 | 小标题分段 + 段落叙述 | 可用加粗标记核心结论 |
| 邮件正文 | 200-400字/条 | 一主题一段 | 不加标题层级，用分段区分主题 |

**关键认知：PPTX不是文档。** PPTX的标题大字已经在说结论了，正文是支撑标题的论据和数据，不是在正文里再写一遍标题。给PPTX写重写段落时，如果标题已经明确写了"CPM和CPE大幅领先行业最低值"，正文就不用再写一遍这句话，直接写数据支撑和为什么。

### 第二步：标记数据完整度

重写段落中每个数字标注来源状态：

- 已有精确数据 → 直接写入数字
- 需要从原始数据补入 → 用 `[待补：数据说明，来源路径]` 占位
- 基于已有数据的推断 → 标注 `[推断]` + 推断逻辑

**禁止：** 用 `XX` 或 `XX%` 这种无信息的占位符。读者不知道XX是什么、从哪找。

正确占位示例：
- `环比下降[待补：AIPS 7月末 vs 6月末精确值，来源：灵犀-度量-人群资产]%`
- `口碑通CPE较6月下降[待补：6月CPE精确值，来源：Slide 10数据表]%`

错误占位示例：
- ❌ `环比下降XX%`（XX是什么？从哪找？）
- ❌ `预计回[待确认]水平线以上`（确认什么？找谁确认？）

### 第三步：标注页间衔接

PPTX格式重写时，必须标注这一页和前后页的逻辑衔接：

```
[前页承接：从Slide X的[前页核心信息]过渡到本页]
...重写内容...
[后页引导：本页结论指向Slide Y的[后页主题]]
```

如果修改的是独立页（如新增的汇总页），标注"新增独立页，前后无强制衔接"。

## 重写内容结构模板

### 复盘数据页（如 Slide 4 投放成本回顾）

```
[定性结论一句话] → [关键数据对比] → [与大盘/上月的差距或优势] → [一句话解释原因] → [对下月的启示]
```

### 归因分析页（如 Slide 5 人群分析）

```
[现象描述] → [环比率值] → [归因分两层：原因1 + 原因2] → [两因叠加的结论] → [下月预期 + 恢复条件]
```

### 渠道效率页（如 Slide 10 FS总体回顾）

```
[总体结论] → [各渠道分述：信息流/搜索/口碑通各2-3句] → [问题渠道诊断路径展开] → [结论：是结构性问题还是出价问题] → [解法方向]
```

### 竞品汇总页（如 Slide 29）

```
[每条竞品一句提炼：节奏/内容/投放模式] → [瑞幸可复用的三条SOP] → [按执行难度排序的优先行动表]
```

### 热点连接页（如 Slide 34 开学季→投放）

```
[热点方向] → [为什么匹配] → [内容方向+投放动作+时间周期] → [预算定位：灵活补充测试，不占核心预算]
```

## 重写铁律

1. **不改数据、不改事实。** 只改表达方式和信息组织。
2. **不跨文档引用。** 重写内容中引用的数据必须来自当前文档内已有的信息。
3. **不加无证据的数字。** 不给报告中不存在的数字。
4. **格式化占位符。** 需要补的数据用 `[待补：说明，来源]` 格式，不用 `XX` 或 `???`。
5. **PPTX正文≠标题复读。** 标题已经说了结论，正文写支撑数据。

## 与 review-revision 的协作

```
review-revision → 输出修改方向和约束
        ↓
review-content-rewrite → 根据修改方向输出重写文字
        ↓
        → 如果review-revision前置三问有"待确认"项，重写时遇到相关部分标[待确认]不推测
```

## 常见失败模式

| 错误 | 表现 | 根因 |
|------|------|------|
| 文档思维写PPTX | 200字段落塞进一个slide | 没确认输出格式 |
| XX占位符 | 不知道XX是什么的占位符 | 没标注数据来源路径 |
| 孤立改页 | 改完Slide 12不管Slide 11和13的逻辑衔接变化 | 没做页间衔接 |
| 在PPTX正文重复标题 | 标题说"成本显著优于大盘"，正文第一句也说"成本显著优于大盘" | 没理解PPTX标题=结论 |
