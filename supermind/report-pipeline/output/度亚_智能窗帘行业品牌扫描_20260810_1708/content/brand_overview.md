# 品牌概览

## 度亚智能窗帘（杜亚 DOOYA）

度亚智能窗帘（宁波杜亚机电技术有限公司）是全球窗帘电机制造领域的绝对龙头。工信部国家级制造业单项冠军，全球窗帘电机市场占有率约30%-35%，12万平米工厂、88条产线、300+专利、2600+员工。2023年营收约20亿+，2021年引入高瓴资本战略投资后加速从制造驱动向品牌驱动的转型。

核心产品覆盖开合帘电机、管状卷帘电机、百叶帘电机、垂直帘电机、室外遮阳电机、开窗机、电池棒、太阳能板等13个品类。C端爆款包括隐形大师（全球首款星闪智能窗帘，749元起）、DT98/DT100隐藏式电机系列、V5/D9系列。全生态兼容米家、华为鸿蒙、天猫精灵、小度、Apple HomeKit五大IoT平台。

线上渠道以天猫杜亚旗舰店和京东杜亚官方旗舰店为双核心，抖音和小红书为内容增长引擎；线下3000+服务网点覆盖全国地级市，安装服务网络是行业中最坚固的竞争壁垒。

## 行业定位

智能窗帘/电动窗帘行业，处于品类从小众走向大众消费的扩张拐点。2026年中国智能窗帘市场规模超400亿元（《2026中国智能电动窗帘消费趋势白皮书》），年增速约30%，精装房渗透率约18%-22%，存量房改造渗透率不足2%。行业CR5约45%-55%，竞争格局正在从分散走向集中。
