## D. ★ 知识串联（核心）

### 缝合点1：Dreaming 单点依赖 × 08-10 缝合点4（单点依赖是系统级结构缺陷）→ 监控类 cron 需要「同构分身」failover

08-10 提出「凡依赖单一通道的机制必须预设 failover」。本次实证：主 session Dreaming 超时 4 天，SP/CEO Dreaming 全部正常——但分身复盘不覆盖主 session 产出（康师傅/芝华仕的复盘完全缺失）。**failover 不只是「另一个通道也能跑」，而是「另一个通道能覆盖同一职责」。**

整合结论：关键 cron 的 failover 设计必须回答「职责覆盖」而非「通道可用」——SP/CEO 的 Dreaming 通道可用但职责不同，等于没有 failover。真正有效的 failover = 分身 Dreaming 的 Step 0 增加「检查主 session 复盘缺口」子项（SP 的 memory/ 目录天然可见主 session 的 dreaming 文件缺失）。已建议 SP 下次 Dreaming 时评估。修复路径 = ①治本（timeout 900）②兜底（合并复盘先例）③体系（分身交叉检查主 session 缺口）。

### 缝合点2：芝华仕 config 品牌名三连坑 × 08-10 缝合点3（实体身份校验盲区）→ 实体校验从「QA 层」前移到「config 层」

08-10 杜亚「度亚」错字暴露实体身份校验盲区，提出 QA 层品牌名校验。08-15 芝华仕把问题升级：品牌名不止会写错，还会**写多**（带括号注释），导致路径断裂+两处 QA 失败。校验位置也要升级：QA 层校验是事后抓错，config 层校验是事前拦截。

整合结论：**实体身份校验应做双层——config 层硬校验（品牌名只允许纯名，禁止 `（）()/` 字符，读 config 时直接拒绝）+ QA 层软校验（正文品牌名逐字比对）**。config 层拦截能同时防「错字」和「多余内容」两类错误，成本低于 QA 层返工。这是「输入端守卫」（07-18 缝合点4）在品牌名维度的落地。

### 缝合点3：tier_inflation bug × 08-10 缝合点2（生成端与检查端成对落地）× 08-07 缝合点5（QA 工具输出真实性）→ 检查器自身的元错误

08-10 提出「QA 规则新增时同步在生成 prompt 强制对应输出格式，否则 QA 永远在抓生成器根本没做的错」。08-15 反向验证：**QA 检查器自己也会错**——`("确认", r'确认')` 误匹配 `[已确认]` 标注本身，把正确内容误报为层级通胀。这是「检查工具输出真实性」（08-07）的又一实例：检查器报错 ≠ 内容真错。

整合结论：QA 规则的正则/关键词必须做「自指排除」——检查器用的关键词不能匹配检查器自己产生的标记（`[已确认]` 里的「确认」）。通用规则：**QA 正则一律用负向断言排除标记上下文**（`(?<!已)确认(?!\])`），或检查器标记用特殊字符（如 `⟦confirmed⟧`）避免与正文词冲突。此教训可复用于所有自建 QA 系统。

### 缝合点4：SC「间歇性可用」第 3 个数据点 × 08-07 缝合点3（双轨信号源互补）→ 信号源健康度评估从「二元」升级为「三态」

SC 08-14 产出、08-15 错位、08-16 产出——连续 3 个数据点确认「间歇性可用」状态（非恢复、非线性退化）。SP 将状态追踪降频（连续缺失 ≥2 天或连续产出 ≥3 天才记录）。

整合结论：**信号源健康度三态 = 稳定可用 / 间歇性可用 / 停摆**。间歇性可用状态下：①主信号源照常消费（有就采）②替代源保持常开（补错位缺口）③状态记录降频（避免每日重复噪音）。三态评估替代「恢复/停摆」二元判断，监控成本随状态明确度下降。SC 停摆 1 个月后进入间歇性可用态，是 08-03「先建替代源再等修复窗口」策略的成果验证——替代源扛过了最坏窗口，主源自己缓过来了。

### 缝合点5：芝华仕 60000 字门槛 × 40KB 内容预检（08-03 阻断二）→ 产出规格的「字数密度」维度

Pipeline 已有 40KB 内容预检（阻断二，防骨架 docx），芝华仕新增 60000 字正文字数门槛（防内容单薄）。两个门槛都是「数量下限」，但管不同层：40KB 管「内容文件总量」（防空壳），60000 字管「docx 正文字数」（防注水不足）。

整合结论：**交付物质量门槛 = 总量门槛（40KB 内容）+ 密度门槛（60000 字正文）+ 结构门槛（QA 11 项）三层**。密度门槛的落地方式是「竞品五维 2500+/品牌」的单元字数规划——把总量拆到单元，subagent 生成时自带字数约束，避免首版 43781 字再二轮增补。此规则写入芝华仕 config 模板作为默认值。

### 缝合点6：SP 08-16 粉丝圈层节点（817 稻米节）× 08-08 节点级别框架（传统大节/行业级节点/品牌主动节点）→ 节点光谱第四类：粉丝圈层节点
