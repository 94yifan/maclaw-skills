# 第7章 模型后训练

## 本章核心论题

本章聚焦后训练（SFT 与 RL）如何将 Agent 利用上下文和工具的能力"沉淀"进参数——即优化全书公式 Agent = LLM + 上下文 + 工具 中的 LLM。第六章的评估体系与仿真环境是后训练的两块基石。本章从预训练、SFT、RL 的目的、原理及组合方式讲透，回答：能力在哪些阶段形成、如何选择组合、项目里该在哪一步下功夫。

## 关键论点与框架

### 论点一：模型能力开发分为预训练、SFT、RL 三阶段，三者统一于"预测下一个词"框架，区别仅在于数据、优化目标和代价
- **论证与机理**：SFT 与预训练数学上同一任务——预测下一个词、最小化同一损失函数。差别：① 预训练用原始文本，SFT 用"输入—输出"对；② SFT 损失只算回答部分（loss masking）。三阶段区别在于"想要什么"及"用什么信号定义想要"。
- **书中证据**：表 7-1——预训练用海量原始文本，代价数千万美元，学世界知识；SFT 用几千到几万条示范对，几小时到几天，学指令遵循与输出格式；RL 用任务环境加奖励信号，代价 SFT 几十到上百倍，学可迁移策略。
- **出处**：7.1 节。

### 论点二：SFT 更容易记住示范，RL 表现出更好的泛化——倾向源于优化目标不同
- **论证与机理**：SFT 最大化标注回答概率（极大似然），驱动复现示范序列，缺乏多样性时过拟合表面模式。RL 最大化期望奖励，探索多路径提高高奖励路径概率，可发现示范中未有的策略。SFT 倾向 mass-covering（覆盖式），RL 配合反向 KL 约束倾向 mode-seeking（寻峰）。
- **书中证据**：GeneralPoints 训练时 J/Q/K 计为 10，测试时分别计 11/12/13：RL 在 GP-L 上 +3.5%，SFT 下降 8.1%；视觉 OOD 上 RL +17.6%，SFT -9.9%。V-IRL-VL 多轮视觉导航中 RL 在规则和视觉 OOD 上均优于 SFT。但非普遍属性：数据多样时 SFT 也能泛化，奖励有偏时 RL 也会过拟合。
- **出处**：7.1.4 节、实验 7-11、7-12。

### 论点三：数据和环境比算法更重要——工业界最反直觉也最值钱的经验
- **论证与机理**：现成 RL 算法会用即可，成败取决于仿真环境保真度和训练数据质量。姚顺雨《The Second Half》回顾 OpenAI 认知演变：2015-2016 算法中心主义→2016-2018 环境→2018 至今先验觉醒。最终优先级：先验 > 环境 > 算法。很多场景下 SFT 数据质量到位甚至不需要 RL。
- **书中证据**：实验 7-2 Q-learning 跑 10000 局需近万次试错才收敛，LLM Agent 第一局 18 步通关——携带海量预训练先验，理解"门""钥匙""剑"的概念结构；规则变化时 Q-learning 需完全重训，LLM 推理直接适应。实验 7-3 固定小预算下算法改进（QK Norm 和 Muon 优化器，提速 3 倍）比堆规模更有性价比。
- **出处**：7.1 节开篇、7.2.2 节、实验 7-2。

### 论点四：结构化输出不稳定时，稳妥策略是"先 SFT 后 RL"——先形后神
- **论证与机理**：RL 用奖励评估模型自己生成的输出，格式混乱则奖励无法解析。SFT 先稳定输出格式，RL 才有打分起点。SFT 立"形"（格式、结构），RL 追"神"（策略、泛化）。在"较小基础模型 + 严格结构化输出"设定下成立。
- **书中证据**：实验 7-11 中未 SFT 直接对 Llama-3.2-Vision-11B 做端到端 RL 完全失败。但 DeepSeek-R1-Zero 证明强基础模型可跳过 SFT 直接 RL 成功，自发涌现反思与长链思考——代价是输出可读性差。最终 R1 仍加回"冷启动 SFT"把"形"立稳，正是"先形后神"的注脚。
- **出处**：7.1.3 节、7.6 节。

### 论点五：RL 的瓶颈不在算法而在环境工程——环境真实、可重置、可并行是前置条件
- **论证与机理**：RL 是试错学习，环境保真度决定策略可用性。造不出真实环境时可用模型模拟：两层——合成工具返回值（ZeroSearch）和仿真环境动态（DreamGym）。但模拟器知识是训练天花板，偏差被策略照单全收，RL 主动利用漏洞。稳妥做法：模拟承担大部分交互量，辅以真实环境定期校准。
- **书中证据**：ZeroSearch 用 LLM 扮演搜索引擎，课程式——初期返回高质量文档，逐步掺噪声，未见过真实搜索引擎的模型直接对接真实搜索依然良好。ReTool 和 AWorld-train 因真实 API 限速、封号、有副作用而搭沙盒。
- **出处**：7.9 节、7.9.2 节。

### 论点六：GRPO 是当前最常用 RL 算法之一，核心机制是同题多条 rollout 组内比较计算相对优势
- **论证与机理**：一次迭代：① 策略模型对同问题生成多条 rollout；② 验证器计算奖励；③ 组内比较计算相对优势（高于平均正、低于平均负）；④ 梯度下降更新。GRPO 同题比较不需额外价值模型；PPO 训练价值模型估计基线适合长轨迹；DPO 离线学习偏好对。均限制单次更新幅度。
- **书中证据**：SWE-bench——16 次 rollout 4 次全通过、12 次失败，组内平均成功率 25%。全成功或全失败时相对优势消失，正是 RLVP 路径信号要解决的问题。复杂 Agent rollout 最慢约 2000 秒，梯度下降约 600 秒，100 steps 接近 72 小时。
- **出处**：7.8 节。

### 论点七：奖励设计沿三个互补维度——来源、时机和信息量；结果奖励解决"办没办成"，路径约束解决"是否按规定办成"
- **论证与机理**：三个维度——① 来源：规则验证（RLVR，最可靠）、人类偏好（RLHF）、模型评判（GRM）；② 时机：结果奖励（ORM，探索自由但信号稀疏）vs 过程奖励（PRM，缓解信用分配但成本高）；③ 信息量：标量、向量、生成式诊断。RLVP 叠加路径信号：R = O + βΦ，O 为任务结果，Φ 为规则逐动作路径惩罚/奖励，两路归一化合并。
- **书中证据**：SimpleVLA-RL 用稀疏结果奖励将 LIBERO 成功率从 17.3% 提升到 91.7%，发现演示中未有的"推切"动作。V-IRL-VL 采用过程奖励，构成"密集反馈换收敛 vs 稀疏反馈换探索"对照。RLVP 将违规从 3.71 降至 0.66。reward seeking 与 reward hacking 的区别：前者不篡改测试但自设浅检查刚好通过。
- **出处**：7.11 节、实验 7-13、7-16。

### 论点八：On-Policy Distillation 把稀疏终点奖励扩展为逐 token 稠密监督，是提升样本效率的关键方向
- **论证与机理**：主流 model-free RL 只在 rollout 结束时得成败标量，中间错误无直接信号。On-Policy Distillation 让学生按自己策略生成轨迹，教师在学生访问的每个状态给下个 token 分布——T 长 rollout 产生约 T 组逐 token 监督，仅消耗计算。无更强教师时用 OPSD：同模型分饰两角，教师见特权信息，学生向教师对齐。
- **书中证据**：ReTool RL 训练时间是 SFT 的 200 倍（9 天 vs 1 小时）。On-Policy Distillation 在数学任务上达到同等性能所需步数约为纯 RL 的 1/10。OPSD 要求学生对着答案能讲清过程才有效，可能丢失原有思考风格。
- **出处**：7.12 节。

## 原则清单

1. **先判断是否需要后训练**：Harness 工程能解决就不训练。大多数应用落在这里。
2. **需要训练时先试 SFT**：成本低见效快，固化输出格式和协议性知识。不适合注入大量事实——需继续预训练或 RAG。
3. **SFT 不够时再加 RL**：适用于需泛化到新场景、探索最优策略、标注成本过高。前提是输出格式已稳定。
4. **输出不稳定时"先 SFT 后 RL"**：SFT 建立格式稳定性（先形后神），RL 发展策略。强模型可跳过但可读性差。
5. **数据质量压倒数量**：数千到数万条高质量样本通常足够。与其堆十万条脏数据，不如精修一万条。
6. **训练数据去重隔离**：去除身份信息、按任务/时间段划分，评估集须来自不重叠的类型。
7. **环境工程优先于算法选择**：RL 训练前确认环境真实、可重置、可并行。
8. **先测信号可达性再增加奖励维度**：纯结果奖励在全败和全胜组都产生零方差。违规易检测优先写路径惩罚。
9. **奖励函数依赖隐藏测试**：特别是"任务完成"判定不能依赖模型自己声明。
10. **边界集与保留集缺一不可**：只盯"不再过早结束"会把模型训练成不敢收尾。
11. **小规模验证关键假设**：少量数据测 SFT 能否稳定格式、简化环境测 RL 能否收敛。快速失败比大规模失败更可接受。
12. **组合 RAG、ICL 和后训练**：RAG 管事实（可更新可追溯），ICL 快速试验策略，程序固化流程，后训练写入难以用语言表达的泛化能力。
13. **LoRA 实践经验**：应用到所有主要权重矩阵（尤其 MLP 层），只加注意力层掉点；SFT 用中高 rank（64-256），RL 用小 rank（8-32）；RL 学习率约全参微调 10 倍。

## 失败模式与反例

1. **后训练记忆事实**：SFT 固化协议性知识，非大量事实。用 RAG 管事实。
2. **格式未稳定就引入 RL**：不稳定输出使训练信号变噪声。先 SFT 稳定格式。
3. **奖励黑客**：模型钻规则漏洞获高分。更隐蔽的 reward seeking——自设浅检查刚好通过。
4. **仿真保真度不足**：仿真过于简化致策略在真实场景完全失效。
5. **模型扮演环境的偏差**：模拟器知识是天花板，偏差被策略吸收，RL 主动利用漏洞。
6. **过度训练泛化下降**：训练损失降但验证恶化，模型死记细节。SFT 尤其易出现。
7. **价值函数崩溃与探索不足**（PPO 特定）：价值估计不准致优势偏差，温度过低陷入局部最优。
8. **低估 RL 计算成本**：SFT 表现好的任务转 RL 可能需 10-100 倍时间。
9. **训练数据质量低下**：SFT 直接学习噪声与偏差，错误固化为参数。
10. **过早结束的过度矫正**：只练"不要过早结束"可能让模型不敢收尾，无限验证。
11. **SFT 数据说话者过少**（语音 SFT）：导致所有人同一腔调。
12. **蒸馏的教师继承问题**：学生继承教师系统性错误，纯输出蒸馏丢失工具鲁棒性。

## 关键术语表

- **预训练**：在海量文本上预测下一个词，学得语言规律与世界知识，代价极高，能力地基。
- **SFT（监督微调）**：用标注"输入—输出"示范对训练，只对回答部分算损失，教会输出格式。
- **RL（强化学习）**：反复尝试根据结果奖惩改进策略，最大化期望奖励。
- **Loss Masking**：SFT 中问题部分不回传梯度，只监督回答，唯一实质性工程区别。
- **LoRA**：不动原始权重，附加低秩矩阵学习，参数量 1%-5%，降低显存和遗忘风险。
- **RLVR**：用测试用例、断言等确定性代码判断结果，最可靠奖励来源。
- **GRPO**：同题多条 rollout 组内比较计算相对优势，不需额外价值模型。
- **PPO**：训练价值模型估计基线、概率比裁剪抑制大幅更新，适合长轨迹。
- **DPO**：跳过奖励模型，从"较好—较差"偏好对离线优化。
- **RLHF**：人工比较训练奖励模型再用 PPO 优化，非本章 Agent RL 主线。
- **Rejection Sampling**：对同问题采样多条候选，验证器筛出正确样本做 SFT。
- **RFT**：拒绝采样数据做 SFT，介于 SFT 与 RL 之间。
- **ORM（结果奖励模型）**：只在 episode 结束时判断成败，信号稀疏探索自由。
- **PRM（过程奖励模型）**：中间步骤反馈，缓解信用分配，标注成本高。
- **GRM（生成式奖励模型）**：输出分数并生成诊断文本，可配合事实校验。
- **RLVP**：结果奖励叠加确定性路径信号，R = O + βΦ，两路归一化合并。
- **On-Policy Distillation**：学生按自己策略生成轨迹，教师每状态给逐 token 分布，稀疏变稠密。
- **OPSD（在轨自蒸馏）**：同模型分饰两角，教师见特权信息，学生向教师对齐。
- **MDP**：RL 数学框架，定义状态、动作、奖励，未来只取决于当前。
- **Q-learning**：为每"状态-动作"维护价值估计的离轨策略算法。
- **Credit Assignment**：判断多步中哪步对最终结果贡献最大。
- **Covariate Shift**：离线模仿中策略偏离示范入无数据状态，缺恢复信号。
- **Reward Hacking**：钻规则漏洞拿高分，与 reward seeking 不同。
- **CoT（思维链）**：回答前逐步推理，可通过蒸馏迁移。
- **VLA**：在 VLM 架构上输出动作，视觉到物理控制端到端。
- **Catastrophic Forgetting**：学新忘旧，LoRA 冻结基座缓解，继续预训练需混合数据。

## 高亮核心论断与金句

%%H%%SFT 在数学上和预训练是同一个任务——都是预测下一个词、最小化同一个损失函数。%%/H%%

%%H%%一句话概括 SFT 的本质：用极高的样本效率，把一套稳定的"输入→输出"映射与协议固化进参数。它固化的是"格式、风格、流程"这类协议性知识（该怎么说、怎么做），而非大量事实性知识（知道什么）。%%/H%%

%%H%%SFT 先把"形"（格式、结构）立起来，RL 再追求"神"（策略、泛化），即先形后神。%%/H%%

%%H%%数据和环境，比算法更重要。%%/H%%

%%H%%几十年来 RL 研究者的优先级可能完全颠倒了——不是算法 > 环境 > 先验，而是先验 > 环境 > 算法。%%/H%%

%%H%%环境失真，策略必废。这不是算法不行，是练习场跟考场不是一回事。%%/H%%

%%H%%模拟器的世界知识就是训练的天花板，模拟器的系统性偏差会被策略照单全收。%%/H%%

%%H%%奖励函数设计不当导致奖励黑客——模型学会钻奖励的漏洞来获得高分，而非真正完成任务。%%/H%%

%%H%%"通过了 grader"不能自动等价于"任务完成了"：评判器是意图的代理，训练越强，模型越可能把代理当成目标本身。%%/H%%

%%H%%在动手调算法之前，先问自己——我的仿真环境，真的像真实世界吗？这个问题的答案，比选 PPO 还是 GRPO 重要得多。%%/H%%

%%H%%很多场景下，只要 SFT 的数据质量到位，你甚至根本不需要做 RL。%%/H%%

%%H%%SFT 擅长覆盖多种已知写法，RL 擅长从候选行为中寻找高奖励策略。%%/H%%

%%H%%SFT 细致学习已有地图，RL 则可以拿着奖励这枚指南针探索地图外的候选路线。地图或指南针不准都会迷路。%%/H%%

%%H%%不是算法决定模型学到什么，而是训练信号教了它什么；而信号的质量，主要由数据和环境决定，不是由算法决定。%%/H%%

%%H%%与其堆十万条脏数据，不如精修一万条干净数据：数据里的每一处噪声，SFT 都可能忠实地写进参数。%%/H%%

%%H%%快速失败比大规模失败更可接受。%%/H%%

%%H%%当前 RL 的主要瓶颈是样本效率：On-Policy Distillation 把一条 rollout 的终点标量扩展为逐 token 监督，RLVP 则把被浪费的环境反馈变成可学习信号，两者是目前看起来最有希望的两个方向。%%/H%%

%%H%%它们的共同点是把环境和数据里本就存在、却被纯结果奖励浪费掉的信息，重新变成模型能学的东西。%%/H%%

%%H%%SFT 的记忆与 RL 的泛化，概括的是本章受控实验中观察到的倾向，并不是不受数据、模型、奖励与环境影响的普遍规律。%%/H%%
