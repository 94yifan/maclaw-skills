# 产品矩阵：瑞幸即享咖啡

瑞幸即享的产品矩阵核心判断是三线并进但尚无一根主线能扛起瑞幸在预包装赛道的心智，冻干、咖啡液、瓶装即饮三个品类都做了布局，但都还没有一款足以定义品类的大单品，这和三顿半的冻干、永璞的咖啡液、星巴克的瓶装形成了明显落差。瑞幸即享的产品可以按三个品类拆开看，每个品类对应不同的竞争逻辑和机会窗口（evidence_tier：mapped）。

冻干速溶咖啡粉是瑞幸即享切入预包装的第一个品类，也是竞争最激烈的一条线。这一品类已经被三顿半用精品化重新定义了，冻干咖啡粉不再是廉价速溶的代名词，而是精品咖啡的便携化表达。瑞幸即享的冻干粉延续了门店的生椰、厚乳等风味心智，把门店爆款的风味做成了冻干粉，这个差异化方向是对的，但在产品力和品牌叙事上还没有完全立起来，消费者在冻干粉这个品类里首选依然是三顿半（evidence_tier：mapped）。这一品类的价格带大致在2到10元一杯，瑞幸即享的定价需要在这条已经被三顿半教育过的价格带上找到自己的位置。

咖啡液是三个品类里增长最快、也是瑞幸即享相对薄弱的一环。永璞把咖啡液做成了品类的代名词，隅田川用胶囊咖啡液占据了挂耳和便携的交叉心智，连咖啡则在下沉市场用性价比打法起量。瑞幸即享的咖啡液如果继续沿用门店的生椰拿铁心智，做生椰拿铁浓缩咖啡液，理论上是有独家优势的，因为生椰拿铁这个爆款心智只有瑞幸真正拥有，把门店爆款做成浓缩液是瑞幸即享最顺的一条路（evidence_tier：mapped）。但咖啡液品类对新鲜度和冷链的要求，以及永璞、隅田川已经建立的先发优势，决定了瑞幸即享在这个品类上要打的是心智迁移仗，而不是从零开始。

瓶装即饮咖啡是三个品类里货架竞争最残酷的一条线，也是瑞幸即享最有门店心智优势的一条线。这一品类由雀巢和星巴克主导，雀巢的丝滑拿铁和星巴克的星冰乐、冷萃占据了商超和便利店的高端与大众两个位置，农夫山泉炭仌则用0糖0卡切走了健康即饮的心智。瑞幸即享的瓶装即饮如果能把生椰拿铁瓶装化，就有机会在货架上复制门店的爆款效应，但瓶装即饮的重资产、渠道分销门槛和星巴克雀巢的深厚护城河，决定了这条线最难打也最值得打（evidence_tier：reported）。

从产品迭代逻辑看，瑞幸即享最大的差异化武器是门店爆款心智的迁移。门店一年能推出上百款新品、沉淀出生椰拿铁、酱香拿铁、橙C美式这样的国民级爆款，这套爆款方法论如果能在预包装产品上复用，瑞幸即享就拥有了三顿半、永璞这些纯零售品牌没有的弹药库（evidence_tier：mapped）。但这个武器目前还没有被充分使用，瑞幸即享的产品线里，门店爆款的预包装化还停留在浅尝辄止的阶段，没有一款产品真正把门店爆款的势能完整地搬运到货架上。
