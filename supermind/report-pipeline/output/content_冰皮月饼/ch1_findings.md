# 第一章 核心发现

冰皮月饼赛道处于品类渗透率爬坡期，市场从港式高端（美心/大班）主导转向多元品牌分层竞争。2024年月饼市场300亿元，冰皮渗透率约8-10%，年增速高于传统广式/苏式月饼。品类竞争的核心变量不是口味创新，而是冷链基础设施的覆盖半径和榴莲供应链的品种控制权。

**发现一：冷链能力是品牌的第一道分水岭。**元祖全国400+门店和好利来近1000家门店本质上是分布式冷链节点网络。没有冷链门店网的品牌（榴芒一刻、电商白牌）依赖顺丰冷运等第三方物流，渠道覆盖半径受限，履约成本高。这意味着有门店的品牌天然占据更多城市的中秋礼赠场景市场份额。

**发现二：榴莲口味占冰皮月饼电商搜索量超50%，但品类即品牌的认知仍属空白。**榴芒一刻在榴莲冰皮细分有先发优势，但距离"冰皮月饼=榴芒一刻"还差很远。美心、元祖、好利来用品牌溢价覆盖多口味产品线，品牌认知壁垒远高于品类认知。

**发现三：冰皮月饼的内容营销存在严重的同质化。**几乎所有品牌都在做"切面爆浆+果肉含量"的视觉套路。好利来是少数尝试设计驱动差异化的品牌，通过包装造型和联名制造社交货币。品类需要从感官营销升级为情感营销和身份营销。

**发现四：价格带分化映射了三种品牌逻辑。**200-400元高端线（美心/好利来）靠品牌资产和设计溢价，100-200元品质线（榴芒一刻/广州酒家）靠品类心智和性价比，50元以下低端线（三只松鼠/白牌）靠渠道流量和价格战。中层品牌面临两端挤压——向上缺品牌资产，向下拼不过价格。

**发现五：冰皮月饼的消费者决策正在从"买什么品牌"变成"刷到什么买什么"。**抖音直播+小红书种草的即时转化链路，让品牌忠诚度在品类中被稀释。榴芒一刻通过"每年限量+100万人惦记"的稀缺叙事对抗这种稀释，美心通过港式正宗品牌身份建立信任壁垒，但大多数品牌在中间地带缺乏防御策略。
