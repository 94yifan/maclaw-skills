# Case Storyteller（奖项案例故事线构建）

把案例故事从零开始构建出来。

---

## 能力一：矛盾结构探测

找到案例最核心的二元对立，作为整个故事线的骨架。

练习方法：
- 先列出10个可能的"vs"
- 再问：哪个vs是这个案例最不可回避、最真实的张力？
- 保留的那一个，就是故事线的骨架

---

## 能力二：文化共识锚点定位

找到一个目标受众天然熟悉、不需要解释就能产生共鸣的文化符号。

判断标准（三问）：
- 这个符号是不是目标用户生活中真实存在的？
- 能不能一句话说出来，不需要背景解释？
- 有没有一种"原来你也知道这个"的共鸣感？

**找不到文化锚点，故事就缺乏传播力。**

---

## 能力三：内容场交汇点计算

找到三个变量在同一时刻叠加的位置——这是故事最有爆发力的物理空间。

计算方式：
- 列出案例涉及的所有变量（用户群体 / 内容形式 / 时间节点 / 平台特性 / 文化符号……）
- 问：哪几个变量在这个案例里是第一次同时出现的？
- 叠加的变量越多，故事越有力

---

## 能力四：三封信结构 vs 起承转合的选择

**三封信结构**适合：多视角叙事、多个人物弧线、需要展现代际差异的案例

**起承转合结构**适合：线性叙事、逻辑递进、策略一层层落地的案例

选择依据：案例本身的叙事需求，不是模板套用。

---

## 能力五：分割页故事化设计

每个分割页是"一句话故事的结尾或转折"，不是"这一页讲什么论点"。

判断标准：
- 看完这页，别人会不会想问"后来呢？"
- 如果不会，这页就是散的

---

## 能力六：七步自检

| 步骤 | 自检问题 |
| -------- | -------- |
| 矛盾结构 | 能不能一句话说清楚核心对立？ |
| 文化锚点 | 目标用户能不能秒懂，不需要解释？ |
| 交汇点 | 多个变量是否叠加，缺一不可？ |
| 叙事结构 | 起承转合是否围绕核心矛盾展开？ |
| 分割页 | 每页是故事的转折，不是论点堆砌？ |
| 实施路径 | 策略和执行能否对应矛盾解决？ |

---

## 两个 Skill 的能力分工

| 能力 | case-packaging | case-storyteller |
| -------- | -------- | -------- |
| 矛盾结构 | ✅ 识别骨架 | ✅ 找到入口 |
| 三层复用性 | ✅ 评估价值 | — |
| 洞察萃取 | ✅ 横向+纵向 | — |
| 文化锚点 | — | ✅ 定位共鸣 |
| 交汇点 | — | ✅ 计算叠加 |
| 链路一致性 | ✅ 自检 | ✅ 校验 |
| 叙事节奏 | ✅ 控制节奏 | ✅ 骨架搭建 |
| 分割页设计 | ✅ 避免套路 | ✅ 故事化 |
| 自检清单 | 六步 | 七步 |

**case-packaging** 解决的是"怎么判断一个案例值不值得包装、包装价值在哪"。

**case-storyteller** 解决的是"怎么把这个案例的故事线从零开始构建出来"。

两者合并，才是一个完整的包奖叙事工作流。
