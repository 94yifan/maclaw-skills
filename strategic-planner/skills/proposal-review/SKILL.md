# 小红书整合营销方案修改审查 SOP

## 背景与定位
基于逸凡在三份方案（嘉华云腿月饼、北纬47°、康尔馨）中的修改意见，结合曼拾《策划方案框架》和《前策分析培训文档》两份标准文档萃取的系统性审查框架。

定位：在逸凡亲自改方案之前，先做一轮结构化审查——对照曼拾标准，找出逻辑断裂、内容缺失、数据来源错误、板块归属混乱。同时，在安全的常规内容之上，基于弱信号洞察提增量创意建议。

---

## 铁律：预算与KOL是我们提，不是问客户

预算分配（KFS预算怎么切、多少钱投哪里）和KOL矩阵（找谁、什么量级、什么配比）**默认由曼拾根据客户状态主动提出**。这是提案的核心价值所在。

- 方案里出现"问客户预算怎么分配""问客户KOL找谁"这类表述 → 不是审查问题，是方向性错误，直接标注为 P0。
- 审查者自己在出建议时，也绝不能反问客户"你预算多少、你想找谁"——应该基于客户状态（品牌阶段/预算规模/赛道竞争）主动给出一版预算切分和KOL矩阵。
- 一句话：客户买的不是我们的提问能力，是我们替他把钱和人都安排明白的能力。凡是让客户自己决定钱和人的环节，等于在卖自己的价值真空。

客户委托范围决定KOL交付深度（2026-08-13 瑞幸案修正）：通用规则是KOL规划（找谁、量级、配比、方向）由曼拾主动提，这是提案核心。但要先判断客户委托范围——瑞幸这类只委托投流的客户，达人推荐曼拾只给建议，达人名单、具体报价、采买执行由客户把控，此时五维雷达图、分档报价属操作层，非强制交付，标建议级即可。正常全案客户则要做完整KOL规划，五维雷达图、达人矩阵配比是必须交付项，缺了照标P0/P1。

## 第一性概念红线：消耗占比 ≠ SOV/C占比（审查基本功，混淆=审查失效）

消耗占比 = 投入端，钱怎么花。渠道/词类/人群各分多少预算，是分配结构。
SOV/C占比 = 效果目标端，声量要占多少。在某个搜索场景里品牌内容占据的可见度份额，是卡位目标。

两者是投入和产出的关系，不是同一维度的两个数字。禁止把消耗占比和SOV/C占比放在一起对减、对齐、判矛盾。

典型错误：拿关键词规划表的消耗占比（竞品词15%）去跟投放目标里的SOV/C卡位占比（竞品词25%）对减，得出两处矛盾的错误结论。一个是花15%的钱，一个是占25%的声量，完全不矛盾，三个卡位目标（品牌词95%+竞品词25%+场景词20%）也各自独立，不存在加总超100%的问题。

审查时看到任何占比数字，先问自己：这是钱（消耗/预算）还是声量（SOV/C/卡位）？分不清这一层，整个审查报告的可信度归零。

## Orchestration（编排规则）

### 触发条件
逸凡或同事在群聊/私聊中发送方案并要求审查。

### 支持的方案格式
- PPTX文件 → python-pptx提取文字
- PDF文件 → 图片型→pdftoppm转换→image工具读关键页；文本型→pdftotext提取
- **飞书云文档链接** → feishu_doc read直接读取文字内容

### 问题定位方式（按格式区分）
- **PPTX/PDF**：标注页码。格式："第X页 [板块名]"
- **飞书云文档**：飞书文档无页码概念，标注板块+段落+句子。格式："[板块名]-第X段-第X句：[原文摘录]"

示例对比：
- PPTX：第40页 竞价人群 → 缺人群体量
- 飞书云文档：竞价广告策略-第3段-第2句："DMP包：品牌人群" → 圈包逻辑未写出，仅写了包名

### 运行时规则
- 模型：Pro模型（deepseek-v4-pro）
- 读取顺序：先理解结构→深读策略推导和Message House→逐模块对照标准
- 飞书云文档：先读全文，提取板块标题作为段落分界，再用板块名+段落序数定位

### 方案类型判断
能判断→标注并选标准。无法确定→问发方案的人（谁发的问谁）。

### 输出
- 结构化审查报告直接发在聊天中，不创建飞书文档（除非明确要求）
- 报告含两部分：标准审查（P0/P1/P2）+ 增量建议

## 核心机制：强因果区 vs 弱因果区

审查不是一套标准通吃全部。按板块分两区，不同标准不同温度。

### 强因果区（严查链路必须完整，跳一步就标断裂）
属于这个区的板块：
- 赛道洞察→策略推导的每一步
- Message House的RTB→卖点
- KFS预算分配逻辑
- 关键词规划
- 人群策略
- 竞品分析→差异化策略

审查标准：数据和结论之间必须强关联，推一步缺一步=P0断裂。

### 弱因果区（只查推导自洽，完整推导=通过；特别亮的标"创新亮点"）
属于这个区的板块：
- 内容Angle设计
- 线下活动创意
- IP联名建议
- 趋势预判/额外机会洞察
- 增量传播计划

审查标准：推导链路完整+逻辑自洽=合格。推导特别出色的标"创新亮点"。完全没推导=P1。强因果区里混入了天马行空的内容（用情怀代替数据做策略判断）→P0。弱因果区里错误地用强因果标准审查创意内容→审查者自己有问题。

### 弱因果区专用洞察方法：弱信号捕捉×主流需求反差

核心逻辑三步（来源：思念柿柿如意汤圆案例）：
1. 看主流搜索词，知道品类入口在哪（"汤圆怎么煮"=品类刚需=教程内容方向）
2. 看长尾搜索词，找到非主流但有方向性的信号（"兔子汤圆""空气炸锅汤圆"=视觉化需求=好玩好拍）
3. 主流和长尾之间的张力=机会空间。品类刚需是"能用"，增量需求是"好看+好玩+好拍"。

#### 四维趋势判断矩阵——不是每一个小词都值得追

1. **方向一致性**：三个以上小词指向同一趋势方向→信号有效。孤立诡异小词→随机噪点Pass。
2. **内容传播力**：用户做完会不会发小红书？会发=天然传播场景，不发=封闭场景。
3. **品类扩展性**：能不能帮品牌触达新人群？纯功能词→不扩人群；跨品类词→扩人群。
4. **内容空白度**：小词搜索结果有没有优质内容？有搜索没内容=蓝海；有搜索且饱和=红海。

四维全过→高价值趋势信号，必须放进内容策略。过2-3个→中等。1个或以下→Pass。

## 审查前置（Step 0，审查前强制）

这一层在跑任何审查步骤之前先做，目的是把「审查对象对不对」钉死，避免凭方案内容倒推猜产品。没有 brief 就查页码查数据，等于在错误的对象上做正确的审查。

### 0.1 先要 brief（强制动作，最高优先）
审核任何方案前，先向逸凡要客户委托 brief。没有 brief，产品对不对、目标对不对都无从判断。
- 有 brief → 三问有答案，产品判断有基准
- 没 brief → 三问作为待确认项先抛给逸凡，不凭方案内容倒推
- 硬规则：拿不到 brief，就把三问列出来等确认，禁止跳过这步直接查页码、查数据

### 0.2 生意盘子三问（①）
1. 客户委托的盘子是什么：系列战略 / 单品战役 / 节点 / 执行
2. 这个产品的生意本质是什么：礼盒=礼赠、节令=节点、速食=即得
3. 曼拾这次该交付的核心价值是什么：投流统筹 / KFS 统筹 / 达人

三问答不出 = 审查失焦。方案里「系列 vs 单品错位」「缺投流」「礼赠人群漏」，根子都是这三问没答。

### 0.3 产品立不立得住（②，P0 级，五查）
1. 卖点是否提炼成独特不通用的关键词（好吃 / 健康 / 高端 = 通用 = 不合格）
2. Key Message 是否绑产品独有资产（金桂 / 产品名 / 谐音），不是通用情感口号
3. KM 是否零理解成本（工艺参数不进 KM）
4. 卖点是否有层级：RTB → 感知 → 限定 → 即得性
5. 产品名词根是否可延展成语言母题

### 0.4 产品穿透链（③，连贯性）
卖点 → 人群（自用+礼赠）→ 内容 → 脚本 → 投放，逐环验证「对象还是不是同一个产品」，换对象 = 断。
关键规则：当多个页面同时有问题，先判断是不是同一个病根（产品没立起来）的并发症，再决定标一条 P0 还是散标一堆 P1。

### 0.5 礼赠 / 节令产品规则（④）
- 礼盒 / 礼赠 / 节令产品，人群必须含「礼赠人群」维度（给谁送 / 什么关系 / 什么心意），缺 = P0
- 自用和礼赠两套人群分开拆
- 节令产品检查「时间轴 vs 节日日期」是否对齐（中秋 campaign 中秋当天不能没动作）

## Playbook（操作手册）

### Step 0: 预备——方案类型 + 分段控制 + 格式识别

三个动作：
1. 识别方案格式（PPTX/PDF/飞书云文档），确定定位方式（页码 vs 板块-段落-句子）
2. 判断方案类型（比稿/长线/节点/执行）。能判断→标注。不能→问发方案的人。类型与深度不匹配→P0。
3. 画方案地图：把全案分两区——强因果区 vs 弱因果区。飞书云文档按板块/章节标题作为分界。

#### 方案类型判断表

| 类型 | 特征 | 标准要求 |
|------|------|----------|
| 比稿方案（年度/半年度） | 客户未合作 | 全量覆盖 |
| 长线合作方案（半年度/年度） | 有数据积累 | 加人群资产+过往投放复盘+分SPU人群 |
| 节点性方案 | 时间紧 | 本品趋势+舆情+过往投放，竞品可精简 |
| 执行案 | 已有策略框架 | 热点梗+趋势预判+内容方向 |

### Step 1: 结构逻辑

PPTX/PDF：提取所有分隔页标题，对照标准清单逐项标 ✓/✗/⚠。
飞书云文档：核对是否有等同于分隔页功能的章节标题，无同等标题→标"缺该板块的分隔/章节标题"。

#### 标准板块清单
封面 / 公司介绍（含灵犀牌照、种草学课程、著作权版权、最新奖项） / 赛道洞察 / 竞品分析 / 本品牌分析 / 产品洞察与策略 / 策略（目标+预算+人群+内容+KOL+竞价） / 转化链路（独立分隔页+种草时间关系图） / 硬广资源（独立分隔页+资源+价值描述） / 子品牌独立方案（如有，独立分隔页+专属视觉） / Roadmap / 报价

#### 板块归属
- 用户口碑/评论 → 本品牌分析-舆情，不属市场洞察
- 人群分析 → 策略板块人群策略
- "我们要做到什么" → 目标recap，不是策略

#### 排列顺序
行业趋势 → 赛道洞察 → 竞品分析 → 本品牌分析 → 产品洞察 → 策略（目标→预算→人群→内容→博主→竞价→定价/IP）→ Roadmap → 报价

#### 平台策略页完整性（⑧ 强化）
小红书 / 抖音策略页要有：甘特图 + 预算 + 矩阵图，不是只放达人列表。投流规划是曼拾核心交付，缺了标 P0。

#### 语句模板（按格式区分）
```
PPTX/PDF格式：
结构问题 [P0/P1]：第X页 [板块名]

飞书云文档格式：
结构问题 [P0/P1]：[板块名/章节标题]
当前：[实际情况]
应：[修改动作]
```

### Step 2: 策略推导 + 段落内部逻辑

#### 策略定义
策略 = 用什么抓手做什么事。正确格式：针对[人群]在[场景]的[需求]，通过K[X]+F[Y]+S[Z]，实现[目标]。

#### 一句话策略 + 品类核心矛盾（⑨ 强化）
- 策略要凝练成一句话：以 X 起点 / 以 X 抓手 / 以 X 扩张 / 达成 X 效果
- 趋势措辞要抓品类核心矛盾（如泡面=即得性），不是泛泛「高端化 / 健康化」

#### Message House逐行检查
RTB→卖点→人群→内容承接→投放承接。RTB必须产品参数级别数字。人群必须具体画像。卖点1-2个极致化场景化点，超3个→分散。

#### 因果链四步
Brief→拆解 2.洞察→机会 3.机会→应做 4.应做→KFS分配

#### 段落内部逻辑（强因果区强制，弱因果区建议）
每段过四层：
1. **数据陈述层**：什么数据+什么来源+什么时间范围。含糊表述（"搜索量较大"）→不合格
2. **数据解读层**：这个数字对用户/品类/品牌意味着什么。前后数据关系是否讲清楚
3. **平台转化层**：在小红书上意味着什么。必须有至少一句小红书平台连接
4. **策略转化层**：因此应做什么。具体到可执行动作

强因果区缺一层=P0。弱因果区缺了标P1。

#### 语句模板（按格式区分）
```
PPTX/PDF格式：
策略定义错误 [P0]：第X页 → [目标recap]

飞书云文档格式：
策略定义错误 [P0]：[板块名]-第X段："[原文摘录]"

段落逻辑缺失 [P0/P1]：[板块名]-第X段-第X句："[原文摘录]"
缺：[数据陈述/数据解读/平台转化/策略转化]
标准：强因果区段落必须包含完整四层逻辑
```

### Step 3: 数据来源与方法合规

对照《前策分析培训文档》核心对照表，逐块核对数据源和路径。

#### 赛道洞察数据源
- 市场供需→灵犀泡泡图（搜索vs有曝光笔记两个轴）
- 品类搜索趋势→灵犀趋势分析（波峰波谷图+事件解释）
- 品类搜索洞察→灵犀/聚光/蒲公英（至少一个来源）
- 品类用户画像→灵犀自定义圈人（I+TI或关键词）
- 市场竞争格局→灵犀品牌SPU排名（近90天/近24月）

#### 竞品分析数据源
- 选竞品→灵犀排名+千瓜投放金额交叉验证数据表
- 竞品搜索趋势→渠道提数（需求表→在线表格→3-5天→渠道群）
- 竞品投放金额→千瓜预估+图文视频占比+博主量级+推算FS
- 竞品投放分析→分SPU拆解表格
- 舆情→千瓜种草舆情+小红书前端（正面TOP3+负面TOP3结构化）

#### 本品分析数据源
- 搜索洞察→聚光以词推词+用户决策路径
- 人群资产(长线)→灵犀-度量
- 过往投放→执行团队结案报告/蒲公英

#### 趋势洞察
热梗/热点经灵犀或蒲公英数据验证。行业大盘标注原始报告机构+名称+时间。

#### 语句模板
```
数据来源不合规 [P0/P1]：
PPTX/PDF：第X页 [分析块]
飞书文档：[板块名]-第X段-第X句

标准：应使用[源+路径]
当前：[实际/无标注]
应改为：[正确源+路径]
```

### Step 4: KFS预算分配 + 品牌阶段战略匹配

#### K（达人矩阵）
量级金字塔(数字+占比)+总篇数+预算+内容方向对应表。分类维度不混淆。五维雷达图MUST HAVE。

#### F（信息流）逐DMP包
四必填：包名+描述/具体体量(必须数字)/圈包逻辑(必须写出来，不能只写包名)/对应内容。+分阶段策略(测试标准+量化指标)

#### S（搜索）
五类关键词：品牌词/品类词/竞品词/兴趣词/痛点词
每类：配比%+词例+预计CPC+搜索量+消耗+卡位策略+素材
回溯：洞察章节所有搜索词在关键词规划逐词验证

#### 品牌阶段×S战略匹配（核心深度）
不只是查有没有，是查配比对不对得上战略。

**判断品牌阶段：** 认知期/成长期/成熟期/高端子品牌

**匹配规则：**
- 认知期→品类教育截流，品类词+兴趣词占比应高。品牌词占比过高=不匹配
- 成熟期→品牌收口，品牌词占比应高
- 子品牌小预算→只卡品牌词+精准场景词。品类词大面积=浪费+可能竞价
- 多品牌线→品类词不重叠。重叠=竞价冲突P0

同样延伸：K金字塔形状匹配品牌阶段。认知期倒三角=预算浪费。

#### 预算策略：饼图+每块解释

#### 预算配置合理性（⑤ 强化，从「数字对不对」到「配置合不合理」）
- KOL 占比对客户 ROI 合不合理
- 从客户盘子倒推切分
- 数字符号 / 单位统一（¥35,000 vs 3.5万 的歧义）

#### 语句模板
```
K缺失 [P0]：[定位]-缺[金字塔/预算/五维雷达图]
F缺失 [P0]：[定位]-DMP包"[包名]"-缺[体量/内容/测试/圈包逻辑]
S缺失 [P0]：[定位]-缺[词类/配比/CPC/搜索量/消耗]

S战略不匹配 [P0]：[定位]
品牌阶段：[XX] | 预算：[XX万]
当前配比：[XX词XX%]
战略要求：[应然的配比]
→ 调整：[具体方案]

竞价冲突 [P0]：A[定位] vs B[定位]，重叠词：[X,Y]
```

8. 投放金额→投放差距？
9. 投放分析→可借鉴方向？

每环节：[有承接/断裂/缺步骤]

### Step 6: 数据质量 + 颗粒度

#### MUST HAVE清单（比稿缺任一项=P0）
- [ ] 赛道泡泡图（搜索vs有曝光两个轴）
- [ ] 赛道趋势图（波峰波谷+事件解释）
- [ ] 上下游词（来源/去向/飙升/热门四类分）
- [ ] 赛道TA画像（年龄/城市/消费力/兴趣四维+策略转化）
- [ ] 品牌SPU搜索量排名
- [ ] 搜后曝光排名+阅读排名
- [ ] 竞品品牌SPU搜索量趋势
- [ ] 每个竞品过往投放分析（分SPU）
- [ ] 本品TA画像
- [ ] 本品品牌/SPU搜索趋势
- [ ] 本品过往投放分析
- [ ] 舆情（正面TOP3+负面TOP3结构化）

#### 颗粒度逐板块
- 泡泡图：两个轴+时间+结论句
- 上下游词：四类分+每类一句解读
- RTB：产品参数级别数字（"宣威放养黑毛猪全支15-20kg仅取2kg入料"，不是"好食材"）
- 人群："25-35岁一线城市中高消费女性糕点爱好者"，不是"品牌人群"
- DMP：圈包逻辑写出来，不是只写包名
- S词类：CPC/搜索量/消耗，不是只有词例
- 预算：饼图+每块解释
- Angle：人群→场景→痛点→解法→形式→标题→数据七要素

#### 数据参照系
一个数字孤立→缺参照系。必须有本品vs竞品/今年vs去年/搜索量vs渗透率。竞品组合全同一类型→维度单一。

#### 结论-数据桥梁
所有结论标记往前找最近数据。间隔超2页(或超2段)无推导→桥梁缺失。

#### 素材元素拆解
元素级别拆解（封面/标题/正文/评论区）=合格。截图罗列=P0。理论框架可放，搭建方法不能放。

#### 竞品选取
必须：高搜+投放力度大+淘天京东销售好+客单价对标。

#### 语句模板
```
PPTX/PDF格式：
MUST HAVE缺失 [P0]：第X页 [项目名]
颗粒度不足 [P1]：第X页 [项目] 当前：[模糊] 应达到：[具体]
参照系缺失 [P1]：第X页 数据[XX]孤立
桥梁缺失 [P0]：第X页结论[原文]，第Y页数据，间隔N页

飞书云文档格式：
MUST HAVE缺失 [P0]：[板块名]-[段落范围]
颗粒度不足 [P1]：[板块名]-第X段-第X句："[原文摘录]"
→ 应达到：[具体数字级别/结构化格式]
参照系缺失 [P1]：[板块名]-第X段：[数据XX]孤立出现
桥梁缺失 [P0]：[板块名]-第X段结论，前置数据在[板块名]-第Y段，区间有N段无推导
```

### Step 7: 矩阵与内容

#### 博主矩阵
MUST HAVE五维雷达图+why。先矩阵后内容。重点angle单博主单页小诗。

#### KOL 匹配产品特性（⑥ 强化）
素食 KOL 不推牛肉味产品（曾黎案例）。KOL 人设与产品调性要咬合。

#### 脚本专业化（⑦ 强化）
脚本要镜号 / 时长 / 画面 / 景别 / VO / 字幕 / 备注，不是文案。KOL 定性描述在前，脚本跟 KOL 走。

#### 逐Angle检查
≤5个。每angle七要素：人群+场景+痛点+解法+形式+标题+预期数据。
PGY预埋词+必带tag。

#### 多阶段差异化
蓄水（品类认知，own一个产品）≠ 爆发（核心产品×场景）≠ 长尾（全品类全人群）
三阶段并列对比找重复→打架P0。

#### 线下活动
独立分隔页/章节标题+预算说明+每个活动简介→目的→操作三要素。

#### 语句模板
```
矩阵缺失 [P0]：[定位]-缺五维雷达图
angle问题 [P1]：[定位]-angle"[名]"，N个超5/缺七要素中的[XX]
阶段打架 [P0]：[定位A] vs [定位B]，重复：[描述]
```

### Step 8: 修改迭代 + 连锁影响

#### 版本管理
第二版+：逐条验证上一版修改→[✓已改/✗未改/△部分改]。两次以上未改→⚠️升P0。

#### 连锁影响检查
每条修改后追问：改完A→B和C需要同步调吗？标注受影响板块。

例：补了人群包体量数字→预算比例可能要调→"连锁影响：修改[定位A]后需同步检查[板块B-预算分配]"。

所有标注按P0/P1/P2分级汇总。

## 使用原则

1. 识别方案格式→确定定位方式（页码 vs 板块-段落-句子）
2. 先分段控制（强因果/弱因果）→再跑审查
3. 强因果区严查链路完整+段落四层逻辑，跳一步=P0
4. 弱因果区查推导自洽，特别亮的标"创新亮点"
5. 数据来源对照前策标准逐项验证
6. 每个问题标注定位+标准条文+可执行修改动作
7. S配比必须跟品牌战略阶段匹配。小预算投全品类词=P0
8. 颗粒度不只标"缺"，必须标"写到什么程度才算够"
9. 第二版+先跑模块八迭代+连锁影响
10. 增量建议独立输出，不标P0/P1/P2
11. 输出直接发聊天，不创建飞书文档
12. 方案类型无法判断→问发方案的人
13. SOV/SOC卡位占比与消耗占比是两个独立维度，不能对齐比较。关键词规划表里的百分比是预算消耗占比（预算怎么切），投放目标里的SOV/SOC占比是搜索结果卡位占比（声量要占多少），两套数字各自成立、互不矛盾，审查时禁止拿它们对减判矛盾。
14. 节点方案审查前，先识别投放周期内的关键节日节点（七夕、情人节、双11、立秋等），再判断预算峰值是否与节点匹配。不要先入为主认为上新日该是峰值，峰值落在节日节点上往往是合理的。
15. 审查方案前先要 brief。没有 brief，先把生意盘子三问抛给逸凡确认，不凭方案倒推猜产品。
16. 产品层审查（立不立得住 / 穿透链 / 礼赠节令）跑在结构审查之前，先钉对象对不对，再查结构好不好。
