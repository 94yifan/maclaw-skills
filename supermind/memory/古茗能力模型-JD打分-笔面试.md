# 古茗市场岗位能力模型：市场（内容方向）& 广告投放（数据方向）

> 燃创为古茗输出的人才评估框架。能力维度通用化，评估时按岗位做行为描述区分。
> 适用岗位：古茗市场部（内容方向）+ 古茗市场部（投放数据方向）

---

## 一、通用能力框架（7大维度）

所有评估围绕7个通用能力维度展开，每个维度下分2个子维度。

| 维度 | 子维度A | 子维度B |
|------|---------|---------|
| 1. 学习能力 | 领域内学习（行业/专业深度） | 跨领域学习（通用能力迁移） |
| 2. 信息敏感度 | 宏观信号捕捉（趋势/变化/异常） | 微观判断力（具体信息的好坏/真伪/价值） |
| 3. 逻辑与分析力 | 结构化思考（拆解/归因/推论） | 决策质量（在不确定中做判断） |
| 4. 策略思维 | 目标反推（从结果倒推路径） | 资源调配（有限条件下最优解） |
| 5. 表达与沟通 | 书面表达（文档/方案/报告） | 口头沟通（对齐/说服/管理预期） |
| 6. 执行与韧性 | 交付力（按时按质把事情做了） | 抗压力（在不确定/压力下稳定输出） |
| 7. 工具杠杆力 | 效率工具（提效类工具掌握程度） | 创新工具（用工具做原来做不了的事） |

## 二、能力分级标尺（带岗位差异化描述）

### 1. 学习能力——领域内学习

| 级别 | 市场内容岗行为描述（古茗版） | 广告投放岗行为描述（古茗版） |
|------|----------------------------|----------------------------|
| L1 | 接受被分配的学习任务，完成培训作业 | 接受被分配的学习任务，完成培训作业 |
| L2 | 主动关注茶饮行业动态（头部品牌动向/新品趋势/平台变化），有自己的信息渠道 | 主动关注平台规则更新/茶饮行业投放数据报告/竞品投放动态 |
| L3 | 能输出茶饮行业案例分析和学习笔记，总结可复用的内容方法 | 新平台/新功能上线后能快速学习并在账户中测试，输出学习文档 |
| L4 | 能把学习成果沉淀为团队方法论（培训材料/案例库/SOP） | 能把茶饮投放经验总结为可复用的策略SOP，推广到团队 |
| L5 | 学习成果对外输出（行业分享/成为平台认证讲师） | 能预判茶饮行业投放趋势变化并提前调整策略方向 |

### 1b. 学习能力——跨领域学习

| 级别 | 通用行为描述（两岗位一致） |
|------|--------------------------|
| L1 | 只关注自己领域的知识，对其他领域不感兴趣 |
| L2 | 愿意接触非本专业的知识（市场岗学数据、投放岗学内容） |
| L3 | 能主动学习跨领域知识并找到与本岗位的连接点（市场岗：从数据里看内容方向 / 投放岗：从内容角度理解素材差异） |
| L4 | 跨领域学习成果能反哺本岗位工作，形成差异化竞争力 |
| L5 | 跨领域融合能力成为个人标签，能解决单一领域视角解决不了的问题 |

### 2. 信息敏感度——宏观信号捕捉

| 级别 | 市场内容岗行为描述（古茗版） | 广告投放岗行为描述（古茗版） |
|------|----------------------------|----------------------------|
| L1 | 能分辨一条茶饮内容好/不好 | 能看出数据报表中明显异常（消耗突变/CTR暴跌） |
| L2 | 能解释一条茶饮内容为什么火/为什么不火 | 能定位数据异常的大致原因（素材/出价/大盘变化） |
| L3 | 能在内容发布前预判传播效果的大致量级 | 能从多维数据交叉验证中发现隐藏问题 |
| L4 | 能在别人没做的时候判断"这个方向会火" | 能建立监控体系，在异常发生前预判风险 |
| L5 | 能定义团队的内容方向标准，让团队的内容成为茶饮行业参照 | 投放数据解读反哺业务决策，提炼对用户/市场的洞察 |

### 2b. 信息敏感度——微观判断力

| 级别 | 市场内容岗行为描述（古茗版） | 广告投放岗行为描述（古茗版） |
|------|----------------------------|----------------------------|
| L1 | 能照做，不判断 | 能按规则执行调整 |
| L2 | 能判断几条备选内容中哪条更好，能说出原因 | 能在给定框架内做基础优化判断（出价调多少/哪个计划暂停） |
| L3 | 能判断一个内容方向是否值得投入，"做还是不做"有依据 | 能在多变量场景中做归因判断，找到核心原因 |
| L4 | 判断力稳定可靠，团队愿意让你做终审人 | 判断逻辑成为团队的参考标准 |
| L5 | 你的判断标准被行业认可 | 你的优化框架被团队持续使用 |

### 3. 逻辑与分析力——结构化思考

| 级别 | 市场内容岗行为描述（古茗版） | 广告投放岗行为描述（古茗版） |
|------|----------------------------|----------------------------|
| L1 | 能听懂别人的分析并照做 | 能看懂数据报表上的关系和趋势 |
| L2 | 能自己整理信息并输出有结构的小结论（竞品调研/品类趋势） | 能建立"数据→假设→验证"的分析链条 |
| L3 | 能拆解复杂问题（客户brief模糊时，能拆成可执行的小问题） | 能在多变量中找到因果关系，不混淆相关和因果 |
| L4 | 能建立团队的分析框架和分析标准 | 能设计团队的优化决策框架（调优逻辑SOP） |
| L5 | 分析结论能影响公司层面的决策方向 | 归因模型成为公司投放策略的基础工具 |

| L3 | 能在信息不完整时做方向性判断，主动承担决策风险 |
| L4 | 能为组织定义决策框架，培养他人的判断力 |
| L5 | 决策质量稳定到可以被写进公司的决策机制 |

## 四、岗位标准与JD建议

### 市场内容岗 JD（古茗市场部）

> 🟡 核心内容 | ⚪ 加分项

古茗正在寻找市场部内容方向的同学加入。

**🟡 1. 学习能力**
茶饮行业迭代快，新品季、联名节点、平台规则轮番变化。我们对你的期待不是"现在懂多少"，而是"新东西来了能多快学会"。

**🟡 2. 信息敏感度**
你对什么内容能打、什么内容不动，有自己的判断。不是说"我觉得好看"，而是能说出一条茶饮内容从选题到传播链条上哪里做对了、哪里可以更好。

**🟡 3. 逻辑与分析力**
你能把一个模糊的需求拆成具体问题。"想推一款新品"——你脑子里不是立刻出创意，而是先搞清楚：推给谁、在哪个平台、目标是什么、怎么算成功。

**🟡 4. 策略思维**
你不是只做"这一条内容"，你能想"这一条放在整月/整季的节奏里是什么位置"。从目标反推路径，而不是从感觉出发。

**🟡 5. 表达与沟通**
把想法说清楚。书面不跑题，口头不绕弯。跟内容团队沟通说人话，跟跨部门对齐说逻辑。

**🟡 6. 执行与韧性**
把事情做了、做完、做好。不会的学，卡住的说。不等到deadline才发现还没开始。

**⚪ 7. 工具杠杆力**
会用AI工具加分，但更核心的是——你不排斥新工具，愿意尝试学。

**工作职责：**
- 参与古茗在小红书/抖音的内容策划、选题讨论和内容执行（文案/视觉方向/brief输出）
- 协助团队在campaign前期做茶饮行业洞察和竞品分析，用数据支持内容决策
- 参与项目执行跟进和数据复盘，从数据中找到内容优化方向

**任职要求：**
- 本科及以上，专业不限（广告/营销/新闻/中文/心理等优先）
- 日常活跃在至少两个社交媒体平台
- 面试带一份个人作品（策划方案/个人账号/文案作品/茶饮行业分析等均可）

---

### 广告投放岗 JD（古茗市场部）

**🟡 1. 学习能力**
平台规则三个月一小改、半年一大改。我们要的不是"现在懂的人"，是"不管怎么改都能快速学会的人"。面试时能说说你最近一次学习新平台/新功能的经历。

**🟡 2. 信息敏感度**
你对数字敏感。不是数学好，而是看到数据变化你能意识到"这里有问题"。数据异常不是你焦虑的来源，是你问出好问题的起点。

**🟡 3. 逻辑与分析力**
你做的每一个优化调整都能说出依据——"我调出价是因为XX，预期产生XX效果"。不是凭感觉调，是推演出的。

**🟡 4. 策略思维**
你不只是管一个账户一个计划。你能想"今天花多少钱、花在哪、怎么花，才能配合品牌整月的营销节奏"。

**🟡 5. 表达与沟通**
你不仅懂数据，还能让不懂数据的人听懂你说什么。跟内容团队沟通素材方向，跟上级汇报数据表现，都知道怎么说。

**🟡 6. 执行与韧性**
投放是每天面对数字和压力的事。ROI好的时候不飘，差的时候不慌了手脚。对账户有主人翁意识。

**⚪ 7. 工具杠杆力**
会Excel基础操作是底线。会用SQL/脚本提效加分。但最核心的是——你有"手工做的能不能用工具代劳"的意识。

**工作职责：**
- 负责古茗在小红书/抖音/腾讯广告等平台的投放执行和账户管理
- 跟进投放数据，输出日报/周报，基于数据做优化调整
- 参与投放策略讨论，根据品牌目标制定预算分配和投放节奏

**任职要求：**
- 本科及以上，专业不限（统计/数学/市场/广告相关优先）
- 对数字有敏感度，不排斥和数据打交道
- 逻辑清晰，能说清楚自己每个调整的原因

### （一）市场内容岗（古茗版）——笔试A卷（建议用时：90分钟）

1. 这三条中你判断哪条数据表现最好？为什么？（至少3个依据）
2. 针对古茗，写一条你认为比这三条都好的内容brief（30字标题 + 50字文案方向 + 配图方向）
3. 你的新brief预期能比最好的那条好多少？你怎么衡量？

**题2【逻辑分析 L2-L4，建议用时20分钟】——模糊需求拆解**

古茗市场部说："想推一款夏季新品，要出圈。"请你：
- 拆解出至少3个你需要先问清楚的问题（按优先级排序）
- 第一阶段建议做什么动作（100字以内）
- 你判断"出圈"成功与否的标准

**题3【策略思维 L2-L4，建议用时20分钟】——茶饮节点策略**

古茗要在端午节做一个节点营销，预算15万。古茗品牌调性：高性价比+年轻化+区域深耕。请输出一份框架：
- 你的切入点选择（送礼场景/家乡味/夏日清凉/其他）及理由
- 核心动作 + 传播链路 + 一个能判断策略对错的指标

**题4【学习能力 + 表达 L2-L4，建议用时15分钟】——茶饮趋势洞察**

用你最近学到的一个分析方法或行业认知来解读一个你看到的茶饮品牌现象（可以是某个联名、新品、营销动作）。
要求写清楚：（1）你学的框架是什么（2）怎么用它理解这个现象（3）如果让你来操作，你会有什么不同

**题5【工具杠杆力 L1-L3，建议用时15分钟】——工具应用**

描述一个你用工具解决某个工作问题的经历。格式：
- 问题背景（20字内）
- 用的什么工具
- 具体怎么用
- 节省了多少时间/提升的效率
- 如果不依赖工具你准备怎么办

### （二）广告投放岗（古茗版）——笔试B卷（建议用时：90分钟）

**题1【信息敏感度 L2-L4，建议用时20分钟】——数据觉察**

以下是一个茶饮品牌7天的投放数据（附件表格）：消耗/展现/点击/CTR/CPC/CVR/ROI。假设这是古茗在小红书的投放数据。请回答：
1. 你发现什么异常？至少2个
2. 你判断异常的可能原因，你会优先查什么
3. 你会做什么调整？预计调整后多久能看到效果变化

**题2【逻辑分析 L2-L4，建议用时20分钟】——归因推理**

古茗投了一条新品素材，在抖音两个不同人群包下跑，ROI相差3倍。请写出推理过程：
- 列出至少3个可能假设
- 你会用什么方法验证每个假设
- 如果第一个假设错了，你下一步做什么

**题3【策略思维 L2-L4，建议用时20分钟】——茶饮投放预算分配**

古茗要在618期间推广一款新品茶饮，总预算12万，目标ROI≥2.5。要在小红书+抖音两个平台分配。
请写出分配方案：
- 预算分配比例及核心理由
- 7天/14天的投放节奏安排
- 用什么指标判断需要调预算？调整底线是多少？

**题4【学习能力 + 表达 L2-L4，建议用时15分钟】——投放平台认知**

最近投放平台有什么规则变化影响到了茶饮品类的投放？请写出：
- 变化内容
- 对茶饮品类投放的正面影响和负面影响各一点
- 你会建议古茗怎么应对这个变化

**题5【工具杠杆力 L2-L4，建议用时15分钟】——提效思维**

你日常投放中最应该用工具替代的手工动作是什么？
- 现在你怎么做（耗时多少）
- 你理想中的工具应该怎么做
- 你有没有试过任何自动化/半自动化方案？效果？

## 七、面试题完整版（含追问路径）

### （一）市场内容岗（古茗版）面试问题库

**第一轮面试（30分钟）——信息敏感度 + 学习能力 + 表达**

**Q1【信息敏感度 L2-L3，5分钟】**
最近刷到一条让你觉得"这个茶饮品牌做得真不错"的内容是什么？
→ 追问链条：好在文案还是画面还是选题？如果换成古茗来做一个类似的，你觉得需要改什么？如果这条内容数据不好，你觉得可能是什么原因？

**Q2【信息敏感度 L3-L4，5分钟】**
你注意到最近古茗在内容风格上有什么变化吗？或者竞品有什么值得注意的变化？
→ 追问链条：你觉得这个变化说明品牌在想什么？是跟着行业趋势走还是古茗自发的？你从哪几个信号看出来的？

**Q3【学习能力 L2-L3，5分钟】**
最近你学了什么让你觉得"这个思路我之前没想到"的东西？
→ 追问链条：在哪学的？学完之后有没有应用过？你平时获取茶饮行业信息的习惯是什么？

**Q4【表达 L1-L2，5分钟】**
请你用一分钟推荐一个你最喜欢的茶饮品牌营销案例。
→ 追问链条：它核心做对了什么？如果让你改进它，改什么？

**Q5【学习能力 L3-L4，5分钟】**
如果你完全没做过茶饮行业的内容，要多久你能写出第一条你觉得"能打"的内容？你从哪开始学？

**面试官打分要点（第一轮）**：
| 指标 | 低分信号 | 高分信号 |
|------|---------|---------|
| 茶饮赛道感知 | 说不出具体的茶饮品牌或案例 | 能说出具体品牌的动作，有自己的判断 |
| 自驱学习 | 等别人教才有新知 | 有主动关注行业动态的习惯 |
| 表达清晰度 | 散，讲不到重点 | 结论先行，有层次 |

---

**第二轮面试（30分钟）——逻辑分析 + 策略思维**

**Q1【逻辑分析 L2-L3，8分钟】**
古茗说要出圈推一款夏季新品，但没有给brief。你第一步做什么？
→ 追问链条：你问的第1个问题是什么？如果产品还没定你会怎么办？如果产品定了但你没喝过，你会怎么办？

**Q2【策略思维 L2-L3，8分钟】**
两个选题：A话题"夏天的第一杯果茶"搜索量高但竞品都在做；B话题"冷泡新方式"搜索量低但没人做。你怎么选？
→ 追问链条：A你怎么突围？B你怎么让它有人看？有没有A+B的结合方式？

**Q3【逻辑分析 L3-L4，8分钟】**
古茗有一款产品去年同期销量很高，今年同期下降30%。你不看数据，第一反应可能的原因有哪些？然后会先查什么数据？
→ 追问链条：如果数据不支撑第一直觉，第二假设是什么？什么时间点换假设？

**Q4【策略思维 L3-L4，6分钟】**
要做一个campaign，预算从80万砍到25万，但目标不变。砍什么？留什么？为什么？

**面试官打分要点（第二轮）**：
| 指标 | 低分信号 | 高分信号 |
|------|---------|---------|
| 拆解能力 | 答得跳跃，没有路径感 | 有明确的一步步分析顺序 |
| 取舍判断 | 什么都想要 | 知道为什么留A砍B |
| 推演完整度 | 只说结论不说推理过程 | 每个决策都能说出来龙去脉 |

**第三轮面试（20分钟）——执行韧性 + 工具杠杆 + 价值观**

**Q1【执行 L2-L3，5分钟】**
描述一个项目同时推进、时间紧、需求反反复复的场景。你怎么处理的？
→ 追问链条：有没有因为忙而出过差错？怎么补救的？后来调整过自己的工作方式吗？

**Q2【执行 L3-L4，5分钟】**
有没有过在信息不足或资源不够的情况下，自己决定推一个方向？
→ 追问链条：结果怎么样？结果不好之后你怎么跟上级交代？你后不后悔这个决定？

**Q3【工具 L1-L3，5分钟】**
你用过的、让你觉得省了很多时间的工具或方法？
→ 追问链条：你怎么发现它的？现在还一直在用吗？

**Q4【价值观匹配，5分钟】**
品牌方市场部的工作节奏比较快，有节点的时候加班很正常。你上一份工作里最忙的时候是什么状态？你怎么扛的？

### （二）广告投放岗（古茗版）面试问题库

**第一轮面试（30分钟）——信息敏感度 + 学习能力 + 表达**

你最近管过的一个茶饮/快消品牌账户，什么指标最让你头疼？

你判断投放计划"该放"和"该停"的标准是什么？

**Q3【学习能力 L2-L3，5分钟】**
最近什么投放规则变化影响到了茶饮品类的投放？

**Q4【表达 L1-L2，5分钟】**
一份投放日报简化成三个核心指标，你选哪三个？为什么？
→ 追问链条：老板只看一个你给哪个？客户只看一个你给哪个？如果这两个不一样你怎么处理？

**Q5【学习能力 L3-L4，5分钟】**
如果让你管一个你完全没用过的平台（比如从小红书转到腾讯广告），你的学习路径是什么？

**面试官打分要点（第一轮）**：
| 指标 | 低分信号 | 高分信号 |
|------|---------|---------|
| 数据敏感度 | 只看表面数据，说不出业务含义 | 能从数据中读出用户/产品信号 |
| 自驱学习 | 等着别人教 | 有主动追踪变化的习惯 |
| 表达专业性 | 指标定义模糊，用词不准 | 能准确说出每个指标的含义和关系 |

**第二轮面试（30分钟）——逻辑分析 + 策略思维**

**Q1【逻辑分析 L2-L3，8分钟】**
古茗同一款新品素材在两个计划里ROI差3倍。你的排查路径？
→ 追问链条：最怀疑哪个变量？如果出价一样的话查什么？如果受众一样呢？时段影响怎么验证？

**Q2【策略思维 L3-L4，8分钟】**
竞品突然翻倍放量，消耗暴增但ROI没降。你觉得它发生了什么？
→ 追问链条：如果是在测试新玩法你怎么办？清库存冲GMV你怎么应对？什么情况下跟？什么情况下不跟？

**Q3【逻辑分析 L3-L4，8分钟】**
古茗一个新账户学习期一直过不了。你的排查路径？
→ 追问链条：先看哪个指标？预算太低怎么办？出价太低呢？CVR太低呢？你是先排除了产品/页面问题还是同时排查？

**Q4【策略思维 L2-L3，6分钟】**
古茗市场部说这个月ROI要从2做到4，但预算没变、产品没变。这个目标合理吗？你怎么跟他们沟通？

**面试官打分要点（第二轮）**：
| 指标 | 低分信号 | 高分信号 |
|------|---------|---------|
| 归因能力 | 归因单一，忽略多变量 | 多假设，排除法+验证法结合 |
| 竞品判断 | 只知道跟或不跟 | 能判断对方意图，制定差异化应对 |
| 对内沟通 | 要么说目标不合理，要么什么都不说 | 能用数据+推理让对方理解合理性和妥协方案 |

→ 追问链条：自己扛还是主动说？什么时候说最合适？给你三天挽救，具体步骤是什么？

## 八、面试流程操作指南

### 建议面试流程总时长
| 轮次 | 时长 | 面试官角色 | 侧重能力 |
|------|------|-----------|---------|
| 第一轮 | 30分钟 | HR或直属同事 | 基础能力确认（信息敏感度+学习+表达） |
| 第二轮 | 30分钟 | 部门负责人或资深同事 | 核心能力评估（逻辑+策略） |
| 第三轮 | 20分钟 | 部门负责人+HR | 软性素质+抗压性+价值观匹配 |
| 笔试 | 90分钟 | 独立完成 | 实操能力验证（笔试题目见第六部分） |

### 面试流程建议

**方案A（充足时间）：** 先笔试 → 筛选 → 第一轮 → 第二轮 → 第三轮
**方案B（快速流程）：** 同步发笔试 + 约第一轮（笔试与第一轮同一天）→ 第二三轮合并
**方案C（实习生/管培生）：** 第一轮面试 + 笔试（面试后发，发回后决定是否进第二轮）

### 笔试题评分建议
- 笔试不设"及格线"，用来验证面试中的判断
- 面试觉得"学习能力很强"但笔试题写得很差——需要深思
- 面试平平但笔试题出色——建议加一轮
- 看思考过程不看对错：写得少不一定不好，写得多但不聚焦也不一定好

### 红线问题（出现任一直接不过）
1. 简历造假
2. "什么都行"没有具体案例支撑
3. 被问不确定的问题时选择编，而不是说"这个我不确定"
4. 对前公司/前老板有明显的负面倾向性描述
5. 笔试完全没有自己的判断，每道题都在"面面俱到"
