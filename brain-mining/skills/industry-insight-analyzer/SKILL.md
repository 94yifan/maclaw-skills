# Industry Insight Analyzer — 行业文章深度分析

## 能力定位

给一份完整的文章内容（文字+图片OCR）→ 输出一份可供同事直接使用的行业洞察分析报告 + 打标签入库 + 支持共创。**不做信息采集，只做分析。**

## 触发条件

- 用户给了一篇已读取的文章内容
- 前面环节已调用 wechat-glm-reader（或其他采集工具）获取了原始内容

## 输入

必须包含：文章标题、来源、日期、正文文本、每张图片的 OCR 文字

## 分析流程（4 个阶段）

### 阶段一：信息提取 + 打标签

#### 信息提取

| 类型 | 提取什么 |
|------|---------|
| 核心数据 | 销售额、增速、ROI、CTR、转化率等 |
| 框架/模型 | 方法论、分析框架、策略模型 |
| 案例 | 品牌做了什么 → 结果 → 可复制点 |
| 工具 | CID、蒲公英、灵犀等具体产品/功能 |
| 趋势判断 | 行业变化方向、消费者行为变化 |

提取原则：只摘录原文信息，不做价值判断。

#### 打标签

| 维度 | 可选值 |
|------|--------|
| 行业 | 茶饮 / 宠物 / 食品饮料 / 数码家电 / 美妆 / 服饰 / 其他 |
| 品牌 | 文章涉及的具体品牌名 |
| 投放方式 | **种草**（=KFS）/ **内循环/闭环电商** / **小红星**（一级外域转化）/ **小红盟**（一级外域转化）/ **CID**（深度外域转化）/ 其他 |
| 内容类型 | 行业解决方案 / 案例复盘 / 趋势洞察 / 方法论 / 品牌动态 |

投放方式层级关系：
```
种草（=普通KFS）
生意：
  ├── 内循环（=闭环电商）
  ├── 小红星（一级外域转化）
  ├── 小红盟（一级外域转化）
  └── CID（深度外域转化）
```

### 阶段二：写报告

固定模板：

```
## 完整价值信息
（一、文章核心数据和结论）
（二、关键框架/模型）
（三、操作层面的打法拆解）

## 启发
（一、对行业本身的理解）
（二、对小红书商业化方向的理解）
（三、对营销方法论的启发）

## 该行业可复用价值（曼拾提案方向）
（一、可提炼的方案）
（二、适合什么客户）
（三、曼拾的切入点）

## 跨行业复用指南
每个方法论框架写：适用行业 → 怎么做 → 判断标准
```

案例写法：背景 → 策略拆解(Step by Step) → 结果 → 为什么值得记住

### 阶段三：知识入库

文件位置：`knowledge/articles/YYYY-MM-DD_文章标题.md`
格式：YAML front matter + 提取内容 + 共创笔记 + 关键洞察

索引维护：新增文章时更新 `knowledge/index/by-industry.md` 和 `by-tag.md`

### 阶段四：共创讨论

用户可能提问、纠正、深挖。做到：
- 只回答已有内容，不编造
- 用户纠正 → 更新文件
- 关联已有 knowledge/ 和 MEMORY.md
- 推理守卫：说"之前"必须先核查

## 写作与格式规范（重要）

### 标题分类体系

报告必须按以下标题类别组织（可灵活使用）：
- **【关键数据】** — 所有量化指标和数据
- **【核心洞察】** — 文章的核心发现和判断
- **【核心框架】** — 方法论、模型、策略框架
- **【打法拆解】** — 操作层面的步骤拆解
- **【案例】** — 品牌案例
- **【工具】** — CID、蒲公英、灵犀等具体产品/功能
- **【复用框架】** — 跨行业可复用的方法论
- **【曼拾切入】** — 曼拾可以直接卖什么方案
- **【BD反哺策略】** — BD负责人可以直接拿去用的话术和客户谈判策略

#### BD反哺策略写作规范

目标：BD负责人看完这个板块可以直接拿去跟客户聊。按客户阶段分类：

新锐品牌（缺认知缺内容缺预算）→ 帮找到差异化切入点降低起步门槛
成长期品牌（有内容但打法乱）→ 帮校准策略找到可放大方向
成熟大品牌（有预算需要突破）→ 帮做情绪IP品牌占位规模化放大
内卷赛道品牌（老品类同质化严重）→ 帮找到新情绪切口和叙事方式

每个策略必须包含：适合阶段 + 核心话术 + 怎么跟客户说 + 曼拾能做什么

### 重点信息高亮标记

在关键内容处加标记前缀，方便快速定位：

📊 DATA — 核心数据、量化结果
⭐ KEY INSIGHT — 最重要的结论性判断
💡 ACTIONABLE — 可以直接用的策略/建议
🎯 对曼拾 — 曼拾的生意切入点
✅ 适用于 — 什么场景能用
❌ 不适用于 — 什么场景不能用
⚠️ WATCH — 风险点/需要注意
👀 例子 — 辅助理解的案例场景

### 案例写作规范

每个案例的写法必须包含：
品牌背景（一句话）→ 策略拆解（Step by Step）→ 结果（量化）→ 案例价值：
  🎯 对曼拾的意义是什么
  ✅ 核心可复制点（3条以内）
  ✅ 适合什么客户（具体客户画像）

### 通用约束

- 不编造数据
- 不说"笔者认为"——直接给判断或"文章显示"
- 跨行业复用必须有逻辑推导路径
- 直接简洁，先结论再展开
