### 模块1：底层认知——平台逻辑与茶饮启示

#### 1.1 小红书平台逻辑

**数据从哪里追踪**

| 数据源 | 路径 | 提供内容 | 权限要求 |
|--------|------|---------|---------|
| 灵犀平台 | lingxi.xiaohongshu.com → 搜索赛道 | 搜索趋势、品类排行、人群画像、内容洞察 | 品牌方后台开通 |
| 蒲公英平台 | pgy.xiaohongshu.com | KOL数据、笔记表现、达人广场 | 品牌方后台 |
| 聚光平台 | 聚光后台 → 报表中心 | 付费投放数据、搜索广告数据、ROI | 代理商/品牌方 |
| 小红书搜索页 | App搜索框 → 输入关键词 | 实时搜索结果排列、搜索联想词 | 公开可用 |
| 创作中心 | 品牌号后台 → 数据中心 | 单条笔记CTR、互动率、完读率 | 品牌号管理权限 |

**核心认知**

小红书是「种草心智 + 搜索确定性」平台。用户进入时往往带有隐约需求——想喝点什么、夏天该喝什么——通过搜索来验证和缩小范围，再通过内容评估做决策。茶饮品类在小红书的搜索占比达到 40-60%，意味着内容在搜索结果中的排位直接决定能获得多少有效流量。

**关键数字**
- 用户决策链路：看到内容 → 点击 → 浏览 → 种草 → 搜索更多 → 下单，约30秒-3分钟
- 内容生命周期：优质笔记发布7天内持续获得搜索流量，30天后衰减至10%以下
- 搜索占比：茶饮新品在小红书搜索量占品类总搜索量40-60%
- 用户行为模式：「先搜后看」与「先看后搜」循环叠加

**操作步骤到颗粒度**
1. 打开灵犀 → 选择「搜索赛道」→ 输入品类词（如「果茶」「奶茶」「轻乳茶」）
2. 截图「搜索趋势图」，标注：①波峰出现的时间点和峰值搜索量 ②波谷持续时间和谷值 ③推测波峰波谷的可能原因
3. 记录TOP10搜索词，按以下维度分类：
   - 品牌词（古茗、喜茶、奈雪等）
   - 品类词（果茶、奶茶、酸奶昔等）
   - 场景词（下午茶、解暑、办公室等）
4. 输出一份「品类搜索图谱」——将TOP10词的搜索量级和趋势方向可视化

#### 1.2 抖音平台逻辑

**数据从哪里追踪**

| 数据源 | 路径 | 提供内容 | 权限要求 |
|--------|------|---------|---------|
| 巨量云图 | 云图后台 → 品牌资产 | 品牌资产、人群资产（A1-A4）、内容数据 | 品牌方开通 |
| 巨量千川 | 千川后台 → 报表 | 广告消耗、ROI、CPM、CTR | 投放账户权限 |
| 抖音创作者平台 | creator.douyin.com | 达人数据、内容表现 | 品牌方后台 |
| 抖音搜索 | App搜索框 → 输入关键词 | 话题播放量、热搜榜 | 公开可用 |
| 蝉妈妈/飞瓜 | 第三方工具 | 竞品投放数据、KOL合作动态、内容素材 | 付费订阅 |

**核心认知**

抖音是「兴趣推荐 + 冲动转化」平台。用户没有明确消费意图被推送到内容，内容前三秒决定用户是否停留，算法根据完播率分配推荐流量池。

**关键数字**
- 流量池层级：200播放 → 2,000 → 2万 → 20万 → 200万+
- 每一级流量池的进入条件：上一级的完播率、互动率、分享率
- 茶饮内容最佳时长：15-30秒
- 冲动转化路径：看到 → 感兴趣 → 点击购物车 → 购买，约5-15秒
- 前三秒完播率：决定是否进入下一级推荐流量池的核心指标

#### 1.3 茶饮启示：双平台分工策略

**小红书：发现型场景**
- 新品上市前7-10天开始预埋搜索词
- 内容方向：产品测评、口味对比、隐藏喝法、DIY教程
- 核心KPI：搜索量增长率、笔记渗透率、品牌词搜索排名
- 策略定位：不是等用户刷到，是让用户搜到的时候你排在前面

**抖音：触发型场景**
- 新品上市当天开始脉冲式投放
- 内容方向：第一口惊艳感、制作过程、场景带入、情绪共鸣
- 核心KPI：完播率、ROI、商品点击率
- 策略定位：不是让用户了解产品，是让用户「现在就想喝」

**同品双平台内容差异**（以一款新品果茶为例）
- 小红书标题：「夏天必喝！这杯果茶的果肉多到我以为在吃水果」
- 抖音前3秒：吸管插进杯子的一瞬间，果肉和冰块翻涌的特写镜头
- 小红书封面：45度产品特写，暖色调，文字标签「果肉×30%」
- 抖音封面：手持饮品在阳光下，动态画面，大字「第一口就沦陷」

**实操练习（45分钟）**
1. 每位学员用自己手机打开小红书，搜索「夏日果茶」，记录前10条笔记的：
   - 标题前8个字
   - 封面第一印象（产品特写/场景/文字/人物）
   - 发布日期
2. 切换抖音搜索同一关键词，记录前10条视频的：
   - 前3秒画面描述
   - 标题文字
3. 对比两张记录表，写出一份「同一产品在小红书和抖音的策略差异总结」（限300字）
4. 小组讨论15分钟，每组选一人用2分钟分享核心结论

### 模块2：热点洞察方法

#### 2.1 每日巡检SOP（共15分钟）

**数据从哪里追踪——巡检清单**

| 序号 | 数据源 | 访问路径 | 具体查看内容 | 用时 | 产出物 |
|------|--------|---------|-------------|------|--------|
| 1 | 小红书热搜榜 | App → 发现 → 搜索框 → 热搜榜 | 热搜词排名、进入/退出榜单变化、上升速度 | 2分钟 | 热搜TOP20截图 |
| 2 | 小红书话题榜 | App → 发现 → 话题页 | 话题浏览量、增长率、相关内容数量 | 2分钟 | 高增长话题记录 |
| 3 | 灵犀行业热词 | 灵犀 → 搜索赛道 → 热词分析 | 品类搜索词TOP50、近7天搜索量变化趋势 | 3分钟 | 异常增长词列表 |
| 4 | 竞品小红书主页 | App → 搜索竞品名 → 主页 | 当日发布数量、平均互动量、内容方向判断 | 2分钟 | 竞品动态记录 |
| 5 | 抖音热搜榜 | App → 搜索 → 热搜榜 | 茶饮相关热点话题及播放量 | 1分钟 | 关联热搜记录 |
| 6 | 行业信息渠道 | 微信/飞书社群、36氪/亿邦等行业号 | 新品发布信息、联名官宣、平台规则变更 | 3分钟 | 行业变动简报 |
| 7 | 第三方监测 | 蝉妈妈/飞瓜 → 竞品监测 | 竞品投放量级变化、KOL合作动态 | 2分钟 | 投放动态摘要 |

**操作步骤到颗粒度**

**Step 1：热搜词捕获（2分钟）**
- 打开小红书App，进入发现页搜索框
- 截图热搜榜TOP20，保存到「巡检文件夹/YYYY-MM-DD/」目录
- 记录当日总时间戳

**Step 2：热度词分级（2分钟）**
- 逐一判断每个热搜词与古茗的关联度：
  - **A类**：词本身与茶饮/饮品直接相关（如「奶茶DIY」「果茶测评」「新品奶茶」）——可能有内容机会
  - **B类**：词与饮用场景/情绪间接相关（如「治愈系」「办公室日常」「闺蜜下午茶」）——可能包装后有内容机会
  - **C类**：完全无关——忽略不计

**Step 3：热度追踪（3分钟）**
- 对A类和B类词，记录以下字段：
  - 词名
  - 当前排名
  - 与昨日排名对比（上升/下降/新入榜/出榜）
  - 搜索量级（有灵犀权限时补充精确数据）

**Step 4：竞品动态监测（3分钟）**
- 依次打开核心竞品（喜茶、奈雪的茶、霸王茶姬、瑞幸、库迪、茶百道、爷爷不泡茶、茉莉奶白）的小红书主页
- 记录：当日发布内容数量、内容平均互动量、内容方向判断（新品/联名/促销/日常种草）

**Step 5：热点判断（3分钟）**
- 对每个A类热搜词做三维评估：

| 评估维度 | 评分标准（1-5分） | 数据来源 |
|---------|-----------------|---------|
| 话题热度 | 话题浏览量增长趋势 | 话题榜 |
| 品牌相关性 | 与古茗品牌调性/当前推品匹配度 | 主观判断+品牌手册 |
| 可执行性 | 24小时内能否产出跟进内容 | 团队资源评估 |

- 综合分 = 话题热度 × 品牌相关性 × 可执行性
- 综合分 ≥ 30分：当日跟进，分配内容任务
- 综合分 15-29分：纳入素材库，择机跟进
- 综合分 < 15分：存档，不跟

**Step 6：输出巡检报告（2分钟）**

输出模板：

```
  · ____：新入榜热搜词 → 判断：___ → 建议动作：___
  B类词：
  · ____：（简述包装后的内容方向）

【竞品动态】
```

#### 2.2 灵犀平台深度使用指南

**操作路径与每一步的含义**

**第一步：进入搜索赛道**
- 路径：灵犀首页 → 左侧菜单「搜索赛道」→ 顶部搜索框
- 输入品类词（建议输入二级品类词而非「茶饮」这种一级词，如「果茶」「奶茶」「轻乳茶」）
- 粒度：品类词越精准，数据越有参考价值

**第二步：解读搜索趋势图**
- 默认展示「近30天搜索量趋势」
- 需要关注的关键点：
  - 波峰：峰值搜索量、峰值出现的日期、峰值前的增长斜率
  - 波谷：谷值搜索量、谷值持续天数
  - 同比对比：切换到「去年同期」看周期性规律
  - 周末效应：如果是茶饮品类，周末搜索量通常会高15-30%

**第三步：分析搜索词联想**
- 路径：搜索趋势图下方 → 「搜索词联想」Tab
- 默认展示与该词关联度最高的20个搜索词
- 分类方法：
  - 品牌词：含品牌名称的词（古茗、喜茶等）
  - 品类词：产品类别词（果茶、奶茶、酸奶昔）
  - 场景词：使用场景（下午茶、解暑、减肥饮品）
  - 功效词：功能诉求（低卡、健康、好喝）
- 核心洞察：「高频且低竞争」的词——搜索量高但品牌内容渗透率低——品类中的蓝海

**第四步：解读人群画像**
- 路径：搜索趋势图下方 → 「人群画像」Tab
- 关注维度：
  - 年龄分布：核心年龄段占比
  - 地域分布：TOP5城市及其占比
  - 消费偏好：关联品类TOP3
  - 消费力层级：高价/中价/低价偏好的比例
- 产出物：一段人群一句话描述，如「18-25岁女性为主，新一线城市集中，消费力中高水平，同时关注美妆和健身品类」

**第五步：提取热门内容特征**
- 路径：搜索赛道下方 → 「内容洞察」模块 → 按互动量排序
- 提取维度：
  - 封面风格TOP3及其占比
  - 标题公式TOP3（提取高频关键词和句式）
  - 内容类型的互动率对比（测评 vs 种草 vs 教程 vs 情感）
- 产出物：一段内容策略建议，如「以产品特写封面为主(60%)，标题多用数字+情绪句式，测评类内容互动率最高(3.2%)」

**实操练习（30分钟）**
1. 每人选择一个古茗当前推的品类词（如「果茶」或指定的其他词）
2. 按以上五步完成完整赛道洞察
3. 输出一份洞察简表，内容包含：
   - 搜索趋势图分析结论（2句话）
   - TOP5高价值搜索词（含搜索量级 + 竞争评估）
   - 核心TA一句话描述
   - 热门内容特征组合公式

#### 2.3 素材库搭建方法

**入库内容填写规范——9字段（缺一不可）**

| 序号 | 字段名 | 填写标准 | 正确示例 | 错误示例 |
|------|--------|---------|---------|---------|
| 1 | 品牌/品类 | 品牌名 + 品类，精确到SPU | 古茗-超A芝士葡萄 | 古茗 |
| 2 | 内容链接 | 完整小红书/抖音URL | https://www.xiaohongshu.com/... | "小红书搜XX" |
| 3 | 发布时间 | YYYY-MM-DD | 2026-07-01 | "7月初" |
| 4 | 点赞 | 精确到百位 | 1.2万 | "挺多的" |
| 5 | 收藏 | 精确到百位 | 3,000 | 留空 |
| 6 | 评论 | 精确到十位 | 456 | 留空 |
| 7 | 分享 | 精确到十位 | 120 | 留空 |
| 8 | 标题 | 完整复制原文 | "夏天第一杯果茶！..." | "大概是一杯果茶" |
| 9 | 封面风格 | 从以下选一：产品特写/场景图/文字图/对比图/人+产品 | 产品特写 | "好看的" |
| 10 | 内容类型 | 从以下选一：种草/测评/探店/教程/情感/对比 | 种草 | "营销内容" |
| 11 | 爆点分析(核心) | 至少3个分析维度，每个维度一句话 | ①标题"数字+情绪"激发点击 → ②封面高饱和产品特写 → ③正文有竞品对比 | "做得好" |
| 12 | 可复用公式(核心) | 可直接复用的标题/封面/结构公式 | 标题："[数字]+[情绪词]+[产品名]"，如"3杯让人回头的果茶" | 空或泛泛而谈 |

**素材库分类体系**
- **一级分类（按品类）**：果茶 / 奶茶 / 咖啡 / 轻乳茶 / 酸奶昔 / 冰淇淋
- **二级分类（按内容类型）**：测评对比 / 颜值种草 / 隐藏喝法 / 情感共鸣 / 场景带入 / 制作教程
- **三级标签**：
  - 节点：520 / 端午 / 七夕 / 国庆 / 双11 / 冬季 / 夏季 / 日常
  - 风格：清新 / 可爱 / 高级 / 搞怪 / 治愈

**日常任务机制**
- 每人每周至少入库3条茶饮行业爆款内容（互动量>5000）
- 只入库爆款（数据好的才值得分析）
- 每周五下午团队review一次，流程：
  1. 每人推荐1条本周最佳入库内容（1分钟说明为什么选这条）
  2. 讨论这条内容可复用的点（3分钟）
  3. 入库到「可复用公式库」中共享

**素材库产出物示例**

### 模块3：内容养成

#### 3.1 好内容判断四标准（附操作步骤和数据源）

**标准一：搜索友好**

判断标准：标题中是否包含用户在搜索框会输入的词

具体操作步骤：
1. 写标题前，先在搜索框输入你打算用的关键词
2. 看搜索结果页第一屏的内容风格（标题类型、封面类型、发布时间）
3. 确保你的标题能融入搜索结果页而不显得突兀
4. 标题至少包含1个品类词 + 1个场景词

检查清单：
☐ 标题中是否至少有一个品类词（果茶/奶茶/新品）？
☐ 标题中是否至少有一个场景词（夏天/下午茶/办公室）？
☐ 在搜索框输入标题的核心关键词，你的内容风格是否匹配第一屏？
☐ 标题前3-5个字是否包含核心搜索词？

**标准二：点击友好**

判断标准：封面 + 标题能否在2秒内激发点击欲望

具体操作步骤：
1. 做好内容后，把封面+标题截图发给一个不了解产品的人
2. 问她：「你想点进来看吗？」——诚实回答才算数
3. 封面必须有视觉焦点（一个就好——产品特写/人物情绪/前后对比/超大文字标签，不要多个焦点）
4. 标题前8个字必须有钩子（数字/情绪/悬念/冲突）

数据源验证：
- 小红书创作中心 → 笔记数据 → CTR（点击率）
- CTR低于品类均值的笔记需要重新优化封面或标题

**标准三：阅读友好**

判断标准：用户是否能在30秒内获取核心信息

具体操作步骤：
1. 正文前100字出现核心结论（不是铺垫，不是"最近发现..."）
2. 用列表/分段/emoji做视觉分区——大段文字在手机上等于没人看
3. 检查：去掉所有形容词和废话，信息密度是否足够

数据源验证：
- 小红书创作中心 → 笔记数据 → 完读率
- 完读率低于60%需要压缩篇幅或提前放置核心信息

**标准四：转化友好**

判断标准：用户看完后知道下一步做什么

具体操作步骤：
1. 正文结尾必须有1句行动引导
2. 行动引导的类型：
   - 门店引导：「快去店里报这句话」「定位附近的古茗」
   - 互动引导：「评论区告诉我你觉得xx还是xx更好喝」
   - 传播引导：「@你的奶茶搭子来看」「点赞收藏下次点单用」
   - 复购引导：「这个喝法我喝了三次了，信我」
3. 结尾必须有1个闭合句——重新强调核心卖点

数据源验证：
- 评论中出现「在哪买」「怎么点」「多少钱」等咨询词的比例
- 咨询评论占比>20%说明转化引导不足，需要修改

#### 3.2 爆款内容公式库

**标题四个公式（各配3个茶饮行业已验证案例）**

**公式一：数字 + 结果**
- 茶饮案例①：「我喝了7杯果茶，只有这杯让我回购了3次」
- 茶饮案例②：「试了5种隐藏喝法，这种好喝到我每天都在喝」
- 茶饮案例③：「古茗这3款新品，我只推荐这1杯」
- 适用场景：测评类内容、多产品对比、经验分享

**公式二：身份 + 场景**
- 茶饮案例①：「打工人夏天的续命水，办公室冰箱里一定要有它」
- 茶饮案例②：「健身完来一杯，清爽好喝零负担」
- 茶饮案例③：「学生党必看！一杯奶茶钱的快乐」
- 适用场景：场景种草、圈层运营

**公式三：对比 + 冲突**
- 茶饮案例①：「以前觉得古茗很一般，直到喝了这杯」
- 茶饮案例②：「全网都在骂的这杯，我喝完想给它道歉」
- 茶饮案例③：「同样都是果茶，为什么这杯卖得最好」
- 适用场景：品牌认知重塑、新品推广、竞争差异化

**公式四：情绪 + 行动**
- 茶饮案例①：「夏天不喝这个我真的会难过」
- 茶饮案例②：「喝完第一口我就知道会回购」
- 茶饮案例③：「这杯好喝到我舍不得发朋友圈（但还是发了）」
- 适用场景：引爆传播、制造社交货币

**封面四个公式（配技术参数）**

**公式一：产品特写 + 高饱和**
- 拍摄参数：产品占画面60-70%，45度俯拍，背景虚化
- 色彩调整：饱和度+20%，对比度+10%，亮度+5%
- 适用：新品首发、核心产品主视觉

**公式二：人物场景 + 自然感**
- 拍摄参数：侧45度角，人物不看镜头，自然光线
- 场景：户外/咖啡厅/办公室——必须与产品使用场景一致
- 适用：生活种草、场景教育

**公式三：对比图 + 左右分屏**
- 常见对比类型：喝前vs喝后、古茗vs竞品、旧款vs新款
- 画面要求：左右两张图的光线/角度/距离必须一致才有对比价值
- 适用：产品升级、竞品差异化

**公式四：文字标签 + 突出卖点**
- 文字规格：粗体，不超过8个字，白色/高亮色
- 标签类型：价格（¥18）/ 限定（夏季限定）/ 新口味 / 联名
- 放置位置：画面上方1/3处或右下角
- 适用：信息型内容、节点限定推广

**内容结构三段式**

| 段位 | 字数 | 内容 | 公式 | 目的 |
|------|------|------|------|------|
| 开头 | 前50字 | 痛点/情绪/悬念切入 | "你是否有过..." "说实话..." "没想到..." | 前15字不跳出 |
| 正文 | 100-200字 | 结论前置 + 3个支撑点 | 结论 → 理由1 → 理由2 → 理由3 | 30秒获取核心信息 |
| 结尾 | 最后50字 | 总结 + 行动引导 | "总结来说..." + "快去..." | 引导下一步动作 |

**实操练习（40分钟）**
1. 每人从素材库选一款产品
2. 基于四个标题公式各写一个标题（共4个版本）
3. 选择最合适的标题，配封面方向和完整正文结构
4. 组内互评：用搜索友好/点击友好/阅读友好/转化友好四标准打分

#### 4.2 目标人群分层法

**三层人群定义与数据识别**

**交易人群（核心层）**
- 定义：近30天购买过古茗的会员 + 茶饮品类高频消费（月≥8次）
- 数据识别：灵犀 → 品牌词搜索且点击>3次 → 圈选
- 沟通方向：新品试饮邀请、会员专属价、集卡兑换
- 内容策略：强调新品与经典款对比、老客才知道的隐藏喝法
- 触达渠道：会员短信推送、微信小程序弹窗、小红书品牌号专属内容

**兴趣辐射人群（中间层）**
- 定义：品类搜索词下互动的用户 + 关注茶饮内容但未关注古茗
- 数据识别：灵犀 → 品类词搜索>2次 且 品牌词搜索=0次 → 圈选
- 沟通方向：产品差异点沟通、解决「为什么选古茗」
- 内容策略：对比测评（古茗 vs 竞品）、新品买点和场景突出
- 触达渠道：小红书信息流、抖音信息流、KOL种草

**帮助传播人群（外层）**
- 定义：对内容有兴趣的高互动用户 + 泛品类人群
- 数据识别：灵犀 → 茶饮内容互动率>品类均值 且 非品牌用户 → 圈选
- 沟通方向：内容分享价值、社交货币
- 内容策略：隐藏喝法/DIY教程、创意改造、高颜值晒单
- 触达渠道：高质量UGC放大、自然流量内容、挑战赛话题

**灵犀人群打包操作步骤**
1. 进入灵犀 → 人群管理 → 创建人群包
2. 交易人群规则：「近30天 搜索'古茗' 且 点击笔记>3次」
3. 兴趣人群规则：「品类词搜索>2次」且「品牌词搜索=0次」
4. 传播人群规则：「茶饮品类内容互动率>品类均值」且「非品牌用户」
5. 命名规范：古茗_人群类型_YYYYMMDD
6. 三个独立人群包分别保存

目标：不是出爆文，是让用户开始搜索产品、积累搜索词权重。

目标：搜索量峰值和曝光峰值在同一时间点形成共振效应。

| 动作 | 操作步骤 | 数据追踪 | 量化指标 | 负责人 |

| 搜索端卡位 | 确保品牌词+产品词+核心场景词出现在搜索结果前三 | 手动搜索验证 + 灵犀搜索排名 | 品牌词排名第1、产品词排名前3 | 投放运营 |

**延续期（节点后3-5天）**

目标：利用节点余温做内容资产沉淀和ROI回收。

| 动作 | 操作步骤 | 数据追踪 | 量化指标 | 负责人 |
|------|---------|---------|---------|--------|

**每日评论情感标注操作**
1. 打开TOP10笔记评论区，每条评论判断情绪类型：
   - 正向（👍）：好评、表达想买、已购买好评
   - 咨询（❓）：问价格、门店、口味、成分
   - 负向（👎）：差评、价格贵、不好喝
   - 种草（💚）：@好友、想尝试、求教程
2. 计算四种情感占比
3. 输出情绪日报：

| 判断标准 | 解读 | 行动 |
|---------|------|------|
| 正向>60% + 种草>30% | 产品认可度极高 | UGC激励好时机 |
| 咨询>30% | 内容关键信息缺失 | 补充价格/门店/口味信息到后续内容 |
| 负向>20% | 产品问题或沟通偏差 | 反馈产品部门 + 调整内容角度 |
| 统一负面词出现 | 系统性产品问题 | 紧急反馈，可能需要产品调整 |

- 关键检查点：前两周热度达标但转化不达标 → 承接端问题，非内容问题

#### 6.4 UGC追踪与放大

**UGC识别标准（四选三即纳入追踪）**
1. 互动率超过品类均值2倍
2. 评论区有≥3条「求教程」「求配方」「在哪买」等行动评论
3. 被≥2个其他博主引用或@
4. 内容有明显传播元素（可模仿、可分享、有话题性）

**UGC激励设计操作步骤**
1. 确定激励形式：晒单抽奖（门槛最低，效果最稳定）
2. 参与门槛：拍1张产品照片 + 写1句话 + 带指定话题tag
3. 奖品设定：新品兑换券 / 第2杯半价 / 限定周边
4. 发布时间：新品上市第3天（第一批消费者已尝鲜，晒单意愿最强）
5. 流量加持：品牌号发布活动帖 + 信息流小预算助推
6. 数据追踪：每日统计活动话题浏览量、参与笔记数、互动率

**UGC放大操作流程**
1. 每天筛选互动率TOP5的用户UGC
2. 做10分制质量评分：
   - 画面质量（3分）：清晰度、光照、构图
   - 内容价值（3分）：独特视角、创意、信息增量
   - 传播潜力（2分）：可模仿性、可分享性
   - 品牌友好（2分）：正面、突出品牌
3. 评分≥7分 → 联系创作者获取二传授权
4. 授权后 → 信息流投放放大
5. 追踪放大后CTR、互动率、转化率
6. 放大后CTR≥原笔记CTR的70% → 追加预算

**投放决策框架**
- 初始投放预算：500-2000元/条（测试期）
- 测试时间：24小时
- 正向决策标准：放大CTR≥原笔记CTR的70%
- 追加预算：5000-10000元/条
- 停投标准：放大CTR<原笔记50%或ROI<1

### 模块7：复盘体系

#### 7.1 复盘核心逻辑

**复盘的目的不是证明做对了什么，是为了下次做得更好。**

每次复盘只回答一个问题：**下次遇到同样的场景，我们的决策会不会不一样？**

复盘频率：
- 每个产品/节点结束后：完整复盘（60分钟）
- 每周五下午：周度快复盘（15分钟，仅看数据异常和关键动作）
- 每季度：季度综合复盘（120分钟，盘点方法论迭代）
