# 「老字号·新活力」青年数字营销官孵化计划

## 宣导传播方案（独立方案）

**方案定位：** 赛事赛前及赛程全程的传播执行方案——覆盖进校园宣导与线上全平台宣导，含具体内容参考（Ref）文案
**适用对象：** 黄浦区就业促进中心项目组、执行机构、合作高校、支持企业
**方案版本：** V1.0（2026年8月27日）

---

## 一、宣导总策略

### 1.1 传播目标

| 目标 | 量化指标（建议） |
|---|---|
| 报名量 | 覆盖高校≥15所，报名学生≥500人 |
| 声量 | 赛事全程内容总曝光≥500万（平台统计口径） |
| 品牌 | "老字号新声代"话题全网可见，成为黄浦区年度青年活动IP |
| 转化 | 报名→海选转化率≥70%，校园宣讲会到场→报名转化率≥50% |

### 1.2 传播主线

不是"招人参赛"，而是"一场老字号与年轻人的双向奔赴"。三条叙事线并行：

- **老字号线**：百年品牌在等你来"翻译"——唤起年轻人的文化自豪与创作欲；
- **机会线**：不只有比赛，还有课程、认证、实习、工作——就业导向实打实；
- **城市线**：黄浦老字号×Citywalk×新声代——城市文化事件感。

### 1.3 阶段划分

| 阶段 | 时间（对应赛事周次） | 核心任务 |
|---|---|---|
| 预热期 | 报名前2周（W1-W3） | 官宣造势、悬念铺垫、校园大使招募 |
| 招募期 | 3-4周（W3-W6） | 报名转化、校园宣讲、平台种草 |
| 赛程期（中期） | 6-8周（W7-W16） | 进程内容化、选手故事、决赛直播 |
| 收官期 | W17-W20 | 成果展、获奖公示、战报沉淀 |

### 1.4 内容资产化原则

赛事全程所有内容（选手作品、花絮、导师金句、老字号故事、数据战报）均归档进入"老字号·新活力"内容素材库，赛后复用为政府年度材料、来年赛事素材、老字号企业宣传素材。

## 二、进校园宣导方案（线下）

### 2.1 目标与节奏

- **目标**：15所高校（上海为主，长三角为辅）学生触达，完成≥500人报名中的约60%来源
- **节奏**：报名前2周启动预热触达，招募期3-4周内完成全部宣讲会（每校1场，重点校2场）

### 2.2 校园渠道体系（五层触达）

| 层级 | 渠道 | 动作 |
|---|---|---|
| 官方层 | 就业办/学工部/团委 | 官方发文（就业信息网、公众号）、学分/综评认定沟通 |
| 院系层 | 商科/传媒/设计/计算机学院 | 学院公众号转发、辅导员群通知、课堂5分钟宣讲 |
| 社团层 | 新媒体社、创业社、摄影社、汉服社等 | 社团合作办宣讲、社团群扩散 |
| 个人层 | 校园大使（每校2-3人） | 朋友圈/校园墙/社群持续种草 |
| 传播层 | 校园KOL/表白墙/闲置群 | 定向投放报名信息 |

### 2.3 校园大使机制

- **招募**：每所合作高校招募2-3名校园大使（优先新媒体社团骨干、有内容创作经验者）
- **职责**：校内扩散（每周1-2条内容）、组织宣讲会到场、答疑引导报名、收集校内反馈
- **激励**：社会实践证明（就促中心盖章）+赛事周边礼包+优先进入孵化营+推荐信（表现优异者）
- **培训**：线上30分钟启动会（项目介绍、报名引导话术、物料使用）

### 2.4 宣讲会标准流程（60-90分钟模板）

| 环节 | 时长 | 内容 |
|---|---|---|
| 开场 | 5分钟 | 播放60秒赛事宣传片（老字号场景+学生作品混剪） |
| 领导致辞 | 5分钟 | 就促中心介绍"老字号·新活力"专项行动与就业服务 |
| 项目介绍 | 10分钟 | 三段式：比赛（怎么比/三个档位）→课程（学什么/种草学认证）→人才计划（工作从哪来） |
| 老字号环节 | 15分钟 | 1-2家老字号代表现场分享（品牌故事+真实命题发布），制造"命题新鲜感" |
| 往届成果 | 10分钟 | 数据+案例：往届大赛作品、获奖者去向（有真实就业案例最好） |
| 奖项与机会 | 10分钟 | 奖金/证书/认证/实习直通/双选会，强调"不是一场普通比赛" |
| 报名指引 | 5分钟 | 扫码报名、参赛档位选择、作品提交要求 |
| Q&A | 10-15分钟 | 现场答疑（常见问题见2.6话术） |
