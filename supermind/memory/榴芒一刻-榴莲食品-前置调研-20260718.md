### 3.6 在中国市场的定位

辻利茶铺在中国定位为**中端抹茶甜品连锁品牌**，以日本百年老铺的品牌背书，通过加盟模式快速铺开。产品线以抹茶冰淇淋、抹茶甜品(布丁、铜锣烧、大福等)、抹茶饮品为主，同时通过联名合作(全家/KKV/寿司郎)拓展品牌影响力。其商业模式更接近"加盟驱动的快消茶饮品牌"而非高端精品甜品店，与榴芒一刻的D2C品牌电商模式差异显著。

## 四、可比冷冻甜品品牌筛选

### 品牌1：诺心 LECAKE

- **规模/定位**：中高端线上蛋糕品牌，成立于上海，主打芝士蛋糕。蝉联四届食品品质品鉴大会金奖，年营收估计数亿元级(精确数据未查到)。纯线上预订+冷链配送模式，覆盖全国多个城市。
- **与榴芒一刻的可比性**：同为线上起家的预包装甜品品牌，冷链配送体系相似。客单价中等偏高(200-400元/个蛋糕)。但产品线以整只蛋糕为主，非"冷冻甜品零食"定位。
- **来源**：lecake.com官网；360搜索相关结果

### 品牌2：21cake（廿一客）

- **规模/定位**：2004年创立于北京，中国线上蛋糕品牌先驱。无实体店模式，纯线上预订+中央工厂生产+冷链配送。年营收据行业估计在数亿元级别(精确数据未查到)。产品以方形蛋糕为主，定位中高端。
- **与榴芒一刻的可比性**：模式高度相似(线上D2C+中央工厂+冷链配送)。但成立更早、体量可能更大。产品为整只蛋糕，非水果甜品细分品类。
- **来源**：360搜索/文库相关结果

### 品牌3：Mvuke Tokyo（布歌东京）

- **规模/定位**：定位高端日式甜品品牌，以布丁和蛋糕为主打。线上线下结合，在一线/新一线城市高端商场设有专柜。年营收估计亿元级(精确数据未查到)。产品形态包括布丁杯、蛋糕卷、伴手礼等。
- **与榴芒一刻的可比性**：客单价和品牌调性相近或略高，都有冷链短保产品，都有线上+线下渠道。但品类不同(综合日式甜品 vs 榴莲专门)。
- **来源**：根据行业认知综合判断，精确数据需进一步调研

### 5.7 修正后的规模判断

#### 保守估算（基于硬数据线性外推）

```
2022年: 2.8亿（✅ 已确认）
2023年: 约5-6亿（基于"1-4月翻倍"推断，未确认）
2024年: 约7-9亿（保守估计30-50%增长，基于单品扩展+线下扩张）
2025年: 约10-14亿（保守估计30-50%增长，基于品类扩展+门店启动）
```

#### 扩张推估（基于增速趋势+品类扩张+渠道拓展）

```
2022年: 2.8亿（✅ 已确认）
2023年: 约5-6亿（基于"1-4月翻倍"+全年推算）
2024年: 约8-12亿（品类从千层→月饼→冰淇淋→粽子全矩阵；线上+线下全渠道）
2025年: 约12-18亿（新增冰淇淋品类第一认证+开启门店扩张+冰博会品牌露出）
```

#### 💡 我们的判断：2025年大概率在8-15亿区间

**依据**：

1. **增速曲线**：2020年200%增长 → 2023年上半年100%增长 → 尽管增速放缓但仍处于高速增长期。即使2024-2025年增速放缓至30-50%，2.8亿基数下两年也可到5-6亿。但考虑到品类大幅扩展（3→4个认证品类）和渠道大幅扩张（线上→全渠道→自营门店），实际增速大概率更高。

2. **品类矩阵效应**：月饼干果→冰粽→冰淇淋→日常品（千层/冻肉/烤烤/手撕包），从单一季节品（中秋）扩展到全年多季节（端午+中秋+夏季+日常），营收季度波动大幅平滑，全年总盘子自然放大。

3. **渠道杠杆**：纯线上D2C → 天猫头部主播 → 盒马/沃尔玛 → 自营门店500+，每个渠道层级都是量级差异的增长。线下尤其是商超渠道的单品铺货量级远大于线上单店。

4. **用户基数翻倍**：1000万→2000万家庭，意味着复购基数翻倍。

5. **反证**：如果2025年只有2-3亿，无法解释：(a)连续拿下三个品类全国第一认证（认证费不菲）；(b)计划开设500+门店；(c)建榴莲产业园；(d)首次参加中国冰博会。这些动作都指向至少10亿级体量。

6. **Bing Copilot AI"2.8亿=2025年"的说法**：经原文核查，此为AI幻觉（将2022年数据张冠李戴到2025年），不可采信。

#### 未解决的问题

- **最核心缺口**：2024年和2025年的实际营收/GMV数字在公开来源中均未查到。榴芒一刻为私企，不公开财报，需天眼查年报（社保人数推算）、第三方电商数据或直接向企业方获取。
- **"6个亿"**的抖音视频标题无法验证是指榴芒一刻还是榴莲冰皮整体市场。
