# Image Remaster - 图片重排技能

**Version:** 1.0.0  
**Author:** MacLaw (yifan)  
**License:** MIT

## Description

把一张图片重排成更清晰、更美观、更简约的风格。

输入：任意图片（截图、海报、PPT、手机照片等）
输出：高清简约风格的新图片

## Trigger

当用户说"重排图片"、"图片重新设计"、"帮我重新排版这张图"时调用。

## Input

- 用户提供的图片（通过 image tool 或直接发送）
- 用户的简短说明（可选）：比如"简约商务风"、"PPT风格"、"小红书封面"等

## Output

生成的图片，自动发送到当前对话。

## Style Guidelines

生成时遵循以下原则：
- **简约清晰**：去除杂乱元素，突出主体
- **现代感**：配色协调，留白得当
- **信息清晰**：层次分明，重点突出
- **高质量**：输出高清版本

## Prompt Template

```
请把这张图片重新设计成简约、高清、专业的风格。
要求：
- 主体清晰突出
- 配色协调简约
- 排版工整有序
- 输出高清版本
- 风格：[用户指定的风格，如无则默认"简约现代风"]

参考原图内容进行合理再创作，保持核心信息不变。
```

## Usage Notes

1. 图片通过 image 工具分析后，用 image_generate 生成
2. 如有多个相似图片，逐个处理
3. 生成完成后直接发送图片给用户
4. 如用户对风格有具体要求，按需调整 prompt
