## 关键技术经验（可复用）

1. **本机没有 rsvg-convert / cairosvg / inkscape / magick**。SVG 转 PNG 用 Chrome 无头：
   `"/Applications/Google Chrome.app/Contents/MacOS/Google Chrome" --headless=new --disable-gpu --hide-scrollbars --no-sandbox --force-device-scale-factor=1 --default-background-color=00000000 --window-size=W,H --screenshot=out.png file:///abs/path/to.svg`
   透明底靠 `--default-background-color=00000000`，白底靠 `FFFFFFFF`。
2. **飞书 rich-text（post）消息里的附件 OpenClaw 不会自动下载**。要用 app 凭据走 API 取：
   - 取消息：`GET /open-apis/im/v1/messages/{message_id}` → body.content 里有 `files[].file_key`
   - 下文件：`GET /open-apis/im/v1/messages/{message_id}/resources/{file_key}?type=file`
   - `message` 工具的 read 只回文本，看不到 post 里的附件，需要查 raw API。
3. **发 SVG 文件给逸凡**：`message` 工具的 attachments/file 传不上去（降级成文本路径）。改用 API：
   - 上传 `POST /open-apis/im/v1/files`（file_type=stream, multipart）
   - 发送 `POST /open-apis/im/v1/messages?receive_id_type=open_id`，msg_type=file
   - 凭据从 `~/.openclaw/openclaw.json` 的 `channels.feishu.appId/appSecret` 读，不要手打（手打会拿到占位串）。用 python + urllib 取 tenant_access_token，curl 做 multipart 上传。
4. **飞书一条消息只带得动一张图**，多图要分条发。
5. 图片理解模型今天不可用（minimax 余额不足、dots 404、glm 超时）。替代方案：用 `swift` + Vision 框架做本地 OCR（脚本 `output/manshi-logo/ocr.swift`，可复用），能拿到带坐标的文本，靠坐标反推版式。
6. 工具进度卡片会显示 failed —— 只要命令链里有一条探测命令返回非零退出码就会标红，不代表任务失败。逸凡会问，记得主动解释。
