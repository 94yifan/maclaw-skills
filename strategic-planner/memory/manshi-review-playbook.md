# 曼拾策略复盘报告写作 Playbook

> 来源：曼拾内部三份文档整合——GRARI 一页纸模板 + 结案复盘报告一本通 + 四步教你轻松写出结案复盘

---

## 一、复盘的目的

对客：专业且好——让客户看懂钱花在哪、效果如何、下一步往哪走
对内：经验沉淀——好的可复用、不好的可规避

---

## 二、整体结构：总-分-总 + GRARI 框架

报告遵循总-分-总逻辑，融入 GRARI 五模块权重分配：

| 模块 | 权重 | 对应 Part |
|------|------|-----------|
| G - Goal 目标回顾 | 10% | Part 1 开篇 |
| R - Result 结果比对 | 10% | Part 1 主体 |
| A - Analysis 分析原因 | 40% | Part 2 + Part 3 |
| R - Review 目的回顾 | 10% | Part 1 结尾 |
| I - Insight 规律总结 | 30% | Part 4 |

四大 Part 展开：
- Part 1：投放成果（喜报——大标题 + 总结句 + 数据化表达）
- Part 2：内容策略分析
- Part 3：竞价策略分析
- Part 4：后续投放建议 + 下一步动作

---

## 三、各 Part 详细写法

### Part 1：投放成果

核心原则：擅用大标题 + 总括句 highlight + 数据化表达。关注客户真正在乎的指标。

#### 1.1 投放亮点

用表格+趋势图对比投前投后，分三组指标：

**搜索指标：**
- SOV/SOC（提升多少，行业排名变化）—— 注意：找直客拉全品牌数据，聚光后台只是代子账号维度有偏差
  - SOV = 在某关键词搜索结果下某品牌广告曝光量 / 该关键词下所有广告曝光量
  - SOC = 在某关键词搜索结果下某品牌广告点击量 / 该关键词下所有广告点击量
- 搜索指数（品牌词、品牌SPU词至少两个，对比投前提升）—— 以聚光为准，蒲公英后台辅助
- 回搜率（证明种草程度，无行业均值默认为0.5%）—— 回搜定义：用户看过广告流量下的笔记后48小时内在小红书搜索特定词的比率

**生意指标：**
- 全店GMV、ROI、进店成本 —— ROI 需自己计算（GMV/消耗成本），进店成本（消耗成本/UV），ROI 和进店成本需行业benchmark（问直客）
- 淘宝联盟维度：内容互动率、引流率、店铺新访客率、收藏加购率、转化率、店铺新客率

**口碑指标：**
- 搜索趋势与投放节奏相关度
- 浅层指标：CPE、CPC、CPM、CTR
- 深层指标：人群渗透率、内容渗透率、搜后曝光渗透率、人群资产
- 品牌广告数据达成（IP资源包、惊喜盒子、品专、火焰话题等）

#### 1.2 策略执行方法论

策略是什么（KFS分配比例等）→ 用了什么抓手（KFS）执行 → 达成了什么效果

#### 1.3 人群分析

核心目的：论证策划端人群策略价值

四象限人群分析：高/低消耗 × 高/低点击或转化
- 高点击/转化 + 高消耗人群：是否与策划端人群策略一致
- 高点击/转化 + 低消耗人群：可进一步拓展，增加预算
- 低点击/转化 + 高消耗人群：是否战略性放弃 or 更换沟通素材
- 低点击/转化 + 低消耗人群：是否战略性放弃 or 更换沟通素材

P/TI人群对比验证：P/TI人群和高消耗投放人群画像对比，共性论证策略价值，差异点用于纠偏+给出进一步人群策略建议

人群画像三维度分析：
1. 基础信息：性别/年龄/婚恋/母婴/消费水平/固定资产/地域/城市/消费档次 —— 反映人群基本形象和消费能力
2. 消费偏好：行业品类偏好/品牌偏好/消费金额/手机价格/品牌及型号 —— 反映人群消费习惯和消费态度
3. 内容偏好：内容兴趣偏好/内容关键词偏好/搜索词偏好/热点关注偏好/博主偏好 —— 反映人群内容行为习惯

占比反映人群整体特点，TGI 反映偏好程度。

---

### Part 2：内容策略分析

#### Overall 内容效果

- 笔记数据概览总表：按笔记方向归纳，需呈现总结性表达，不做模糊表达
- 选取博主的量级、数量、内容分配篇数、数据达成表现

#### 优质笔记分析

不按爆文定义笔记好坏，按客户目标定义：

用 XY 轴四象限处理，坐标轴选取需与客户关注目标匹配（回搜、进店成本、站外转化率、CTR、组件点击率、TI深度种草人数等维度），有定量取数范围值。

#### 评论区洞察

用户真实关注点在哪里 → 总结用户点 + 发散品牌可升级/改进什么

#### UGC 洞察

- 站内 UGC 数量
- UGC 讨论内容
- 品牌词云与 UGC 讨论核心的关联度 → 给出品牌新建议

#### 竞品分析（同期同类品 Case Study）

核心宗旨：看竞品哪里做得好，我们哪里欠缺，可以学到什么，变成我们自己的方法论

浅层指标：商单笔记数、预估投放金额、笔记预估曝光阅读互动量、搜索热度趋势、笔记内容规划（多看几页笔记得出场景×人群×买点的投放模式）

深度指标：人群渗透、阅读渗透、搜后曝光渗透、AIPS人群资产（含TI人数）

品牌广告分析：品牌广告、线下活动、电商动作 —— 关注对数据的正向影响 → 哪些可复用

竞品选定标准：站内优质赛道品牌、有在站内投放且花钱多的、销售产品类似的品牌。以客户想看的死对头为准。

---

### Part 3：竞价策略分析

#### 投放策略三段论

- 测试期：新笔记赛马测试及基础互动数据积累，挖掘CPC、CPM成本低的潜力笔记，搜索端品类词、品牌词露出
- 放量期：以CPE成本较低笔记持续放量，兼顾CPM成本，进行出价和定向优化
- 转化期：集中投放高转化人群，放大粉丝人群定向，TI成本降低

#### 渗透策略

目标人群圈选 → 基于投放目标圈选核心人群包 → 数据验证（CTR/CPE等指标对比行业基准）

#### 广告位策略

- 信息流广告 - 高效触达层：哪项指标最优，原因
- 视频流广告 - 深度互动层：哪项指标最优，原因
- 搜索广告 - 精准转化层：哪项指标最优，原因

#### 人群包分析

- 曝光人群分析：CPM 对比行业 benchmark
- 互动人群分析：CPE 对比行业 benchmark
- 总结：做得好的人群 + 需要优化的人群 + 需要停投的人群

---

### Part 4：后续投放建议 + 下一步动作

#### 行业/赛道洞察

数据来源地图：

| 来源 | 路径 | 看什么 | 用途 |
|------|------|--------|------|
| 蒲公英 | 创意中心-内容广场 | 竞品关键词表现、上下游词灵感、竞品投放商业笔记分类/博主量级 | 竞品内容策略对标 |
| 千瓜 | 品牌/品类搜索 | 博主、笔记、花费、笔记数据、行业、画像、舆情 | 竞品投放规模和效果 |
| 灵犀 | 洞察-行业-市场机会 | 品牌在赛道内整体表现、搜索量/SOV/渗透排名、SPU竞争格局 | 深度洞察和预算牵引 |
| 直客 | 拉取 | 大盘数据、行业benchmark、竞品消耗 | 数据校准 |

四象限行业格局分析（灵犀）：
- 第一象限（高阅读高搜索）：保持优势，加大营销投入巩固份额
- 第二象限（高阅读低搜索）：提升品牌关键词优化，加强用户主动搜索引导
- 第三象限（低阅读低搜索）：综合提升品牌声量，KFS助力
- 第四象限（低阅读高搜索）：优化内容质量和人群匹配，拉大笔记数量

#### 下一步动作整合规则

⚠️ 强制规则：下一步动作不能杜撰。必须满足两个条件：
1. 每一个动作都能回溯到前文（Part 1-3）中分析过的具体发现
2. 结合行业趋势分析，确保建议方向有趋势支撑

整合方法：
- 遍历 Part 1-3 中所有出现过下一步/建议/优化的结论句
- 合并同类项，按优先级排序
- 拆分为三个维度：内容 / 竞价 / 执行对接
- 每个动作写清楚：做什么 + 为什么（引用前文哪个发现）+ 怎么做

## 四、策略型分析强制格式

每一条策略型分析必须遵循三段式：

```
1. 一句话总结结论（这个数据说明什么）
2. 两到三句话阐述如何通过量化数据得出这个结论（用了什么对比参照物、什么数据支撑）
3. 一句话提未来建议和方向
```

示例：

> 本次投放CPE优于行业基准60%。信息流CPE均值2.0，对比行业benchmark 6.15-9.27处于最低值以下；其中都市活力女性人群CPE仅0.7，互动成本全组最优。后续情感向内容应对该人群加大投放权重至40%。

不是这样的：
- ❌ "CPE表现优异" → 没有量化、没有参照物、没有下一步
- ❌ "CTR 15.6%，表现很好，建议继续保持" → 没有对比参照物，建议空洞

## 五、结论写作红线

### 红线一：数据与结论必须有因果关系

- ❌ "CPM 低，说明触达人群精准" → CPM 反映的是系统出价竞争力，精准度看 CTR 和 CPC
- ❌ "进店 UV 量大，说明引流高效" → 进店 UV 量只说明跑量好，引流效率看进店率
- ❌ "进店率和转化率优于大盘，说明 GMV 更高" → 只能说明钱花得性价比高，GMV 取决于钱能不能花够
- ✅ "种草成本仅0.46，在本次投放所有内容方向中最低，情感共鸣类内容能以最低成本触达目标用户。建议将爱的群像类内容预算占比提升至40%。"

### 红线二：最小暴露负面原则

热度下降、数据走低等负面信息，尽可能做外部归因（大盘波动、竞品猛烈投放、品牌被限流等），同时在内部找可优化的动作。不做自我否定式结论。

### 红线三：每个数据都要有 So-What

数据陈列不是复盘。每个数据后面必须跟上：这说明什么、所以下一步做什么。不写仅供参考的数据。

### 红线四：结论落点要准确、具体

- ❌ "这个组合效果最优" → 为什么最优？是满足情绪需求还是功能需求？
- ✅ "Kitty粉丝人群对治愈感、颜值场景内容接受度更高，IP联名内容应以场景化视觉为主，减少硬广产品展示"

### 红线五：用五问法深挖根因

不止于表层的"转化率低因为人群不对"，追问到底：
- Q1: 为什么 CPUV 高？→ 进店转化率低
- Q2: 为什么进店转化率低？→ 点击用户只想看 IP，对产品无购买意图
- Q3: 为什么内容吸引的是这类用户？→ 素材过于侧重 IP 展示，未突出产品功能
- 根因：内容卖点与 IP 流量错配，未实现 IP 引流产品承接

## 六、数据分析方法

### 数据对比三段式

第一步：找参照物
- 对比大盘（行业 benchmark）
- 对比竞品（同类品牌同期表现）
- 对比本品历史（环比/同比）
- 对比本品当下内部（拆分内容方向/人群包/词包对比）

第二步：异动下钻
对比出的异常指标进行下钻分析，定位异常原因。如：搜索CPUV高 → 看大盘分场域CPUV表现 → 下钻看搜索计划消耗降序 → 是否有高消耗计划CPUV偏高拉高整体

第三步：趋势分析
分析异常指标的by-day趋势，判断是持续异常还是某几天异常

### KPI 三层分级

P0 北极星指标（2-3个）：与目的最相关的核心指标。如整体提升销量看转化率/CPUV/长效ROI；人群资产提升看CPTI/特定人群渗透率；心智占位看SOV/C

P1 核心过程指标：如TI人群效率与互动看CPE/回搜

P2 参考指标：如CPC、CTR等浅层指标

### 平台特有指标关系（重要）

小红书是双列信息流，用户主动选择要点击哪篇笔记，不是系统强推。因此指标之间的关系需要在这个逻辑下理解：

**CPM 与 CTR 的关系：** CPM 受 CTR 影响。CTR 高说明封面和标题打中了精准人群，用户主动选择点进来，系统识别到高互动后给予更多曝光机会，CPM 自然升高。所以 CPM 高 + CTR 高不是成本问题，恰恰说明人群精准、内容吸引力强，是正向信号。

**SEM 卡位场景下 CPC 与 SOV/C 的关系：** 能占住搜索结果首位通常 CPC 成本不低，因为首位竞争激烈。CPC 与 SOV/C 卡位情况成反比——要守住占位就得接受较高的 CPC。

## 七、数据准备阶段

### 准备前确认三件事

1. 数据口径：总流量？自然流？广告流？信息流数据是否包含视频内流？
2. 数据周期：汇总数据还是by-day数据？时间周期是否一致？
3. 数据粒度：是否能满足框架需求？通常需要达人×笔记ID粒度、账户×场域×计划×笔记×创意粒度、关键词粒度、人群包粒度

### 数据来源

| 来源 | 数据维度 |
|------|----------|
| 蒲公英投后数据 / 商业内容中心 | 达人数据（合作笔记数/粉丝量级/篇均价），总流量数据（总曝光/阅读/互动/爆文率） |
| 聚光 / 千帆推广报表 | 竞价广告数据：从曝光到转化全链路 |
| 灵犀度量模块 | AIPS数据、口碑数据、一方/三方数据 |

## 八、灵犀使用指南

灵犀覆盖全部流量场景（自然流、效果广告、品牌广告、薯条等），数据经过加工更具目的性。

### 投放中/后可用的模块速查

| 模块 | 看什么 | 说明什么 |
|------|--------|----------|
| 资产分析 | AIPS人群结构和基数 | 高于集均值=正向需保持；查看人群资产比例是否健康 |
| 流转分析 | 资产变化明细、流转路径分层 | 资产量级不够需加大投放；优化O/A/I→TI流转比例 |
| 渗透分析 | 机会分析/渗透追踪/策略制定 | 人群渗透率变化趋势，制定投放策略和中期盯盘 |
| 得失分析 | 拉新和流失比例、来源/流失SPU | 拉新>流失=策略有效；拉新<流失=内容疲软/竞争严峻 |
| 种草趋势 | 笔记贡献、搜索词贡献 | 笔记点击带来的TI人数、搜索词CTR和TI人数 |
| 品牌搜索分析 | 关键词SOV/SOC表现 | 无法保证核心关键词第一时需引导客户追加预算 |

## 九、视觉呈现原则

核心：Less is more。能用一句话说清楚的不用两句，能用图表说清楚的不用大段文字。

具体规则：
- PPT中各模块内容加总 = 标题（标题就是本页的结论）
- 最大程度可视化：字数越少越好，逻辑越清晰越好
- 善用四象限图分析
- 重点数字highlight（好的用红色加粗，不好的用绿色，策略及关键动作句用紫色加粗）
- 格式一致：降序排列、统一占比格式
- 不得已使用大段文字时合理highlight、分行分段做好间隔

## 十、完整执行流程

```
1. 确认复盘目的和客户关注的核心指标
2. 准备数据（确认口径/周期/粒度）
3. 搭框架（GRARI + Part 1-4 骨架）
4. 填 Part 1：投放成果（亮点数据 + 策略执行方法论 + 人群分析）
5. 填 Part 2：内容策略分析（overall效果 + 优质笔记四象限 + 评论区 + UGC + 竞品）
6. 填 Part 3：竞价策略分析（投放策略三段论 + 渗透策略 + 广告位 + 人群包）
7. 填 Part 4：后续投放建议（行业洞察 + 下一步动作整合）
8. 逐条检查策略型分析是否遵循三段式格式
9. 过结论写作五条红线
10. 检查下一步动作是否能全部回溯到前文分析
11. 质检：data-report-review skill五维审查
12. 视觉优化
```
