## D. 知识串联（核心环节）

### 串联十一：策略深度×预算区间——BD报价连接框架（新串联）

这是过去一个月知识积累中最后一块未被连接的拼图。

**当前状态：** 曼拾内容策略统一框架已覆盖情绪入口（前端）、叙事结构（中端）、科学交付（后端）。情绪深度×搜索词距×投放节奏框架也已打通前端到后端。但所有框架到「这个项目报多少钱」之间，是断层的。

**断裂的具体表现：**

BD总监拿到行业框架后，能说清楚市场，能说清楚策略，但说不清楚价格。目前的情况是：

- 策略深度（前端情绪定位深度） → 决定了内容策略复杂度 → 决定了内容生产成本
- 词距长度（搜索转化周期） → 决定了竞价预算分配比例 → 决定了投放花费
- 交付复杂度（小红盟/CID/CPUV） → 决定了技术基础设施成本
- **但没有任何一个框架帮助估算「前面这些加起来到底该报多少」**

**新串联：** 将三个已知框架（情绪深度×词距×投放节奏、内容→搜索→归因三段论、CFO算账基准）做乘算，得到粗略的报价计价器。

```
报价 = 策略咨询Layer × 内容生产Layer × 投放管理Layer

策略咨询Layer（前端）：
- 浅层情绪（畅爽感/快消食饮）→ 标准行业方案, 基础费率
- 中层情绪（欣赏感/数码家电）→ 定制化行业方案, 上浮30-50%
- 深层情绪（意义感/教育汽车）→ 品牌诊断+行业解决方案, 上浮80-100%

内容生产Layer（中端）：
- 词距<3天（搜索即买）→ 轻内容+高竞价投放, 内容成本30%, 竞价成本70%
- 词距5-9天（需比较）→ 深内容+均衡竞价, 内容成本50%, 竞价成本50%
- 词距>9天（需多次触达）→ 深内容+低竞价, 内容成本70%, 竞价成本30%

投放管理Layer（后端）：
- 基础KFS → 标准代理费
- KFS+CID → 附加技术费
- KFS+小红盟+品牌资产复用 → 附加数据费+持续优化费
```

**但这个框架有一个致命缺陷：** 它假设我们有「标准费率」，但我们没有。CFO的算账基准在SOUL.md中只说了「不低于25%利润率」和「工时×单价+合理利润」但未提供标准单价和工时应如何按行业/策略深度差异化。

**这个缺失不是知识分析能解决的——需要逸凡或CFO提供费率基准输入。**
