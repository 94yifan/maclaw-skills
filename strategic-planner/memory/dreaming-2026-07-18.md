## D. ★ 知识串联（核心环节）

### 串联一：BreaC Lab brand-scan pipeline × SP的brand-packaging + case-packaging skill → 品牌分析→诊断→叙事构建的一体化工作流

**来源：** Suprimind今天在榴芒一刻项目中实践了完整的品牌扫描方法论，包含：
- 五维模型全扫描（市场、产品、渠道、品牌、趋势）
- 竞品deep/reference/summary三档体系（deep套五维、reference一句话定位、summary背景布）
- 前置赛道框定（确定竞争边界）
- 创品策略（跨界借鉴型13个方向 + 原创型8个方向）
- 创始人深度画像（潮汕背景/创业轨迹/经营理念）
- 电商数据必采不跳过

**已有连接：** SP的brand-packaging skill（P3前置痛点深挖、P2S痛点-解法映射、三波段递进叙事设计）、case-packaging skill（案例叙事重构、价值萃取）、knowledge-forge（方法论整合）。

**串联判断：**
BreaC Lab的pipeline和SP的skill是**同一能力栈的上下流关系**。BreaC Lab做的是"前台品牌诊断"（输入品牌数据→输出五维扫描报告），SP做的是"后台叙事包装"（输入品牌报告→输出包装叙事）。

两者结合，可以形成一个完整的**品牌营销服务链**：

```
BreaC Lab pipeline                    SP skills
品牌数据采集 → 五维扫描报告        品牌报告 → 痛点深挖(P3) → 解法映射(P2S) → 叙事构建(三波段)
      (Supermind)                        (brand-packaging + case-packaging + case-storyteller)
```

这个服务链意味着：
1. BreaC Lab的产品交付物（五维品牌扫描报告）天然是SP的技能调用输入
2. SP的brand-packaging skill可以复用BreaC Lab的竞品三档体系和前置赛道框定作为叙事语境

**对曼拾/燃创咨询的价值：** 这条服务链打通后，客户从"拿到品牌诊断报告"到"看到可交付的包装叙事"只需要一次知识传递，无需重复调研。

### 串联二：品牌扫描pipeline v1.3 × 产品力进化三阶段 → 创品策略需要三阶段判断

**来源：** Suprimind今天在榴芒一刻的创品策略中划分了"跨界借鉴型（13个方向）"和"原创型（8个方向）"两类。同时，北纬47度的报告输出了一整份竞争格局。

**已有连接：** 07-12缝合4的产品力进化三阶段（标准化可调→成分配方化→文化资产化）。

**串联判断：**
品牌sprint中创品策略的有效性取决于品牌当前处于三阶段的哪一阶段：
- 阶段一（标准化可调）：适合跨界借鉴型创品——借鉴成熟品类做微创新
- 阶段二（成分配方化）：跨界借鉴+原创混合——部分做成分组合创新
- 阶段三（文化资产化）：适合原创型创品——品牌主导品类定义，自己做创新

**对pipeline的改进建议：** 在Step 10创品策略中，先用五维判断品牌处于产品力三阶段的哪个阶段，再分配跨界借鉴和原创的比例。
