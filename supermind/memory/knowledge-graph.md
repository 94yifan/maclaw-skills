#### 消费者洞察

**归属**：SM
**类型**：消费者研究
**定义**：通过定性和定量方法理解消费者的真实需求、行为动机和决策过程
**属性**：
- 定性方法：深度访谈、焦点小组、民族志、影子观察
- 定量方法：问卷调查、数据分析、A/B测试
- 洞察需要超越表面描述，找到行为背后的「为什么」
**关系**：
- 导致 → 产品创新、服务设计优化、营销策略制定

**应用场景**：品牌咨询（消费者调研核心方法）

#### 代言类型演进路径

**归属**：SM
**类型**：品牌战略/消费者研究
**定义**：代言类型从「娱乐流量」演进到「成熟明星」到「体育/健康」到「文化机构」——品牌选择代言类型本质上是在选择「想成为什么样的品牌」
**属性**：
- 娱乐明星：流量逻辑，适合新锐品牌快速建立认知
- 成熟明星：品牌逻辑，适合腰部品牌去性价比标签
- **体育/健康**：功能逻辑（健康叙事），转化路径最短；2026-05-08 古茗西瓜汁+瑞幸×商竣程+沪上阿姨「羽坛天菜」三条线索同时出现，第五赛道从「偶发」升级为「周期性赛道」
- 文化机构：信用背书，适合头部品牌建立文化高度
- 演进方向：从流量逻辑→品牌逻辑→功能逻辑→文化逻辑
**关系**：
- 导致 → 品牌定位、传播策略、资源投入优先级

**应用场景**：品牌战略（代言选择）、消费者研究（解读竞品动作）
**来源**：2026-05-07 多品牌代言案例整合（瑞幸×商竣程/幸运咖×梁朝偉+迪丽热巴/库迪×VOGUE）
**入库日期**：2026-05-07

#### HPP 技术背书扩散

**归属**：SM
**类型**：品牌战略/消费者研究
**定义**：HPP（高压冷杀菌）技术背书从酸奶品类扩散到鲜果品类，意味着技术标准正在成为品类的基础配置，无技术背书的品牌将面临信任压力
**属性**：
- 扩散路径：酸奶→鲜果（库迪杨梅率先使用）
- 信号意义：技术标准升级是品类成熟标志
- 消费者感知：HPP = 更健康、更新鲜、更可信
- 竞争含义：没有技术背书的鲜果产品，正在从差异化变为劣势
**关系**：
- 导致 → 产品策略（是否跟进技术）、传播策略（技术背书传播）

**应用场景**：茶饮品牌策略、行业竞争分析
**来源**：2026-05-07 库迪杨梅 HPP 案例 + 2026-05-08 古茗西瓜汁 HPP 跟进
**入库日期**：2026-05-07
**最后更新**：2026-05-08（多品牌共振 = 标配化确认）

#### 技术+产品+营销三维叙事框架

**归属**：SM
**类型**：品牌战略
**定义**：腰部品牌高端化需要同时在技术、产品、营销三个维度建立感知——单一维度的「高端化叙事」越来越难以为继
**属性**：
- 技术层：HPP等工艺叙事，建立产品力信任
- 产品层：明星产品/季节新品，承载叙事落地
- 营销层：顶流代言/文化IP，建立消费者情感连接
- 完整案例：库迪 = HPP技术 + 杨幂代言 + VOGUE策划人，三维同时建立
- 适用边界：有清晰高端化路径的腰部品牌；缺乏任一维度会显得「堆砌」
**关系**：
- 导致 → 品牌升级战略、资源分配优先级
- 关联节点 → HPP技术背书扩散（技术层）、代言类型演进路径（营销层）

**应用场景**：茶饮品牌高端化路径设计、品牌战略制定
**来源**：2026-05-08 库迪三维叙事整合 + 多品牌时令共振分析

**归属**：SM
**类型**：品牌战略
**定义**：茶饮品牌国际化呈现两条路径——文化渗透（联名先行）和据点建立（开店先行），代表不同的品牌资产积累方式

#### 康德义务论与GTM

**归属**：SM
**类型**：品牌战略/消费者研究
**定义**：康德义务论中「定言命令 vs 假言命令」的框架，对高端品牌传播策略的直接意义——真正高端的品牌讲的是「你应该这样做」（定言命令），不是在满足需求，而是在重新定义消费者应该想要什么
**属性**：
- 假言命令式品牌：「买了会更快乐」（依赖消费者既有欲望）
- 定言命令式品牌：「你应该用这种方式对待自己」（独立于消费者既有欲望的道德主张）
- 人性公式：永远把人视为目的，不仅仅是手段——消费者不能被工具化
- 核心连接：GTM的终极目标不是persuasion，而是autonomy enablement
**关系**：
- 连接 → CSDF（认知位移设计框架）：两者在「认知自主性回归」上有最深共识
- 导致 → 品牌叙事策略、高端化路径

**应用场景**：茶饮品牌高端化叙事设计、品牌价值观建立
**来源**：2026-05-09 康德义务论萃取 × CSDF深化
**入库日期**：2026-05-09

#### CSDF（认知位移设计框架）

**归属**：SM
**类型**：咨询方法论
**定义**：通过真实体验时刻的系统编排，推动客户信念转变的 GTM 理论体系。核心命题：营销不再是信息传递，而是通过体验设计认知位移
**属性**：
- 四大支柱：认知架构（judgment premise）、信念转变（belief transformation）、体验锚定（experiential anchoring）、moment编排
- 核心主张：从"信息传播"转向"认知位移"，从"用户体验"转向"信念承载"，从"触点管理"转向"真相时刻编排"
- 学术关键词：cognitive architecture, belief transformation, experiential anchoring, embodied decision-making, moment orchestration, cognitive stabilization
- 与康德义务论最深连接：CSDF追求的"belief stabilization"在康德框架里意味着——好的体验设计让人感觉"我自己判断这件事是对的"，而不是"我被说服了"
- **GTM的终极目标不是 persuasion，而是 autonomy enablement**
**关系**：
- 连接 → 康德义务论与GTM：两者在「认知自主性回归」上形成学科交叉验证
- 连接 → 审美叙事第四维：没有信念移动的体验设计是装饰，没有体验设计的信念战略是PPT
- 导致 → 品牌传播策略、GTM方案设计

**应用场景**：品牌高端化路径设计、GTM方案制定、品牌战略白皮书
**来源**：2026-05-09 CSDF框架深化（memory/CSDF_认知位移设计框架_2026-05-09.md）
**入库日期**：2026-05-09

#### 审美叙事第四维

**归属**：SM
**类型**：品牌战略
**定义**：腰部品牌高端化从三维叙事升级为四维——技术→产品→代言→审美，四维齐全才能真正高端化。审美叙事是品牌定制视觉语言，不是借用已有IP流量
**属性**：
- 技术层：HPP等工艺叙事，建立产品力信任
- 产品层：明星产品/季节新品，承载叙事落地
- 营销层：顶流代言/文化IP，建立消费者情感连接
- **审美层（第四维）**：品牌定制视觉语言（插画艺术家专为品牌创作），建立品牌文化身份
- 库迪×Hattie Stewart案例：英国插画艺术家为库迪专门创作包装，是「品牌定制视觉语言」而非借用已有IP
- 判断标准：有技术缺技术、有产品缺产品、有代言缺审美——分别对应的升级路径不同
**关系**：
- 更新 → 技术+产品+营销三维叙事框架（新增第四维）
