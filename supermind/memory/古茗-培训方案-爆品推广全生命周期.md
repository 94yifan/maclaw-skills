# 古茗 爆品推广培训方案：从洞察到复盘，理解平台×产品×人群×数据的全生命周期

---

## 第一部分：培训框架

### 培训主题
**从洞察到复盘：小红书×抖音爆品推广的全生命周期打法**

### 培训对象
古茗市场/品牌/推广团队（建议：内容、媒介、数据三个职能线联席参加）

### 培训时长建议
1天（5-6小时授课+1小时实操workshop）或分2天（每天3小时）

### 框架总览

```
模块1：认知构建（1-1.5h）
├── 平台的底层逻辑差异（小红书 vs 抖音）
├── 茶饮品类在两个平台的核心规律
└── 爆品≠好产品的底层逻辑：平台×产品×人群×数据的四维关系

模块2：内容策略（1-1.5h）
├── 茶饮爆品内容公式
├── 素材策略：从BGC到P/UGC
├── 不同生命周期阶段的内容打法
└── 内容诊断：什么样的内容值得加投

模块3：投流策略（1.5h）
├── 小红书聚光投放
│   ├── 计划搭建逻辑（搜索/信息流/达人）
│   └── 出价策略与预算分配
├── 抖音千川投放
│   ├── 计划搭建逻辑（商品卡/直播/短视频）
│   └── RTA/DMP人群策略
└── 双平台协同策略（小红书种草→抖音收割）

模块4：数据复盘（1h）
├── 数据工具：灵犀/千川数据/聚光数据
├── 关键指标体系与判读
├── 何时放大、何时止损的判断逻辑
└── 从数据到洞察的复盘框架

模块5：workshop（1h）
└── 基于古茗实际产品做一次完整的推广方案设计
```

## 第二部分：详细培训内容

### 模块1：认知构建

#### 1.1 两个平台，两种逻辑

**小红书：人群×场景×决策**
- 核心逻辑：强搜索+强种草。「让消费者先看到→再搜到→最后下单」
- 用户行为路径：浏览笔记→搜索品牌/品类→看测评/对比→种草→买
- 适合茶饮的场景：新品首发测评、季节限定、成分解读、喝法教程、打卡探店
- 核心机制：自然流量红利仍在（好内容获得推荐→搜索沉淀），信息流+搜索双引擎
- 茶饮品类的机会：小红书用户对食品饮料的搜索增速远超大盘，「新品上市」是最大的搜索流量入口

**抖音：兴趣×冲动×转化**
- 核心逻辑：强推荐+强转化。「让消费者先看到→再感兴趣→直接下单」
- 用户行为路径：刷到内容→产生兴趣→点击商品→下单购买
- 适合茶饮的场景：新品打卡、现场制作过程、限时优惠、联名开箱
- 核心机制：流量池推荐（完播率+互动率+转化率决定下个流量池）
- 茶饮品类的机会：抖音本地生活（团购、外卖）是茶饮转化最短路径，直播间/短视频直接挂车

**关键区别：**
- 小红书的种草是「理性的说服」，用户带着寻找/对比的心态
- 抖音的种草是「感性的冲动」，用户带着消遣/娱乐的心态
- 同一个产品，两个平台的备赛方向完全不同

#### 1.2 茶饮品类在两个平台的核心规律

**小红书茶饮规律：**
- 上新期：搜索量达到峰值，关键词布局决定成败
- 内容偏好：真实感 > 精致感 > 广告感。用户要的是「这杯到底好不好喝」而不是「这杯拍得真好看」
- 爆品公式：真实体验+成分解读+场景代入+利益点传递
- 高互动内容类型：对比测评、隐藏喝法、热量/成分解读、地域限定打卡
- 关键时间点：上新前3天（搜索预热期）→上新当天（搜索爆发期）→上新后3-7天（长尾沉淀期）

**抖音茶饮规律：**
- 内容偏好：高对比+强节奏+明确利益点。前3秒必须给出「值得看的理由」
- 爆品公式：冲突/反常识（比如「这杯居然…」）+制作过程（视觉冲击）+立刻下单的理由（限时/限量/优惠）
- 高转化内容类型：真实门店打卡、对比实验、优惠倒计时、联名开箱
- 直播间核心：价格杠杆是最强转化手段，其次是「大家都在买」的从众效应
- 关键时间点：上新前1天（预告）→上新当天（直播+短视频齐发）→上新后3天（追投ROI好的素材）

#### 1.3 爆品不是天生的，是养出来的

**爆品四维全生命周期：**

```
产品端 → 内容端 → 投流端 → 数据端
  │         │          │          │
  ▼         ▼          ▼          ▼
选品决策  内容生产  放量策略  复盘迭代
```

核心认知转变：爆品不是「选出来的」，是「测出来+追投+迭代」的结果。数据决定放量，不是直觉决定放量。

**爆品全生命周期四阶段：**

| 阶段 | 周期 | 核心任务 | 内容策略 | 投放策略 |
|------|------|----------|----------|----------|
| 测试期 | D-7~D-3（上新前） | 验证内容方向、测试人群画像 | 3-5个不同角度内容同时测试 | 小额测试，每日500-1000元。关注CTR、CPE、互动率 |
| 爆发期 | D0~D3（上新当天起） | 锁定爆品素材、快速放量 | 加码优质内容方向，投放预算倾斜 | 放大起量，日耗可达测试期5-10倍。关注RR、转化率 |
| 稳定期 | D4~D14 | 降低CPA、扩大人群 | 补充UGC/达人内容，维持搜索热度 | 持续追投，关注ROI和CVR。 |
| 迭代期 | D15+ | 老素材迭代、挖掘新卖点 | 新角度内容测试、品类拓展 | 重测或降低预算转入下一新品周期 |

### 模块2：内容策略

#### 2.1 茶饮爆品内容公式

**小红书内容公式：**
```
[品类/场景] × [成分/工艺/利益点] + [真实体验] + [行动号召]
```

举例（古茗情境）：
- 西瓜椰椰：「夏天第一杯西瓜椰椰！XXX鲜果HPP冷榨 + 实测喝完不腻」→ 评论区互动引导
- 牛油果系列：「牛油果脑袋集合！XX控糖版实测，热量大公开」→ 成分党精准吸引

**抖音内容公式：**
```
[前3秒钩子] + [制作/使用过程] + [利益点总结] + [立即下单]
```

举例（古茗情境）：
- 「你敢信这杯只要9块9？！」→ 门店现场制作画面 → 「限时3天，错过等一年」→ 点击团购

#### 2.2 素材矩阵：BGC+PGC+UGC三层覆盖

**BGC（品牌自产）：** 上新预热、品牌宣传片、产品详情页
- 小红书：官方号发布产品故事、成分科普、品牌理念
- 抖音：官方号发布预告、花絮、优惠信息

**PGC（达人/博主）：** 测评、探店、开箱
- 小红书：垂类美食博主（500-5000粉丝素人→1-10万腰部→10万+头部）
- 抖音：本地生活博主、探店博主、美食测评博主
- 选择逻辑：不是粉丝越多越好，而是「这个人的粉丝和我目标用户重不重合」

**UGC（用户自发）：** 打卡、晒单、喝法分享
- 用户自发内容是最有说服力的内容
- 机制设计：晒单有奖、最佳喝法征集、种草返券

#### 2.3 不同生命周期阶段的内容打法

**测试期内容：**
- 做3-5个不同角度的内容版本（成分党版、颜值版、优惠版、场景版、测评版）
- 各投500-1000元测试，跑2-3天看数据
- 谁是「天选素材」？CTR>8%、CPE<3元、互动率>10%的素材

**爆发期内容：**
- 找到天选素材后，做同类型的3-5个变体（换封面、换开头、换口播）
- 天选素材直接加预算跑，变体素材放小额测试
- 同时发动达人矩阵做同角度内容，用铺量抵消素材衰减

**稳定期内容：**
- 天选素材开始衰减时（通常7-14天），补充UGC内容启动第二轮
- 关键词搜索页的流量稳定下来后，持续优化搜索词的笔记数量
- 补充新的使用场景内容（比如西瓜椰椰从「饮品攻略」转向「下午茶搭配」）

**迭代期内容：**
- 上一轮爆品沉淀的数据（人群画像、高互动关键词、出价数据）反哺下一轮新品
- 爆品的「成功经验」不是复制文案，是复制「做内容的逻辑」

#### 2.4 内容诊断：什么样的内容值得加投

**加投信号：**
- 小红书：笔记发布后48小时自然阅读>1000，互动率>10%，搜索阅读占比>30%
- 抖音：视频完播率>30%，互动率>5%，商品点击率>3%
- 共同信号：评论区出现了「真的假的」「在哪里买」「好喝吗」等真实询问

**止损信号：**
- 小红书：72小时自然阅读<300，CPE>10元，CTR<3%
- 抖音：完播率<15%，点赞率<2%，转化率<1%
- 共同信号：大量负面评论、评论区离题（没人讨论产品）

**关键认知：素材本身有寿命。**
- 一套内容跑7-14天后，CPA开始上涨、CTR开始下降是正常衰减，不是投流策略的问题
- 解决方案：持续生产新内容，而不是加价追跑同一套素材

### 模块3：投流策略

#### 3.1 小红书聚光投放

**投放形式：**
- **信息流广告（发现页）：** 被动曝光，强推荐。适合做人群破圈、新品教育
- **搜索广告（搜索结果页）：** 主动拦截，强转化。适合做精准截流、搜索卡位
- **达人合作加热：** 给优质达人笔记加热投流，放大内容势能

**计划搭建逻辑：**

信息流计划：
- 定向方式：人群标签（兴趣+行为+人群包）
- 出价方式：oCPM（目标转化出价）、CPC（按点击出价）
- 预算分配：单计划日耗建议500-2000元起测，跑出数据后放大

搜索计划：
- 关键词选择：品牌词+品类词+场景词+竞品词
- 茶饮搜索热门词示例：奶茶推荐、新品奶茶、XX同款、好喝不腻奶茶
- 出价策略：品牌词守住首位（可能CPC偏高但转化高），品类词争取前三

**出价策略：**
- 新品期：oCPM+高预算，目标是跑出模型，不要过度关注CPA
- 稳定期：CPC抢占搜索流量，关注搜索成本
- 衰减期：oCPM降预算，筛选高转化人群包

**预算分配建议：**
- 新品期：信息流70%（人群破圈）+ 搜索30%（精准截流）
- 稳定期：信息流40% + 搜索60%（搜索沉淀）
- 达人加热：占总预算的15-20%

**平台工具使用——数据观察建议：**
- 灵犀：看人群画像、搜索趋势、品类热搜词
- 聚光后台：看转化漏斗（曝光→点击→互动→转化）
- 蒲公英：达人合作数据分析、内容效果评估

#### 3.2 抖音千川投放

**投放形式：**
- **短视频带货：** 挂小黄车/团购链接，跑销量
- **直播带货：** 直播间投流，转化效率最高
- **商品卡：** 搜索卡位，补货

**计划搭建逻辑：**

短视频计划：
- 素材优先：先有好的素材再建计划，不要先建计划再找素材
- 定向方式：行为兴趣定向 + 人群包 + 智能放量
- 出价方式：OCPM（支付ROI出价）、放量投放

直播计划：
- 直播间投流的本质是「让更多人进来」，不是「让进来的人买」
- 直播间质量决定投流效果的三分之二
- 预算分配：短视频引流+直播间引流+商品卡，三个计划同时跑

**RTA/DMP人群策略：**
- DMP人群包：茶饮兴趣人群、竞品人群、品类偏好人群
- RTA（实时竞价）：对接一方数据，屏蔽已转化用户，提高新客获取效率

**出价策略（茶饮行业参考）：**
- 短视频：OCPM + ROI目标设定（根据产品毛利计算最低可接受ROI）
- 直播间：按进入成本（CPM/CPE）而非按ROI出价，直播间ROI要看整场不是单计划
- 茶饮参考值：CPM 15-30元、CPE 3-8元、ROI 2-3.5

#### 3.3 双平台协同策略

**种草到收割的标准路径（小红书种 → 抖音收）：**

```
【小红书种草】          【抖音收割】
  达人测评内容    →     品牌直播间挂车
  搜索卡位        →     千川追投种草视频
  信息流曝光      →     同款/同素材的短视频挂车
  用户搜索产品    →     第一时间看到抖音团购/外卖链接
```

**为什么这么打？**
- 小红书的强项是建立认知和信任（「这个品牌不错」「这个产品想试试」）
- 抖音的强项是完成即时转化（「现在下单」「立即购买」）
- 两个平台用户重叠率约30%，但小红书的种草会直接影响抖音的搜索转化

**实际执行建议：**
- 小红书先跑搜索卡位+达人测评，投放2-3天后
- 同步在抖音搭建同产品的千川计划
- 小红书搜索量上升的信号 = 抖音开始放量的最佳时机

#### 3.4 平台工具：判断是否值得加投、何时放大、是否成功

核心问题三个：

**① 怎么判断值不值得加投？**

判断标准分层：
- P0（致命信号——不值得投）：CTR<3% + 互动率<5% + 转化率<行业均值1/2
- P1（观察信号——可以小投再看）：CTR 5-8% + 互动率8-12% + 数据稳定
- P2（追投信号——值得大投）：CTR>8% + 互动率>12% + 转化率>行业均值

小红书特定加投信号：搜索阅读占比>30% + 自然互动>100
抖音特定加投信号：完播率>30% + 商品点击率>3%

工具动作：
- 小红书聚光：看计划级别的CTR、CPE、转化漏斗
- 小红书灵犀：看品类热搜词趋势、人群画像
- 抖音千川：看素材级别的完播率、互动率、商品点击率
- 抖音数据参谋：看行业大盘数据对比

**② 什么时候放大？**

放大节奏：
- D0-D2（测试期固定）：不放量，只测素材和人群。日耗1000-3000元
- D3-D5（判断期）：天选素材跑出后，预算跑满不限量跑1天（日耗3000-10000元），看数据是否维持
- D5-D7（放量期）：数据维持或更好，按日耗的30-50%逐日加量
- D7+（稳定期）：保持日耗不变，关注素材衰减曲线

放大的前提条件：
- 小红书：有2-3条天选素材在同时跑
- 抖音：有1-2条高ROI素材在同时跑
- 两个平台都满足：ROI>目标值持续72小时以上

**③ 怎么判断投的成功与否？**

成功判断框架（三个维度）：

1. ROI维度（最直接）：
   - 小红书：直接ROI + 间接ROI（搜索量增长、品牌词搜索量提升）
   - 抖音：支付ROI + A3人群增长
   - 茶饮行业ROI参考：小红书直接ROI 1.5-2.5（加上间接效应，真实ROI 3-6），抖音ROI 2-3

2. 效率维度：
   - 小红书：CPUV（单次有效观看成本）、CPTI（单次兴趣人群获取成本）
   - 抖音：CPM/CPE/ROI、直播间停留时长
   - 效率指标比ROI更早预警变化

3. 人群维度：
   - 品牌词/品类词搜索量变化（反映种草效果）
   - 新客占比（反映拉新能力）
   - 品牌A3人群（小红书灵犀）/A3-A4人群（抖音数据）
   - 竞品人群渗透率（反映是否抢到竞品份额）

**投放成功的信号矩阵（非单一ROI判断）：**

| 信号 | 小红书 | 抖音 |
|------|--------|------|
| P0（成功） | ROI达标+搜索量增长30%+A3人群增长 | ROI达标+直播间停留>30s+新客>60% |
| P1（良性） | ROI接近目标+搜索量稳定 | ROI接近目标+商品点击率达标 |
| P2（预警） | ROI低于目标但A3人群在增长 | ROI低于目标但A3人群增长+搜索量上升 |
| P3（失败） | ROI远低于目标+无搜索增长+人群无变化 | ROI远低于目标+无转化+无人群沉淀 |

**重要认知：小红书投流最容易被误解的一点**
小红书的投流效果不只看直接ROI。一条小红书笔记可能带来：
- 直接转化（通过笔记挂链购买）——短期ROI
- 品牌搜索增长（用户被种草后去搜索）——中期ROI
- 品牌心智建立（下一次该品类购买时优先选择）——长期ROI

衡量小红书投流成功，需要同时看短+中+长三个时间维度的信号，不能只看直接ROI下结论。

### 模块4：数据复盘

#### 4.1 数据工具

**小红书：**
- 聚光后台计划报表：人群画像、转化漏斗、素材数据
- 灵犀：搜索趋势、品类洞察、人群资产
- 蒲公英：达人合作数据
- 小红书数据分中：曝光→阅读→互动→留资→转化

**抖音：**
- 千川后台计划报表：人群画像、素材数据、转化数据
- 数据参谋：行业大盘、品类数据、竞品对比
- 巨量云图：品牌人群资产、A3-A4人群流转、竞品分析
- 抖店数据：商品维度ROI、SKU级转化数据

**核心原则：** 每天看表不如建好看表框架。先想清楚「我要看什么」，再开后台。

#### 4.2 关键指标体系

**三个层级指标（参考逸凡的one-page复盘框架）：**

P0（北极星指标）—— 用1-2个指标回答「这个项目值不值得继续」
- 小红书：直接ROI+品牌词搜索量增长率
- 抖音：支付ROI+新客占比
- 茶饮行业实际参考：小红书直接ROI>1.5（含间接效应>3）算合格，抖音ROI>2算合格

P1（核心过程指标）—— 用来判断「过程中动作对不对」
- CTR（点击率）：内容好不好的第一信号。小红书信息流CTR>5%、搜索CTR>10%
- CPE（单次互动成本）：内容互动效率。小红书CPE<5元、抖音CPE<8元
- CPM（千次曝光成本）：人群精准度。小红书CPM<80元、抖音CPM<30元
- CPI（单次商品点击成本）：从曝光到转化的效率

P2（参考指标）—— 用来发现异常
- CPC：注意和信息流效率可能冲突（高CTR素材可能导致CPC上升）
- 完播率/阅读完成率：前提是内容够好
- 收藏率/分享率：强信号指标，说明内容有价值

**茶饮行业基准线（参考，需根据实际产品调整）：**
- 小红书信息流：CTR 5-8%，CPE 3-8元，CPM 60-100元
- 小红书搜索：CTR 8-15%，CPC 1-3元
- 抖音短视频：CTR 3-6%，CPE 3-10元，ROI 2-3.5
- 抖音直播间：CPM 15-30元，停留时长>30s

#### 4.3 何时放大、何时止损

**放大三部曲：**

第一步：找到「天选素材」
- 小红书的判断标准：CTR>8% 且 CPE<3元 且 自然互动>100
- 抖音的判断标准：完播率>30% 且 互动率>5% 且 转化率>3%
- 注意：别只看1天数据，看连续3天

第二步：验证「放大不崩」
- 预算日增30-50%，不要翻倍加
- 每加一次看一下数据趋势——CPE/CPA/ROI有没有明显恶化
- 如果有恶化，说明素材/人群容量已到顶

第三步：拆成「素材迭代+放量并行」
- 一边把好素材跑满预算
- 一边做同类型的变体素材补充，准备接替

**止损信号：**
- 小红书：CPE连续3天>10元、CPM>150元、CTR<3%
- 抖音：CPE连续3天>15元、ROI<1持续48小时
- 全网：评论区出现大量负面评价、品牌搜索量不增反降

**核心机制——素材衰减：**
- 任何素材都有生命周期（通常7-14天）
- 衰减信号：同素材CPE逐日上升、CTR逐日下降
- 应对方式：不要加价追刀，新素材换掉旧素材

#### 4.4 从数据到洞察的复盘框架

**使用逸凡one-page复盘的GRARI框架：**

```
G（Goal）目的回顾 —— 这次推广的北极星指标是什么？预算怎么分配的？
R（Result）结果比对 —— 与目标比，结果如何？哪些超预期、哪些低于预期？
A（Analysis）原因分析 —— 做得好的关键动作是什么（素材/人群/节奏）？做得不好的根本原因是什么？
R（Review）目的回顾 —— 最早设定的目的达成的？如果没达成，为什么？
I（Insight）规律总结 —— 这次学到了什么？哪些经验可以复用到下一款新品？
```

**茶饮行业复盘的特殊要点：**
- 新品ROI和成熟产品ROI要分开看。新品前7天ROI<1是正常的，关键看趋势——ROI是否在逐日上升
- 不同产品定位（流量款、利润款、品牌款）的ROI标准不同。流量款可以接受ROI偏低，利润款必须ROI偏高
- 季节因素影响大盘——夏季茶饮大盘CPM通常高于冬季，搜索量也更高
- 竞品动作要纳入复盘——如果竞品在你上新期也大规模投放，你的CPM会自然上升

# 古茗 爆品推广 one-page

## G（Goal）目的与目标

**目的：** 让这款新品在目标人群中建立「好喝+值得买」的认知，驱动上新期间的销量增长

**预算分配：** 小红书60% / 抖音40% | 信息流50% / 搜索20% / 达人20% / 直播间10%

**P0北极星指标：** 
- 小红书：直接ROI≥1.5 + 品牌词搜索量周环比增长≥30%
- 抖音：支付ROI≥2.5 + 新客占比≥60%

**P1核心过程指标：**
- 小红书：CTR>5% | CPE<5元 | 搜索阅读占比>30%
- 抖音：完播率>30% | CPE<8元 | 直播间停留>30s

**P2参考指标：** CPC、CPM、收藏率、分享率

---

## 节奏策略

| 阶段 | 时间 | 内容策略 | 投流策略 | 判断标准 |
|------|------|----------|----------|----------|
| 测试期 | D-7~D-3 | 3-5个内容角度测试 | 日耗1000-3000，信息流70%搜索30% | 找CTR>8%+CPE<3元的天选素材 |
| 爆发期 | D0~D3 | 天选素材变体+达人矩阵 | 日耗放大至5000-15000，信息流70%搜索30% | 数据是否维持/TI人群是否增长 |
| 稳定期 | D4~D14 | 补充UGC+新场景内容 | 日耗稳定，信息流40%搜索60% | ROI达标+搜索量是否稳定 |
| 迭代期 | D15+ | 新角度测试+品类拓展 | 降预算重测或转入下一新品 | 素材是否衰减/人群是否到顶 |

---

## 放大与止损规则

**加投触发（3个条件满足2个）：**
- CTR>8% 持续72小时
- CPE<3元 持续72小时  
- 搜索阅读占比>30%

**放大节奏：** 预算日增30-50%，不行就停

**止损触发（满足任一）：**
- CTR<3% + CPE>10元 持续48小时（内容失效）
- ROI<1 持续72小时（成本失控）
- 负面评论多且搜索量不增（方向有问题）

**素材生命周期：**
- 天选素材有效7-14天，到期自动换
- 不要加价追衰减的素材，做新素材

---

## 复盘框架（项目结束后用）

**A - Analysis（做得好的）：**
- 策略力：人群选得准/素材方向对/节奏卡得对
- 执行力：内容交付及时/投流调整快速/达人选得对
- 管理力：突发变化应对得当/预算调整果断

**A - Analysis（做得不好的）：**
- 策略力：素材角度选错了/人群太宽或太窄/节奏慢了
- 执行力：内容交付延迟/投流计划没建好/达人没按时发
- 管理力：变化没及时发现/调整反应慢了/内外部沟通有断点

**I - Insight（规律沉淀）：**
- 哪类内容跑得好（成分解读/测评选购/打卡探店/优惠攻略）
- 哪类人群转化率高（年龄段/地域/兴趣标签）
- 哪个阶段最容易踩坑
- 【可复用的】方法论：这次做对的逻辑，下周新品继续用

---

## 关键认知清单（给团队）

1. 爆品是「测出来+追投+迭代」的结果，不是「选出来」的。测试期的数据决定一切。
2. 素材有寿命——7-14天，到期换，不要加价追。
3. 小红书的ROI要看三个时间维度（短期直接ROI+中期搜索增长+长期品牌心智），单一维度下结论会误判。
4. 数据工具是用来判断的，不是用来看的。想清楚「我要判断什么」，再看后台。
5. 投流的本质是放大好内容，不是拯救烂内容。内容不行，投多少都是浪费。
6. 抖音的直播间ROI要看整场，不是单计划。短视频ROI要看3天以上趋势，不是当天数据。
7. 小红书种草→抖音收割是一条已验证的路径，值得所有新品试一试：先让消费者在小红书被种草，然后他们在抖音搜索下单。
8. 每个新品都是下一款爆品的「数据积累」——沉淀人群、素材、出价经验，比单次ROI更重要。
