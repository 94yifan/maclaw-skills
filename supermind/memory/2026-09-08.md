
## 2026-09-08 · 逸凡共创培训课程《AI时代策划人的能力体系》

### 项目概况
- 逸凡发起共创一门给曼拾管培生的内部培训课程，主题：AI 时代策划人的能力体系。
- 一整天密集共创，从框架、到内容深化、到交付物，多轮迭代。
- 交付物三件：飞书云文档 + HTML deck（39 页）+ 两轴四象限 PNG 图。

### 课程最终框架（核心资产，可复用）
- **三个 Keywords（主线）**：当回事（心态）、问到底（思维）、给判断（交付）。一根链：为什么做、怎么做、交付什么。
- **九个金句**（每 keyword 三句）：
  - 当回事：把自己当回事才会把事当回事 / 苟活是先从心里把自己辞退了 / 交作业还是交结果，差别在心里签没签自己的名
  - 问到底：客户给的是需求不是问题，问题挖出来方案才轮到你出 / 追问到底是挖到再问一句就是废话的地方 / 敢问到底才敢对客户说你要的可能不是曝光
  - 给判断：客户买的是判断不是勤快 / 一份方案只有一个主张，多了等于没有 / 讲给外行听能复述才算有主张
- **两条线**：工作线 8 session（Ownership/问对问题/选对答案/思考链路/洞察/交付/工具/skill）+ 成长线 3 session（输入/沉淀/工具跟进）。每个 session 四件套：思维+实战+案例+作业。

### 本 session 沉淀的关键方法论（燃创/曼拾课程内核）
- **五层追问链**：动机→上下文→结果→权重→终极目标。结构=前两问理解他、第三问翻译他、后两问挑战他。
- **品牌问题五类**：认知、信任、生意、竞争、组织。
- **两轴四象限**：横轴心智层（营销能碰）/生意层（营销碰不了），纵轴紧急/不紧急。
- **紧迫性两种含义**（逸凡追问出来的）：生意层的紧迫=生存倒计时（问命），心智层的紧迫=时机窗口（问势）。
- **第一性原理两个问题**：①客户真正的问题是什么 ②客户凭什么立马选我们（曼拾）做服务商。
- **三个错误认知**：客户是出题人/客户说的对/多问显得不专业（不敢追问的根）。
- **一份方案只能有一个主张**：眉毛胡子一把抓的根因是不敢（把风险转移给客户）。判断方法：压成一句话外行能复述。
- **AI 交互六模式**：发散、圆桌、共创、质疑、交叉、把关。
- **七阶段交互**：资料收集（把关+交叉）/创意发散（发散+圆桌）/收敛（质疑+交叉）/产出（共创）/QC（把关+质疑）/修改（共创增量）/多项目协作（把关+圆桌）。
- **KFS 方法论**（小红书整合营销，曼拾核心业务）：K=KOL 种草造浪、F=Feeds 信息流放大、S=Search 搜索截流。

### 重要概念纠正（逸凡）
- "客户给的是方案"是错的 → **客户给的是需求，我们才是给方案的人**。链条：客户给需求→策划人挖问题→策划人给方案。
- 客户为什么给需求不是问题（三层）：省力、体面、他以为找到了答案。
- 案例要用真实营销需求（如"我要做新品宣发"），不是执行手段（如"我要找 KOL"）。找 KOL 不是需求，是 KFS 里的 K 环节手段。
