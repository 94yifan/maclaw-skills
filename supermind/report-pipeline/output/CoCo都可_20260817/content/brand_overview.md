# 品牌概览：CoCo都可

CoCo都可是一家被严重低估、但增长引擎已经失速的老牌现制茶饮品牌，它的核心矛盾是二十多年积累的品牌资产没有转化成当下的竞争势能。CoCo创立于1997年，由台湾人洪肇水在淡水创立，是现制茶饮行业最早的连锁品牌之一，比蜜雪冰城早了整整两代创始周期（evidence_tier：reported）。经过近三十年经营，CoCo已发展为全球门店超过5000家、覆盖中国大陆、台湾、港澳、美国、日本、东南亚、欧洲等市场的跨国茶饮品牌，是中国现制茶饮出海最早、覆盖最广的企业之一（evidence_tier：reported）。

从品牌定位看，CoCo的心智标签一直是经典台式奶茶，珍珠奶茶和鲜芋系列是它的立身之本。在消费者认知里，CoCo代表的是十多年前街边那杯温润的珍珠奶茶和软糯的鲜芋圆，这份认知既是资产也是包袱。资产在于，珍珠奶茶和鲜芋系列在华南、华东积累了一批稳定的忠实客群，复购率可观；包袱在于，这份心智已经老化，年轻消费者提起CoCo，想到的是长辈常喝的奶茶，而非当下值得打卡、值得分享的新茶饮。对比之下，霸王茶姬用国风鲜奶茶、喜茶用鲜果茶、蜜雪冰城用极致低价，各自抢到了清晰且年轻的心智（evidence_tier：mapped）。

从规模看，CoCo全球5000多家门店的体量在现制茶饮行业已不具备头部优势。蜜雪冰城已经冲到4万家以上，古茗、茶百道、沪上阿姨各自站稳8000到9000家，霸王茶姬突破6000家，CoCo在大陆的门店规模被甩开了数量级的差距（evidence_tier：reported）。CoCo的独特性在于多国布局形成的海外与台湾存量，强势维度是海外与台湾，弱势维度是大陆扩张动能，这种结构决定了它是一个存量老牌，而非增长新锐。

从价格带看，CoCo定位于10到20元的中低价位，介于蜜雪冰城的下沉平价与霸王茶姬、喜茶的高端之间。这个价位带本身是现制茶饮最大的存量市场，古茗、茶百道、沪上阿姨、一点点都在这个区间竞争，CoCo面临的正是中国茶饮竞争最激烈的一条价格带（evidence_tier：mapped）。

从经营模式看，CoCo长期坚持区域授权加盟，直到2024年6月才开放单店加盟，这二十多年的保守是它门店规模掉队的直接原因之一。区域授权保证了品质和管控，也限制了扩张速度，导致CoCo在三四线城市的密度远低于蜜雪冰城和古茗（evidence_tier：reported）。CoCo尚未上市，长期对资本保持警惕、明确表示一段时间内没有上市计划，这是它缺乏资本杠杆、营收量级落后头部一个数量级的根本原因（evidence_tier：reported）。
