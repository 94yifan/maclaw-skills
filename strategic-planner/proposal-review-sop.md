# 小红书整合营销方案修改审查 SOP

## 背景与定位
基于逸凡在三份方案（嘉华云腿月饼、北纬47°、康尔馨）中的修改意见，结合曼拾《策划方案框架》和《前策分析培训文档》两份标准文档萃取的系统性审查框架。

定位：在逸凡亲自改方案之前，先做一轮结构化审查——对照曼拾标准，找出逻辑断裂、内容缺失、数据来源错误、板块归属混乱。同时，在安全的常规内容之上，基于弱信号洞察提增量创意建议。

---

## Orchestration（编排规则）

### 触发条件
逸凡或同事在群聊/私聊中发送方案文件，并明确要求审查。

### 运行时规则
- 模型：Pro模型（deepseek-v4-pro）
- PPTX→python-pptx提取文字；图片PDF→pdftoppm转换→image工具读关键页
- 读取顺序：TOC和分隔页理解结构→深读策略推导和Message House→逐模块对照标准

### 方案类型判断
能判断→标注并选标准。无法确定→问发方案的人（谁发的问谁，不管是逸凡还是同事）。

### 输出
- 结构化审查报告直接发在聊天中，不创建飞书文档（除非明确要求）
- 报告含两部分：标准审查（P0/P1/P2）+ 增量建议

## 核心机制：强因果区 vs 弱因果区

审查不是一套标准通吃全部。按板块分两区，不同标准不同温度。

### 强因果区（严查链路必须完整，跳一步就标断裂）
属于这个区的板块：
- 赛道洞察→策略推导的每一步
- Message House的RTB→卖点
- KFS预算分配逻辑
- 关键词规划
- 人群策略
- 竞品分析→差异化策略

审查标准：数据和结论之间必须强关联，推一步缺一步=P0断裂。

### 弱因果区（只查推导自洽，完整推导=通过；特别亮的标"创新亮点"）
属于这个区的板块：
- 内容Angle设计
- 线下活动创意
- IP联名建议
- 趋势预判/额外机会洞察
- 增量传播计划

审查标准：推导链路完整+逻辑自洽=合格。推导特别出色的标"创新亮点"。完全没推导=P1。强因果区里混入了天马行空的内容（用情怀代替数据做策略判断）→P0。弱因果区里错误地用强因果标准审查创意内容→审查者自己有问题。

### 弱因果区专用洞察方法：弱信号捕捉×主流需求反差

核心逻辑三步（来源：思念柿柿如意汤圆案例）：
1. 看主流搜索词，知道品类入口在哪（"汤圆怎么煮"=品类刚需=教程内容方向）
2. 看长尾搜索词，找到非主流但有方向性的信号（"兔子汤圆""空气炸锅汤圆"=视觉化需求=好玩好拍）
3. 主流和长尾之间的张力=机会空间。品类刚需是"能用"，增量需求是"好看+好玩+好拍"。

#### 四维趋势判断矩阵——不是每一个小词都值得追

1. **方向一致性**：三个以上小词指向同一趋势方向→信号有效。孤立诡异小词→随机噪点Pass。
2. **内容传播力**：用户做完会不会发小红书？会发=天然传播场景，不发=封闭场景。
3. **品类扩展性**：能不能帮品牌触达新人群？纯功能词→不扩人群；跨品类词→扩人群。
4. **内容空白度**：小词搜索结果有没有优质内容？有搜索没内容=蓝海；有搜索且饱和=红海。

四维全过→高价值趋势信号，必须放进内容策略。过2-3个→中等。1个或以下→Pass。

## Playbook（操作手册）

### Step 0: 预备——方案类型 + 分段控制

两个动作：
1. 读封面和TOC，判断方案类型（比稿/长线/节点/执行）。能判断→标注。不能→问发方案的人。类型与深度不匹配→P0。
2. 画方案地图：把全案分两区——哪些页属于强因果区，哪些属于弱因果区。后面的审查按分区标准执行。

#### 方案类型判断表

| 类型 | 特征 | 标准要求 |
|------|------|----------|
| 比稿方案（年度/半年度） | 客户未合作 | 行业大盘+平台趋势+赛道洞察+竞品深度分析+品牌TA画像+投放分析+竞争格局 全量覆盖 |
| 长线合作方案（半年度/年度） | 有数据积累 | 加人群资产分析、过往投放内容复盘、分SPU人群圈定 |
| 节点性方案（中秋/端午等） | 时间紧 | 本品搜索趋势+舆情+过往投放分析，竞品分析可精简 |
| 执行案 | 已有策略框架 | 热点梗洞察+趋势预判+内容方向设计 |

### Step 1: 结构逻辑

提取全案所有分隔页标题，对照标准清单逐项标 ✓有/✗缺/⚠错位。

#### 标准板块清单
封面 / 公司介绍（含灵犀牌照、种草学课程、著作权版权、最新奖项） / 赛道洞察 / 竞品分析 / 本品牌分析 / 产品洞察与策略 / 策略（目标+预算+人群+内容+KOL+竞价） / 转化链路（独立分隔页+种草时间关系图） / 硬广资源（独立分隔页+资源+价值描述） / 子品牌独立方案（如有，独立分隔页+专属视觉） / Roadmap / 报价

#### 板块归属
- 用户口碑/评论 → 本品牌分析-舆情分析，不属市场洞察
- 人群分析 → 策略板块下属人群策略
- 目标recap → 策略推导一部分
- "我们要做到什么" → 目标recap，不是策略

#### 排列顺序
行业趋势 → 赛道洞察 → 竞品分析 → 本品牌分析 → 产品洞察 → 策略（目标→预算→人群→内容→博主→竞价→定价/IP）→ Roadmap → 报价

多品牌线：主品牌在前，子品牌独立方案在后。子品牌必须独立分隔页+独立视觉。

#### 语句模板
```
结构问题 [P0/P1]：第X页 [板块名]
问题：[归属错误/缺分隔页/顺序错误]
标准：策划方案框架第X条
当前：[实际情况] → 应：[修改动作]
```

### Step 2: 策略推导 + 段落内部逻辑

#### 策略定义
策略 = 用什么抓手做什么事完成什么目标。
正确格式：针对[人群]在[场景]的[需求]，通过K做[X]+F做[Y]+S做[Z]，实现[可量化目标]。

#### Message House逐行检查
- 顶层：Big Idea / 品牌主张（一句one-liner）
- 中层：产品RTB → 卖点拆解（每个卖点必须追溯到RTB，产品参数级别具体数字）
- 下层：每个卖点 → 沟通人群（具体画像，不是"全部人群"） → 翻到内容策略页查承接 → 翻到投放页查承接
- 策划方案框架要求：highlight一句话，1-2个极致化场景化的点。超过3个→标"卖点分散"

#### 因果链四步验证
1. Brief原文 → 拆解核心问题
2. 洞察 → 发现了什么机会
3. 机会 → 推导品牌应该做什么
4. "应当做" → 拆解为KFS分配

#### 段落内部逻辑（强因果区强制，弱因果区建议）
每段分析文字必须过四层：

**第一层：数据陈述层**
什么数据 + 什么来源 + 什么时间范围。
不能说"搜索量较大"，要说"近90天搜索量10,051（灵犀）"。
检查：所有数据陈述是否具体到数字+来源+时间？

**第二层：数据解读层**
这个数字对用户/品类/品牌意味着什么。
嘉华P7核心问题："有搜索量"和"渗透率低"之间的关系要讲清楚，不能各说各的。
检查：前后数据之间的逻辑关系是否被明确陈述？多个数据点是否被串联解读？

**第三层：平台转化层**
在小红书上意味着什么。
康尔馨P25问题：只有行业趋势没有小红书趋势，这件事跟小红书有什么关系？
检查：每段分析是否有至少一句连接到小红书平台价值？

**第四层：策略转化层**
因此我们应该做什么。具体到可执行动作，不是模糊方向。
检查：策略建议是否可以落地执行？

强因果区四层缺一层=P0。弱因果区缺了标P1建议。

#### 语句模板
```
策略定义错误 [P0]：第X页
当前：[目标recap/战术罗列]
应改写：针对[人群]在[场景]的[需求]，通过[KFS]实现[目标]

Message House缺失 [P0/P1]：第X行 卖点"[卖点名]"
- RTB支撑：[有/缺]，需补充产品参数级别具体数字
- 人群对应：[具体人群画像/"全部人群"需拆分]
- 内容承接：[有/缺，标注页码]
- 投放承接：[有/缺，标注页码]

段落逻辑缺失 [P0/P1]：第X页 [段落描述]
缺：[数据陈述/数据解读/平台转化/策略转化]
标准：强因果区段落必须包含完整四层逻辑
```

### Step 3: 数据来源与方法合规

对照《前策分析培训文档》核心对照表，逐块核对方案中每个数据分析块的数据源和路径。

#### 赛道洞察数据源核对
- 市场供需 → 灵犀-洞察-行业-市场分析。必须：泡泡图（搜索vs有曝光笔记两个轴）
- 品类搜索趋势 → 灵犀-洞察-行业-趋势分析。必须：趋势图+波峰波谷图+波峰事件解释
- 品类搜索洞察 → 灵犀搜索洞察/聚光以词推词/蒲公英内容广场。至少一个来源
- 品类用户画像 → 灵犀自定义圈人（行业优选I+TI人群，或关键词圈人）
- 市场竞争格局 → 灵犀市场机会-品牌&SPU排名。时间：近90天/近24月

#### 竞品分析数据源核对
- 确定目标竞品 → 灵犀品牌排名+千瓜投放金额交叉验证。必须有数据表，不能只有一句话
- 竞品搜索趋势 → 渠道提数流程（需求表→在线表格→3-5天→渠道群要数据）。检查：是否有数据来源说明和可视化图表？没有→数据可能被跳过
- 竞品投放金额 → 千瓜商业笔记预估投放金额+图文视频占比+博主量级分布。是否只给了K没给FS？
- 竞品投放分析 → 千瓜商业笔记列表+分SPU筛选
- 舆情分析 → 千瓜种草舆情+小红书前端搜索。必须是正面TOP3+负面TOP3结构化总结

#### 本品分析数据源核对
- 搜索洞察 → 聚光以词推词-词根拓词/上下游推词+用户决策路径
- 人群资产（长线品牌） → 灵犀-度量-人群资产
- 过往投放分析 → 执行团队结案报告/蒲公英我的数据导出

#### 趋势洞察数据源核对
- 热梗/热点/趋势预判 → 必须经灵犀或蒲公英数据验证
- 行业大盘数据 → 必须注明原始报告机构+报告名称+发布时间，不能只有截图

#### 语句模板
```
数据来源不合规 [P0/P1]：第X页 [分析块]
标准要求（前策标准）：应使用[数据来源+具体路径]
当前：[实际使用的数据源，或"无标注"]
应改为：[正确的数据源+操作路径]

示例：
数据来源不合规 P0：第14页 竞品搜索趋势
标准要求：竞品搜索趋势需走渠道提数流程（需求表→在线表格→3-5天→渠道群）。
当前：无数据来源说明，无可视化图表。怀疑该数据被跳过。
补充方式：先填提数需求表。
```

### Step 4: KFS预算分配 + 品牌阶段战略匹配

#### K（达人矩阵）
- 量级金字塔：头部/腰部/垂类/素人具体数量+占比%
- 总篇数、预算分配
- 内容方向对应表：什么人→什么内容类型→针对什么问题
- 分类维度三选一不混淆（按人群/产品/阶段）
- 重点angle单博主单页推荐小诗
- MUST HAVE：赛道五维雷达图+why描述

#### F（信息流）逐DMP包检查
每个DMP包四必填：
- 包名+人群描述
- 具体体量数字（必须是阿拉伯数字）
- 圈包逻辑必须写出来（"近30日搜索过'云腿月饼'的25-40岁女性"，不能只写包名）
- 对应投放的内容类型
- 额外：分阶段投放策略（测试标准+量化指标）、预算分配比例

#### S（搜索）
- 品专+搜三own品牌词
- 吸黏拽模型
- 五类关键词细分：品牌词（品牌/品牌品类/品牌spu/品牌攻略词）/品类词/竞品词替代品词/兴趣词/痛点词
- 每类必须有：配比%+词例+预计CPC+搜索量+预计消耗+卡位策略+应用素材
- 回溯验证：把洞察章节出现的所有搜索相关词拉出来，在S关键词规划里逐词搜索

#### 品牌阶段×S战略匹配（核心深度判断）

不只是查"有没有配比数字"，是查"配比对不对得上品牌战略目标"。

**第一步：判断品牌阶段**
- 认知期品牌：品类认知度低，需要"让别人知道这个品类里有我"
- 成长期品牌：品类有认知，需要"在品类里建立品牌偏好"
- 成熟期品牌：品牌已建立，需要"在品类里守住位置"
- 高端子品牌：预算有限，需要"精准触达高价值用户"

**第二步：判断S应然的角色**
- 认知期→品类教育截流，品类词+兴趣词占比应高。品牌词占比过高=战略不匹配
- 成长期→品牌建设+品类卡位并举
- 成熟期→品牌收口，品牌词占比应高
- 子品牌小预算→只卡品牌词+精准场景词。品类词竞品词大面积投放=浪费+可能跟主品牌抬价

**第三步：判断预算规模和词类广度的匹配**
- 小预算（<20万）：只投品牌词
- 中预算（20-50万）：品牌词+核心品类词+精准兴趣词
- 大预算（50万+）：全品类词竞品词卡位

**第四步：多品牌线竞价检查**
主品牌+子品牌的品类词竞品词并排对比。重叠词=P0竞价冲突。正确排布：主品牌打声量卡品类词，子品牌做品质卡品牌词。

#### K金字塔×品牌阶段匹配（延伸）
- 认知期品牌：金字塔底部要大（素人多），靠UGC铺认知。倒三角（头部多素人少）=预算浪费
- 成熟期品牌：金字塔可以偏上，头部达人做品质背书

#### 预算策略
必须有饼图展示分配+每一块为什么这么分的解释。

#### 语句模板
```
K矩阵缺失 [P0]：第X页
标准：MUST HAVE五维雷达图+NICE TO HAVE量级分布
当前缺失：[具体缺项]

F信息流缺失 [P0]：第X页 DMP包"[包名]"
标准：四必填（包名+描述/具体体量/圈包逻辑/对应内容）
当前缺失：[体量/内容/测试标准/圈包逻辑]

S搜索缺失 [P0]：第X页
标准：五类关键词细分+配比+CPC+搜索量+消耗+卡位+素材
当前缺：[具体词类/数字]

S战略不匹配 [P0]：第X页
品牌阶段：[认知期/成长期/成熟期/子品牌]
预算规模：[XX万]
当前配比：[XX词XX%]
战略要求：[根据品牌阶段和预算规模应然的配比]
问题：[为什么当前配比不合适]
→ 调整建议：[具体修改方案]

竞价冲突 [P0]：品牌A第X页 vs 品牌B第Y页
重叠词：[词1,词2,词3]
后果：同时投放互相竞价抬价
方案：主品牌保留[词X]，子品牌只投品牌词
```

### Step 5: 因果链

#### 正向因果——强因果区13个环节逐项检查

**赛道洞察因果链（6环节）：**
1. 市场供需（灵犀泡泡图）→ 得出赛道机会判断（供不应求/供过于求）？→ 这个判断导向了预算策略？
2. 品类搜索趋势（灵犀趋势图+波峰波谷）→ 识别了季节性波动？→ 导向了阶段化预算分配？
3. 品类搜索洞察（上下游词）→ 还原了用户需求路径？→ 导向了关键词布局+内容选题？
4. 笔记内容洞察 → 提炼了内容沟通方向？
5. 品类用户画像 → 锁定了目标人群？→ 导向了人群策略？
6. 市场竞争格局（品牌SPU排名）→ 得出了竞争策略和差异化定位？

**竞品分析因果链（4环节）：**
7. 竞品搜索趋势（渠道提数）→ 预判了品类流量机遇？
8. 竞品投放金额（千瓜）→ 明确了投放差距和优化方向？
9. 竞品投放分析（分SPU）→ 提炼了可借鉴的内容方向和投放策略？
10. 竞品舆情 → 识别了品类核心买点和潜在风险？

**本品分析因果链（3环节）：**
11. 本品搜索洞察（聚光上下游词+决策路径）→ 导向了内容方向和投流策略？
12. 用户决策路径 → 识别了不同决策阶段的关键触点？
13. 人群资产（灵犀-度量）→ 诊断了人群健康度？→ 指导了蓄水和转化优化？

每个环节标注：[有承接/断裂/缺该分析步骤]

#### 反向因果
策略章节每个策略动作（做溯源/做测评/投某类词/选某类博主），回到洞察章节找支撑数据。有数据支撑→标注来源页码。没找到→"凭空出现"。

弱因果区（内容Angle/线下创意/IP/趋势预判/增量传播）不跑因果强度检查——这些是创意区，只看推导是否自洽。

#### 语句模板
```

```

### Step 6: 数据质量 + 颗粒度

#### MUST HAVE清单（逐页逐勾，比稿方案缺任一项=P0）
- [ ] 小红书赛道分析：灵犀泡泡图（搜索vs有曝光笔记两个轴）
- [ ] 赛道趋势：搜索趋势图+波峰波谷图+搜索词分析
- [ ] 赛道机会：灵犀热门搜索词+上下游词（来源/去向/飙升/热门四类分，词类分析）
- [ ] 赛道TA画像（年龄/城市/消费力/兴趣偏好四维+附策略转化句）
- [ ] 品牌&SPU搜索量排名（灵犀赛道下品牌排行）
- [ ] 灵犀搜后曝光排名+阅读排名
- [ ] 竞品品牌+SPU搜索量趋势
- [ ] 每个竞品的过往投放分析（分SPU拆解）
- [ ] 本品TA画像
- [ ] 本品品牌/SPU搜索趋势
- [ ] 本品过往投放分析
- [ ] 舆情分析（正面TOP3+负面TOP3结构化总结）

**NICE TO HAVE：**
- [ ] 站外赛道分析
- [ ] 博主量级分布+数量类型页

#### 颗粒度逐板块深化检查

**赛道洞察颗粒度：**
- 泡泡图：两个轴（搜索vs有曝光笔记）+时间范围（近90天/近24月）+核心结论句"赛道处于XX阶段"
- 搜索趋势图：波峰波谷标注+波峰对应的事件/季节解释
- 上下游词：按来源/去向/飙升/热门四类分，每类至少一句"这意味着用户[XX需求/行为]"
- TA画像：年龄+城市等级+消费力+兴趣偏好四维，附"这个画像对内容策略意味着什么"

**竞品分析颗粒度：**
- 竞品选取：灵犀排名+千瓜投放金额交叉验证的数据表，不能一句话
- 投放金额：K金额+图文视频占比+博主量级分布+推算FS金额
- 投放分析：分SPU拆解表格，不能只品牌维度的总览
- 舆情：正面TOP3+负面TOP3结构化总结

**Message House颗粒度：**
- RTB：产品参数级别具体数字（"宣威放养黑毛猪全支15-20kg仅取2kg入料"，不是"好食材"）
- 人群："25-35岁一线城市中高消费女性糕点爱好者"，不是"品牌人群"
- 卖点数量：1-2个极致化场景化的点，超3个→标"卖点分散"

**KFS颗粒度：**
- K矩阵：具体数字（头部X人/腰部Y人/垂类Z人/素人N篇），不能只有占比%
- F信息流：圈包逻辑必须写出来，不能只写包名
- S搜索：每类词预计CPC/搜索量/消耗必须标注，不能只有词例
- 预算：饼图+每一块为什么这么分的解释

**内容Angle颗粒度：**
- 完整故事链七要素：人群→场景→痛点→解法→内容形式→标题示例→预期数据
- 缺一环=颗粒度不够

#### 数据参照系
一个数字孤立出现=标"缺参照系"。必须有对比：
- 本品 vs 竞品
- 今年 vs 去年
- 搜索量 vs 渗透率
- 品牌词 vs 品类词

竞品组合如果全是同一类型（都选高投放品牌，缺高转化低投放黑马）→标"竞品组合维度单一"。

#### 结论-数据桥梁
扫描方案中所有"因此/所以/这意味着/由此可见"结论，往前翻找最近数据引用。间隔超2页且无中间推导→标"桥梁缺失"。

#### 素材元素拆解
收尾段素材/投放建议页：
- 是元素级别拆解（封面结构/标题公式/正文结构/评论区引导/共性元素提取）=合格
- 是截图罗列+主观描述=P0"素材页需元素级别拆解，不是截图凑数"
- 理论框架（吸黏拽）可以放，搭建方法（教客户怎么投）不能放

#### 竞品选取验证
必须同时满足：站内高搜+站内投放力度大+淘天京东销售表现好+客单价可对标。
选取不符合此标准的竞品→标"竞品选取不合理"。

#### 语句模板
```
MUST HAVE缺失 [P0]：策划方案框架第X条 [项目名称]
当前方案缺失：[具体缺失内容及影响]

颗粒度不足 [P1]：第X页 [项目]
当前：[模糊表述/缺数字/缺结构化格式]
应达到：[具体数字级别/结构化格式]

参照系缺失 [P1]：第X页 数据[XX数值]
问题：孤立出现，无对比参照。
应增加：[本品vs竞品/今年vs去年/搜索量vs渗透率/品牌词vs品类词]

数据桥梁缺失 [P0]：第X页结论"[原文摘录]"
最近前置数据在第Y页，间隔N页且无推导过程连接。

```

### Step 10: 增量建议（新增模块）

在标准审查P0/P1/P2汇总完成之后，独立输出增量建议。

#### 定位
基于方案现有数据信号，提出方案中未被利用的创意方向和机会点。属于弱因果区，供发散参考，不属强制修改。

#### 数据来源
- 上下游词中方案没用但四维矩阵过滤通过的词
- 竞品分析中没被讲的差异化机会
- 人群分析中没覆盖的子人群
- 节点/场景中新的内容切口
- 内容表现形式上的新玩法

#### 三段式格式
每条增量建议包含：
1. **数据线索**：第X页 [具体数据/信号]
2. **机会推导**：这个信号意味着什么，为什么有机会
3. **内容建议**：具体可以做什么内容/什么形式/什么人群

#### 与标准审查的关系
- 增量建议不标P0/P1/P2
- 不属强制修改
- 标题："## 增量建议（非必要，供参考）"
- 标注："以下建议基于方案现有数据信号，属弱因果区的机会洞察。不需数据验证，供执行团队发散参考。"
- 用分割线与标准审查区隔

#### 语句模板

## 使用原则

1. 每次审查先分段控制（模块零）→画出强因果区/弱因果区地图→再跑审查
2. 强因果区严查链路完整和段落四层逻辑，跳一步=P0
3. 弱因果区查推导自洽，不查因果强度，特别亮的标"创新亮点"
4. 数据来源必须对照前策标准逐项验证——不只是"有没有"，是"从哪来、对不对"
5. 每个问题标注具体页码+标准条文来源+可执行的修改动作
6. 方案类型不匹配/数据源不合规/MUST HAVE缺失/强因果链路断裂→一律P0
7. S配比不只要查有没有数字，必须跟品牌战略阶段匹配。小预算投全品类词=P0
8. 颗粒度不只标"缺"，必须标"写到什么程度才算够"
9. 第二版+必须先跑模块八迭代追踪+连锁影响检查
10. 增量建议在标准审查完成后独立输出，用分割线区隔，不标P0/P1/P2
11. 审查输出直接发在聊天中，不创建飞书文档（除非逸凡明确要求）
12. 方案类型无法判断时→问发方案的人，不等不猜
