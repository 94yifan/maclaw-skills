# 黄浦区"老字号·新活力"青年数字营销官孵化计划

## 完整执行方案（比赛 + 培养计划 + 后续人才计划）V3.0

**项目定位：** 以MCN化运营模式（非签约属性），为黄浦老字号打造青年数字营销人才孵化平台
**主办单位：** 黄浦区就业促进中心（建议联合区商务委、区文旅局）
**项目支持方：** 曼拾（广告代理/数字营销专业机构）
**核心平台方：** 小红书（办公地与注册地均在黄浦区）
**方案版本：** V3.0（2026年8月27日定稿：整合比赛、培养计划、后续人才计划三部分，含Roadmap、合作方体系与合作方角色）

## 一、项目背景与机遇

### 1.1 老字号之困：强场景、强叙事，但传播断层

黄浦区拥有全国最密集的老字号资源带——南京东路、淮海路、豫园三大商圈集聚了邵万生、三阳南货、老大同、沈大成、新雅粤菜馆、杏花楼、培丽酱菜、茂昌眼镜、吴良材眼镜、老庙黄金、童涵春堂、大世界等一批中华老字号与上海老字号。这些品牌共同拥有两个被反复验证的禀赋：

- **强场景**：百年门店、非遗技艺、匠人现场、历史建筑，天然具备"内容空间"潜质；
- **强叙事**：每个品牌背后都有数十年乃至上百年的故事、工艺与城市记忆，天然具备"内容素材"富矿。

但老字号普遍面临同一个断层：**品牌资产与年轻消费者的连接方式没有更新**。货架还是那个货架，门店还是那个门店，但年轻人获取信息和做消费决策的方式已经全面迁移到内容平台与数字渠道。老字号不是没有故事，而是没有一支能把故事翻译成年轻人语言、把门店变成打卡场景的内容队伍。

### 1.2 青年之困：有才华、有热情，但缺场景、缺出口

上海高校毕业生规模持续处于高位，就业结构性矛盾突出——企业招不到"会做数字营销的人"，学生找不到"能发挥数字营销能力的工作"。大学生普遍具备内容创作热情与学习能力，但缺少三个东西：

- **缺实训场景**：没有真实品牌、真实门店、真实需求让他们练手；
- **缺作品集**：没有商业级作品，求职时简历苍白；
- **缺岗位通道**：不知道"数字营销"有哪些岗位方向，也不知道去哪应聘。

### 1.3 时代之机：AI工具爆发 + 数字营销成为品牌标配 + 国潮文化红利

- **AI降低创作门槛**：AIGC文案、图片、视频工具链成熟，非传媒专业学生也能产出专业级内容，生源池从"专业学生"扩大到"全体大学生"；
- **数字营销成为品牌标配**：无论内容种草、直播带货还是效果投放，品牌都急需能落地执行的人；
- **国潮与文化消费红利**：Citywalk、非遗热、国货自信，年轻人正在主动走向老字号——缺的只是"数字营销翻译官"。

**平台策略：全平台通识 + 属地核心平台。** 课程与赛制按"全平台"设计——老字号被看到，可能发生在小红书、抖音、视频号、B站、美团、淘宝直播等任何阵地；学生的数字营销能力应是跨平台、可迁移的通识能力。平台资源接入上，以**小红书为核心平台**：小红书办公地与注册地均在黄浦区，是天然的属地合作伙伴，具备政策协同、资源直通、人才留区的独特条件；同时开放其他平台资源按作品需要接入。

### 1.4 就促中心之基：八年品牌资产与已验证的方法论

黄浦区"老字号·新活力"创新创业专项行动自2017年5月首创首发，已沉淀为全国标杆：

- 入选联合国《上海手册》全球25个案例之一；
- 与7家老字号集团建立战略合作，建成星光色谷、邵万生、大世界演艺中心3家老字号公共创业实训基地；
- 累计发布老字号创新需求167项，组织创新创业活动171场，2万余人次参与，产生创新方案632个，促成51个创新合作对接意向；
- 赛事方法论成熟：中国好创意大赛辐射全国526所高校、6644件作品；2024年"中华杯"黄浦美食大赛530余名学生报名、360余组作品、17校宣发辐射近万名学生；
- **"AI+新媒体"创业陪跑计划已验证"培训+陪跑"模式**：三个月全流程陪跑，4家陪跑企业粉丝总量增长8.5%、活跃度提升4.6%、全渠道曝光超10万次。

**黄浦独有的属地闭环优势：** 小红书（办公地与注册地均在黄浦区）叠加黄浦老字号集聚区、高校资源、就促中心就业服务体系，使本项目具备全国罕见的属地闭环——头部内容平台总部、老字号场景、青年人才、政府就业服务同处一区，平台资源可直通、学生就业可留区、老字号焕新可落地。这是其他城区难以复制的竞争壁垒。

**结论：体系完整、方法成熟、品牌响亮，唯一缺的是"从活动到人才资产"的沉淀闭环。** 过往赛事结束，作品归档，但人散了——学生没有持续成长通道，企业没有人才储备池，政府没有可追踪的就业成果。本项目补齐这一环。

## 三、项目目标

### 3.1 总目标

建成一个可持续运营的黄浦老字号数字营销人才孵化平台：**让老字号真正被看到，让大学生有班可上，让"老字号·新活力"品牌再上一个台阶。**

### 3.2 量化指标（建议值，最终与就促中心对齐）

**育人维度**
- 覆盖高校≥15所（含上海及长三角高校）
- 报名学生≥500人（对标2024年中华杯530人规模）
- 课程结业≥100人（含种草学认证通过者≥50人）
- "老字号青年数字营销人才库"入库≥200人

**传播维度**
- 老字号参与≥10家，发布真实创新需求≥15项
- 学生产出可发布内容作品≥300件（含AI辅助创作）
- 赛事全程内容总曝光≥500万（平台统计口径）

**就业维度（核心KPI）**
- 达成实习/见习/就业对接≥50人，其中明确就业（offer/入职）≥20人
- 就业跟踪：结业后3/6/12个月回访，形成就业成效报告
- 人才库年度企业查询与推送≥10家老字号/企业

**品牌维度**
- 赛事成为"老字号·新活力"专项行动年度标杆活动
- 沉淀"门店内容空间"改造示范案例≥3个
- 形成可复制的"政府+平台+专业机构+高校+老字号"多元协同模式

## 四、项目总体方案（三段式架构）

### 4.1 总体架构

本项目由三个相互咬合的部分组成，共同构成"选拔—培养—成才"完整闭环：

| 部分 | 名称 | 解决什么 | 核心产出 |
|---|---|---|---|
| 第一段·比赛 | 老字号新声代·青年数字营销达人赛 | 选拔有潜力的学生，制造声量 | 500+报名、200强、30强、获奖者 |
| 第二段·培养 | 达人孵化课程（三档） | 教会学生做数字营销的能力 | 100+结业学员、种草学认证、真实作品 |
| 第三段·人才计划 | 人才库+就业对接+常态化运营 | 让学生有班上、让企业有人用 | 200+人才库、50+就业对接、年度报告 |

**三段逻辑：** 比赛是入口（选人），课程是过程（育人），人才计划是出口（用人）。没有人才计划，比赛和课程就是一次性的活动；有了人才计划，三者变成可复利的人才资产系统。

### 4.2 年度运营节奏：赛事年度化，人才计划全年化

- **赛事与课程**：每年一届，11月启动、次年3月收官（详见第十章Roadmap）；
- **人才计划**：全年运营——赛事落幕不等于项目结束，人才库持续更新、季度双选会、企业需求对接、就业追踪贯穿全年。

### 4.3 学生视角的全流程体验

```
报名参赛（提交作品）→ 海选晋级 → 按档位命题创作 → 进入孵化营（分班学习）
→ 三档课程（通识/进阶/实战）→ 种草学认证考试 → 门店实战（探店/方案/直播）
→ 决赛竞技（分档设奖）→ 结业入库（人才库建档）→ 双选会对接 → 就业/实习/创业
→ 就业追踪（3/6/12个月）→ 优秀者成为下一届导师（反哺闭环）
```

## 五、比赛方案：老字号新声代·青年数字营销达人赛

### 5.1 设计原则

- **真实命题**：所有赛题来自老字号真实经营需求，作品直接服务"老字号被看到"这一核心目标；
- **AI贯穿**：AI工具全程允许且鼓励，设AI应用专项奖励；
- **多形态参赛**：产出一份营销方案、做一次真实带货、写一组种草笔记——不同能力形态均可参赛；
- **分档竞技**：按作品形态与难度分档，各档独立评审、独立设奖；
- **赛训一体**：比赛与课程咬合——比到哪一关，课程跟到哪一层；
- **门店即考场**：实战考核在老字号真实门店/真实渠道完成。

### 5.2 赛制（四阶段）

**阶段一：报名海选（线上）**
- 条件：上海及长三角高校在校大学生（含毕业两年内青年），专业不限
- 提交：个人简历+一份自选方向初试作品（笔记/短视频/方案提纲均可）
- 评审：讲师团初筛，择优200人进入初赛
- 目的：低门槛广撒网，AI降低创作门槛后非专业学生也能拿出作品

**阶段二：初赛（按档命题创作）**
- 老字号企业发布真实需求命题（每家1-2题），选手按所选档位任选命题创作
- 评审：企业代表+讲师团按档位分别评审，择优100人晋级孵化营
- 目的：检验基本能力与品牌理解力，为分班培养提供依据

**阶段三：复赛（孵化营+分档实战）**
- 100名晋级选手进入课程体系（详见第六章），按赛事档位与基础分层编班
- 实战考核（分档）：内容班门店探店内容制作（真实发布）/ 策略班营销方案路演答辩 / 实战班真实直播带货或投放（真实数据计分）
- 评审：四方评审团（企业+平台+专业机构+高校）打分+真实数据加权，择优30人晋级决赛
- 目的：真实场景检验，产出可直接使用的商业级成果

**阶段四：决赛（分档竞技+直播实战）**
- 形式：内容创作档作品展映+阐述；策略策划档方案路演+质询；实战转化档老字号专场真实直播（数据实时计分）
- 评审：四方评审团现场打分，三档分别评定
- 奖项：各档冠军1/亚军2/季军3；单项奖4（最佳创意/最佳AI应用/最佳直播表现/最佳人气）；全场总冠军1（跨档综合）
- 荣誉：证书+奖金+孵化资源包（导师陪跑、流量扶持、实习直通卡）
- 目的：巅峰对决即传播事件，决赛直播=老字号专场直播节

### 5.3 档位设计（作品形态 × 实际难度）

**档位一：内容创作力（入门档）——写笔记、拍视频、做探店**

| 维度 | 说明 |
|---|---|
| 作品形态 | 种草笔记/图文/短视频/探店vlog（1-3条），可含AI辅助 |
| 实际难度 | ★★☆☆☆（入门友好） |
| 时间投入 | 单条1-3天 |
| 技能门槛 | 基础内容创作+平台发布，AI工具显著降门槛 |
| 适合人群 | 全体学生，特别是非传媒专业、首次参赛者 |
| 评审侧重 | 选题与文案质量、画面呈现、真实传播数据 |
| 对老字号价值 | 直接可用的内容资产，真实发布即品牌曝光 |

**档位二：策略策划力（进阶档）——产出一份完整的数字营销方案**

| 维度 | 说明 |
|---|---|
| 作品形态 | 营销方案书：品牌诊断→人群洞察→传播策略→内容规划→渠道组合→预算分配→效果预估→执行节奏 |
| 实际难度 | ★★★☆☆（中等） |
| 时间投入 | 1-2周 |
| 技能门槛 | 市场分析、策略思维、方案撰写表达 |
| 适合人群 | 商科/广告/市场营销专业或有实习经验者 |
| 评审侧重 | 问题洞察、策略逻辑、商业可行性、路演答辩 |
| 对老字号价值 | 可执行的策略输入，落地后成为品牌资产 |

**档位三：实战转化力（高阶档）——做一次真实的带货或投放**

| 维度 | 说明 |
|---|---|
| 作品形态 | 真实直播带货/短视频带货/广告投放，附真实转化数据与复盘报告 |
| 实际难度 | ★★★★☆（较高，但最值钱） |
| 时间投入 | 2-4周 |
| 技能门槛 | 直播表达/投流操作、数据敏感度、抗压能力 |
| 适合人群 | 有基础、敢于真实实战、愿意承受结果的学生 |
| 评审侧重 | 真实转化数据（GMV/ROI/转化率）+复盘质量 |
| 对老字号价值 | 直接可量化的销售与投放效果，最硬的成果证明 |

**难度实话实说：** 档位一容易出量、难出彩（拼选题与细节）；档位二容易空谈、难落地（要经得起"预算从哪来、谁来执行"的追问）；档位三门槛最高、价值最大（真实数据不会说谎，一份真实战报胜过十份漂亮方案）。

### 5.4 评审机制

**四方评审团**（每档3-5人）：老字号企业代表（懂品牌与生意）+平台方运营专家（懂算法与流量）+专业机构总监（懂商业转化与方法论）+高校教授（懂人才培养）。
**评分维度**（按档位加权）：内容档=创意30%+质量30%+传播数据20%+品牌契合20%；策略档=洞察30%+逻辑30%+可行性25%+答辩15%；实战档=转化数据40%+执行30%+复盘20%+呈现10%。
**真实数据加权**：复赛起真实发布数据按10%-20%权重计入总分，让市场反馈参与打分。

### 5.5 奖项与激励

- 奖金（建议值）：各档冠军2万/亚军1万/季军5000/单项奖3000；全场总冠军另奖3万
- 证书：就促中心+联合主办盖章（可写入简历与综评）
- 孵化资源包：3个月导师陪跑、平台流量扶持、老字号实习直通卡、人才库优先推荐权
- 特殊激励：优秀作品获得真实落地机会（方案类由专业机构协助落地执行、带货类进入真实渠道投放，署名归学生）

## 六、培养方案：达人孵化课程

### 6.1 课程定位

"理论+实操+陪跑"三位一体的MCN化孵化课程，构建**"通识型+专业化"双轨体系**：通识型面向全体学生建立全景认知与基础能力；专业化面向有基础与职业意向的学生深入方法论与实战技能，对接行业认证（含小红书"种草学"营销人才认证）。课程按全平台逻辑设计，不绑定任何单一平台。

### 6.2 课程档位体系（三档）

**档位一：数字营销通识营（通识型·入门）**

| 维度 | 说明 |
|---|---|
| 定位 | 零基础入门，全专业可学；建立数字营销全景认知+老字号文化底座+AI工具上手 |
| 适合人群 | 全体在校大学生（含非传媒商科专业） |
| 课时 | 约16-20课时（2天线下集训+8课时线上录播） |
| 课程内容 | ①数字营销全景图：内容种草/直播带货/效果投放/私域运营是什么、怎么选 ②老字号文化认知：品牌故事、非遗技艺、场景叙事（含门店参访） ③内容创作基础：选题、文案、视觉、剪辑入门 ④AI工具入门：AIGC文案/图片/视频工作流实操 ⑤小红书种草学通识：种草营销底层逻辑与平台规则（官方通识内容） |
| 考核方式 | 线上测评+提交1份个人内容作品 |
| 学完takeaway | 数字营销全景认知；AI工具链上手；1个个人账号冷启动；通识结业证书；具备参赛入门档能力 |

**档位二：数字营销官进阶营（专业化·进阶）**

| 维度 | 说明 |
|---|---|
| 定位 | 掌握完整方法论与实战技能，对接行业认证，成为"能独立交付"的数字营销人才 |
| 适合人群 | 有基础的学生、通识营结业且考核优秀者、商科/传媒/设计专业学生 |
| 课时 | 约40课时（3天线下集训+4-6周导师陪跑+实战任务） |
| 课程内容 | ①种草营销方法论：小红书种草学认证课程（种草逻辑、内容策略、流量组合打法、数据复盘） ②策略策划实战：品牌诊断、人群洞察、渠道组合、预算分配、方案撰写 ③直播带货实操：话术脚本、场控、门店实景直播演练 ④AI进阶应用：数字人、AI视频、投放辅助 ⑤IP与人设打造：账号定位、内容人设、商业化边界 ⑥职业化基础：作品集打造、简历面试 |
| 考核方式 | 小红书种草学官方认证考试+实战任务（探店内容/营销方案/直播演练三选二） |
| 学完takeaway | 小红书"种草学"营销人才认证（官方证书）；完整作品集（2-3个真实作品）；门店实战经历；进阶结业证书；人才库入库+优先推荐资格；具备参赛进阶/高阶档能力 |

**档位三：数字营销官实战营（专业化·高阶/就业直通）**

| 维度 | 说明 |
|---|---|
| 定位 | 真实商业实战+就业直通；在真实老字号命题中完成可量化商业成果 |
| 适合人群 | 进阶营结业且考核优秀者、有实战意愿与时间投入的学生 |
| 课时 | 8-12周（项目制实战，含企业导师1V1） |
| 课程内容 | ①真实项目实战：真实直播/真实投放/真实方案落地（可选方向） ②商业数据复盘：ROI、转化率、复盘报告 ③就业冲刺：作品集定稿、模拟面试、双选会实战 ④创业辅导：入驻实训基地辅导 |
| 考核方式 | 真实商业成果（GMV/ROI/方案落地）+复盘答辩 |
| 学完takeaway | 真实商业战报（简历硬成果）；企业导师背书与推荐信；就业/实习offer（双选会直通）；人才库高级认证；创业孵化资格 |

**三档关系：** 通识营→进阶营→实战营逐级进阶，也可按基础直接选档；与赛事档位对应衔接——课程学哪档，参赛比哪档，学赛一体。

### 6.3 小红书"种草学"营销人才认证接入

- **认证背景**：小红书官方营销学习平台"种草学"推出营销人才认证体系，是内容营销领域行业认可的能力凭证（具体认证名称与等级以平台官方最新体系为准，建议依托属地关系与小红书团队合作确认）
- **接入方式**：
  1. 通识营：引入种草学官方通识课程内容（线上学习），作为入门认知模块
  2. 进阶营：接入种草学认证课程+官方考试，通过者获官方认证证书——作为进阶营毕业硬指标之一
  3. 合作机制：依托小红书总部在黄浦的属地优势，争取官方讲师授课、考试费用优惠/补贴、认证直通通道（纳入政企合作框架）
- **认证价值**：行业认可的能力凭证，提升简历含金量；认证学员进入小红书生态就业推荐视野；与人才库联动，形成"官方认证+政府背书"双保险

### 6.4 教学形式（升级版"AI+新媒体陪跑计划"）

- **线下集训**：按档位分营——通识营2天、进阶营3天、实战营以项目制为主
- **六周导师陪跑**：每两天作品日评、每周1V1复盘、每双周分享课——完成账号冷启动或方案打磨
- **门店实战月**：分档进驻老字号门店（内容班探店、策略班调研、实战班直播/投放）
- **线上课程平台**：录播+直播+资料库，支持非上海学生参与
- **结业考核**：学分制，完成全部模块+实战任务+作品集，颁发结业证书

### 6.5 证书体系（五层）

1. **通识结业证书**：《老字号青年数字营销官通识结业证书》（就促中心认证）——通识营结业即发
2. **进阶结业证书**：《老字号青年数字营销官结业证书》（就促中心+老字号企业联合认证）——进阶营结业即发
3. **小红书种草学认证**：官方营销人才认证证书（进阶营考核通过）——行业认可凭证
4. **达人认证**：实战营考核优秀者获《老字号青年数字营销达人认证》——人才库高级认证+就业直通
5. **获奖证书**：赛事获奖证书（政府背书，就业直通凭证）

## 七、后续人才计划（本项目灵魂：从"活动"到"机制"）

### 7.1 定位：比赛和课程是一次性的，人才计划是永续的

过往赛事的最大遗憾：比赛结束，作品归档，人散了。后续人才计划解决这个问题——**把赛事筛选出的人才变成可持续运营的资产**，让就业促进从"活动成效"变成"机制成效"。这是本项目区别于全国同类赛事最本质的差异。

### 7.2 老字号青年数字营销人才库

**入库标准（四级递进）：**
| 级别 | 条件 | 权益 |
|---|---|---|
| L1 建档 | 报名参赛即建档（能力测评+基础信息） | 赛事资讯、课程推送 |
| L2 结业 | 任一档课程结业 | 企业查询可见、双选会入场券 |
| L3 认证 | 种草学认证通过/达人认证 | 优先推荐、季度定向推送 |
| L4 实战 | 实战营完成真实商业成果 | 高级认证、企业直推、导师推荐信 |

**人才标签体系：** 技能标签（内容创作/策略策划/直播带货/投放优化/AI应用）+ 档位标签（通识/进阶/实战）+ 认证标签（种草学/达人）+ 意向标签（就业/实习/创业），支持企业按标签精准检索。

**运营机制：** 季度更新（新增学员+技能变化+就业状态）；企业开放查询（需授权）；定向推送（按企业需求匹配合适人才）；年度盘点（库规模、就业率、结构分析）。

### 7.3 人才成长路径（反哺闭环）

```
学员（参赛）→ 认证人才（结业+认证）→ 从业者（就业/实习/创业）
→ 优秀从业者（1-2年后）→ 导师/讲师（回课堂授课，拿课酬）
→ 资深从业者（3年后）→ 评委/企业需求方（回赛事出题选人）
```

人才计划不只是一条就业管道，还是一条**人才反哺链**——往届优秀学员成为下一届的导师、评委、企业用人方，项目因此具备自我造血能力。

### 7.4 常态化就业服务（全年运营，不随赛事结束）

| 机制 | 频率 | 内容 |
|---|---|---|
| 双选会/对接会 | 季度1次 | 企业摆摊+学员路演作品集现场双选 |
| 企业需求对接 | 持续 | 收集老字号及生态企业用人需求，建立年度需求池 |
| 人才定向推送 | 季度 | 按需求池匹配人才库，向企业推送 |
| 就业追踪 | 3/6/12个月 | 就业率、岗位类型、薪资、留存数据，写入年度成效报告 |
| 创业孵化 | 持续 | 优秀创业者入驻实训基地，首席创业指导师跟踪辅导 |

### 7.5 老字号企业人才输送机制（让企业有稳定的用人来源）

- **年度用人计划对接**：每年赛事启动前，收集老字号企业次年数字营销岗位需求（实习+全职），纳入需求池；
- **定制化输送**：企业有急招需求时，人才库定向检索+导师推荐，最快1周内完成对接；
- **实习转正通道**：推动老字号将赛事学员实习纳入"见习基地"机制（延续已有17个岗位/13人见习的基础），实习表现优秀者转正；
- **联合培养**：与用人需求大的老字号共建定向班（企业命题+企业导师+企业岗位），形成"招生即招工"的深度绑定。

### 7.6 三年发展规划

| 年度 | 阶段 | 目标 | 关键动作 |
|---|---|---|---|
| 第一年（2026-2027） | 打样 | 赛事完整跑通；人才库≥200人；就业对接≥50人 | 本届赛事全流程落地；人才库V1上线；双选会×2；成效报告 |
| 第二年（2027-2028） | 扩面 | 长三角高校扩展；老字号覆盖≥20家；人才库≥1000人；就业对接≥150人 | 赛事规模翻倍；季度双选会常态化×4；定向班试点；模式复盘优化 |
| 第三年（2028-2029） | 常态化 | 人才计划独立运营（不依赖赛事）；人才库≥3000人；年度就业对接≥300人 | 人才计划独立预算与团队；平台化运营；模式对外输出（可复制至其他区/城市） |

**三年后的理想状态：** 赛事只是人才计划的年度"招新入口"，人才库、就业服务、企业对接全年自动运转——一个真正可持续运营的黄浦老字号数字营销人才生态。

## 九、宣导方案

### 9.1 传播主线与话题资产

- **核心话题**：#老字号新声代 #老字号青年数字营销官 #老字号Citywalk
- **传播主线**：不是"招人参赛"，而是"一场老字号与年轻人的双向奔赴"——让社会看到老字号在年轻化，让年轻人看到老字号的新机会
- **内容资产化**：赛事全程所有选手作品、花絮、导师金句、老字号故事均为可复用内容资产，赛事结束即沉淀为"老字号·新活力"内容素材库

### 9.2 三阶段传播节奏

**阶段一：预热期（报名前2周）**
- 官宣海报与宣传片：老字号掌门人+非遗匠人+高校学生同框
- 校园大使招募：每所合作高校2-3名（大使获社会实践证明）
- 老字号门店话题预热：门店"新声代"主题物料+扫码报名
- 政务新媒体首发：就业促进中心公众号/视频号

**阶段二：招募期（3-4周）**
- 高校渠道：就业办/团委发文、校园宣讲会（10余所高校，延续成熟打法）、社团合作、学生社群
- 平台渠道：小红书（核心，属地官方合作通道）话题页/活动位/信息流+抖音/视频号/B站/美团资源位
- 门店渠道：老字号门店物料+店员话术（"在拍我们店的年轻人都能参加"）
- 关键机制：**报名即参与传播**——报名作品带话题发布，海选期即为赛事造势

**阶段三：赛程期（6-8周）**
- 赛事进程内容化：花絮、选手故事、导师金句、老字号冷知识
- 门店实战切片传播：探店vlog、直播高光时刻
- 决赛直播：老字号专场直播节（决赛日=传播峰值日）
- 成果展：决赛后"老字号新声代成果展"（优秀作品+人才库开放），企业HR到场，兼作就业对接会

### 9.3 渠道矩阵

| 渠道 | 主体 | 动作 |
|---|---|---|
| 高校渠道 | 就促中心+高校 | 官方发文、宣讲会、校园大使 |
| 平台渠道 | 小红书（核心）+其他平台 | 话题运营、流量扶持、活动位 |
| 政务渠道 | 就促中心 | 公众号、视频号、媒体报道 |
| 老字号渠道 | 老字号企业 | 门店物料、官号联动、员工转发 |
| 专业渠道 | 曼拾等 | 行业社群、达人/KOC资源、案例包装 |

## 十二、风险与保障

| 风险 | 应对 |
|---|---|
| 学生参与度不足 | 证书+奖金+就业直通三重激励；AI降低创作门槛；分档制让不同起点学生都有位置；校园大使渠道；与高校学分/综评联动 |
| 老字号配合度不足 | 区商务委背书动员；命题轻量化（企业只出命题和场景，执行由秘书处承担）；成果反哺企业（作品+人才+曝光） |
| 档位三（实战转化）报名不足 | 实战班导师1V1护航；提供直播间/设备/货品支持；明确"真实数据不等于必须盈利"的评分口径；设保底参与奖 |
| 种草学认证合作未落地 | 方案中已标注"以官方最新体系为准"；属地政企框架内推进；若认证未按期接入，先用自有课程体系兜底，认证作为加分项 |
| 内容合规风险 | AI内容标注规则前置培训；作品知识产权约定（署名+授权范围）；平台规则合规纳入课程 |
| 就业转化不及预期 | 保底机制：实训基地见习承接；数据透明：就业追踪如实呈现；目标分档（对接数/就业数/满意数） |
| 平台资源承诺落空 | 资源协议前置书面确认；多平台并行分散依赖；专业机构作为落地执行方 |
| 人才库运营断档（赛事结束后的空窗） | 人才计划纳入就促中心年度就业服务预算与人员编制；季度运营节奏固化（双选会/推送/追踪）；三年规划逐年评估 |
| 执行质量风险 | 第三方执行机构+工作组例会（周例会+里程碑评审）；关键节点成果验收 |
