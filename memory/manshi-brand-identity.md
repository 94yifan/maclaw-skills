## 使命愿景价值观（逸凡 2026-10-14 提供，原文）

**初心**：只做有效营销，帮助客户生意真正增长跃升。

**使命**：陪伴长期主义品牌创造势能。

**愿景**
- 对客户：帮助好品牌用更少的营销费用完成更高效的生意成长，陪伴客户成为具有行业影响力的 TOP 品牌。
- 对伙伴：成为社会大学的一站，让曼拾的伙伴们每一天都能完成自我成长与实现，走在不虚度的人生道路；陪伴伙伴们成为具有行业影响力的营销专家。
- 对公司：做出被知晓的、对行业有撬动的好案例及行业方法论，成为具有行业影响力的头部社交营销机构。

**价值观**
- 态度至诚：怀感恩心，做利他者。感谢客户选择我们让我们有体面的工作，感谢团队同事加入让我们可以成为彼此背靠的战友；与同事背靠背，帮助彼此承担，团体打仗力更强，成就团体就是成就自己。
- 结果导向：成有用事，用结果说话，结果论断。
- 积极不放弃：人生绝非一马平川，困难面前勇登攀。积极乐观，永不放弃。

## 五心体系（logo 五颗心的解释，2026-10-14 逸凡定调后更新）

**逸凡明确五个关键词**：感恩 · 韧性 · 创意 · 成长 · 实效拿结果。她自己指出 韧性+心、实效拿结果+心 读不通。

给她三个解法：
- A 全部用 X之心：感恩之心 · 坚韧之心 · 创意之心 · 成长之心 · 结果之心（正式、统一，但不适合当口号）
- B 换成现成两字词+心（推荐）：感恩心 · 恒心 · 创意心 · 成长心 · 实效心（想保留韧性原词就用 坚韧之心，别写韧性心）
- C 两字名 + 四字副题（最推荐组合）：感恩心·感恩利他 / 恒心·韧性生长 / 创意心·创意破局 / 成长心·成长共享 / 实效心·结果说话

结构：对人=感恩心；对自己=恒心、成长心；对事=创意心、实效心。英文：GRATITUDE · GRIT · CREATIVITY · GROWTH · IMPACT。

价值观对应：感恩→态度至诚（对外即公益）；韧性→积极不放弃；创意→有效营销的手段；成长→愿景；实效拿结果→初心（只做有效营销）+ 结果导向。

待逸凡定：韧性是留在副题（恒心·韧性生长）还是名字直接用坚韧之心。

## 五心体系（早期版本，保留备查）

结构：花蕊 = 初心；五颗心 = 五种用心对象；茎 = 积极不放弃。

1. **实效心** — 只做有效营销，帮客户生意真正增长跃升（初心）。动作：立项先写清这一稿要撬动的生意指标。
2. **长期心** — 陪伴长期主义品牌创造势能（使命）。动作：不做一次性爆款交付，做能沉淀方法论的动作。
3. **至诚心** — 感恩利他，对客户和伙伴都背靠背（价值观·态度至诚）。动作：有问题第一时间说；团队信息透明。对外就是公益心。
4. **结果心** — 成有用事，用结果说话，结果论断（价值观·结果导向）。动作：复盘只看生意结果、可复制方法、下次更快。
5. **成长心** — 每天长一点，陪伙伴成为行业专家，陪客户成为 TOP 品牌（愿景）。动作：清晰的能力曲线；公司出被行业认可的案例与方法论。

（备选：把公益独立成第五颗心，成长心并入长期心。）

## 凤凰纹样叙事（2026-10-14 提给逸凡，待定稿）

- 破题：先脱离龙凤呈祥/宫廷语境。古义凤为雄、凰为雌（尔雅·释鸟：鶠，凤，其雌皇），合称即阴阳共生，本不偏性别 → 解决她担心的全人性问题；凤凰非梧桐不栖、非竹实不食 = 择善而栖；凤凰现则天下安 = 吉兆非权力符号。
- 主线：凤凰是风，五叶草是幸运，风把幸运吹向更远的地方 → 幸运的传播（不把幸运攥在手里，而是铺开）。有说法指上古文字凤与风相通，凤是带来风的鸟。诗经·大雅·卷阿 凤凰于飞、凤凰鸣矣 讲凤飞群鸟随 = 声量靠被跟随。
- 国际化：讲成世界共通的火鸟（埃及本努、希腊菲尼克斯、斯拉夫火鸟），凤凰是东方那一只 → 重生与希望，不猎奇。
- 三个可复用词：择善而栖（客户与内容标准）· 和鸣而传（达人生态与传播逻辑）· 浴火重生（长期主义复利）。
- 视觉：凤凰保持底纹不做主角；一句话 看得见的是五叶草，看不见的是凤凰。

**待核**：尔雅·释鸟 与 诗经·卷阿 引文原文、甲骨文凤/风相通的具体出处（2026-10-14 外网搜索超时，未核）。

## 五心定稿候选（2026-10-14 12:12 逸凡提议后）

逸凡提议：加 利他心，把 恒心 换成 成事心。我的判断（推荐）：

**五颗心：感恩心 · 利他心 · 创意心 · 成长心 · 成事心**
- 花蕊 = 初心（只做有效营销，帮客户生意真正增长）
- 茎 = 积极不放弃（韧性）——撑住五颗心，不单独占一颗
- 副题四字：感恩心·记人好处 / 利他心·成人达己 / 创意心·创意破局 / 成长心·每日精进 / 成事心·结果说话 / 茎·韧性生长
- 英文：GRATITUDE · ALTRUISM · CREATIVITY · GROWTH · IMPACT（利他也可用 GIVING）

理由：感恩（向内记恩）与利他（向外给予）是态度至诚的两个方向，不重复，且利他心是公益的正式落点；成事心比恒心更主动、更贴生意语言，且名字直接来自价值观原文「成有用事，用结果说话，结果论断」；韧性放茎上，每颗心都能回原文。
提醒逸凡：创意心不在使命愿景价值观原文里，是能力项；若要求五心条条回原文，可把创意心换成坚韧心。
