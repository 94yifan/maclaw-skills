**最强宫位：** 兄弟宫（太阳权+巨门禄+右弼）→ 团队凝聚和沟通是天生的
**最弱宫位：** 交友宫（空宫+天魁）→ 自己没有识人选人能力

**学习方式：** 讨论式学习>实战学习>听播客。不适合长时间纯听课。已报长课需配内部分享转化。

## Skill迭代记录（ziwei-insight v2）

### 输出格式最终版

每层结构：**加粗结论** → 依据/命盘对应 → 启示/管理动作
正文核心关键词必须加粗。

### 八层结构

1. **底色层** — 命宫/身宫/来因宫定基调
2. **强弱层** — 十二宫排序，前三强+三弱，每宫有依据+管理启示
3. **拿捏层** — 驱动力排序（含手段ROI排序）+ 软肋排序（含危险信号+管理者怎么做）+ 死心塌地条件清单
4. **时间层** — 原局长板 / 当前大限激活长板 / 当年流年窗口
5-6. **三板块** — 专业业务板块 + 管理板块 + 成长板块
7. **学习与发展层** — 学习方式偏好（含命盘依据、发挥优势、避免劣势、落地建议）+ 学习频率 + 学习方向建议 + 已报长课补救方案
8. **场景层**（选配）— 有真实事件时反推验证

### 其他新增规则

- **逻辑红线：** 每段分析必须有命盘依据的明确对应，没有直接关系的现象不硬凑、不强解释
- **启动前必问三条：** 职级？汇报关系？近期事件？
- **员工匹配规则：** 如果给的名字在飞书系统匹配不上员工，追问是未导入还是新同事
- **关于名字的备注：** 同一人可能有英文名+中文名，用中文名建立档案
- **管理手段多元化：** 不能只靠紫微命盘推导，必须调用德鲁克/管理九大模块等现代管理手段组合输出

### 技能复用说明

- 团队成员卡片统一存储在 `team-insights/{中文名}.md`
- 每次分析后同步更新MEMORY.md 人员档案
- 下次提及该人名时自动读取卡片再回复

## 管理教训（本次修正）

1. **重写=重写，改=只改问题部分。** 逸凡说只改一句话时，我应激性重写了全文，丢失了原来的颗粒度，浪费了时间。以后写就是写，改就是只改问题部分。
2. **工具报400不意味着工具不可用。** 逸凡纠正后重新尝试即成功，不应直接放弃。
3. **紫微斗数分析强挂钩须谨慎。** 来因宫文昌忌跟包奖事件没及时发现之间没有直接逻辑关系，不应硬凑。
4. **SOUL.md格式规则必须遵守。** 报告中使用引号做概念强调违反了SOUL.md写法规定，以后统一用加粗。
5. **不要给管理建议贴虚标签。** 稻盛利他/老子无为/鬼谷子捭阖这些偏哲学的框架，逸凡判断为"虚"，以后只调用德鲁克/管理九大模块等可落地的现代管理手段。
