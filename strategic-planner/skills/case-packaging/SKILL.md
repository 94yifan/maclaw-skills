# Case Packaging（奖项案例包装评估）

判断案例值不值得包装，以及包装价值在哪里。

---

## 能力一：二元对立的矛盾结构思维

任何好的奖项案例，都有一个核心的结构性张力作为骨架。矛盾必须是真实的、对立的，不是表面的并列。

| 假的二元对立（太空洞） | 真的二元对立（有骨感） |
| -------- | -------- |
| "传统 vs 现代" | "仪式感需求 vs 功能性需求" |
| "短期 vs 长期" | "节点营销ROI vs 长线品牌建设" |
| "平台 vs 品牌" | "平台游戏规则 vs 品牌长期目标" |

**核心练习：** 拿到一个案例，先问——这个案例解决了一个什么二元对立？如果找不到，这个案例还没找到骨架。

---

## 能力二：三层复用性分析

每个案例必须同时回答三个问题：

1. 平台为什么要用这个案例说服客户？
2. 行业客户凭什么觉得自己也能学？
3. 同阶段的其他品牌能不能直接复用？

三个问题有一个答不上来，案例就缺了一条腿。

---

## 能力三：洞察萃取——横向展开 × 纵向深挖

**横向展开：** 一个核心洞察不能停在它本身，要追问它下面还有没有更细的维度。
- 洞察是"用户决策" → 展开为：谁在决策？影响决策的人有几个？每个人的诉求差异是什么？
- 洞察是"使用场景" → 展开为：这个场景在什么时候发生？什么触发了这个场景？场景里的人际关系是什么？

**纵向深挖：** 遇到一个现象，连问三次"为什么"直到最底层驱动因素。
- 现象：用户愿意为IP溢价
- 为什么？（因为信任背书）
- 为什么是信任不是别的？（因为这个品类认知门槛高）
- 为什么现在这个品类认知门槛成了核心矛盾？（因为新用户第一次进场，老办法已经失效）

---

## 能力四：链路一致性校验

背景挖的坑，必须在成果里填上。

自检问题：
- 洞察解决的是背景里哪个具体痛点？
- 实施动作回应的是哪个具体洞察？
- 成果数据能不能溯源到最初的痛点？

**最常见的死法：** 背景说"品牌认知困境"，实施做的是"促销引流"，两者之间没有映射关系。

---

## 能力五：宏大叙事 × 情动点的配比

宏大叙事给评委一个"为什么重要"的答案，情动点给评委一个"为什么感动"的记忆。两者不是并列关系，是**承载关系**——宏大叙事是骨架，情动点是血肉。

情动点的三个层次：
- **场景人感**——让人想到自己生活的具体画面
- **情绪人感**——让人产生"确实是这样"的共鸣
- **人物人感**——让人记住一个具体的角色

---

## 能力六：叙事节奏控制

好的包奖叙事遵循这个节奏：

1. 反常识结论（30秒抓住注意力）
2. 第一性追问（为什么是这个）
3. 策略生成（顺出来的，不是硬套的）
4. 落地动作（有细节，能执行）
5. 成果数据（到位，不空洞）
6. 方法论收束（一个名字，一句话公式）

---

## 六步自检清单

| 步骤 | 自检问题 |
| -------- | -------- |
| 矛盾结构 | 能不能一句话说清楚核心对立？ |
| 三层复用 | 三个问题能同时回答吗？ |
| 洞察萃取 | 横纵向展开了吗？ |
| 链路一致性 | 背景→洞察→实施→成果是否闭环？ |
| 叙事配比 | 宏大叙事和情动点是否承载而非并列？ |
| 叙事节奏 | 六步节奏是否完整？ |
