# 第六章附：机会地图

CoCo都可的机会不在追热点，而在把自己已经握住的独特资产重新定价，当前市场给它的最佳机会窗口恰恰藏在它被忽视的鲜芋心智、供应链底子和海外版图里。下面从品类趋势、渠道结构、人群需求、竞争空白四个维度做扫描，再用一个2×2矩阵对机会排序。

## 一、四维机会扫描

### 维度一：品类趋势

现制茶饮的主战场已经完成从奶茶到鲜奶茶再到鲜果茶的迁移，未来三年的增量集中在三个方向。第一个是国风鲜奶茶，霸王茶姬靠原叶鲜奶冲到6000家（evidence_tier：reported），验证了鲜奶茶品类的高增长和高溢价空间。第二个是健康化与真材实料，低糖、鲜果、五谷、植物基成为消费决策的新变量，沪上阿姨的五谷鲜果茶饮正是踩中这条线。第三个是平价质价比，蜜雪冰城用4万家门店（evidence_tier：reported）证明极致低价在下沉市场的统治力。对CoCo而言，鲜奶茶和健康化是它能够切入的品类增量，芋头作为天然的健康感食材，正好卡在鲜奶茶和健康化的交叉点上，这是它最顺手的品类机会。

### 维度二：渠道结构

新茶饮的渠道重心正在从一二线城市的商场店和街边店，向下沉市场和外卖双线转移。蜜雪冰城把下沉市场的单店模型做到极致，古茗、茶百道在二三线城市的街边店密度是CoCo的数倍，而下沉市场的外卖渗透率和单店坪效仍在爬升。CoCo长期集中在华东华南的一二线街边店，渠道结构单一，三四线城市的密度严重不足。渠道维度给CoCo的机会是清晰的：用2024年刚开放的单店加盟（evidence_tier：reported）补位下沉市场空白，同时把外卖和私域运营补成第二销售曲线。这个维度的机会门槛不高，但需要先解决单店模型和加盟商管理的问题。

### 维度三：人群需求

消费人群正在代际更替，Z世代和00后成为茶饮消费主力，他们的需求与CoCo所服务的老客群有代差。年轻人群要的是情绪价值、社交货币和高颜值产品，以及奶茶之外的健康感，而CoCo的核心客群偏成熟，品牌调性偏传统。这里的机会是双向的：一端是CoCo可以用鲜芋系列的情感记忆和怀旧感，服务好存量客群和高线城市的下沉需求；另一端是需要一个年轻化的子产品线或联名动作，去重新赢得年轻人。人群维度的关键判断是，CoCo不需要讨好所有人，它需要明确自己的核心人群是谁，然后围绕这个人群做深，而不是在两个人群之间摇摆。

### 维度四：竞争空白

把竞品格局摊开看，会发现一个明显的空白地带。蜜雪冰城锁死10元以下极致低价，一点点和CoCo挤在10到20元的台式奶茶区间，古茗、茶百道、沪上阿姨占据中端20元左右，霸王茶姬和喜茶在高端与国风赛道，这里几乎没有一家品牌把鲜芋这个品类做深做透。芋头在消费者认知里天然带健康、暖胃、怀旧的标签，却没有一个品牌把它当作品牌级资产来运营。这就是CoCo的竞争空白：用鲜芋系列做差异化，避开与蜜雪的低价肉搏，也避开与霸王茶姬的国风正面竞争，在10到20元这个价位带打一张别人都没有的牌。

## 二、2×2矩阵：市场吸引力×CoCo可执行性

把扫描出的机会放进一个横轴是市场吸引力、纵轴是CoCo可执行性的2×2矩阵，结果分四类。

第一象限是高吸引力高执行性，落在最优先位置。鲜芋鲜果茶饮的品类重构属于这一类，市场端健康化和真材实料是明确趋势，执行端CoCo有二十多年的鲜芋产品积累和现成客群，投入产出比最高。供应链能力产品化也落在这里，塑化剂风波中幸免已经验证了它的供应链底子（evidence_tier：reported），把这套能力对外输出几乎没有认知成本。

第二象限是高吸引力低执行性，属于需要补课的机会。下沉市场的渠道放量是这一类，市场空间巨大，但CoCo的单店加盟体系刚起步，加盟商管理和标准化运营能力还没经过放量检验，需要先补组织和中台能力。海外第二曲线也在这里，机会真实存在，但CoCo目前的海外运营是顺其自然的状态，缺少主动的战略组织。

第三象限是低吸引力高执行性，属于顺手做但不优先的机会。外卖和私域运营属于这一类，CoCo做起来不难，但它只是效率优化，不是结构性增长，可以放到日常经营里消化，不占用战略资源。

第四象限是低吸引力低执行性，属于放弃项。追国风鲜奶茶的正面竞争属于这一类，霸王茶姬已经把国风心智占满，CoCo硬切进去既没有吸引力优势，也缺乏执行上的基因匹配，明确不建议做。

## 三、机会排序

第一优先是鲜芋鲜果茶饮的品类重构。这是CoCo最该all in的机会，理由有三：一是竞争空白明确，没有头部品牌做透鲜芋；二是执行成本最低，现成产品和客群在手里；三是与CoCo的台湾老牌、暖胃健康的心智天然契合。具体动作是把鲜芋系列独立成品牌资产，主推一到两款核心单品，把芋头供应链做深。

第二优先是下沉市场的渠道补位。这是规模增长的主引擎，用单店加盟在四川、湖南、山东、江西、福建等重点区域（evidence_tier：reported）快速补密度，前提是先把单店模型跑通。这个机会的市场吸引力足够大，但执行上需要投入组织建设。

第三优先是海外第二曲线。这是CoCo区别于所有同行的差异化增长，海外门店的客单价和品牌溢价更高，且几乎没有同级别对手。它排在第三不是因为不重要，而是因为它依赖前两个机会先在国内站稳，才能有资源去海外深度经营。

第四优先是供应链能力产品化。它更像是前三项的基础设施和放大器，本身不是独立增长曲线，但能显著降低前三个机会的执行成本，建议作为贯穿全程的能力建设来推进，而不是单独立项。

收尾判断：CoCo的机会地图很清楚，先抓鲜芋心智这个最便宜的机会，再用单店加盟补下沉密度，用海外版图拉高天花板，供应链作为底座贯穿始终。这套排序的核心逻辑是先从自己手里现成的牌打起，把确定性最高的机会先兑现，再逐步升级执行能力去抓更大的机会。
