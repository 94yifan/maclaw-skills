# 曼拾复盘系统交互Playbook v3

> **定位**：给AI执行看的系统级操作手册。含Schema定义、Orchestration编排、哲学验证框架。
> **前置读取要求**：执行本playbook前，AI必须已加载 data-report-review、creative-performance-diagnoser2、greko 三个skill的完整内容。

---

## 0. 前置问询

执行任何复盘任务前，必须完成以下三项确认。缺一不可。

### 0.1 客户模板确认

**流程**：
1. 先问：客户是否有指定模板？
2. **有指定模板** → 按客户模板结构组织内容，同时内部以GRARI五模块（Goal / Result / Analysis / Review / Insight）校验内容完整性。缺失模块在内部标注，不在报告中暴露。
3. **无指定模板** → 使用OnePage GRARI框架作为默认输出结构。

**GRARI五模块速查**：
| 模块 | 占比 | 内容 |
|------|------|------|
| G - Goal 目标回顾 | 10% | 项目目的 / 预算分配 / why这么设定 / 核心阶段可量化目标 |
| R - Result 结果比对 | 10% | 目标完成情况 / 差距对比 / 亮点和不足 / 是否新增减少了目标 |
| A - Analysis 分析原因 | 40% | 做得好的(亮点事件+关键动作，三力拆解) / 做得不好的(问题事件+有差距的关键动作，三力拆解+客观原因) |
| R - Review 目的回顾 | 10% | 最早目的是否完成 / 为什么(资源分配/执行/情景变动三个维度) |
| I - Insight 规律总结 | 30% | 做得好的萃取为可复用方法论 / 做的不好的提炼为提升经验 |

### 0.2 受众适配

**确认读者是谁，据此决定术语深度和数据粒度**：

| 读者 | 术语深度 | 数据粒度 | 重点 |
|------|---------|---------|------|
| 品牌总监 | 高(可用专业术语) | 粗(战略层指标) | 目的是否达成、ROI、竞品格局 |
| 媒介执行 | 中(关键术语需解释) | 细(执行层指标) | 具体操作、人群包效果、出价策略 |
| 内部团队 | 中 | 细 | 可复盘经验、SOP优化、方法论沉淀 |

### 0.3 复盘目的确认

- **对客**：专业且好 → 重点放在成果展示 + 策略解释 + 下一步建议
- **对内**：经验沉淀（好和不好）→ 重点放在Analysis和Insight模块，三力拆解，可复用方法论

### 1.3 数据缺失Fallback路径

当关键指标缺失时，执行以下路径（不强行输出薄报告）：

```
缺失指标检测
    │
    ├── 标准指标完整 → 正常执行标准模板
    │
    ├── 标准指标缺失 → 启动动态诊断SOP
    │       │
    │       ├── 主动切换分析框架
    │       ├── 创造衍生指标替代缺失标准指标
    │       │   例：ROI缺失 → 创造RPV(Revenue Per View)=总成交金额/总观看次数
    │       │   例：CTR缺失 → 用互动率(总互动/曝光)近似衡量内容吸引力
    │       │   例：CVR缺失 → 用进店率(进店UV/点击UV)近似衡量转化效率
    │       └── 输出时标注"该结论基于衍生指标X，置信度低于标准指标"
    │
    └── 数据严重不足(>50%关键字段缺失) → 如实报告数据缺口
            ├── 列出缺失清单
            ├── 标注哪些结论因数据不足而降级
            └── 给出建议补充的数据维度
```

### 1.4 数据准备三确认

执行分析前必须确认：

1. **数据口径**：总流量 / 自然流 / 广告流 / 信息流是否含视频内流
2. **数据周期**：汇总还是by-day / 周期是否一致
3. **数据粒度**：达人×笔记ID / 账户×场域×计划×笔记×创意 / 关键词 / 人群包

## 2. Orchestration — 执行编排

### 2.1 两模式分支

```
输入任务
    │
    ├── 同事已完成报告 → 检查模式
    │       │
    │       ├── Step 1: 通读全文，标记疑点
    │       ├── Step 2: 逐条过五维审查清单（见§2.2）
    │       ├── Step 3: 标注四类问题
    │       │      ├── 数据问题 → 指明位置+修改后数据+理由
    │       │      ├── 逻辑问题 → 指明位置+修改后推理+理由
    │       │      ├── 结论问题 → 指明位置+修改后结论+理由
    │       │      └── 表达问题 → 指明位置+修改后表述+理由
    │       ├── Step 4: 输出Review建议层（独立于报告正文，标注"内部策略团队看"）
    │       └── ⚠️ 检查模式不用于检查自己写的报告
    │
    └── 从零开始 → 重写模式
            │
            ├── Step 0: 前置问询（§0）
            ├── Step 1: 数据准备三确认（§1.4）
            ├── Step 2: 数据缺失检测 → fallback路径判断（§1.3）
            ├── Step 3: 按产出物模板（§3）逐模块生成
            └── Step 4: 自检：逐条过五维审查清单（§2.2）
```

### 2.2 五维审查清单

来源：data-report-review skill。审查结果格式见§2.3。

#### 维度1：数据准确性

- [ ] 报告中的每个关键数字，能追溯到数据来源
- [ ] 百分比、增长率、占比等计算结果正确
- [ ] 数据是最新的，无过时数据被当作当前状态
- [ ] 引用的来源说的确实是报告中写的那个意思

#### 维度2：逻辑连贯性

- [ ] 每个结论都有充分的论据支撑（论证链完整）
- [ ] 报告内部无自相矛盾
- [ ] 无逻辑跳跃——前提到结论之间每一步都成立
- [ ] 重要结论考虑了替代解释

**三层追问内嵌**（来源：greko）：
- 第一层：数据前提是否成立？计算口径和对比参照物是否正确？
- 第二层：本质矛盾是否被识别？去掉数字后，真正的问题是什么？
- 第三层：反例是否被排除？换时间周期或人群包，结论还成立吗？

#### 维度3：结论质量

- [ ] 无从有限数据推出过于宽泛的结论
- [ ] 不同确定程度的结论已明确区分（高置信/中置信/低置信）
- [ ] 建议具体到可以执行
- [ ] 分析的局限性已声明

**五条红线检查**（来源：曼拾方法论）：
- [ ] 数据与结论有因果关系（非相关性冒充因果）
- [ ] 最小暴露负面原则（占比恒定时此消彼长是自然现象；热度下降做外部归因）
- [ ] 每个数据都有So-What
- [ ] 结论落点准确具体，经五问法深挖根因
- [ ] 下一步动作回溯前文分析发现+结合行业趋势

#### 维度4：受众适配

- [ ] 专业术语的使用匹配目标受众
- [ ] 分析深度匹配受众需求——不过浅也不过深
- [ ] 最重要的发现放在最显眼的位置
- [ ] 整体篇幅合适，无冗余

#### 维度5：表达质量

- [ ] 每句话只表达一个意思，无歧义
- [ ] 每段有一个明确的中心论点
- [ ] 章节之间的衔接流畅
- [ ] 表格、图表、标题等格式统一
- [ ] 禁用模糊措辞："应该""大概""看起来"等

### 2.3 审查结果输出格式

```
## 审查结果

**数据准确性：** ✅ 通过 / ⚠️ N处修改
**逻辑连贯性：** ✅ 通过 / ⚠️ N处修改
**结论质量：** ✅ 通过 / ⚠️ N处修改
**受众适配：** ✅ 通过 / ⚠️ N处修改
**表达质量：** ✅ 通过 / ⚠️ N处修改

**修改摘要：**
- [位置] → [原内容] → [修改后] → [理由]
```

### 2.4 常见失败模式识别

| 如果听到/看到 | 实际需要做 | 不够的是 |
|-------------|-----------|---------|
| "数据准确的" | 核查每个关键数字的来源 | "我仔细写的" |
| "逻辑严谨的" | 逐条检查论证链 | "读起来通顺" |
| "结论可靠的" | 交叉验证、考虑反例 | "和直觉一致" |
| "适合受众的" | 模拟受众视角阅读 | "不太专业" |
| "报告完成了" | 跑完整个审查清单 | "我检查过了" |

### 2.5 危险信号

出现以下任一信号，立即触发深度review：

- 使用"应该""大概""看起来"等模糊措辞
- "写完就想发"，没有重新审阅
- 对自己的分析过于自信
- 篇幅很长但没有检查内部一致性
- 关键数字没有来源标注

## 3. 产出物模板

### 3.1 GRARI一页纸模板

```
## G - Goal 目标回顾 (10%)
- 项目目的：为什么要做这件事（如加强品牌在xx人群的渗透/提升新品生意）
- 预算分配
- 为什么这么设定目标
- 核心阶段的可量化目标

## R - Result 结果比对 (10%)
- 目标完成情况
- 差距对比（目标 vs 实际）
- 亮点和不足
- 是否新增/减少了目标

## A - Analysis 分析原因 (40%)
### 做得好的
- 亮点事件 + 关键动作
- 三力拆解：策略力 / 执行力 / 管理力 + 客观原因

### 做得不好的
- 问题事件 + 有差距的关键动作
- 三力拆解 + 客观原因（目标修改 / 预算降低 / 大盘变化 / 竞品投放 / 品牌限流）

## R - Review 目的回顾 (10%)
- 最早目的是否完成
- 为什么：资源分配 / 执行 / 情景变动三个维度

## I - Insight 规律总结 (30%)
### 做得好的 → 萃取为可复用方法论
- 策略层面：——
- 执行层面：SOP / 媒介选K / 内容制作 / 投流 / 品牌广告
- 管理层面：机动性

### 做的不好的 → 提炼提升经验
- 策略制定修改
- 执行SOP优化
- 人员配置优化
- 预警和机动机制
```

### 3.2 Part 1 — 投放成果

**核心原则**：擅用大标题 + 总括句highlight + 数据化表达。关注客户在乎什么。

#### 1.1 投放亮点

投前投后对比，表格+趋势图。

**搜索指标**：
- SOV（某关键词下品牌广告曝光量 / 该关键词所有广告曝光量）
- SOC（某关键词下品牌广告点击量 / 该关键词所有广告点击量）
- ⚠️ 找直客拉全品牌数据，聚光后台只是代子账号维度有偏差
- 搜索指数（品牌词+品牌SPU词至少两个，以聚光为准，蒲公英后台辅助）
- 回搜率（点击广告后48小时内搜索过回搜词的用户去重人数 / 点击广告用户去重人数）
- ⚠️ 回搜率是by笔记维度不是by关键词维度；无行业均值默认0.5%

**生意指标**：
- 全店GMV
- ROI = GMV / 消耗成本（需行业benchmark问直客）
- 进店成本 = 消耗成本 / UV（需行业benchmark问直客）

**淘宝联盟维度**：
- 内容互动率（浅层种草程度高）
- 引流率（人群精准+内容吸引度高）
- 店铺新访客率（引流新客多）
- 收藏加购率（需考虑价格/竞争优势）
- 转化率（实际下单转化好）
- 店铺新客率（新客已成功下单）

**口碑指标**：
- 搜索趋势与投放节奏相关度

**浅层指标**：
- CPE = 价格/总互动
- CPC = 消费/点击量
- CPM = 价格/总曝光×1000
- CTR = 阅读量/曝光量

**深层指标**：
- 人群渗透率 = 品牌人群在品类人群中占比（⚠️ 每个客户取数逻辑不同，先和客户对齐）
- 内容渗透率 = 品牌内容阅读量在该类目所有内容阅读量中占比
- 搜后曝光渗透率 = 搜索后品牌内容曝光量在该类目所有内容曝光量中占比
- 人群资产

**品牌广告数据达成**：
- IP资源包 / 惊喜盒子 / 品专 / 火焰话题等

#### 1.2 策略执行方法论

策略是什么（KFS分配比例等） + 用了什么抓手（KFS） + 达成了什么效果

#### 1.3 人群分析

论证策划端人群策略价值。

**人群四象限**（高/低消耗 × 高/低点击或转化）：
- 高点击转化+高消耗：是否与策略一致
- 高点击转化+低消耗：可拓展加预算

## 4. 规则速查

### 4.1 策略型分析三段式格式

**格式（结论优先）**：
1. **第一句**：一句话总结结论
2. **第二到四句**：通过量化数据论证结论（对比参照物 + 数据支撑）
3. **最后一句**：未来建议和方向

**写完后的自检（三层追问内嵌，不输出答案但必须过一遍）**：
- 第一层：数据计算口径对吗？对比参照物选对了吗？
- 第二层：数据反映的核心矛盾是什么？去掉数字后本质问题是什么？
- 第三层：结论有反例吗？换时间周期或人群包结论还成立吗？

### 4.2 结论写作五条红线

1. **数据与结论必须有因果关系**
   - CPM无法反映触达人群精准（CPM反映系统竞争力），精准看CTR和CPC
   - 进店UV量无法反映引流高效（只说明跑量好），引流效率看进店率
   - 进店率和转化率优于大盘无法指向GMV更高（只说明性价比高），GMV取决于钱能不能花够花完

2. **最小暴露负面原则**
   - 占比恒定时此消彼长是自然现象，不做负面归因
   - 热度下降做外部归因（大盘变化/竞品投放/品牌限流）

3. **每个数据都要有So-What**
   - 缺乏归因要追问提升原因是什么、做对了什么
   - 展示差异化动作

4. **结论落点准确具体**
   - 执行五问法深挖根因：
     - 为什么CPUV高？→ 进店转化率低
     - 为什么进店转化率低？→ 用户只想看IP对产品无购买意图
     - 为什么？→ 素材过于侧重IP未突出产品功能
     - 根因：内容卖点与IP流量错配，未实现IP引流产品承接

5. **下一步动作必须回溯**
   - 不能杜撰，必须回溯到前文分析发现
   - 结合行业趋势

### 4.3 三层追问框架

来源：greko skill。嵌入三段式写作和质检review链。

**书写规范层**（每写一条策略型结论时内置）：
- **第一层 — 苏格拉底追问**：数据计算口径和对比参照物是否正确？这个结论的前提本身成立吗？
- **第二层 — 柏拉图看透**：数据反映的核心矛盾是什么？去掉数字后，本质问题是什么？（这是影子还是火光？）
- **第三层 — 亚里士多德验证**：结论有没有反例？换时间周期或人群包，结论还成立吗？能用三段论结构化表达吗？

**质检review链层**（在逻辑连贯性检查中追问）：
- 数据前提是否成立？
- 本质矛盾是否被识别？
- 反例是否被排除？

**Prompt要求层**（三段式写完后追加三层自问）：
- 必须过一遍三层追问，不输出答案，但确保经得起推敲

### 4.4 双重美德论

来源：greko skill 中苏格拉底"自知其无知" + 亚里士多德"中道"。

**苏格拉底美德 — 实事求是，承认无知**：
- **依据**："我唯一知道的，就是我一无所知"；德性即知识——认识不到的东西也做不到
- **在复盘中的应用**：
  - 数据缺失时如实标注，不强行编造
  - 结论强度与数据支撑匹配：数据不足 → 结论降级，标注置信度
  - 缺失清单单独列出，给出建议补充维度
  - 审查没有捷径——不过完清单不能说"完成了"

**亚里士多德中道 — 在两端之间找到平衡**：
- **依据**："美德在两个极端之间，而不是在极端上"
- **在复盘中的两极与中道**：

| 极端之一（不足） | 中道（美德） | 极端之二（过度） |
|----------------|------------|----------------|
| 数据不全就不写，等所有数据完美 | 数据不全时动态切换分析框架，创造衍生指标 | 数据不全强行输出薄报告，堆满0和N/A |
| 过度保守，结论模糊到毫无价值 | 有数据说数据，没数据说缺口，结论标注置信度 | 过度自信，声称完成但没验证 |
| 用概念代替行动，追问不止没有结论 | 追问为了找到可行动的方向，问透之后必须有结论有行动 | 急于给结论，跳过验证 |

**在Review建议层中的应用**：
- Review建议层（内部策略团队看的优化路径）不进入报告正文
- 报告正文用如实标注（数据缺失标注 + 结论强度降级 + 缺失清单 + 建议补充）
- 两者分层：客户看到的是诚实且专业的报告；内部看到的是知道下一步怎么改进的路径

### 4.5 表达质量规范

来源：data-report-review skill + 对话确认规则。

**段落结构**：
- 每段一个中心论点
- 段落间有逻辑衔接（因果/递进/转折/并列）
- 最大程度可视化：字数越少越好、逻辑越清晰越好

**禁用措辞**：应该、大概、看起来、似乎、可能（除非有置信标注）、差不多、基本上

**标题规则**：
- PPT中各模块内容加总 = 标题
- 擅用大标题 + 总括句highlight
- 可视化图表标记重点：格式一致降序占比、重点数字highlight

**分析型句子写作公式**：
- 先列所有动作 → 语句升维 → 做减法

### 4.6 动态诊断SOP

来源：creative-performance-diagnoser2 skill。

当输入数据缺少关键指标时：

1. **不机械输出单薄报告**——主动切换分析框架
2. **创造衍生指标替代缺失的标准指标**
3. **分析与数据强关联**——每个核心数据表后紧跟深度分析和行动建议
4. **关键词与业务结果挂钩**——识别高转化词而非高频词
5. **明确分类**——清晰列出优质素材和劣质素材清单

### 4.7 衍生指标计算规则

来源：creative-performance-diagnoser2 skill。

| 缺失指标 | 衍生替代指标 | 计算公式 | 注意事项 |
|---------|------------|---------|---------|
| ROI | RPV (Revenue Per View) | 总成交金额 / 总观看次数 | 衡量单次观看价值 |
| CTR | 互动率 | 总互动 / 曝光 | 近似衡量内容吸引力 |
| CVR | 进店率 | 进店UV / 点击UV | 近似衡量转化效率 |
| 转化率 | 收藏加购率 | (收藏数+加购数) / 点击量 | 衡量购买意向强度 |

**四象限分类法**（素材诊断用）：
- 基于整体平均值划分CTR和CVR的高中低三档
- **明星素材**：高点击高转化 → 值得放大
- **引流型素材**：高点击低转化 → 检查落地页与素材匹配度
- **转化型素材**：低点击高转化 → 优化封面图和标题
- **问题素材**：低点击低转化 → 暂停重构

### 4.8 平台指标关系规则

**小红书双列信息流**（用户选择逻辑）：
- CTR高 → 封面标题打中精准人群 → 系统给更多曝光 → CPM升高
- CPM高 + CTR高 = 人群精准的正向信号
- 因果链：CTR ↑ → CPM ↑（而不是反过来）
