## 第一步：错题本

### 错误1：browser.disconnect() TypeError（脚本bug）⭐

**现象：**
```
TypeError: browser.disconnect is not a function
    at main (file:///private/tmp/crawl-tea.mjs:99:17)
```

**根因：** `chromium.connectOverCDP()` 返回 CDPBrowser 对象，该对象没有 `disconnect()` 方法。这个方法根本不存在于 Playwright 的 CDP 连接对象上。

**怎么修复（具体代码改动）：**
删除 `/private/tmp/crawl-tea.mjs` 第 99 行：
```javascript
// 删掉这一行
await browser.disconnect();
```
**原因**：我们是连接到一个已有 Chrome 用户会话，不是自己启动的浏览器，不应该断开它。进程结束时让浏览器保持连接即可，不需要任何清理动作。

**预防：** 以后任何用 `connectOverCDP` 的脚本都不应该调用 `disconnect()`，因为这不是自己启动的浏览器。

- **根本解决方案**：Cron session 产出必须写入 workspace 文件才算完成，不能只依赖 session 结束后自动保存

**预防：** 爬虫完成后立即写文件，不要等 session 结束后依赖自动保存；加入 `process.exit(0)` 确保正常退出。
