### 串联三百二十二（核心·合同）：定量承诺把文案成本转成合同义务——第三级承诺必须配检测方法、抽检频次、不达标处理

**证据：** 古茗榴莲系列（马来西亚猫山王 + 泰国金枕双品种、100% 真实果肉、每杯果肉量约等于一瓣完整榴莲）；霸王茶姬黔野山月亮（贵州刺梨 + 石榴 + 木姜子）；瑞幸辣皮子牛肉恰巴塔（新疆辣皮子 + 阿克苏苹果）；CoCo 红豆青稞木薯（东北红豆 / 日喀则青稞 / 广西黄心木薯）。

**串联：** SP 今日缝合1（产地三级阶梯：地名 → 品种/产区 → 定量）＋ 318（计价单位）＋ 312（代言合同四条款）。

**新认知：** 三级阶梯的前两级是防守，第三级是**法律级承诺**。地名可查、品种可核，用户不会拿尺子量；一旦写成每杯约一瓣、100% 真实果肉，它就变成合同法上的履行标准——用户拿去称，落差直接落进广告法第二十八条（虚假宣传）。此时成本结构改变：一半留在市场部（文案），一半转移到供应链与法务（检测、抽检、赔付条款）。

**算账：** 前置成本（第三方检测 + 抽检）一次性、可预算、有上限；后置成本（客诉、平台处罚、召回）无上限。第三级承诺的经济性只有一句：检测成本 < 客诉期望成本 × 发生概率。算不平就不要写第三级，退回品种级。

**落地动作：** 新品提案加一张「承诺-证据-赔付」三列表：每条定量承诺写明检测方法（谁检、什么口径）、抽检频次、不达标处理（换货 / 赔付 / 下架）。第二列填不出来的，不许写进文案。

**BD 应用：** 客户市场部要写 100% 真实果肉，先问供应链能不能出检测报告、采购合同有没有对应条款。答不出，这条文案就是埋在品牌脚下的雷。顾问的价值是比客户早三步看到那张赔付单。

**串联：** 312（代言合同四条款）＋ 10-14 缝合5（可收藏周边）＋ 319（券机制的信息承载位）。

**新认知：** 可发声周边把授权标的从静态形象扩到声音，法律上是另一项权利（表演者权 / 录音制品权），标准代言合同的肖像条款通常盖不住。授权标的四要素：**肖像、姓名、声音、签名**。声音授权必须写死四件事：载体清单（键帽 / 礼盒 / 小程序语音）、复制数量、使用期限、能否二次剪辑。

### 串联三百二十四（核心·算账）：IP 联名用已验证大单品承接，是把转化方差压到最小——代价是新品增量为零，第三个变量是授权期

**证据：** 茶百道 × 遗忘之海定档 10/23，联动饮品落在超厚芋泥系列（现有大单品）；对照同日奈雪 × 卡斯波和丽莎配法式可可（新品线）、沪上阿姨 × 初音未来用定制包装（不改 SKU）。

**串联：** 308（联名回收期）＋ 318（计价单位）＋ 10-21 轻量1（官宣三段式）。

**新认知：** 联名有两种承接方式，风险结构相反。存量 SKU 承接：IP 带新客，口味不带新风险，ROI 方差小，但联名结束后没有留存产品。新 SKU 承接：IP + 新品味双重下注，方差大，成了就留下一条新增长曲线。

**被忽略的第三个数是授权期。** IP 授权通常 1–3 个月，SKU 生命周期 6–18 个月。存量承接，授权到期后销量不断崖（用户认的是芋泥）；新 SKU 承接，授权到期那天新品同时失去流量与身份，最容易变成一次性 SKU。茶百道选芋泥不是保守，是把授权期与产品周期的错配风险让 IP 方承担。

**落地动作：** 联名提案加「承接 SKU 类型」一栏，算两版 ROI：存量版（增量客单 × IP 触达）／新版（新品存活率 × 授权期后留存）。客户只给 IP 不给预算时，先问授权期多长；短于 3 个月，默认推存量承接。

**BD 应用：** 客户说联名要有新品，先问授权到期后这个新品还卖不卖。答不出，就用存量承接，把预算花在包装和内容上，不花在开新品上。

### 串联三百二十五（核心·算账）：限定范围是成本工具不是稀缺话术——MOQ 决定单城还是全国

**证据：** 沪上阿姨 × 初音未来 10/26 上海指定门店，定制包装含抽拉明信片、旋转杯套、纸袋，到店打卡领贴纸；对照喜茶深圳新茶坊限定三款只在空间内供应。

**串联：** 318（计价单位＝场）＋ 316（周边获取门槛毛利）＋ 321（门店现场动作）。

**新认知：** 定制包装有起订量，单城限定之所以成为行业惯例，不是因为更稀缺，是因为它更容易摊平 MOQ。消耗量 = 门店数 × 单店日均杯量 × 活动天数，达不到 MOQ 就只能退回低起订量物料。这正好解释了单城联名的物料结构为什么总是贴纸 + 杯套 + 纸袋三件套——它们是起订量最低的组合。

**算账：** 定制物料可行性 = 消耗量 ≥ MOQ。缺口多大，就用通用物料补多大。反过来，全国铺开若杯量不足，异形包装的单位成本会高于它带来的内容价值。

**落地动作：** 联名物料提案先算消耗量，再定物料层级：足量 → 异形包装；不足 → 杯套 + 贴纸；严重不足 → 只做数字物料（表情包 / 壁纸）。合同写清物料归属与剩余物料处置（授权到期后不得继续使用）。

**BD 应用：** 客户要全国铺开的联名包装，先算 MOQ 与消耗量。算下来不够，就老实说这是单城项目，把预算从包装挪到内容，效果不一定差。

### 元洞见（BM·履约科目轴）：结构设计的第十八个落点

承 321（计价单位轴），今日补**履约科目轴**。

**任何一条对外表达，都必须在预算表里找到它的履约科目。** 定量承诺 → 检测与抽检；声音周边 → 授权与录音；限定范围 → MOQ 与物料；历史数据 → 口径与证明；整点免单 → 门店峰值与履约工时。

**找不到履约科目的那条表达，就是未来要赔的那条。** 与计价单位轴的分工：单位轴管怎么算钱，履约轴管算到的钱够不够履约。两条都过，报价才可执行；只过第一条，报价单好看，交付时亏在看不见的科目上。

**判据：** 出一版提案，逐条把对外承诺映射到预算科目，映射不上的表达要么删，要么加预算。
