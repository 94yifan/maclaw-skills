## 五维模型（由逸凡定义）

①市场/渠道 → 财报七项+市场表现力四项+渠道=生意渠道(天猫/京东/抖音/线下)
②品牌力 → 六子项(大帽子/代言/IP/公益/线上种草/线下营销)+社交媒体联动+组织力
③产品 → 四类品取数(销量Top3-5/口碑声量/品类代表1-3个/品牌特色)+三方对齐检查
④趋势(逸凡三趋势模型) → 行业风向/内容热点/用户情绪。竞品只归纳，本品归纳+预判
⑤人群 → 核心画像+可拓展人群+人群资产。竞品只归纳，本品归纳+预判

## 关键规则（不变的）

- 字数不设上限，用完整句子清晰表达
- 结论先行(判断→两个以上数据→收尾判断)
- 禁止AI腔(引号概念强调/星号破折号/填充词)
- 禁止中间态用语(我找到了/查到了/正在看)
- 单品牌段不做跨品牌对比
- 品类/渠道分开
- Pro写分析(主session)，GLM 5.2写所有脚本代码，GLM 5V截图审查，Flash采集修正
- 财报按上市地分支(A股扣非/港股经调整/美股Non-GAAP)
- 竞争模式按行业实际归纳，不预设固定类型
- 失败后写pipeline_error.md并hard stop→通知逸凡

### 逸凡的6项补充（playbook v4核心新增）

1. 竞争模式不要预设固定类型（系统飞轮者那套是宠物食品特例），每个行业自己归纳
2. 市场维度框定财报七项+市场表现力四项子维度
3. 渠道=生意渠道标准化，每个渠道的分析内容/数据源/角色判断全部写死
4. 品牌力=六子项(大帽子/代言/IP/公益/种草/线下营销)+社交媒体联动+组织力
5. 产品取数四类品(销量最好/口碑声量/品类代表1-3个/品牌特色)，每个品类不限于1个SKU
6. 竞品趋势人群只做归纳，本品趋势人群要归纳+预判建议

### 离线新增：产品三方对齐

逸凡指出品牌力和产品力分析需要评价关键词、商品详情页卖点、以及卖点vs品牌campaign的对齐检查。追加了三项：
- 商品详情页卖点提取SOP
- 品牌叙事→产品卖点→用户感知 三方对齐判断
- QA三方对齐检查项

### 晚间：Pipeline开发 + 清闲LiberNovo验证

**Pipeline脚本**：GLM 5.2编写，3,331行Python。`python pipeline.py --config X --step N`，14步流程，每步契约验证，失败hard stop+写pipeline_error.md+通知逸凡。

**验证执行**：
- v1失败：假说浏览器反爬跳过采集，数据是综合推断。逸凡质疑"三个平台都反爬？不合理吧"
- 实际测试：浏览器可用，天猫搜索页数据直接可提取。3分钟采完5品牌天猫+京东+永艺财报
- v3完整版（211KB docx）：补采了永艺/黑白调/保友的商品详情页评价关键词和卖点描述。行业研报web_search不稳定只拿到百度百科数据

**采集到的关键数据**：
- 清闲 OC1 Pro: ¥3,765, 1万+付款, 热销榜第5。S1: ¥2,529, 2000+付款
- 西昊 C300二代: ¥1,500, 3万+付款, 401万+看过。B100Pro: ¥549, 10万+付款
- 永艺 新沃克pro+: ¥429, 10万+付款, 好评率98.2%。评价高频词TOP1是"收货顺利/物流效率"（说明服务体咸在补产品认知不足）
- 黑白调 E3Pro: ¥1,699, 3万+付款。评价高频词TOP1是"客服服务很好"（同样的问题——服务在补产品）
- 保友 金豪B雄鹰: ¥1,802, 好评率99.2%。评价"安装方便/性价比高"
- 永艺财报：2024全年营收未披露细分，扣非净利润、毛利率等数据来自公开搜索

**核心洞察**：
1. 清闲是品类定义者——全行业用网布时清闲选海绵舒适+动态追腰+新风换气，重新定义标准
2. 三方对齐：清闲OC1 Pro品牌叙事/产品卖点/用户感知三层高度一致，在2-3年新品牌中很稀缺
3. 全行业没有品牌做到三层完全对齐——永艺评价第一是"收货顺利"而非产品性能，黑白调"客服好"排第一
4. 品牌溢价被市场接受：OC1 Pro是C300的2.67倍价格但销量差距只有1:1.5
5. 清闲最大短板：有品类定义力无品类话语权——零campaign/零代言/零联名，品牌体系完全空白
6. 三种行业竞争模式从数据归纳：参数内卷型(永艺/黑白调)、全价格带收割型(西昊)、高端体验锁定型(清闲/保友)。清闲和保友路径不同：保友走稳健信任背书、清闲走创新品类教育（ROI更高风险更大）

**数据局限**：
- 行业研报web_search不稳定（只拿到百度百科数据）
- 清闲和西昊的商品详情页未重新提取（只用了搜索页数据）
- 回头客率只在商品详情页有，未全品牌覆盖
