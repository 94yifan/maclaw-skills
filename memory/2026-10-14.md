## 可复用方法：纸张实拍感 mockup（纯 Python，不依赖 GPU/在线模型）

1. 卡面：暖白底 `(252,250,246)` + 细颗粒噪声 + 纤维条带 + 低频斑块 + 左上光源渐变。
2. 吃墨质感：矢量稿先锐利合成，再整体乘上纸张纹理 + 0.35px 高斯模糊 + alpha 边缘 0.45px 柔化 → 得到油墨渗进未涂布纸的感觉。
3. 裁切边：alpha 外扩倒角 2.2px 做 rim，边缘轻微压暗 + 提亮 1%。
4. 阴影三层：接触阴影（偏移 3,5 / 模糊 7 / 0.50 + 深色 96,86,78）+ 半影（10,16 / 20 / 0.34）+ 环境（26,42 / 55 / 0.26）→ 卡片才不飘。
5. 桌面：暖米色 + 径向光衰 + 低频宏观斑块 + 灰尘点 + 0.6px 模糊。
6. 全局收尾：暗角 0.18-0.22、颗粒 2.4、轻微暖色分级（R×1.012、B×0.994）、卡片表面再加 1.8% 斜向明暗渐变（模拟纸不平）。
7. 透视/旋转：PIL `transform(PERSPECTIVE)` 做梯形 + `rotate(expand=True)`，四角坐标解线性方程（`_quad_to_coeffs`）。
8. 注意：numpy 2.x 去掉了 `ndarray.ptp()`，要用 `np.ptp(a)`。
