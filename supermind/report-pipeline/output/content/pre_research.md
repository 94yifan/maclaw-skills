# PITAKA 前置调研框架

项目：PITAKA 品牌与手机壳赛道分析报告（高端手机壳 / 芳纶纤维）
行业：手机壳 / 手机保护配件
阶段：Step 2 前置调研（待逸凡确认竞品框架）

## 模块A：赛道框定与竞品筛选

### A1 赛道定义

本报告把手机壳按"用户为什么付钱"切成三层，而不是按材质或价格简单分档。三层对应三种完全不同的竞争逻辑，混在一起看会得出错误结论。

1. 材质美学派：为稀缺材质、手感、轻薄付费。价格带 200-800 元。代表 PITAKA、LLC、邦克仕 Benks、EVUTEC。竞争核心是材质叙事能否撑住溢价，以及同一材质下谁能把成本与良率做得更好。
2. 功能防护派：为参数、防护等级、功能创新付费。价格带 80-400 元。代表 图拉斯、决色、UAG、OtterBox。竞争核心是功能可验证性与渠道覆盖。
3. 潮流设计派：为设计、身份表达、联名付费。价格带 200-600 元。代表 CASETIFY、dbrand、Apple 官方壳。竞争核心是设计供给速度与品牌势能，材质不是主要变量。

### A2 PITAKA 的竞争位置假设（待数据验证）

PITAKA 处于材质美学派头部，客单价 300-700 元，海外收入占比高于国内。国内面临四向挤压：

1. 同材质下压：LLC 用抖音内容驱动 + 更激进价格带切同一批"凯夫拉爱好者"，是最直接对手。
2. 全品类侧压：邦克仕以芳纶壳 + 膜 + 充电配件的品类组合和更宽的渠道覆盖截流。
3. 向上被压制：CASETIFY 用联名与设计供给把高端价格带的天花板占住，PITAKA 的材质叙事难以转化为身份叙事。
4. 向下被截流：图拉斯用功能创新（支架、散热、磁吸）在 100-300 元带提供"看起来更值"的选择。

核心分析轴：材质稀缺性叙事能撑多高的溢价，以及 PITAKA 的全球化品牌资产能否在国内市场转化为份额。

### A4 待逸凡确认的三件事

1. LLC 是否指抖音/小红书上的凯夫拉手机壳品牌 LLC（维纳斯、黄金甲系列），而非某个公司实体简称。
2. deep 是否维持 5 席，或把 EVUTEC、UAG 之一升入 deep（材质直接竞争 vs 防护天花板，二选一）。
3. 报告口径：以国内市场为主、海外作对照，还是全球市场平铺。

## 模块B：创始人深度挖掘

本报告默认关闭。PITAKA 创始人不是公开的品牌驱动变量，硬写会产出无信源内容。若逸凡要求，再单独补。

## 模块C：未上市品牌规模推算

PITAKA、LLC、决色、邦克仕均为非上市主体，规模推算采用锚点 + 侧面证据链（电商销量、评论数、渠道层级、认证信息、海外平台在售情况），交叉去伪后给区间，不给单点数字。

## 模块D：创品设想建议

从三条线找机会：材质线（芳纶之外的稀缺材质与工艺）、功能线（磁吸生态配件的组合创新）、叙事线（材质故事如何转化为身份表达）。每条给借鉴来源、可行性、风险边界与优先级。

## 数据采集前置判断

电商必采：天猫、京东、抖音三平台的价格带、销量区间、评价关键词。判断依据：手机壳是高频比价品类，价格带与评价是本品与竞品定位差异的第一手证据。
