## 飞书文档空白 bug 修复（已完成）

**逸凡报的问题**（11:39）：不止 CEO 一个 subagent 会碰到——开新飞书云文档写正文时不稳定，经常传回空白文档，且写不进去导致 token 消耗非常大。

**根因**：feishu 插件 api.js 的 document.convert（markdown→block 转换）接口在限流/瞬时失败时返回空结果，旧代码不重试不报错，静默返回空数组 → 文档空白。subagent 看到写入成功实际是空的，反复重试整个流程，token 爆炸。

**修复**（api.js 3 处，11:43 落地，11:45 gateway 重启加载）：
1. convert 加 3 次指数退避重试（800ms*2^n+jitter），识别限流错误码（99991400 系列、429）和超时
2. 非空 markdown 返回 0 blocks 判定为 EMPTY_CONVERT，重试或抛错，不再静默成功
3. create 支持一步写入 content（create+write 合并），写失败明确报错

**验证**：正常写入 ✓、空内容边界 ✓、连续 5 篇压力写入 ✓，读回内容完整。

**文件**：`/Users/yifansmacmini/.openclaw/npm/projects/openclaw-feishu-dc69f44688/node_modules/@openclaw/feishu/dist/api.js`
备份：`api.js.bak-20260801`（11:14 原版）、`api.js.bak-20260801-pre-fix`（11:43 修复前）

**影响**：全局修复，所有走 feishu_doc 的 subagent（CEO/CFO/SP/SM/BM/SC/book）都受益。
