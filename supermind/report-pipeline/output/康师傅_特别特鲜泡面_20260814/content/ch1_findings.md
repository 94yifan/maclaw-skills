# 核心发现与咨询窗口

## 核心发现

发现一：方便面品类在2025年重回增长，但增长是K型的。2025年中国方便面市场规模1849.9亿元，同比增长7.9%，2026年一季度以5.8%的同比增幅继续领跑包装食品大类。但增长高度分化：6元以上中高端产品销售额同比劲增31%，零油炸品类增速达18.7%，而平价产品依然占据近半销量。增长几乎全部由价格提升贡献，而非销量放量 [报道层]。

发现二：康师傅领跑的原因不是涨价，而是品类升级加品牌力。2026年上半年方便面业务137.33亿元，同比增长2%，高价袋面销售占比达38.3%。康师傅在行业最悲观时保持进攻，2025年上新367款，用新产品对应新场景、新人群 [已确认]。

发现三：特别特鲜泡面是康师傅切入非油炸加类现制健康升级心智的关键单品。它以单篓水煮工艺实现5分钟冲泡还原鲜煮口感，上市即登顶抖音新品榜TOP1，验证了年轻人对类现制速食的强烈买单意愿。这是康师傅在健康化阵线上最重要的一次品类定义尝试 [报道层]。

发现四：竞争格局高度集中但暗流涌动。前五大品牌吃掉84%市场份额，康师傅45%、统一16%、白象12%、今麦郎10%是当前格局。但白象以约130亿营收逆袭，汤达人连续多季度正增长扛起统一的高端化，今麦郎坚持非油炸健康高地，非油炸这条线正在变成多方争夺的主战场 [报道层]。

发现五：非油炸赛道的竞争本质是品类定义权之争。今麦郎、五谷道场证明了只有健康口号守不住品类，特别特鲜泡面用工艺体验重新定义了非油炸的价值，康师傅是唯一同时握有工艺、渠道、心智三重能力的玩家，但它能否把工艺领先转化为品类定义权，是本次扫描要回答的核心问题 [推测]。

## 咨询窗口

康师傅在非油炸健康方便面赛道的竞争，本质是一场谁先定义品类标准的竞争。特别特鲜泡面的单篓水煮工艺是一个技术壁垒，但它需要被翻译成消费者能感知、能传播的品类叙事。燃创咨询的切入窗口在于：帮康师傅把工艺领先转化为品类定义权，在非油炸赛道建立像红烧牛肉面之于传统方便面那样的心智锚点。

具体切入窗口有三个：一是非油炸品类定义与特别特品牌策略，解决品类命名权和心智锚点问题；二是年轻健康人群的场景内容体系，解决康师傅年轻化短板和内容供给缺口；三是渠道精准匹配与新品放量模型，把康师傅的渠道优势转化为特别特的规模化能力。这三个窗口分别对应品类、人群、渠道三个维度，是康师傅特别特鲜泡面从卡位到放量的完整路径。

本次扫描的最终判断可以概括为一句话：康师傅在非油炸赛道的胜负手，不是它已经拥有了什么，而是它愿不愿意把特别特鲜泡面当作一个品类来定义、来投入、来深耕。工艺和渠道的优势是确定的，但品类定义权的争夺才刚刚开始，接下来十二个月是康师傅用特别特锁定非油炸心智的关键窗口。这场品类定义权之争的结局，将决定康师傅在方便面行业下一个十年的位置，也决定特别特鲜泡面能否成为非油炸品类里的红烧牛肉面。
