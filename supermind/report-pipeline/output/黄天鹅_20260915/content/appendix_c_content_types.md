# 附录C：竞品内容类型分析

项目: 黄天鹅 品牌扫描报告（可生食鸡蛋与高品质品牌鲜蛋赛道）

## 五分类定义

把六个深度竞品在抖音、小红书、微博、B站等内容平台的投入拆成五类。曝光型追求触达量级，涨粉型追求账号资产沉淀，收藏型追求攻略干货的留存价值，转化型追求即时成交，人设型追求品牌人格与记忆点。占比为基于品牌公开内容风格与渠道布局的估计值，属推测口径。

## 各品牌内容特征速览

圣迪乐靠中国航天事业合作伙伴的权威背书做曝光，靠功能营养蛋的卖点叙事做转化，是这批竞品里声量最大、投放最重的一家。它的内容缺一个可反复演绎的母题，用户记住的是牌子而非某条具体内容，增长靠投放规模而非内容杠杆。

正大蛋业靠泰国正大集团的全球招牌与国家队运动员指定产品做安全牌叙事，曝光型占比近半。它的内容创造力与差异化有限，在可生食细分心智上反而容易被更会讲故事的黄天鹅压制，抖音小红书上几乎没有成体系的自营种草阵地。

兰皇靠日本可生食鸡蛋先行者的源头故事做人设，靠日料与温泉蛋烹饪场景做收藏，人设与收藏合计超过六成。它几乎不做内容电商，声量锁在日料圈与华润高端超市里，无法承接可生食概念被黄天鹅教育起来之后的大众化红利。

咯咯哒靠中国第一个鸡蛋品牌的历史叙事与灭菌鸡蛋标准发起者的本土话语权做曝光，主动经营国货老字号人设。但它在年轻平台的种草能力偏弱，历史叙事停留在企业宣传片口吻，母题有价值却没被内容杠杆放大。

德青源靠中国最大蛋品生产企业之一的规模叙事做曝光，内容仍以传统广告与渠道铺货为主，内容平台经营停留在销售转化层面，是这批竞品里内容资产最薄弱的一家。

樱姬小町靠日本可生食标准加健康轻食的低价叙事做转化，靠轻食与健身攻略做收藏，是这批竞品里最会做种草内容的。但用户记住的是便宜的可生食鸡蛋这个品类而非品牌本身，增长容易被同价位新锐分流。

## 跨品牌阵营小结

六个品牌分三条阵营。人设收藏阵营是兰皇，靠日本源头故事与日料场景锁定小众圈层，健康但天花板低。曝光转化阵营是圣迪乐、正大、咯咯哒、德青源这四个有规模或权威背书的品牌，内容服务于权威背书与销售转化，共同问题是缺可沉淀的人设与收藏资产，增长靠资源与渠道而非内容魅力。种草转化阵营是樱姬小町，用新消费打法切黄天鹅存量心智，锋利但品牌根基浅。

## 对黄天鹅的启示

黄天鹅自身处在曝光转化向内容驱动转型的位置，借到了品类开创者的人设红利与分众的曝光红利，但收藏型攻略与用户信任资产仍待补强，这是它相对这六个对手最需要补的内容短板。兰皇的收藏型与樱姬小町的收藏型各占三成，是唯一两个收藏型占比过三成的品牌，而它们恰好是心智最稳与起量最快的两家，这说明收藏型内容是可生食鸡蛋品类里撬动留存与转化的关键杠杆。黄天鹅要反超，第一步是把收藏型内容的占比提上来，用攻略干货补上它最缺的一块。
