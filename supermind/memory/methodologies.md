## 使用说明

当需要创制新方法论时，按以下格式追加：

```markdown
## [方法论名称]

**公式/核心描述**：[方法的核心内容]

**来源知识节点**：[从知识图谱的哪些节点来的]

**核心洞察**：[这个方法论解决了什么问题]

**应用场景**：[场景1] / [场景2]

**验证记录**：[首次应用日期和效果]

**入库日期**：YYYY-MM-DD
```
