# 汇总品牌：三得利 / AGF Blendy / 摩可纳

## 三得利

三得利是全球即饮咖啡的规模化领导者，BOSS罐装咖啡在日本即饮咖啡市场长期占据第一，是其咖啡业务的绝对核心（evidence_tier：reported）。三得利食品国际作为集团饮料主体，年营收在万亿日元量级，其中咖啡和软饮料是日本本土的主力品类，罐装即饮是它的立身之本（evidence_tier：mapped）。核心产品BOSS罐装咖啡在日本定价约100到150日元，折合人民币约5到8元，中国市场的三得利利趣系列拿铁定价约5到6元一瓶，走的是大众价格带的即饮路线（evidence_tier：mapped）。渠道上三得利依托全球化的便利店和商超网络，尤其在日本7-11等便利店的冷藏和常温货架上占据高密度陈列，是典型的渠道加规模驱动型玩家（evidence_tier：reported）。趋势位置上，三得利正从罐装即饮向冷藏精品即饮升级，Craft BOSS低温系列就是它对即饮咖啡高端化的回应（evidence_tier：mapped）。核心人群是高频即饮的上班族和通勤人群。它与瑞幸即享的关系是即饮场景的间接竞争者，双方在品类形态上有别，但都在争夺都市人群的便捷咖啡消费，三得利的规模壁垒和渠道深度是瑞幸即享短期难以复制的。

## AGF Blendy

AGF Blendy是日本味之素集团旗下AGF的大众咖啡品牌，靠挂耳、液体咖啡胶囊和速溶覆盖了居家冲泡的全场景，是日本国民级的滴滤咖啡代表（evidence_tier：reported）。AGF依托味之素集团的食品与咖啡业务，在日本速溶和滴滤市场属于第一梯队品牌，规模可观但未单独披露咖啡收入（evidence_tier：mapped）。核心产品包括滴滤挂耳咖啡和液体浓缩咖啡胶囊，挂耳单袋约2到3元，液体胶囊单颗约2到3元，价格带与隅田川高度重合（evidence_tier：mapped）。渠道上Blendy在日本走商超和药妆店的密集铺货，在中国主要通过跨境电商和电商平台触达，线下实体渗透有限（evidence_tier：mapped）。趋势位置上，Blendy是挂耳和液体咖啡两个品类扩容的受益者，其胶囊液体咖啡顺应了咖啡液化的行业风向（evidence_tier：mapped）。核心人群是追求方便和日式口感的家庭与办公室饮用者。它与瑞幸即享的关系是最直接的品类竞争者，尤其Blendy的液体咖啡胶囊与瑞幸即享的咖啡液产品在同一细分赛道正面冲突，日式品牌心智是它相对瑞幸即享的优势，而瑞幸即享的现磨咖啡认知和本土供应链则构成反击筹码。

## 摩可纳

摩可纳Moccona是全球咖啡巨头JDE旗下的精品冻干速溶品牌，用玻璃罐装和进口心智把自己从速溶红海里区隔出来，主打的是精品化速溶（evidence_tier：reported）。JDE是全球最大的咖啡集团之一，年营收约80亿欧元量级，摩可纳是其面向亚太和中国市场的主力冻干品牌之一（evidence_tier：mapped）。核心产品是冻干速溶咖啡，玻璃罐装容量通常100克，定价约50到80元一罐，折合单杯约1.5到2元，在速溶品类里属于偏高端的价格锚（evidence_tier：mapped）。渠道上摩可纳在中国主要走天猫等电商平台和进口超市，靠跨境电商与进口心智做动销，线下铺货有限（evidence_tier：mapped）。趋势位置上，摩可纳踩中了速溶咖啡精品化和冻干化的趋势，用冻干工艺和玻璃罐的品质感承接了传统速溶的升级需求（evidence_tier：mapped）。核心人群是追求品质感但又不愿自己磨豆的家庭冲泡用户。它与瑞幸即享的关系是速溶和冻干细分里的竞争者，摩可纳靠进口精品心智和稳定的冻干品质，瑞幸即享则靠现磨咖啡的品牌认知和性价比切入，双方争夺的是同一批想升级传统速溶的中间层用户。

## 参考品牌

AGF是味之素集团旗下的咖啡品牌母品牌，产品覆盖速溶、挂耳、液体咖啡和即饮咖啡，价格带从几元一杯的速溶到十几元的即饮不等，是日本全品类咖啡选手，在中国以电商和跨境为主要渠道，与瑞幸即享在咖啡液和挂耳细分存在直接品类竞争（evidence_tier：mapped）。

UCC悠诗诗是日本上岛咖啡旗下的全球咖啡品牌，以速溶、挂耳和瓶装即饮咖啡闻名，其职人咖啡系列在国内有稳定认知，价格带约3到10元一杯，渠道覆盖商超和电商，与瑞幸即享在挂耳和即饮两个方向都有竞争关系，且UCC的日本精品心智是它的护城河（evidence_tier：mapped）。

连咖啡是中国的咖啡新零售品牌，从外卖现磨咖啡起家后转型预包装，主打咖啡液和冻干速溶，价格带约2到5元一杯，渠道以电商和私域为主，与瑞幸即享同属本土咖啡液赛道，是同一消费人群里的直接竞品（evidence_tier：mapped）。

Costa是英国咖啡连锁品牌，2018年被可口可乐收购后由可口可乐运营其瓶装即饮和咖啡豆业务，瓶装即饮价格带约15到20元，渠道依托可口可乐的全球分销网络，与瑞幸即享在即饮咖啡的高端区间形成竞争，其门店和品牌心智是主要资产（evidence_tier：reported）。

统一雅哈是统一企业旗下的即饮咖啡品牌，主打雅哈冰咖啡等常温即饮，价格带约4到6元，渠道深度依托统一在传统通路和便利店的网络，与瑞幸即享在即饮场景的便利店货架上直接竞争（evidence_tier：mapped）。

康师傅贝纳颂是康师傅旗下的即饮咖啡品牌，贝纳颂拿铁是主力单品，价格带约5到6元，渠道依赖康师傅庞大的饮料分销体系，与炭仌、统一雅哈同属渠道驱动型即饮玩家，与瑞幸即享在便利店即饮场景竞争（evidence_tier：mapped）。

魔爪Monster是美国的功能饮料品牌，其咖啡味能量饮料切入咖啡加功能的交叉品类，价格带约6到10元，渠道依托可口可乐体系，与瑞幸即享在功能咖啡这一细分上形成差异化竞争，但核心仍是能量饮料而非纯咖啡（evidence_tier：reported）。

麦斯威尔Maxwell House是卡夫亨氏旗下的速溶咖啡品牌，主打三合一速溶和袋装咖啡，价格带约0.5到2元一杯，渠道覆盖商超和电商，与瑞幸即享在速溶咖啡的大众价格带存在竞争，是传统速溶阵营的代表（evidence_tier：mapped）。

喜茶瓶装是喜茶旗下的瓶装饮料线，以无糖茶和气泡水为主，咖啡类产品有限，价格带约5到8元，渠道依托便利店和电商，与瑞幸即享的竞争集中在年轻消费者和健康饮料心智上，而非纯咖啡品类（evidence_tier：mapped）。

## 趋势综述

预包装咖啡正在经历从速溶向更便捷形态的迁移，咖啡液和冻干成为承接现磨消费外溢的主要载体，隅田川的鲜萃液、AGF Blendy的胶囊液、连咖啡的咖啡液共同印证了这一方向（evidence_tier：mapped）。即饮咖啡则向低糖化和黑咖化升级，星巴克冷萃、炭仌黑咖啡、统一雅哈和康师傅贝纳颂的拿铁都在无糖与健康标签上做文章（evidence_tier：mapped）。精品化与大众化并存，三顿半式的冻干精品和隅田川式的3元挂耳同时成立，说明预包装咖啡在价格带两端都在扩容（evidence_tier：mapped）。渠道上，线下便利店的即时消费与线上电商的囤货消费并行，农夫山泉炭仌和雀巢靠线下密度，三顿半和永璞靠线上流量（evidence_tier：mapped）。品牌资产外溢成为通用打法，星巴克门店心智授权给雀巢做即饮，三得利和UCC的日本咖啡心智直接迁移到预包装产品（evidence_tier：reported）。

## 人群综述

预包装咖啡的核心消费人群高度重叠，集中在20到40岁、有咖啡饮用习惯、追求便捷的城市白领和上班族，月可支配收入大致在5000到15000元区间（evidence_tier：mapped）。这批人群的决策逻辑是效率优先，在办公室和居家场景里用最低的时间成本获得一杯比传统速溶更好的咖啡。价格敏感度呈明显的分层，低端用户被1到2元的速溶和冻干承接，中端用户集中在2到6元的挂耳和咖啡液，高端用户则为15元以上的即饮和精品速溶付费（evidence_tier：mapped）。健康意识和无糖诉求正在成为新的筛选标准，尤其是即饮咖啡人群里，无糖黑咖的偏好持续上升（evidence_tier：mapped）。
