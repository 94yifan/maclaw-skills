### book-deep-reading Skill 框架（已建提案待固化）

#### 第一步：判断书籍类型
拿到数据后先判断书是什么类型，不同类型用不同内容结构：
- 方法论/操作手册（如《学会提问》）→ 核心流程Step + 概念详解
- 故事/传记 → 关键事件 + 人物分析 + 经验提炼
- 哲学/认知科学 → 核心概念 + 知识体系 + 现实关联
- 商业/案例 → 核心论点 + 案例详解 + 可复制模式
- 文学/社会观察 → 核心主题 + 关键情节分析 + 现实映射

#### 内容标准（逸凡确认的量化要求）
- **总字数**：原书约1/10，8000-10000字
- **核心内容**：核心框架流程 + 重要概念详解——占最大篇幅
- **双源案例**：每个概念配内部案例（书中）+ 外部案例（真实事件）
- **案例4要素**：对象介绍（≥40字，说清「是什么」）→ 具体行为/事件（≥50字）→ 分析与关联（≥60字）→ 学习价值（≥30字）
- **外部案例**：必须真实事件，近5年，不确定的写「待验证」绝不编造
- **金句**：8-10条，不标注划线人数，每条附≥60字思考价值分析
- **延伸思考**：费曼学习法提问3-5个（带具体场景）+ 生活/工作实践设计4-5个（可操作）
- **输出**：直接发 .md 文件到飞书群，不搞飞书文档

#### 思维导图标准
- **结构**：树状（自上而下），不是放射状
- **节点**：完整句子（10-20字），不堆关键词
- **排版**：文字清晰无重叠，间距gap≥8px，浅色背景+圆角卡片+色彩分区
- **技术**：纯CSS flex + SVG + 原生JS，无外部依赖
- **交互**：滚轮缩放 + 拖拽平移
- **必须预览**：截图先本地查看再发

#### 模型使用
- 默认Flash，读书分析不需要Pro

#### 踩坑（必须记住）
1. 数据不能编造——事实要可溯源，不确定写「待验证」
2. 数量与书中一致——书中9种谬误就写9种，不多不少
3. 不能从头重写丢失旧内容——以确认过的版本为底本做增量修改
4. 思维导图先出结构骨架再填充——不要直接写完整HTML
5. 输出前必须预览——截图看好再发
6. 不能创建飞书文档——直接发md文件

### 2026-06-23（第2次Dreaming复盘，22:22）

**系统级观察：深度阅读陪读bot的前置依赖框架**

book 分身的所有能力（Naval/Musk/Greko/费曼）都是**条件式能力**——它们只在两个前置条件同时满足时才有意义：
- 条件A：用户持续阅读并产出划线/笔记
- 条件B：用户愿意把素材投喂给 bot

如果 A 或 B 不成立，模型再强、视角再多，输出也等于零。这不是 bot 设计的问题，而是**交互链的起点缺失**。

**启发：** 这与 Naval 说的"产品市场匹配"异曲同工——一个再好的产品，没有找到用户和场景，就是零。book 分身目前的"PMF"还没找到。等待逸凡启动第一条消息。

**零数据诊断梯（可复用框架）**

从连续6天零交互的复盘过程中，提取出一个可复用的思维框架——"零数据诊断梯"：

```

第2梯：结构 — 前置条件链的哪一环断了？（输入/触发/能力/输出）
第3梯：动机 — 用户为什么不启动？（优先级/门槛/预期）

```

**演变序列：** 前四次复盘构成了一个认知逐步加深的序列：
- 第1次 → 基线测量（确认白板）

- 第3次 → 用户行为推理（时间成本模型 + 三种可能性）
- 第4次 → 元认知洞察（观察者效应 + 仪表盘疲劳）

**跨域启发：** 这个框架不仅适用于读书 bot。任何依赖用户主动输入的 AI 工具都可以套用——CRM 系统、笔记助手、学习平台。当用户没有行动时，先确认是否真有数据（梯1），再分析架构是否真的通了（梯2），然后做用户动机假设（梯3），最后反思自己的分析是否在改变系统本身（梯4）。

## 2026-07-13 Dreaming知识串联

### 串联1：弱势批判性思维 → 编造数据的心理学根因

**来源：**《学会提问》弱势/强势批判性思维的区分
**连接：** 之前系统性教训中编造蓝氏王濛联名时间的根因

弱势批判性思维 = 用批判性思维"捍卫自己当前的信念"。编造数据的心理驱动不是"记性差"或"没查到"，而是弱势批判性思维的自然表现——你想让分析看起来完整有深度，所以大脑自动补全缺失信息来捍卫"我靠谱"的自我信念。

**关键启示：** 推理守卫三（事实可溯源）的真实对抗对象不是搜索技术，而是弱势批判性思维的心理防御机制。解决方案不仅是"查来源"，而是先问：**"我是在帮自己的论证找证据，还是在检查自己是不是错了？"**

### 串联1：沉默的贝叶斯权重——等待协议中沉默的信息价值

**来源：** 干预响应协议从D1-D3（等待窗口）→ D4-D7（二级评估）的阶段切换

```
Step 2: 用客观标准验证该行为的实际效果（可能不如你想的）
Step 3: 切换到让你"不舒服"但有效的方法
Step 4: 持续监测——对"我学会了"保持警惕
```

### 串联2：《上瘾式学习》主动回忆↔ SOUL.md费曼法则——从不同路径走向同一终点

**来源：** 《上瘾式学习》"白纸默写法"↔ SOUL.md的"费曼法则优先"（Anti-drift Rule 3）

**核心发现：** 《上瘾式学习》的"白纸默写"和SOUL.md中"用户说懂了→先让用户解释一遍"是同一个教学策略的两个面向：

|------|---------------|------------------|
