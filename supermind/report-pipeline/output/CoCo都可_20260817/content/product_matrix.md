# 产品矩阵：CoCo都可

CoCo都可的产品矩阵核心判断是经典款撑住了基本盘、却缺新爆款接棒，SKU老化是它产品代际没跨过的直接体现。CoCo的产品线大致分为四大类，珍珠奶茶系列、鲜芋系列、鲜果茶系列、以及咖啡与轻饮系列，其中前两类是历史最久、贡献最大的基本盘，后两类是近年来尝试的新增长点，但均未跑出足以接棒的大单品（evidence_tier：mapped）。

珍珠奶茶系列是CoCo的起家品类，也是其心智最深的标签。经典珍珠奶茶、红豆奶茶、布丁奶茶等SKU构成了CoCo的基础盘，产品稳定、复购稳定，但创新空间有限，长期停留在经典口味打安全牌的状态。对比之下，蜜雪冰城靠极致低价把珍珠奶茶做到几块钱一杯，一点点靠更新鲜的台式奶茶心智在同价位直接分食，CoCo的珍珠奶茶既没有蜜雪的成本优势，也没有一点点的更新鲜感知，处于两头受挤压的位置（evidence_tier：mapped）。

鲜芋系列是CoCo二十多年积累下来的招牌产品线，也是它手里最被低估、几乎没人抢的一张牌。鲜芋圆奶茶、芋泥奶茶、芋圆仙草等SKU在华南、华东有稳定的忠实客群，芋头的软糯口感与CoCo的台式基因高度契合。主流竞品里，没有任何一家把芋头做成品牌级符号，霸王茶姬主打茶底、喜茶主打鲜果、沪上阿姨主打五谷，芋头这个心智是空白的，这是CoCo重建差异化护城河成本最低的切入点（evidence_tier：mapped）。

鲜果茶系列是CoCo试图跟风新茶饮的尝试，芒果、葡萄、柠檬等时令鲜果SKU都有布局，但产品力与喜茶、奈雪的茶存在明显代差，鲜果茶的供应链门槛和上新节奏都对CoCo的数字化能力提出了更高要求，CoCo在这一品类上始终处于跟随而非引领的位置（evidence_tier：speculation）。

咖啡与轻饮系列是CoCo近年试水的新方向，但现制咖啡赛道已被瑞幸、库迪用极致价格战打穿，CoCo的咖啡SKU缺乏差异化，难以构成增长点（evidence_tier：speculation）。

从价格带分布看，CoCo产品集中在10到20元区间，主力单品如珍珠奶茶、鲜芋奶茶定价在12到18元，这个价格带正是古茗、茶百道、沪上阿姨、一点点密集竞争的地带。CoCo缺乏一款能在产品力、价格力、话题性上同时建立高势能的大单品，这是它产品矩阵与头部竞品最根本的差距。霸王茶姬的伯牙绝弦、喜茶的多肉葡萄都是能够定义品类的高势能大单品，CoCo至今没有对标的单品（evidence_tier：reported）。

从产品迭代节奏看，CoCo的上新速度和爆款命中率都明显落后。头部品牌以周为单位上新、以月为单位推爆款，CoCo的上新节奏更接近传统餐饮的季度甚至年度节奏，这在以快著称的新茶饮行业里是致命的短板（evidence_tier：speculation）。

从电商渠道表现看，CoCo的线上产品结构同样偏弱。天猫、京东旗舰店以茶叶、杯子周边和少量预包装产品为主，付款人数与门店生意规模完全不匹配，对比之下蜜雪冰城、古茗等品牌天猫旗舰店爆款月销普遍过千件、付款人数过千，CoCo旗舰店的电商存在感仅是品牌展示窗口（evidence_tier：mapped）。线上渠道的薄弱既是产品结构问题，也是品牌数字化运营能力不足的体现，与线下渠道依赖存量形成呼应。
