## 1. 为什么写复盘

复盘有两个核心目的：

1. **对客**：专业且好——让客户看到你的策略思考、执行效果和后续方向
2. **对内**：经验沉淀——好的萃取为方法论复用到下一个项目，不好的提炼为避坑经验

一个完整的复盘不是数据堆砌，也不是流水账。它的结构是：有事实数据 → 有洞察结论 → 有投放建议。三个缺一不可。

> **随堂测验 1-1**：以下哪句话最接近复盘的核心结构？
> A. 数据越多越好，把所有截图都放进去
> B. 有事实数据、有洞察结论、有投放建议
> C. 重点是让客户觉得我们很努力
> D. 只写做得好的，避免暴露问题
>
> （答案见本章末尾）

## 2. 框架总览

### 2.1 GRARI五模块框架

曼拾的标准复盘框架是GRARI，五个模块各有明确的篇幅占比和内容要求：

| 模块 | 占比 | 写什么 | 不要写成 |
|------|------|--------|---------|
| **G - Goal 目标回顾** | 10% | 项目目的/预算分配/为什么这么设定目标/核心阶段可量化目标 | 不要只列数字不解释为什么 |
| **R - Result 结果比对** | 10% | 目标完成情况/差距对比/亮点和不足/是否新增减少了目标 | 不要只报喜不报忧 |
| **A - Analysis 分析原因** | 40% | 做得好的(亮点事件+关键动作+三力拆解)；做得不好的(问题事件+有差距的关键动作+三力拆解+客观原因) | 不要只说"效果好"不说"为什么好" |
| **R - Review 目的回顾** | 10% | 最早目的是否完成/为什么(资源分配/执行/情景变动) | 不要跳过目的直接看数字 |
| **I - Insight 规律总结** | 30% | 做得好的萃取为可复用方法论；做的不好的提炼提升经验 | 不要写"下次注意"这种没操作性的总结 |

**"目的"和"目标"的区别**：
- **目的**：为什么要做这件事。例如"加强品牌在xx人群的渗透""提升新品生意"
- **目标**：实际量化的结果指标。例如"ROI达到2.5""TI人群增长30%"

### 2.2 三力拆解

在A模块和I模块中，用三力拆解来分析原因和总结规律：

| 力 | 追问方向 |
|----|---------|
| **策略力** | 策略方向对不对？人群选对了吗？内容方向对吗？ |
| **执行力** | 执行到位吗？素材量够吗？出价调了吗？反馈时效如何？ |
| **管理力** | 资源分配合理吗？预警及时吗？机动调整够快吗？ |

以上三个维度之外，叠加**客观原因**：目标修改/预算降低/大盘变化/竞品投放/品牌限流。

### 2.3 GRARI结构与旧版Part 1-4的对应关系

旧版复盘习惯用"Part 1投放成果 / Part 2内容分析 / Part 3竞价分析 / Part 4后续建议"的四段式。GRARI框架不是废弃这些内容，而是把它们按逻辑重组：

- Part 1（投放成果）的高层汇总数据归入 G-Goal 和 R-Result
- Part 1（投放成果）的策略执行+人群分析归入 A-Analysis
- Part 2（内容分析）归入 A-Analysis 的内容与渠道子模块
- Part 3（竞价分析）归入 A-Analysis 的策略执行子模块
- Part 4（后续建议）归入 I-Insight

### 2.4 OnePage GRARI 模板

当客户没有指定模板时，使用以下一页纸框架输出复盘报告：


## 3. 数据准备

### 3.1 数据准备三确认

在下笔分析之前，必须先完成三个确认。少一个都不能开始：

**确认一：数据口径**
- 总流量 / 自然流 / 广告流？各自的占比？
- 信息流数据是否包含视频内流？
- 不同数据源的口径是否一致？

**确认二：数据周期**
- 是汇总数据还是by-day数据？
- 各数据源的时间周期是否一致？
- 投前投后对比的基准周期是什么？

**确认三：数据粒度**
- 达人×笔记ID维度？
- 账户×场域×计划×笔记×创意维度？
- 关键词维度？
- 人群包维度？

### 3.2 数据来源

| 数据来源 | 提供什么 | 适用场景 |
|---------|---------|---------|
| 蒲公英投后数据 / 商业内容中心 | 达人数据 + 总流量数据 | 内容效果、达人表现 |
| 聚光 / 千帆推广报表 | 竞价广告曝光到转化全链路 | 投放执行数据、ROI计算 |
| 灵犀度量模块 | AIPS / 口碑 / 一方三方数据 | 全链路复盘、品牌度量 |
| 直客拉取 | 大盘数据 / benchmark / 竞品消耗 / 全品牌SOV/SOC | 行业对比基准 |
| 淘宝联盟 | 内容互动率/引流率/店铺新访客率/收藏加购率/转化率/店铺新客率 | 电商后端转化数据 |

**灵犀 vs 聚光/蒲公英 的关键区别**：
- 灵犀覆盖全部流量场景（自然流/效果广告/品牌广告/薯条），数据经过加工更具目的性
- 聚光/蒲公英只覆盖竞价广告链路，是原始投放数据

### 3.3 KPI三层分级

拿到数据后第一件事：把指标按三层分级，而不是所有指标混在一起看：

| 层级 | 定位 | 典型指标 | 关键规则 |
|------|------|---------|---------|
| **P0 北极星（2-3个）** | 与目的最相关的核心指标 | 整体提升销量→转化率/CPUV/长效ROI；人群资产提升→CPTI/特定人群渗透率；心智占位→SOV/SOC | 非P0指标与P0冲突时，以P0为准 |
| **P1 核心过程** | TI人群效率与互动 | CPE / 回搜 | 过程健康度 |
| **P2 参考** | 浅层指标 | CPC / CTR | 浅层指标可能与核心指标冲突，仅作参考 |

### 3.4 三大分析方法

| 方法 | 怎么做 | 目的 |
|------|--------|------|
| **数据对比** | 对比大盘 + 竞品 + 本品历史 + 本品当下内部拆分（内容方向/人群包/词包） | 找到"好还是不好"的参照坐标 |
| **异动分析** | 对比出异常 → 下钻定位原因 | 找到"为什么突然变了"的根因 |
| **趋势分析** | by-day趋势判断持续异常还是某几天异常 | 区分系统性问题和偶发问题 |

> **随堂测验 3-1**：一个项目的数据显示CTR很高但ROI很低。按KPI三层分级，CTR和ROI分别属于哪个层级？如果发生冲突，以哪个为准？
>
> **随堂测验 3-2**：你拿到了聚光和灵犀两套数据，其中某指标的口径不一致。你应该怎么做？

## 4. G - Goal 目标回顾

### 4.1 这个模块做什么

G模块回答三个问题：我们为什么要做这个项目？我们要做到什么程度？我们用什么资源去做？

它的作用是给整个复盘建立基准线。后面所有模块的判断——"好还是不好""完成还是没完成"——都依赖于G模块设定的基准。

### 4.2 包含哪些数据和信息

**必须包含**：
- 项目目的（非量化的"为什么做"）
- 预算总额及分配逻辑（K:F:S比例，各占多少，为什么）
- P0北极星指标（2-3个）+ P1核心过程指标 + P2参考指标
- 核心阶段的可量化目标（测试期/放量期/转化期各自的目标数字）

**可选但建议包含**：
- 高层汇总数据：总花费、总曝光、总点击、总互动（仅用于建立基准线，不需要展开分析）

### 4.3 怎么写

**写作顺序**：目的 → 预算分配逻辑 → KPI设定 → 阶段目标

**具体格式要求**：

第1段：写目的。一句话说清楚为什么要做这个项目。格式："本项目的目的是……。"

第2段：写预算和分配逻辑。格式："预算总额xx万，分配比例为K:F:S = x:x:x。K占x%是因为……，F占x%是因为……，S占x%是因为……。"

第3段：写KPI三层。用表格呈现，P0放在最上面。格式：

| 层级 | 指标 | 目标值 | 为什么设定这个目标 |
|------|------|--------|-------------------|
| P0 | xxx | xxx | xxx |
| P0 | xxx | xxx | xxx |
| P1 | xxx | xxx | xxx |
| P2 | xxx | xxx | xxx |

第4段：写阶段目标。格式："测试期（xx周）：目标xxx；放量期（xx周）：目标xxx；转化期（xx周）：目标xxx。"

### 4.4 注意什么——常犯错误和红线

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| 只列K:F:S比例，不解释为什么 | 没有分配逻辑，客户会问"凭什么是这个比例" | 每个比例后面跟一句"因为……" |
| 目的和目标混为一谈 | "目的是ROI达到2.5"——ROI是目标不是目的 | 目的是"为什么做"，目标是"做到什么数字" |
| 阶段目标没有量化 | "测试期目标是降低成本"——降到多少？ | 每个阶段目标必须有数字 |
| 在G模块开始分析原因 | "因为前期素材不够所以把大部分预算放在放量期"——这是A模块的事 | G模块只写"是什么"，不写"为什么是这样"（预算分配逻辑除外） |

### 4.5 正例反例对比

**正例**：

本项目的目的是加强品牌在25-35岁精致妈妈人群的渗透，让目标人群在决策路径上优先搜索和考虑本品牌。

预算总额50万。分配比例为K:F:S = 4:4:2。K占40%用于内容制作和达人合作，因为精致妈妈人群对真实体验型内容信任度高，需要多篇不同角度的种草笔记建立信任。F占40%用于信息流和搜索投放放大优质内容，因为该品类在搜索场的竞争激烈，需要足够预算卡位。S占20%用于搜索关键词精准拦截和品牌专区，因为目标人群的搜索路径明确，搜索拦截是转化效率最高的环节。

| 层级 | 指标 | 目标值 | 为什么设定这个目标 |
|------|------|--------|-------------------|
| P0 | TI人群增长 | +30% | 项目核心目的为人群渗透，TI是种草深度的核心指标 |
| P0 | ROI | 2.5 | 客户内部考核标准，低于2.0将影响下期预算 |
| P1 | CPE | ≤10元 | 互动效率是过程健康度指标 |
| P2 | CTR | ≥3.5% | 浅层参考，辅助判断内容质量 |

测试期（前2周）：目标CPE≤15元，找到3-5篇潜力笔记。放量期（第3-6周）：目标ROI≥2.0，CPE≤10元。转化期（最后2周）：目标ROI≥3.0，TI成本≤8元。

**反例**：

本次投放总花费50万，KFS分配40%/40%/20%。目标ROI 2.5，CPE 10元，CTR 3.5%。

**怎么改**：反例只有数字没有逻辑。KFS为什么是4:4:2？ROI 2.5是怎么定的？这些数字背后的判断是什么？客户看完只知道"你们定了这些数字"，不知道"为什么要定这些数字"。补上每个数字的设定逻辑——"因为……所以……"。

## 5. R - Result 结果比对

### 5.1 这个模块做什么

R模块做一件事：把实际跑出来的数字和目标做对比，把投前投后的变化做对比。它的核心动作是"找差距"——哪些达到了？哪些没达到？哪些超出了期望？

⚠️ R模块只负责呈现结果和差距，不负责解释原因。原因留给下一章A模块。

### 5.2 包含哪些数据

本章是所有投放核心数据的汇总。按数据类别分为以下六组：

**第一组：目标达成总览**
- P0/P1/P2各指标实际值 vs 目标值
- 达成率（实际值/目标值，百分比）

**第二组：搜索指标**
- SOV（声量份额）：某关键词下品牌广告曝光量 / 该关键词所有广告曝光量。⚠️ 找直客拉全品牌数据。聚光后台只是代子账号维度，数据有偏差
- SOC（点击份额）：某关键词下品牌广告点击量 / 该关键词所有广告点击量。⚠️ 同上，需要直客拉取全品牌数据
- 搜索指数：品牌词 + 品牌SPU词至少两个维度。以聚光为准，蒲公英后台辅助验证
- 回搜率：用户看过广告/流量笔记后48小时内搜索特定词的比率。公式：点击广告后48小时内搜索过回搜词的用户去重人数 / 点击广告用户去重人数。⚠️ 回搜率是by笔记维度，不是by关键词维度。⚠️ 无行业均值时默认0.5%

**第三组：生意指标**

| 指标 | 公式 | 注意 |
|------|------|------|
| 全店GMV | 客户提供/电商后台 | — |
| ROI | GMV / 消耗成本 | 需行业benchmark，问直客 |
| 进店成本 | 消耗成本 / UV | 需行业benchmark，问直客 |

**第四组：淘宝联盟维度**

| 指标 | 反映了什么 |
|------|-----------|
| 内容互动率 | 浅层种草程度高 |
| 引流率 | 人群精准 + 内容吸引度高 |
| 店铺新访客率 | 引流新客多 |
| 收藏加购率 | 需考虑价格/竞争优势 |
| 转化率 | 实际下单转化好 |
| 店铺新客率 | 新客已成功下单 |

**第五组：浅层指标**

| 指标 | 公式 | 注意事项 |
|------|------|---------|
| CPE | 价格 / 总互动 | — |
| CPC | 消费 / 点击量 | — |
| CPM | 价格 / 总曝光 × 1000 | CPM无法反映触达人群精准，精准看CTR和CPC |
| CTR | 阅读量 / 曝光量 | — |

**第六组：深层指标**

| 指标 | 公式 | 注意 |
|------|------|------|
| 人群渗透率 | 品牌人群在品类人群中占比 | ⚠️ 每个客户取数逻辑不同，先和客户对齐 |
| 内容渗透率 | 品牌内容阅读量在该类目所有内容阅读量中占比 | — |
| 搜后曝光渗透率 | 搜索后品牌内容曝光量在该类目所有内容曝光量中占比 | — |

**第七组：品牌广告数据达成**
- IP资源包 / 惊喜盒子 / 品专 / 火焰话题等

### 5.3 怎么写

**核心原则**：
- 每一项数据必须有对比参照物。目标值、投前数据、行业benchmark至少选一个
- 擅用大标题 + 总括句highlight + 数据化表达
- 关注客户在乎什么（不是你在乎什么）
- 最大程度可视化：字数越少越好，逻辑越清晰越好
- PPT中各模块内容加总 = 标题

**对比格式**：

标准句式："[指标]实际[数值]，vs 目标[数值]（达成率xx%），vs 投前[数值]（变化幅度xx%），vs 行业benchmark[数值]（差距xx%）。"

**三组必做对比**：
1. 搜索指标对比：SOV/SOC/搜索指数/回搜率 → 投前投后变化
2. 生意指标对比：GMV/ROI/进店成本 → 目标完成率
3. 口碑指标对比：内容互动率/CPE/CPM/CTR/评论情感 → 品牌声量变化

**亮点和不足**：
- 亮点：超出目标的指标，用"达成率xx%，超出目标xx个百分点"格式
- 不足：未达标的指标，用"达成率xx%，差距为xx个百分点"格式
- 如有新增/减少的目标，单独说明

### 5.4 注意什么——常犯错误和红线

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| 只报喜不报忧 | 不足不写不代表不存在。客户自己能看到数据，你不说反而降低信任 | 不足要有，而且要正视。同时给出"这个不足会在A模块中分析原因"的指向 |
| 只列数据不对比 | "ROI 2.8"——2.8算好还是不好？ | 每个数字必须有参照物：vs 目标/vs 投前/vs 行业 |
| 回搜率按关键词维度 | 回搜率是by笔记维度 | 写"笔记A的回搜率xx%"，不写"品牌词A的回搜率xx%" |
| 用CPM判断人群精准 | CPM不反映精准度 | 精准看CTR和CPC |
| SOV/SOC用聚光后台数据 | 聚光只是代子账号维度 | 找直客拉全品牌数据 |
| 没有说明是否新增/减少了目标 | 如果投中调整了目标但不说，Result和Goal对不上 | 单独说明调整了什么、为什么调整 |

### 5.5 正例反例对比

**正例**：

**P0指标达成**：ROI实际2.8，完成率112%（vs 目标2.5），高于行业benchmark 1.8约56个百分点。TI人群实际增长34%，完成率113%（vs 目标30%），两个P0指标均超额完成。

**搜索指标**：投后品牌词搜索指数从5.2万提升至8.1万（+56%），超过目标值8万。SOV从12%提升至18%（+6pp），SOC从8%提升至14%（+6pp），SOV-SOC差值为4pp，说明搜索曝光正在有效转化为点击。

**生意指标**：全店GMV 140万，vs 投前同期110万（+27%）。进店成本8.5元，vs 行业benchmark 12元（低29%），引流效率优于行业均值。

**不足之处**：CPE实际12元，达成率83%（vs 目标≤10元，差距2元）。P1指标未达标。回搜率0.6%，vs 目标0.8%（差距0.2pp）。两点不足均将在A模块中下钻分析原因。

**反例**：

ROI 2.8，CPE 12元，搜索指数8.1万，CPM 18元，SOV 18%，SOC 14%。整体效果好。

**怎么改**：反例只有数字没有对比、没有分析。2.8算好还是不好？8.1万是高还是低？12元CPE是超了还是差了？每一项数据都必须带上参照物（目标值/投前值/行业均值）和量化幅度，否则数据就是孤岛。

### 5.6 随堂测验

**5-1**：回搜率应该按什么维度计算？如果客户问你"品牌词A的回搜率是多少"，你应该怎么回答？

**5-2**：以下哪个对比写法最有说服力？为什么？
A. 投后CTR为3.5%
B. 投后CTR为3.5%，比投前2.0%提升75%
C. 投后CTR为3.5%，比投前2.0%提升75%，高于行业benchmark 2.8%约25个百分点

## 6. A - Analysis 分析原因

### 6.0 这个模块做什么

A模块是GRARI中占比最大的模块（40%）。它回答一个核心问题：结果为什么是这样？

事情做得好，要弄清楚"做对了什么，能不能复用到下一个项目"。事情做得不好，要弄清楚"哪里有问题，下次怎么避免"。

A模块拆为三个子节：策略执行方法论分析、人群分析、渠道与内容分析。

---

### 6.1 策略执行方法论分析

#### 6.1.1 做什么

拆解投放的策略设计和执行过程。从KFS分配到三阶段节奏，从渗透策略到资源调配，把"我们做了什么"和"为什么这样做"说清楚。

#### 6.1.2 包含哪些数据

- KFS实际分配比例和消耗数据
- 三阶段（测试/放量/转化）的实际执行数据：每个阶段的预算消耗、核心指标达成、关键动作
- 渗透策略执行情况：人群圈选方案、CTR/CPE对比行业基准
- 资源调配记录：预算增减、出价调整、素材替换等
- 三力拆解（策略力/执行力/管理力）+客观原因

#### 6.1.3 怎么写

**KFS分配分析**：

不要写成"我们用了KFS"。写成："K的占比xx%，F的占比xx%，S的占比xx%，这样的分配逻辑是……（因为品牌现阶段以xxx为核心目标，所以xxx占比更高）。最终达成的效果是……。"

标准句式："[策略是什么] + [用了什么抓手] + [达成了什么效果]"

**三阶段投放策略分析**：

| 阶段 | 做什么 | 核心目标 | 实际表现 | 差距分析 |
|------|--------|---------|---------|---------|
| **测试期** | 赛马测试 + 挖掘低成本潜力笔记 + 搜索端露出 | 找到有效的内容和人群组合 | xxx | xxx |
| **放量期** | CPE低成本笔记放量 + 出价定向优化 | 放大已验证的效果 | xxx | xxx |
| **转化期** | 集中高转化人群 + 放大粉丝定向 + TI成本降低 | 收割转化 | xxx | xxx |

每个阶段要写三句话：做了什么、预期什么、实际什么。

**三力拆解**：

对做得好的和做得不好的分别拆解：

| 力 | 做得好的追问 | 做得不好的追问 |
|----|------------|--------------|
| **策略力** | 策略方向对不对？人群选对了吗？内容方向对吗？ | 方向偏在哪里？人群选错了哪些？内容方向为什么没打中？ |
| **执行力** | 执行到位吗？素材量够吗？出价调了吗？反馈时效如何？ | 哪里掉链子了？是量不够还是质不够？调优慢在哪里？ |
| **管理力** | 资源分配合理吗？预警及时吗？机动调整够快吗？ | 预算分配哪里不合理？预警触发了吗？调整是不是太慢了？ |

以上三个维度之外，叠加**客观原因**：目标修改/预算降低/大盘变化/竞品投放/品牌限流。

⚠️ 客观原因不是借口。每写一条客观原因，紧跟着写"在这种限制下我们做了xxx应对，效果是xxx"。

#### 6.1.4 注意什么——常犯错误和红线

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| KFS只列比例不写逻辑 | "KFS=4:4:2"——客户看到的是比例，不是思考 | 每个比例后面跟"因为……" |
| 三阶段只写做了什么不写结果 | "测试期我们测了3组人群"——然后呢？ | 每个动作后面必须跟"达成了什么" |
| 三力拆解变成互相甩锅 | "策略力没问题，执行力掉链子"——说得太笼统 | 每个力都要有具体的行为和数据支撑 |
| 客观原因当万能借口 | "大盘不好所以我们ROI低"——那竞品为什么能做到？ | 客观原因后必须跟"我们做了什么应对" |

#### 6.1.5 随堂测验

**6-1**：分析"投后ROI不达标"时，三力拆解各应该追问什么？

---

### 6.2 人群分析

#### 6.2.1 做什么

从人群维度分析投放效果：哪些人群投对了、哪些投错了、哪些值得继续投、哪些需要调整甚至放弃。

#### 6.2.2 包含哪些数据

**人群四象限**（高/低消耗 × 高/低点击或转化）：

| 象限 | 特征 | 动作 |
|------|------|------|
| 高点击转化 + 高消耗 | 优质且跑量 | 检查是否与策略一致 |
| 高点击转化 + 低消耗 | 优质但量小 | 可拓展加预算 |
| 低点击转化 + 高消耗 | 花钱多效果差 | 战略性放弃 or 换素材 |
| 低点击转化 + 低消耗 | 花钱少效果差 | 战略性放弃 or 换素材 |

**P/TI人群对比验证**：列出共性和差异点。P人群和TI人群有哪些重叠？哪些TI人群是从P人群流转过来的？哪些是直接进入TI的？

**人群包分析**：

| 维度 | 对比指标 | 输出 |
|------|---------|------|
| 曝光人群 | CPM对比benchmark | 覆盖效率 |
| 互动人群 | CPE对比benchmark | 互动效率 |
| 总结 | — | 好的 / 需优化的 / 需停投的 |

**人群画像三维度**：

1. **基础信息**：性别/年龄/婚恋/母婴/消费水平/固定资产/地域/城市/消费档次
2. **消费偏好**：行业品类偏好/品牌偏好/消费金额/手机价格/品牌型号
3. **内容偏好**：内容兴趣偏好/内容关键词偏好/搜索词偏好/热点关注偏好/博主偏好

⚠️ 占比反映整体特点，TGI反映偏好程度。不要只看占比不看TGI。

**AIPS资产流转分析**：
- 哪些人群拉动了O→A→I的流转？
- 哪些人群拉动了I→TI（种草到深层种草）的流转？
- 哪些人群的转化率高（从种草到购买）？
- 哪些人群AIPS资产增长但转化低（种了草没收割）？

#### 6.2.3 怎么写

第1步：画四象限图。X轴用消耗（高/低），Y轴用点击或转化（高/低）。四象限各标注几组核心人群，每个象限给一句话判断。

第2步：P/TI对比。格式："P人群的特征是xxx，TI人群的特征是xxx。两者的共性是xxx，差异是xxx。差异说明xxx。"

第3步：人群画像分析。用表格呈现三维度数据，每个维度跟一句洞察。格式："该维度占比最高的是xxx（xx%），TGI最高的是xxx（TGI=xxx），说明xxx。"

第4步：AIPS流转分析。格式："人群A的流转路径是xxx→xxx→xxx，转化漏斗为xxx%。人群B的流转路径是xxx→xxx→xxx，在xxx环节流失严重。"

#### 6.2.4 注意什么——常犯错误和红线

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| CPM高就说是人群精准 | CPM反映竞价竞争力，不反映精准度 | 精准看CTR和CPC。CPM高+CTR高=精准；CPM高+CTR低=系统给了曝光但用户不点 |
| 只列人群画像不写洞察 | "25-30岁占比40%"——然后呢？ | 每个数据后面跟一句"说明……" |
| P/TI对比只看差异不看共性 | 差异是优化方向，共性是已有优势 | 共性和差异都要写，各有用途 |
| 四象限只画不判 | 画了四象限但没有下一步动作 | 每个象限给一句话动作：扩/守/调/弃 |

#### 6.2.5 随堂测验

**6-2**：某人群CPM很高但CTR也很高，这个人群是精准还是浪费？说明判断依据。

### 6.3 渠道与内容分析

#### 6.3.1 做什么

从渠道（搜索/信息流/视频流）和内容（笔记/评论/UGC/竞品）两个角度分析效果，找到哪条渠道、哪种内容对目标贡献最大。

#### 6.3.2 包含哪些数据

**搜索投放分析**：
- 词类分布（品牌词/品类词/竞品词/长尾词各占多少消耗和转化）
- 匹配方式（精确/短语/广泛各占多少，哪种ROI最高）
- 各词类成本（CPC/CPM）和SOV/SOC表现
- 搜索词上下游分析：上游词看搜前心智，下游词看品类内容洞察

**信息流投放分析**：
- 人群定向效果（各人群包的CTR/CPE/ROI对比）
- 内容素材效果（各素材方向的CTR/CPE/转化对比）
- 投放模式对比（控成本 vs 放量 vs 自动出价的效果差异）

**视频流投放分析**：
- 视频完播率、互动率、转化率
- 视频内容类型效果对比（口播/测评/vlog/教程等）

**广告位策略对比**：

| 广告位 | 定位 | 分析重点 |
|--------|------|---------|
| 信息流 | 高效触达层 | 分析该层哪项指标最优 + 分析原因 |
| 视频流 | 深度互动层 | 分析该层哪项指标最优 + 分析原因 |
| 搜索 | 精准转化层 | 分析该层哪项指标最优 + 分析原因 |

**各渠道嵌入内容分析（四维度）**：

| 维度 | 分析内容 | 判断标准 |
|------|---------|---------|
| **选题** | 笔记切入角度是否匹配目标人群需求 | 高CTR的选题共性是什么 |
| **封面/标题** | 封面点击率和标题吸引力 | CTR是否高于该方向均值 |
| **内容正文CTI** | 正文是否有效传递核心卖点、是否有行动引导 | 完读率+转化率综合判断 |
| **评论区CPU** | 评论区运营是否到位、是否有品牌回复和引导 | 评论互动率+评论情感倾向 |

**内容整体效果**：
- 笔记数据概览总表：按笔记方向归纳，配总结性表达
- 博主量级/数量/内容分配篇数/数据达成
- 用表格呈现，每行一个笔记方向，每列一个指标

**优质笔记分析**：

⚠️ 不要按"爆文"定义好坏，按客户目标定义。

做法：画XY四象限图。X轴和Y轴选择匹配客户目标的指标。可选坐标轴：回搜 / 进店成本 / 站外转化率 / CTR / 组件点击率 / TI深度种草人数。必须给出定量取数范围值（不能只说"高"和"低"）。

**评论区洞察**：

三个层次：
1. 用户真实关注点：用户在问什么、关心什么
2. 用户态度：用户对产品的态度和认知
3. 品牌可升级改进：从用户反馈中提炼品牌可做的动作

**UGC洞察**：
- UGC数量：用户自发的讨论量
- 讨论内容：用户在说什么
- 品牌词云与UGC讨论核心关联度：UGC讨论的方向和品牌想传达的是否一致
- 品牌新建议：从UGC中发现品牌可以借势的方向

**竞品分析Case Study**：

竞品选定原则：优质赛道品牌 + 花钱多的 + 产品类似的，以客户死对头为准。

浅层指标：
- 商单笔记数
- 预估投放金额
- 笔记曝光/阅读/互动量
- 搜索热度趋势
- 笔记内容规划

深度指标：
- 人群渗透
- 阅读渗透
- 搜后曝光渗透
- AIPS含TI人数

品牌广告分析：
- 品牌广告 / 线下活动 / 电商动作
- 正向影响
- 可复用点

#### 6.3.3 怎么写

**搜索分析写法**："在搜索投放中，[词类A]消耗占比xx%，CPC为xx元，SOV为xx%。[词类B]消耗占比xx%，CPC为xx元，SOV为xx%。整体来看，[结论：哪类词性价比最高/哪个词类需要调整]。"

**信息流分析写法**："在信息流投放中，[人群包A]的CTR为xx%，CPE为xx元，ROI为xx。[人群包B]的CTR为xx%，CPE为xx元，ROI为xx。综合对比，[结论：哪个组合最优]。"

**内容分析写法**："[选题方向A]共xx篇笔记，平均CTR为xx%，CPE为xx元。其中表现最好的笔记是[笔记ID/方向]，[关键数据]。该方向之所以有效，是因为[封面/标题/正文/评论区哪个维度做得好]。"

**竞品分析写法**："竞品[品牌名]同期投放估计xx万，商单xx篇，主要投放方向是xxx。与我品相比，竞品在xxx指标上领先/落后。值得关注的是xxx（具体发现）。"

#### 6.3.4 注意什么——常犯错误和红线

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| 按"爆文"定义好坏 | 爆文不等于有效笔记。一篇百万阅读但零转化的笔记对ROI无贡献 | 按客户目标定义好坏，指标选回搜/进店成本/转化率而非阅读量 |
| 四象限只说"高"和"低" | 没有定量标准，"高"是个主观词 | 给出具体的数值范围，例如"CTR>4%为高，<2%为低" |
| 竞品分析只列数据不对比 | 竞品数据本身没有意义，和本品对比才有 | 每个竞品指标后面跟"本品为xx，差距为xx" |
| 评论区只截屏不提炼 | 截100条评论让客户自己看，等于没做 | 提炼成3-5个核心发现，每条跟一句话"品牌可以做什么" |

#### 6.3.5 随堂测验

**6-3**：如果客户的目标是"降低进店成本"，优质笔记分析的XY轴应该选哪两个指标？

**6-4**：评论区发现大量用户在问"这个和XX品牌比哪个好"，你应该怎么利用这个信息？

**6-5**：一个笔记在测试期CPE很低但互动量也不高，应该进入放量期吗？为什么？

**6-6**：信息流和搜索的广告位策略有什么根本不同？各应该关注什么指标？

## 7. R - Review 目的回顾

### 7.1 这个模块做什么

Review模块回答一个根本问题：我们最初想做的那件事，做到了吗？

它和前面的Result模块有本质区别：Result看的是数字达没达标，Review看的是目的达没达到。一个项目可以数字全部达标但目的没达到（比如ROI超额完成但品牌形象受损）；也可以数字没达标但目的达到了（比如ROI没到但品牌搜索指数和口碑大幅提升，为下一阶段积累了资产）。

### 7.2 包含哪些数据和信息

- 项目最初设定的目的是什么（引用G模块）
- 目的是否完成（用一个明确的是/否回答）
- 为什么完成/未完成（三个维度的归因）
- 资源分配维度：预算的分配方式是否支持了目的达成？K:F:S的比例验证结果如何？
- 执行维度：执行过程中有没有偏离目的？中间做对了什么、做错了什么？
- 情景变动维度：外部环境有没有变化？大盘、竞品、平台政策有无显著变化？

### 7.3 怎么写

**写作格式**：

第1段：明确回答目的是否完成。格式："本项目最初目的是[引用G模块的目的]。回顾整个投放周期，这个目的[已完成/未完成/部分完成]。"

第2段：已完成的部分。格式："其中，[具体目的A]，通过[关键动作]实现了[具体效果]。"

第3段：未完成或有差距的部分。格式："但在[目的B]上存在差距。[实际表现]与预期[预期表现]有xx的差距，主要原因是在[资源分配/执行/情景变动]维度上……。"

第4段：三段归因。

| 维度 | 追问 | 对目的达成的影响 |
|------|------|----------------|
| 资源分配 | 预算分配是否支持了目的？K:F:S比例是否需要复盘后调整？ | 正向/负向，具体说明 |
| 执行 | 执行过程中是否始终围绕目的？有没有"做偏了"？ | 正向/负向，具体说明 |
| 情景变动 | 外部环境有没有改变项目的假设前提？ | 正向/负向，具体说明 |

### 7.4 注意什么——常犯错误和红线

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| 跳过目的直接说"效果好" | 复盘报告不是报喜报告。效果好也要回到目的验证 | 先说"目的是什么"，再说"做到了没有" |
| 把Review写成Result的重复 | "ROI达标所以目的达成了"——Review不是第二次Result | Review的重点是"目的"这个更上层的概念，不是数字 |
| 只归因于客观原因 | "因为大盘不好所以目的没达到"——那为什么要做这个项目？ | 资源分配和执行维度也要归因。即使大盘不好，我们的应对是否及时？ |
| 目的没达到就回避 | 目的没达到不代表复盘没价值。恰恰相反，目的没达到的复盘往往更有学习价值 | 如实写，重点是写清楚"为什么"和"下次怎么做" |

### 7.5 正例反例对比

**正例**：

本项目最初目的是加强品牌在25-35岁精致妈妈人群的渗透。回顾整个投放周期，这个目的已完成。

完成的证据：投后精致妈妈人群的TI人数增长34%，超过目标的30%。灵犀数据显示该人群从O→A→I→TI的流转率从投前的12%提升至投后的19%。品牌在该人群的搜索指数从5.2万提升至8.1万，说明目标人群不仅在被动接收内容，也在主动搜索品牌。

但"加强渗透"这个目的中，有一个隐含的子目的是"让精致妈妈在同类产品中优先考虑本品牌"——这部分的验证还不够充分。竞品分析显示精致妈妈人群的竞品搜索关联度仍然较高（用户搜索本品牌后继续搜索竞品的比例为22%），说明品牌在决策场景中的排他性还不够强。

归因：
- 资源分配维度：K:F:S=4:4:2的分配支持了种草目的，40%的内容制作预算确实产生了多角度种草内容。但S仅占20%，在搜索拦截场景的预算不足可能是竞品搜索关联度高的原因之一。
- 执行维度：执行整体围绕目的展开，内容选题始终瞄准精致妈妈场景（遛娃/辅食/早教），人群包圈选准确。但在转化期内容方向稍微偏向了泛母婴人群，导致部分预算浪费在非核心人群上。
- 情景变动维度：投放期间竞品A也加大了在精致妈妈人群的投放，竞争环境加剧，部分推高了获客成本。

**反例**：

本项目目的是加强品牌在精致妈妈人群的渗透。从数据来看效果很好，ROI 2.8超额完成，搜索指数增长56%，各项指标全面达标。建议下一期继续加大投放。

**怎么改**：反例的核心问题是——把"各项指标全面达标"等同于"目的完成了"。ROI达标和精致妈妈人群渗透是两件事。一个品牌的ROI可以靠泛人群拉高但精致妈妈人群渗透率反而下降。Review模块的价值就是区分"数字好"和"目的对"，回到最初想做的事做验证。

## 8. I - Insight 规律总结

### 8.1 这个模块做什么

I模块回答两个问题：从这次投放中我们学到了什么？下次怎么做会更好？

它是复盘的终章，也是最有长期价值的模块。好的Insight可以直接复用到下一个项目，让团队持续进化。

### 8.2 包含哪些数据和信息

**第一块：可复用方法论**

从做得好的部分中萃取规律，按三维度组织：

| 维度 | 萃取方向 | 示例 |
|------|---------|------|
| **策略** | 哪种策略设计可复用到下一个项目？ | "精致妈妈人群的K:F:S=4:4:2配比在种草场景验证有效，同类型项目可参考" |
| **执行** | SOP / 媒介选K / 内容制作 / 投流 / 品牌广告各环节，什么做法可以固化？ | "测试期赛马机制：每篇笔记跑满48小时，CTR<2%立即暂停换素材，该SOP可将潜力笔记识别效率提升xx%" |
| **管理** | 资源调配、预警机制、机动响应有哪些可复用的模式？ | "预算预警机制：当CPE连续3天超过目标值20%时自动触发人群包复盘，该机制将异常响应时间从5天缩短至2天" |

**第二块：提升经验**

| 维度 | 提升方向 | 具体行动 |
|------|---------|---------|
| **策略制定修改** | 策略层面哪里需要修正？ | "转化期内容方向偏离核心人群，下次需增设阶段中期策略复核节点" |

- 灵犀四象限行业格局分析（高/低阅读 × 高/低搜索）：

| 象限 | 特征 | 策略 |
|------|------|------|
| 高阅读高搜索 | 内容+搜索均有优势 | 保持优势，加大投入 |

| 低阅读低搜索 | 内容+搜索均弱 | 综合提升KFS助力 |
| 低阅读高搜索 | 搜索好但内容弱 | 优化内容，拉大笔记量 |

**第四块：下一步动作整合规则**

⚠️ 下一步动作不能杜撰。必须同时满足两个条件：
1. 回溯到前文分析中的具体发现
2. 结合行业趋势判断

下一步建议拆为三维度：

**内容维度**：
- 角度放大还是放弃？
- 笔记数量/形式/配比如何调整？
- 有哪些热点可以追踪？

**竞价维度**：
- 人群圈选如何优化？
- 投放目标如何调整？
- 搜索词如何优化？

**执行对接维度**：
- SOP对接流程
- 审稿对齐机制
- 反馈时效要求

### 8.3 怎么写

**可复用方法论写法**：

格式："[规律名称]：[一句话描述规律]。本次投放中，[具体做法]使得[具体指标]从[前值]提升至[后值]（+xx%）。此规律可在[适用场景]中复用，复用时的注意事项是[xxx]。"

⚠️ 规律必须是可复用的，不能是"这次运气好"。如果一个规律无法在下一个项目中主动复现，它就不是方法论。

**提升经验写法**：

格式："[问题名称]：[一句话描述问题]。[具体表现]导致[具体影响]。下次优化的具体动作是[xxx]，预期优化效果是[xxx]。"

⚠️ 提升经验必须有具体行动。"下次注意"不是经验，"下次在测试期第二天检查CTR，<2%立即换素材"才是。

**下一步建议写法**：

格式："基于前文[xxx分析]的发现：xxx。结合当前[xxx趋势]，建议下一阶段[具体动作]，预期达成[具体效果]。"

⚠️ 每个建议必须标注"追溯到前文哪个分析"。

### 8.4 注意什么——常犯错误和红线

| 错误 | 为什么错 | 正确做法 |
|------|---------|---------|
| 写"下次注意" | 没有操作性 | 写成"下次在[什么时间][做什么]，预期效果[什么]" |
| 方法论太宽泛 | "内容要做得好"——什么叫好？ | 具体到可量化的标准："CTR>3.5%的笔记封面具有xx共性，可固化为封面制作模板" |
| 下一步建议突然冒出前文没提过的东西 | "建议参考竞品A的做法"但前文根本没分析竞品A | 每个建议必须标注"追溯至前文xx分析" |
| 行业洞察只放截图不放判断 | 四象限图很漂亮但没有文字结论 | 每个象限跟一句"所以我品应该……" |
| 把Insight写成Result的总结 | "本次ROI 2.8，效果很好" | Insight是规律和方法论，不是数据摘要 |

### 8.5 正例反例对比

**正例**：

**可复用方法论：测试期双维度赛马机制**

本次投放中，测试期采用了"内容方向赛马 + 人群包赛马"的双维度赛马机制：每篇笔记投放3组人群包，每组跑48小时，以CPE和CTR为联合判断标准（CPE<15元且CTR>3%则为潜力笔记进入放量池）。该机制使潜力笔记筛选准确率从往期的60%提升至85%，放量期资金浪费率降低30%。此规律在种草型项目（以TI/CPE为核心目标）中可直接复用。复用时的注意事项是：需确保测试期预算至少占总预算的15%，否则样本量不足以做出统计显著判断。

**提升经验：转化期内容方向偏离问题**

转化期第5-6周，内容方向从"精致妈妈种草"偏向"泛母婴科普"，导致核心人群CPE从8元上升至14元（+75%），浪费预算约3.5万元。根因是内容团队为了冲互动量选择了泛流量话题。下次优化的具体动作：在放量期结束前增设"阶段策略复核会"，对照G模块的目的检查当前内容方向是否偏离。预期优化效果：避免约5%的预算浪费。

**下一步建议**：

基于6.3渠道与内容分析中的发现：精致妈妈人群在搜索场的回搜率为0.8%，高于该方向均值0.5%，说明该人群主动搜索意愿强。结合灵犀行业数据显示该品类搜索量呈上升趋势（+15% QoQ），建议下一阶段将搜索预算从20%提升至30%，重点卡位"精致妈妈+产品场景"长尾词。预期达成效果：SOV提升5pp，搜索转化ROI从1.8提升至2.5。

**反例**：

本次投放ROI 2.8效果不错。做得好的方面：KFS配比合理、人群圈选准确、内容质量高。做得不好的方面：转化期效果有波动。下一步建议加大搜索预算、优化人群、做好内容。

**怎么改**：反例的问题——没有一条是可以直接复用的规律或可以执行的动作。"KFS配比合理"——什么比例？什么场景下合理？"优化人群"——怎么优化？优化什么？每一个Insight必须落到"什么场景下、做什么、预期什么效果"。

## 9. 怎么写策略型结论

### 9.1 三段式格式

每一条策略型结论严格按以下结构写（结论优先）：

1. **第一句**：一句话总结结论
2. **第二到四句**：通过量化数据论证结论——必须包含对比参照物 + 数据支撑
3. **最后一句**：未来建议和方向

**示例**：

> 本次投放CTR提升显著，内容策略有效打中目标人群。投后CTR为4.2%，较投前2.1%提升100%，高于行业benchmark 3.5%约20个百分点，同时回搜率从0.3%提升至0.8%。建议下一阶段将该内容方向作为主力种草方向，加大预算配比至40%以上。

拆解这个例子：
- 第一句：结论 → "内容策略有效打中目标人群"
- 第二到四句：数据论证 → CTR 4.2% vs 投前2.1%（自身对比）+ vs 行业3.5%（外部对比）+ 回搜率佐证
- 最后一句：建议 → 加大预算配比至40%

### 9.2 结论写作五条红线

#### 红线一：数据与结论必须有因果关系

不是有关联就是因果。以下常见陷阱务必避开：

| 错误写法 | 为什么错 | 正确写法 |
|---------|---------|---------|
| "CPM高说明触达人群精准" | CPM反映的是系统竞价竞争力，不反映人群精准度。精准看CTR和CPC | CPM升高反映竞价竞争力提升；人群精准度看CTR（xx%）和CPC（xx元） |
| "进店UV量高说明引流高效" | 进店UV只说明跑量好。引流效率看进店率 | 进店UV xx万，跑量充足；引流效率看进店率（xx%） |
| "进店率和转化率优于大盘说明GMV更高" | 进店率和转化率好只说明性价比高。GMV取决于钱能不能花够花完 | 投放性价比优秀（进店率xx%，转化率xx%），GMV提升取决于预算能否加量 |

#### 红线二：最小暴露负面原则

- 占比恒定时此消彼长是自然现象，不把它写成"某指标下降"
- 热度下降优先做外部归因（大盘变化/竞品投放/品牌限流），而非直接归因为"内容不行"

#### 红线三：每个数据都要有So-What

不要只列数据不解释。

好例子："CPE从15元降至8元，降幅47%" → 这是数据，没有So-What。

加上So-What："CPE从15元降至8元，降幅47%，说明内容互动效率大幅提升，主要驱动因素是笔记封面点击率从2.1%提升至4.5%"

追问方向：
- 提升/下降的原因是什么？
- 做对了什么/做错了什么？
- 和竞品/行业比是什么水平？

#### 红线四：结论落点准确具体—五问法深挖根因

不要停留在"效果不好"的层面。用五问法持续追问：

**示例**：
- 为什么CPUV高？→ 进店转化率低
- 为什么进店转化率低？→ 用户只想看IP，对产品无购买意图
- 为什么用户对产品无购买意图？→ 素材过于侧重IP，未突出产品功能
- **根因**：内容卖点与IP流量错配，未实现"IP引流→产品承接"

#### 红线五：下一步动作回溯前文

不要在建议部分突然冒出前文没有分析过的方向。每一个建议都要能指向前文的具体发现。

### 9.3 常见错误对照表

| 常见错误 | 表现 | 纠正 |
|---------|------|------|
| 结论过宽 | "本次投放效果很好" | 具体到哪个维度好、好在哪、好多少 |
| 无参照物 | "CTR为4.2%" | 加上对比：比投前高多少？比行业高多少？ |
| 归因跳跃 | "因为换了素材所以ROI提升" | 中间缺了逻辑链：换了什么素材→什么指标变了→为什么ROI就提升了 |
| 数据罗列 | 表格后无分析文字 | 每个核心数据表后紧跟分析（说明"为什么"）和行动建议（指导"怎么办"） |
| 假设当结论 | "可能因为大盘涨了" | 用"可能"但没标注置信度 → 要么查数据确认，要么标注"该结论因缺少大盘数据置信度较低" |

### 9.4 分析型句子写作公式

```
第一步：先列出所有相关动作和发现
第二步：语句升维——从"做了什么"升维到"意味着什么"
第三步：做减法——删掉不支撑结论的细节，只保留核心论证链
```

> **随堂测验 9-1**：以下结论违反了哪条红线？
> "本次投放CPM为18元，高于行业均值15元，说明我们的精准度很高。"
>
> **随堂测验 9-2**：用五问法分析：某笔记互动量很高，但进店UV很低。请写出追问链并找到可能的根因。

## 10. 检查清单与表达规范

### 10.1 发出前的五项自检

#### 检查三：结论质量

- [ ] 有没有从一个数据推出太大的结论？
- [ ] 确定的和不确定的，我区分开了吗？
- [ ] 给出的建议具体到能执行吗？

#### 检查四：受众适配

- [ ] 给品牌总监看的内容，用了太多执行细节吗？

- [ ] 最重要的发现放在最前面了吗？
- [ ] 有没有可以删掉的冗余部分？

#### 检查五：表达质量

- [ ] 每段只有一个中心论点吗？
- [ ] 段与段之间读起来能顺下去吗？
- [ ] 有没有"应该""大概""看起来"这类模糊词？
- [ ] 表格、标题格式统一了吗？

### 10.2 表达质量规范

**段落规则**：
- 每段一个中心论点
- 段落间有逻辑衔接（因果/递进/转折/并列）
- 最大程度可视化：字数越少越好、逻辑越清晰越好

**禁用措辞清单**：
- 应该、大概、看起来、似乎、可能（除非有置信度标注）
- 差不多、基本上、某种意义上

**标题规则**：
- PPT中各模块内容加总 = 标题
- 擅用大标题 + 总括句highlight
- 可视化图表标记重点：格式一致降序占比、重点数字highlight

### 10.3 发出前必读——危险信号

如果出现以下任一情况，先别发，再检查一遍：

- 你用了"应该""大概""看起来"这类词
- 你想"写完就发"，不想再看第二遍
- 你觉得"这次肯定没问题"
- 报告很长但你从没检查过前后是否一致
- 有关键数字但你没标来源

### 10.4 数据缺失时的处理

当关键数据不全时：
1. **不要强行输出薄报告**——满篇的"数据缺失"比不写还差
2. **主动切换分析角度**——有什么数据就深入分析什么，不要盯着没有的数据
3. **创造替代指标**——比如没有ROI数据，可以用"成交金额/观看次数"来衡量每次观看的价值
4. **如实标注**——报告中哪些结论因为数据不全而打了折扣，要明确说出来

### 11.4 随堂测验参考答案

**1-1**：B。复盘的核心结构是"有事实数据 → 有洞察结论 → 有投放建议"。

**2-1**：A - Analysis（40%）。因为分析原因是复盘最有价值的部分——做得好为什么好、做得不好为什么不好，这才是可复用的经验。

**2-2**：策略力问"人群选对了吗？内容方向对吗？"；执行力问"素材量够吗？出价调了吗？"；管理力问"预算分配合理吗？预警及时吗？"

**3-1**：CTR是P2参考指标，ROI是P0北极星指标（如果目的与生意相关）。冲突时以P0为准——CTR高不是目标，ROI才是。

**3-2**：先确认哪个口径最接近全流量场景（灵犀覆盖更全），再标注口径差异，不混用两个数据源的数据做直接对比。

**4-1**：A是目标（量化），B是目的（非量化"提升认知度"），C是目标（量化），D是目的（非量化"建立口碑基础"）。

**4-2**：必须写：A（分配逻辑是对客户专业度的展示）和B（阶段目标是G模块的核心组成）。可选：E（行业benchmark可作为目标设定的参考依据，但不强制）。不该写：C（大盘趋势分析是A模块或I模块的内容，G模块不需要）和D（竞品预算不是本项目的目标设定依据，除非客户明确要求对标）。

**5-1**：回搜率是by笔记维度不是by关键词维度。应该回答"笔记A的回搜率是xx%"，而不是"品牌词A的回搜率是xx%"。

**5-2**：C最有说服力。A没有参照物，读者无法判断3.5%是好是坏。B有自身对比但缺少外部对标。C同时有自身对比（vs投前+75%）和外部对标（高于行业25pp），从两个维度验证了CTR的提升。

**6-1**：策略力问"人群选对了吗？内容方向对吗？"；执行力问"素材量够吗？出价调了吗？"；管理力问"预算分配合理吗？预警及时吗？"

**6-2**：精准。CPM高+CTR高是人群精准的正向信号——CTR高说明封面标题打中精准人群，系统给更多曝光推高CPM。因果链是CTR↑→CPM↑。

**6-3**：X轴可选进店成本（越低越好），Y轴可选转化率或CTR（越高越好）。

**6-4**：这个信息说明用户在做购买决策阶段的横向对比。品牌可以：(1)在内容中提前埋入差异化卖点回应竞品对比；(2)在搜索端卡位"品牌vs竞品"相关长尾词。

**6-5**：不应该。CPE低说明互动成本低是好事，但互动量不高说明跑量不够。应先诊断互动量低的原因（人群圈选太窄？素材不够？），再决定是否放量。

**6-6**：信息流是"推"逻辑，关注触达效率（CTR/CPM）；搜索是"拉"逻辑，关注转化效率（SOV/SOC/进店率）。

**7-1**：典型例子——某品牌投放ROI 3.0超额完成目标（Result好看），但Review发现80%的TI增长来自泛母婴人群而非项目最初设定的精致妈妈人群（目的没达到）。Result看数字达标，Review看目的偏了。另一个例子——ROI 1.5没达标（Result不好看），但品牌搜索指数翻倍、竞品用户大量回流、品牌口碑净推荐值从30提升至55（目的超预期完成）。

**8-1**：不能。下一步建议必须回溯前文分析发现。前文没分析竞品数据，就不能凭空建议参考竞品。

**8-2**：A不是方法论（运气不可复现），B是可复用方法论（有可量化的共性特征和具体模板），C不是方法论（"需要继续提升"没有操作性），D是可复用方法论（有具体数值和适用场景）。

**9-1**：违反红线一（数据与结论必须有因果关系）。CPM反映系统竞价竞争力，不反映人群精准度。精准看CTR和CPC。

**9-2**：追问链：互动量高但进店UV低 → 为什么？→ 用户对内容感兴趣但不点链接 → 为什么？→ 内容吸引力强但缺乏行动引导 → 为什么？→ 笔记中缺少明确的CTA（呼吁行动）或组件位置不明显 → 根因：内容有吸引力但转化路径不清晰，需强化CTA设计和组件露出。

**10-1**：禁用措辞包括：应该、大概、看起来、似乎、可能（除非有置信度标注）、差不多、基本上、某种意义上。不能用这些词的原因是它们模糊、不确定，削弱结论的权威性。复盘报告需要"确定"和"数据说话"，不是"感觉"和"猜测"。
