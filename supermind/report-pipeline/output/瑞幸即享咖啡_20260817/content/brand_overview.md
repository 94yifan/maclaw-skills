# 品牌概览：瑞幸即享咖啡

瑞幸即享咖啡是瑞幸咖啡向零售预包装领域延伸的产品线，核心判断是它握着整个预包装咖啡赛道里最独特的一张牌，即瑞幸门店体系沉淀下来的品牌心智和供应链，但要把这张牌在速溶、咖啡液、瓶装即饮三个品类上分别打出来，还面临完全不同的竞争结构。瑞幸即享不是独立的创业品牌，而是瑞幸咖啡这家中国最大连锁咖啡品牌之一的产品线，2024年瑞幸门店超过2万家（evidence_tier：reported），门店规模和品牌声量是瑞幸即享进入预包装赛道最大的势能来源。

从产品结构看，瑞幸即享覆盖预包装咖啡的三大品类，冻干速溶咖啡粉、咖啡液（冷萃液与浓缩液）、瓶装罐装即饮咖啡。这三个品类对应的是三个完全不同的消费场景和竞争格局，速溶咖啡粉拼的是精品化和性价比心智，咖啡液拼的是便携和新鲜感，瓶装即饮拼的是便利店货架和即饮场景的即时满足。瑞幸即享用同一套品牌资产同时切入三个品类，这是它的机会，也是它的风险，资源分散可能导致三块都做不透（evidence_tier：mapped）。

从品牌心智看，瑞幸即享最大的资产是门店打出来的爆款心智。生椰拿铁、酱香拿铁、橙C美式这些门店爆款，已经在消费者心里建立了瑞幸等于平价好喝、敢于创新、自带流量的认知，9.9元的心智更是把瑞幸和极致性价比绑定在了一起。这些心智在预包装品类里是稀缺的，三顿半、永璞、隅田川这些品牌没有瑞幸这种国民级的门店认知，雀巢、麦斯威尔则是传统速溶的老牌认知，缺乏年轻化和话题性。瑞幸即享要做的是把这套门店心智迁移到货架上，让消费者在便利店和电商里看到瑞幸三个字时，本能地联想到生椰拿铁和9.9元的平价精品（evidence_tier：mapped）。

从价格带看，瑞幸即享横跨了从几元一杯的速溶到十几元一瓶的即饮的宽价格带，这与它门店9.9元的心智存在张力。门店的9.9元是现磨现做的体验价，预包装产品的成本结构和定价逻辑不同，瑞幸即享需要在守住平价心智和建立零售端合理价格体系之间找到平衡，这是它进入预包装赛道最先要解决的问题（evidence_tier：speculation）。

从公司背景看，瑞幸咖啡2017年由陆正耀创立，2020年爆发财务造假危机后退市，2021年完成重组并实现重生，现任董事长兼CEO郭谨一带领瑞幸走出低谷、门店突破2万家（evidence_tier：reported）。这段从爆雷到重生的经历，让瑞幸拥有了两个重要的组织特质，一是极强的供应链和数字化能力，二是对快速试错和爆款打法的熟练运用。瑞幸即享正是这套能力体系向零售端的延伸，它能否复制门店的爆款方法论，是决定这条产品线成败的关键（evidence_tier：mapped）。
