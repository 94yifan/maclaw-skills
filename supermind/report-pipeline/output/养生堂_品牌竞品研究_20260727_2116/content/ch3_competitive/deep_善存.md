# 深度品牌：善存

## 五维扫描

### 市场渠道（3.5/5）

善存原属辉瑞，2022年随赫力昂从GSK分拆后在伦敦和纽约两地上市。中国区渠道以线上天猫和京东旗舰店加线下药店为主。其在全球维生素矿物质品牌中市场份额排名第一，但在中国市场的渠道覆盖深度不如汤臣倍健。线上旗舰店运营规范但缺乏Swisse式的内容营销和抖音直播矩阵。线下药店渠道由赫力昂中国团队覆盖，铺货率较高但终端推荐力度弱于国产品牌。渠道效率中规中矩，没有明显短板也没有突出亮点。

### 品牌力（4/5）

善存是全球维生素矿物质品类的代名词，品牌历史超40年，每天一片补充30种维生素矿物质的产品主张在中国消费者心智中扎根最深。中文名善存与善良存续的积极联想加分。在30岁以上城市中产人群中的品牌信任度极高，是自动购买场景中最容易被想起的品牌之一。小红书笔记约2万篇，品牌自发传播力弱于Swisse。品牌形象偏专业和保守，缺乏年轻化表达和情感化品牌故事，在Z世代中的认知度和偏好度持续走低。

### 产品（3.5/5）

善存以多种维生素矿物质片为核心产品，覆盖成人、男士、女士、银发族群四个细分产品线。另有维生素C、维生素B族等基础单品。产品以科学配方为核心卖点，价格带69-199元属于大众主流价位。产品线的核心问题在于品类过于集中：全部围绕维生素矿物质这一个品类，在蛋白粉、益生菌、鱼油、氨糖等高增长品类上几乎完全缺席。善存是一片好的多维片但难以用一片补充30种的逻辑去跟Swisse的护肝片或汤臣倍健的蛋白粉竞争消费者的购买关注。

### 趋势（3/5）

维生素矿物质品类是保健品核心基本盘，品类增速稳健但已是低个位数增长。善存在精准营养、口服美容、护肝、助眠等新兴功能赛道的布局几乎空白。赫力昂全球研发实力虽强，善存在中国市场的本土化创新和产品迭代速度明显落后于国产品牌。银发族多维产品细分是善存为数不多的趋势响应，但在老龄化最大的受益品类（氨糖、辅酶Q10、鱼油）上善存没有产品布局。

### 人群（3/5）

核心用户以30岁以上注重基础营养补充的消费者为主。品牌认知度高但购买转化率依赖习惯性消费而非主动种草。在年轻人群中的品牌渗透率持续下降，面临Swisse和汤臣倍健以及新锐品牌的激烈竞争。天猫旗舰店回头客率约10%-15%，复购尚可但新客获取乏力。善存目前最大的人群风险是存量用户自然老去而新增年轻用户跟不上。

## 竞争定位

善存在维生素矿物质品类对养生堂形成最直接的品类竞争。养生堂天然VE和VC面临善存多维片的品类替代威胁——消费者在选择基础营养补充剂时，善存的一片搞定对养生堂的分开服用具有强替代逻辑。但善存产品线单一、创新不足，养生堂若能在天然维矿赛道建立更强的差异化认知并在新品类上持续拓展，可以减轻善存的直接竞争压力。
