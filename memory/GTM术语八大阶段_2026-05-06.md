# GTM（Go-To-Market）八大阶段与核心术语

> 来源：微信公众号「出海营销Se姐」
> 原文链接：https://mp.weixin.qq.com/s/lmLJFyiG7R3EPTvcdliPgg

---

GTM 没有"万能公式"，但有一套通用的思维底层。所有成功的出海、品牌、产品增长，本质都在做同一件事：**让产品与市场的距离更短、让决策更高效、让增长更可持续。**

理解术语只是开始，真正的关键，是在不同阶段，能用这张"术语地图"去判断问题、拆解动作、校准方向。

---

## 一、战略与市场洞察（Strategy & Market Insight）

在所有 GTM 策略中，洞察是起点。你得先弄清楚：市场多大、客户是谁、机会在哪。

| 英文术语 | 中文释义 | 说明 |
|---|---|---|
| GTM (Go-To-Market) | 上市/营销/市场进入策略 | 从产品上市到市场扩张的全链路计划 |
| Market Segmentation | 市场细分 | 按人群、地域、需求划分市场 |
| TAM (Total Addressable Market) | 可服务市场总量 | 这类产品在全球范围内，理论上能覆盖的最大市场规模 |
| SAM (Serviceable Available Market) | 可进入市场 | TAM 的一部分，代表产品实际可触达的市场范围 |
| SOM (Serviceable Obtainable Market) | 可获得市场 | 真正能拿下的市场份额 |
| ICP (Ideal Customer Profile) | 理想客户画像 | 你的产品最匹配的目标客户群 |
| Buyer Persona | 买家角色 | 用故事化方式描绘客户动机与决策 |
| Positioning | 品牌定位 | 在市场中形成差异化认知 |
| Value Proposition | 价值主张 | 告诉客户"为什么选你" |
| Competitive Landscape | 竞品格局 | 评估主要竞争对手和市场结构 |
| Differentiation Strategy | 差异化策略 | 建立独特卖点（USP）形成竞争壁垒 |
| PMF (Product-Market Fit) | 产品市场匹配 | 市场确实需要并愿意为之付费的产品 |
| GTM Motion | 市场打法模式 | 例如直销、自助、电商、渠道合作等路径 |

---

## 二、产品与价值主张（Product & Value Proposition）

产品不是"做出来"才卖，而是"找到谁需要"。这个阶段的关键是：让市场理解你是谁、你解决什么问题、为什么你更好。

| 英文术语 | 中文释义 | 说明 |
|---|---|---|
| UVP (Unique Value Proposition) | 独特价值主张 | 产品解决的核心痛点与差异点 |
| MVP (Minimum Viable Product) | 最小可行产品 | 用最小投入验证市场需求 |
| Product Line | 产品线 | 同类产品的系列组合 |
| Feature Prioritization | 功能优先级 | 决定开发顺序与用户价值取舍 |
| Go/No-Go Decision | 上市决策点 | 判断产品是否准备好进入市场 |
| Beta Test | 内测 | 通过小规模测试验证用户反馈 |
| Product Roadmap | 产品路线图 | 规划功能上线节奏与发展方向 |

---

## 三、渠道与销售体系（Channel & Sales）

让更多人知道你是谁。这个阶段，重点不是"卖"，而是"被看见、被记住"。

| 英文术语 | 中文释义 | 说明 |
|---|---|---|
| Sales Funnel | 销售漏斗 | 从认知到购买的转化路径模型 |
| Direct Sales / Indirect Sales | 直销/分销 | 销售方式：直接面向客户或通过合作伙伴 |
| Channel Partner | 渠道伙伴 | 代理商、分销商、零售商等合作方 |
| Sales Enablement | 销售赋能 | 提供资料、培训和工具帮助销售转化 |
| Pipeline Management | 销售管线管理 | 跟踪销售机会从线索到成交的全过程 |
| Deal Size / Win Rate | 客单价/成交率 | 销售效率关键指标 |
| Pricing Strategy | 定价策略 | 包括成本导向、价值导向等 |

---

## 四、商业指标与ROI（Business Metrics）

让用户开始想了解你、尝试你。关键是从"认知"走向"兴趣"，让品牌进入他们的决策清单。

| 英文术语 | 中文释义 | 说明 |
|---|---|---|
| CAC (Customer Acquisition Cost) | 获客成本 | 获取一个客户所花的平均费用 |
| LTV (Lifetime Value) | 客户生命周期价值 | 一个客户带来的总收入 |
| ROI (Return on Investment) | 投资回报率 | 营销或投放的回报比例 |
| ARPU / ARPPU | 每用户平均收入/付费用户平均收入 | 衡量用户价值 |
| Payback Period | 回本周期 | CAC 与 LTV 平衡的关键指标 |
| Churn Rate | 流失率 | 停止使用或购买的客户比例 |
| Retention Rate | 留存率 | 继续使用或复购的客户比例 |

---

## 五、营销与传播（Marketing & Communication）

让用户真正下单。这里最考验的是"转化逻辑"，你的内容、落地页、流程，是否足够让人信任并行动。

| 英文术语 | 中文释义 | 说明 |
|---|---|---|
| Brand Awareness | 品牌认知 | 目标受众对品牌的认知程度 |
| Share of Voice (SOV) | 声量占比 | 品牌曝光在行业中的占比 |
| Content Marketing | 内容营销 | 用内容创造价值并吸引受众 |
| E/P/O Media Model | 赢得/付费/自有媒体 | Earned / Paid / Owned 三类传播资源 |
| Influencer Marketing | 红人营销 | 借助 KOL/KOC 内容传播品牌 |
| Campaign Management | 活动管理 | 规划与执行广告、公关活动 |
| Brand Equity | 品牌资产 | 品牌认知、信任与忠诚的总价值 |
| Demand Generation | 需求生成 | 教育与激发潜在购买动机 |
| Lead Generation / Nurturing | 线索获取/线索培育 | 从关注到成交的培育过程 |
| CTR / CPC / CPM / CPA | 点击率/每次点击成本/千次曝光成本/每次行动成本 | 广告四大基础指标 |
| Attribution Model | 归因模型 | 识别哪个渠道贡献最大 |
| CRO (Conversion Rate Optimization) | 转化率优化 | 让更多流量转化为实际购买 |

---

## 六、留存与客户成功（Retention & Customer Success）

留存，是所有增长的底层逻辑。让客户回来一次，比找一个新客户更划算。

| 英文术语 | 中文释义 | 说明 |
|---|---|---|
| Customer Journey | 客户旅程 | 从首次接触到忠诚的完整体验 |
| Email Drip Campaign | 邮件滴灌营销 | 自动化触达与激活 |
| Reactivation | 用户召回 | 唤醒流失客户 |
| Community Marketing | 社群营销 | 通过社群提升黏性与转介绍 |
| Customer Success | 客户成功 | 主动帮助客户实现目标，降低流失率 |
| NPS (Net Promoter Score) | 净推荐值 | 衡量客户愿意推荐的程度 |

---

## 七、增长与裂变（Growth & Advocacy）

当客户开始替你说话，增长就会自己发生。GTM 的终点不是卖出产品，而是让用户成为你的传播者。

| 英文术语 | 中文释义 | 说明 |
|---|---|---|
| Growth Loop | 增长飞轮 | 用户行为驱动的自循环增长机制 |
| Referral Program | 推荐机制 | 老带新、激励式裂变 |
| UGC / PGC / CGC | 用户/专业/联合生成内容 | 内容来源分类 |
| Social Proof | 社会认同 | 来自用户或权威的信任背书 |
| Virality Coefficient | 病毒系数 | 衡量裂变效率 |
| Engagement Rate | 互动率 | 内容与用户的互动深度 |
| Retention Cohort | 留存分群 | 分批追踪不同时间注册用户留存情况 |

---

## 八、执行与项目管理（Execution & Optimization）

再好的策略，都要落到执行。这一阶段，关注的是资源调配、时间节奏、团队协同与复盘机制。

| 英文术语 | 中文释义 | 说明 |
|---|---|---|
| OKR / KPI | 目标与关键结果/绩效指标 | 衡量项目执行成效 |
| Roadmap / Milestone | 路线图/里程碑 | 项目阶段规划 |
| Sprint / Agile | 敏捷迭代 | 快速试错与优化机制 |
| A/B Testing | 对照测试 | 用数据验证创意与假设 |
| Dashboard | 数据仪表盘 | 实时追踪指标表现 |
| Post-Mortem Review | 项目复盘 | 复盘经验与教训 |
| GTM Playbook | 市场打法手册 | 系统化执行标准与案例模板 |
