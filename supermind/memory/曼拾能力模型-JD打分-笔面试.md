# 曼拾通用岗位能力模型（多岗位通用版）

> 基于逸凡7月7日反馈重构：能力维度去岗位特化，保持通用性；每个维度分级时按岗位写差异化行为描述。
> 适用岗位：市场（内容方向）+ 广告投放（数据方向），两份JD/打分/笔面试共用一套框架。

---

## 一、通用能力框架（7大维度）

所有评估围绕这7个通用能力维度展开，每个维度下分2个子维度。

| 维度 | 子维度A | 子维度B | 为什么通用 |
|------|---------|---------|-----------|
| 1. 学习能力 | 领域内学习（行业/专业深度） | 跨领域学习（通用能力迁移） | 两个岗位都需要持续学习，只是学的内容不同 |
| 2. 信息敏感度 | 宏观信号捕捉（趋势/变化/异常） | 微观判断力（具体信息的好坏/真伪/价值） | 市场岗对内容敏感，投放岗对数据敏感，底层能力一致 |
| 3. 逻辑与分析力 | 结构化思考（拆解/归因/推论） | 决策质量（在不确定中做判断） | 两个岗位每天都要做判断，只是判断对象不同 |
| 4. 策略思维 | 目标反推（从结果倒推路径） | 资源调配（有/限条件下最优解） | 内容有内容策略，投放有投放策略，但思考逻辑一样 |
| 5. 表达与沟通 | 书面表达（文档/方案/报告） | 口头沟通（对齐/说服/管理预期） | 两个岗位都要对内对齐、对外沟通 |
| 6. 执行与韧性 | 交付力（按时按质把事情做了） | 抗压力（在不确定/压力下稳定输出） | 项目制公司的通用生存能力 |
| 7. 工具杠杆力 | 效率工具（提效类工具掌握程度） | 创新工具（用工具做原来做不了的事） | AI时代每个人都该有的能力，不分岗位 |

## 二、能力分级标尺（带岗位差异化描述）

> 每项以"市场版 / 投放版"分别描述。如果描述只有一个版本，表示此维度在两个岗位的行为表现一致。

### 1. 学习能力——领域内学习

| 级别 | 市场内容岗行为描述 | 广告投放岗行为描述 |
|------|------------------|------------------|
| L1 | 接受被分配的学习任务，完成培训作业 | 接受被分配的学习任务，完成培训作业 |
| L2 | 主动关注行业动态（头部品牌/爆款案例/平台变化），有自己的信息来源 | 主动关注平台规则更新/行业数据报告，能说出本周投放行业的变化 |
| L3 | 能输出学习笔记或案例分析，总结可复用的方法 | 新平台/新功能上线后能快速学习并在账户中测试，输出学习文档 |
| L4 | 能把学习成果沉淀为团队方法论（培训材料/案例库/SOP） | 能把投放经验总结为可复用的策略SOP，推广到团队 |
| L5 | 学习成果对外输出（行业分享/成为平台认证讲师/媒体约稿） | 能预判行业趋势变化并提前调整策略方向 |

### 1b. 学习能力——跨领域学习

| 级别 | 通用行为描述（两岗位一致） |
|------|--------------------------|
| L1 | 只关注自己领域的知识，对其他领域不感兴趣 |
| L2 | 愿意接触非本专业的知识（市场岗学数据、投放岗学内容） |
| L3 | 能主动学习跨领域知识并找到与本岗位的连接点（市场岗：从数据里看内容方向 / 投放岗：从内容角度理解素材差异） |
| L4 | 跨领域学习成果能反哺本岗位工作，形成差异化竞争力 |
| L5 | 跨领域融合能力成为个人标签，能解决单一领域视角解决不了的问题 |

---

### 2. 信息敏感度——宏观信号捕捉

| 级别 | 市场内容岗行为描述 | 广告投放岗行为描述 |
|------|------------------|------------------|
| L1 | 能分辨一条内容好/不好 | 能看出数据报表中明显异常（消耗突变/CTR暴跌） |
| L2 | 能解释一条内容为什么火/为什么不火 | 能定位数据异常的大致原因（素材/出价/大盘） |
| L3 | 能在内容发布前预判传播效果的大致量级 | 能从多维数据交叉验证中发现隐藏问题 |
| L4 | 能在别人没做的时候判断"这个方向会火" | 能建立监控体系，在异常发生前预判风险 |
| L5 | 能定义团队的内容方向标准，让团队的内容成为行业参照 | 投放数据解读反哺业务决策，提炼对用户/市场的洞见 |

### 2b. 信息敏感度——微观判断力

| 级别 | 市场内容岗行为描述 | 广告投放岗行为描述 |
|------|------------------|------------------|
| L1 | 能照做，不判断 | 能按规则执行调整 |
| L2 | 能判断几条备选内容中哪条更好，能说出原因 | 能在给定框架内做基础优化判断（出价调多少/哪个素材下掉） |
| L3 | 能判断一个内容方向是否值得投入，"做还是不做"有依据 | 能在多变量场景中做归因判断，找到核心原因 |
| L4 | 判断力稳定可靠，团队愿意让你做终审人 | 判断逻辑成为团队的参考标准 |
| L5 | 你的判断标准被行业认可 | 你的优化框架被团队持续使用 |

---

### 3. 逻辑与分析力——结构化思考

| 级别 | 市场内容岗行为描述 | 广告投放岗行为描述 |
|------|------------------|------------------|
| L1 | 能听懂别人的分析并照做 | 能看懂数据报表上的关系和趋势 |
| L2 | 能自己整理信息并输出有结构的小结论（竞品分析/调研结论） | 能建立"数据→假设→验证"的分析链条 |
| L3 | 能拆解复杂问题（客户brief模糊时，能拆成可执行的小问题） | 能在多变量中找到因果关系，不混淆相关和因果 |
| L4 | 能建立团队的分析框架和分析标准 | 能设计团队的优化决策框架（调优逻辑SOP） |
| L5 | 分析结论能影响公司层面的决策方向 | 归因模型成为公司投放策略的基础工具 |

### 3b. 逻辑与分析力——决策质量

| 级别 | 通用行为描述（两岗位一致） |
|------|--------------------------|
| L1 | 需要明确指令才能做决定 |
| L2 | 能在给定框架内做小范围决策（选图/选文案/选渠道/选出价） |
| L3 | 能在信息不完整时做方向性判断，主动承担决策风险 |
| L4 | 能为组织定义决策框架，培养他人的判断力 |
| L5 | 决策质量稳定到可以被写进公司的决策机制 |

---

### 4. 策略思维——目标反推

| 级别 | 市场内容岗行为描述 | 广告投放岗行为描述 |
|------|------------------|------------------|
| L1 | 理解策略文档并能按策略方向执行 | 理解投放策略并按策略执行计划操作 |
| L2 | 能独立做小方案的策略逻辑（节点活动/单品推广） | 能独立制定账户策略（预算分配/出价策略/周期节奏） |
| L3 | 能操盘中型campaign方案（预算+节奏+触点+人群） | 能设计多账户/多平台的投放策略组合 |
| L4 | 能设计品牌全年的内容策略框架 | 能把投放策略与品牌整体营销策略对齐 |
| L5 | 策略能力成为公司竞争利器 | 投放增长体系成为公司核心能力 |

### 4b. 策略思维——资源调配

| 级别 | 市场内容岗行为描述 | 广告投放岗行为描述 |
|------|------------------|------------------|
| L1 | 分配什么做什么 | 预算给多少花多少 |
| L2 | 能在有限资源下判断"这个项目该做/不该做" | 能在给定预算下做品效配比判断 |
| L3 | 能根据目标反推资源需求，主动争取合理资源 | 能根据ROI表现动态调配预算 |
| L4 | 能在多项目间做优先级和取舍决策 | 能在多客户多账户间做资源最优分配 |
| L5 | 资源调配逻辑成为公司经验复用标准 | 预算策略上升为商业决策 |

---

### 5. 表达与沟通

> 此维度两岗位行为描述一致，但应用场景不同。

| 级别 | 通用行为描述 |
|------|-------------|
| L1 | 能把一件事说清楚，书面表达无语病无逻辑断层 |
| L2 | 能用结构化方式表达观点（结论先行+有论据+有层次） |
| L3 | 能针对不同对象调整表达方式（对客户讲价值、对团队讲执行、对老板讲结论） |
| L4 | 能用表达引导他人思考和决策，在会议中把控讨论方向 |
| L5 | 表达具有说服力和影响力，能在行业场合代表公司发声 |

---

### 6. 执行与韧性

> 此维度两岗位行为描述一致。

| 级别 | 通用行为描述 |
|------|-------------|
| L1 | 能完成分配的任务，遇到问题会主动问 |
| L2 | 能在给定时间内交付，不拖延不甩锅，卡住时主动暴露 |
| L3 | 能同时跟2-3个项目，能区分优先级，压力下保持交付质量 |
| L4 | 能在资源不足/信息有限/时间紧急时做决策并推进，能在不确定中带团队前进 |
| L5 | 能承受业务层面的责任和风险，为团队交付质量兜底 |

---

### 7. 工具杠杆力——效率工具

| 级别 | 市场内容岗行为描述 | 广告投放岗行为描述 |
|------|------------------|------------------|
| L1 | 只会用基础办公工具（Word/PPT/Keynote） | 只用投放后台+基础Excel |
| L2 | 会用AI工具提效（ChatGPT写文案/MJ出图） | 会用Excel做数据分析（透视表/vlookup） |
| L3 | 能用AI完成原本做不了的事（批量素材生成/数据分析） | 会用SQL或脚本自动化重复操作 |
| L4 | 能设计团队的工具工作流，提升整体效率 | 能搭建投放数据看板和自动化工具 |
| L5 | 工具使用方式影响行业或被平台认可 | 能用AI重构投放工作流（自动出价/智能分配/预测模型） |

### 7b. 工具杠杆力——创新工具

| 级别 | 通用行为描述 |
|------|-------------|
| L1 | 不知道有什么工具可以用 |
| L2 | 知道有什么工具，但只是"会用"阶段 |
| L3 | 能用工具做的事情绝不手动做，有"工具优先"的意识 |
| L4 | 能评估新工具的价值，判断"这个工具值不值得引入团队" |
| L5 | 能借助工具改变岗位的工作方式和工作边界 |

## 四、修改版JD（按通用能力维度写）

### 市场内容岗 JD

**我司**已深耕社交媒体整合营销9年，长期服务霸王茶姬、IT、思念、coco、方太等客户，是小红书首批整合营销牌照代理商（全网6家）。

公司氛围不错，但新媒体代理商广告行业特殊，卷起来加个班很难避免。想做成事的适合我们，特玻璃心斤斤计较时间的老油条真不适合我们。

我们需要什么样的内容策划——

**1. 学习能力—领域内**
你要对社交媒体有持续的好奇心。不是"我知道什么火"，而是"我一直在学为什么火"。来面试时能说出你最近学到了什么，以及你怎么用新学到的东西理解了某个品牌动作。

**2. 信息敏感度**
你对"什么是好内容"有自己的判断，不只是说"我觉得好看"。你能说出一条内容从选题到发布到传播链条上，哪里做对了、哪里可以更好。

**3. 逻辑与分析力**
你能把一个模糊的需求拆成具体问题。"客户想出圈"——你脑子里不是立刻出一个创意，而是先想：出给谁看、在哪里出、怎么算出了。

**4. 策略思维**
你不是只做"这一条"，你能想"这一条放在整月/整季的节奏里是什么位置"。你能从目标反推路径，而不是从感觉出发。

**5. 表达与沟通**
你能把想法说清楚。书面不跑题，口头不绕弯。跟创意团队沟通说人话，跟客户沟通说价值。

**6. 执行与韧性**
你能把事情做了、做完、做好。不会的学，卡住的说，别到了deadline才说还没开始。

**7. 工具杠杆力**
会用基础工具（PPT/Keynote等）。会用AI工具加分。但更重要的是——你不排斥工具，愿意学新的。

**工作职责：**
- 参与品牌在小红书/抖音的内容策划、选题讨论和内容执行（文案/视觉方向/brief输出）
- 协助资深策划在campaign前期做行业调研和竞品分析，用数据支持内容决策
- 参与项目的执行跟进和数据复盘

**任职要求：**
- 本科及以上，广告/营销/新闻/中文/心理等专业优先（不是这些专业但作品够硬一样欢迎）
- 日常活跃在至少两个社交媒体平台，能说出你关注的博主和为什么关注
- 面试带一份个人作品（课程作业/社团方案/个人账号/文案作品都可以）

### 广告投放岗 JD

**公司简介同上。**

我们需要什么样的投手——

**1. 学习能力—领域内**
平台规则三个月一小改、半年一大改。我们要的不是"现在懂的人"，是"不管怎么改都能快速学会的人"。面试时能说说你最近一次学习新平台或新功能的经历。

**2. 信息敏感度**
你对数字敏感。不是数学好，而是看到数据变化你能意识到"这里有问题"。数据异常不是你焦虑的来源，是你问出好问题的起点。

**3. 逻辑与分析力**
你做的每一个优化调整都能说出依据——"我调整出价是因为XX，我预期会产生XX效果"。不是凭感觉调，是推演出的。

**4. 策略思维**
你不只是管一个账户一个计划。你能想"今天花多少钱、花在哪、怎么花，才能配合品牌整月的营销节奏"。

**5. 表达与沟通**
你不仅懂数据，还能让不懂数据的人听懂你说什么。跟内容团队沟通素材方向，跟客户汇报数据表现，都知道怎么说。

**6. 执行与韧性**
投放是每天面对数字和压力的事。ROI好的时候不飘，差的时候不慌了手脚。对账户有主人翁意识——这是你管的事，你负责到底。

**7. 工具杠杆力**
会Excel基础操作（透视表/vlookup）是底线。会SQL/会用脚本提效加分。但最核心的是——你有"用手工做的事能不能用工具代劳"的意识。

**工作职责：**
- 负责品牌在小红书/抖音/腾讯广告等平台的投放执行和账户管理
- 跟进投放数据，输出日报/周报，基于数据做优化调整
- 参与投放策略讨论，根据品牌目标制定预算分配和投放节奏

**任职要求：**
- 本科及以上，专业不限（统计/数学/市场/广告相关优先）
- 对数字有敏感度，不排斥日常和数据打交道
- 逻辑清晰——能说清楚自己做每个调整的原因
- 有任一平台的投放实操经验优先

| 执行韧性 | 通用 | 10% | 完成分配任务 | 同时跟2-3个项目 | 在不确定中主动推进 | /5 |
| 工具杠杆 | 效率/创新 | 10% | 只用基础工具 | 会用AI/Excel提效 | 能设计团队工具工作流 | /5 |

**总分** = 各项×权重 的和, 满分5.0分

## 八、面试流程操作指南

### 建议面试流程总时长
| 轮次 | 时长 | 面试官角色 | 侧重能力 |
|------|------|-----------|---------|
| 第一轮 | 30分钟 | HR或直属同事 | 基础能力确认（信息敏感度+学习+表达） |
| 第二轮 | 30分钟 | 部门负责人或资深同事 | 核心能力评估（逻辑+策略） |
| 第三轮 | 20分钟 | 部门负责人+HR | 软性素质+抗压性+价值观匹配 |
| 笔试 | 90分钟 | 独立完成 | 实操能力验证（笔试题目见第六部分） |

### 面试流程建议

**方案A（充足时间）：** 先笔试 → 筛选 → 第一轮面试 → 第二轮面试 → 第三轮面试
**方案B（快速流程）：** 同步发笔试 + 约第一轮面试（笔试与第一轮同一天）→ 第二、三轮合并
**方案C（实习生/管培生）：** 第一轮面试 + 笔试（面试后发，发回后决定是否进第二轮）

### 笔试题评分建议
- 笔试不设"及格线"，而是用来验证面试中的判断
- 如果面试中觉得"学习能力很强"，但笔试题写得特别差——可能需要深思
- 如果面试平平但笔试题出色——建议加一轮
- 笔试答案不要只看对错，看思考过程：写得少≠不好，写得多但不聚焦≠好

### 红线问题（出现任一直接不过）
1. 简历造假
2. 表现出"什么都行"但没有具体项目或案例支撑
3. 被问到一个不确定的问题时，选择编而不是说"这个我不确定"
4. 对前公司/前老板有明显的负面倾向性描述
5. 笔试中完全没有自己的判断，每道题都在"面面俱到"

## 七、这套框架的设计逻辑

**核心思路：能力维度通用化，行为描述岗位化，面试追问场景化。**

- 7大维度+14个子维度覆盖两个岗位的全部评估需求，而且加新岗位时不需要增加新维度，只需要写新岗位的行为描述
- 笔试题通用，面试追问区分——减少出题工作量，同时保证面试深度
- 不需要"网感"这种岗位特化词，全部用通用能力词（信息敏感度）加行为描述区分

**举个例子：同一个"信息敏感度L3"的行为描述**

市场版：能在内容发布前预判传播效果的大致量级
投放版：能从多维数据交叉验证中发现隐藏问题

**这两个描述都指向"信息敏感度L3"，但说的不是同一件事。这也是为什么能力维度要保持通用——它描述的是"同一个能力层次"，不是"同一个动作"。**
