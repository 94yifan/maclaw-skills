# 创始人研究

杜亚机电创始人鲍永林，浙江宁波人。2002年在宁波创立杜亚机电技术有限公司，从管状电机OEM起步，20年深耕单一品类做到全球窗帘电机市占率30%-35%。

关键节点：2002年宁波杜亚机电成立→2012年营收突破7亿元（员工2600+，厂房9.5万平米）→2015-2018年推出智能窗帘系列（M1/D9等）→2020年B1支持小度音箱→2021年引入高瓴资本战略投资→2024-2025年推出隐形大师/DT98/成品帘+李佳琦直播破圈。

核心经营理念三条：专注单一品类做到全球第一（20年不跨界）；从OEM到自主品牌渐进转型（双轮驱动降低风险）；拥抱生态但不依赖生态（全生态兼容策略保持独立性）。

创始人风格：典型浙江制造企业家，低风险/长周期/靠规模效率取胜。2021年接受高瓴而非互联网巨头投资，重视独立性高于估值。2024-2025年加大C端品牌和内容营销投入，推动公司从制造驱动向品牌驱动转型。
