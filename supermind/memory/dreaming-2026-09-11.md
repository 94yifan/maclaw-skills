## D. ★ 知识串联（核心环节）

### 缝合点1（主，元层）：投递盲区 = 消费方的自动加载路径缺失，「投递通道」是静默失败家族的共同上游

**来源：** 今日两条独立事实。①CFO 定位：9/10 三条行动计划今日 0 执行，根因不是执行力，是规则只写在 dreaming 文件里，而该文件不被任何 session 自动加载。②主 session 09-10 复盘消息 run error + not-delivered，文件完整落盘但逸凡从未看到。

**串联判断：** 与 09-01 缝合点4（复盘静默：产出但没被消费）、09-02 缝合点1（转达链路缺送达验证）、07-13 推理守卫七（逸凡感知窗口=飞书，本地文件不可见）、09-10 缝合点5（挂账要在注意力窗口）合流。这些是同一结构的四个剖面：**信息或规则只有进入消费方的自动加载路径才算存在**。对 agent，自动加载路径 = MEMORY.md / SOUL.md / 脚本本身；对逸凡，感知路径 = 飞书消息与交付物。产出不等于存在，存在等于投递到消费方的加载路径。判断方法：写任何规则或汇报之前先问，它是谁在什么时机自动读到的，答不出来就换通道。家族新成员命名**投递盲区**：与复盘静默的区别在于，复盘静默是产出方没有消费，投递盲区是投递本身没有进入消费路径，两边都以为完成了。

### 缝合点2（主，元层）：归因错位 = 信号真实但归因错误，代理指标改善不等于行为改变

**来源：** 今日两个同构案例。①孤儿文件治理：tmp/ + .gitignore 落地后 git status 干净了，但「创建即留存」的行为没变，今天新增 8 个脚本全留。②CFO 手填 AutoNumber，前 5 条恰好与自增序列重合，回执看起来全对，实际错误被系统吸收。

**串联判断：** 与 09-05 静默失败家族（信号与产物脱节）、08-02 假成功同族，但是新形态：信号与产物都正常，脱节发生在归因层。git status 干净是 .gitignore 产生的，不是行为改变；编号正确是 AutoNumber 产生的，不是写入正确。整合结论：**验收治理动作时必须问这个信号是谁产生的，用行为的直接证据而不是代理指标（proxy signal）**；代理指标改善不等于行为改变。这条同时解释了为什么「症状消失」最容易伪装成「问题解决」。

### 缝合点3（主，机制轨）：窗口家族第四形态「半定义边界」，边界的缺省部分是隐式决策

**来源：** SC 今日发现 evaluate 过滤只设下界（>= 抓取起点减 24h），没有上界，11:00:01 与 11:00:02 两条帖越界入窗，明日可能重复入窗。

**串联判断：** 窗口家族此前三形态：过滤口径缝隙（09-03，声称窗口不等于实际过滤窗口）、存档断链（09-06，存档不等于产物数据源）、跨窗归属（09-07，昨日尾部条目进今日窗口，记忆边界）。今日补第四形态**半定义边界**，其独特之处是缺口不是写错的，是被省略的，省略的部分被系统按无限制执行。整合结论：**定义边界必须显式写出两端加缺省行为声明**；凡 `>= start` 这类单边过滤，都要问另一端发生了什么。通用化：所有筛选、过滤、规则，缺省部分不是中性的，是一个隐式决策。与 09-10 缝合点1（副作用解耦）同族，都是没被显式处理的默认行为造成损坏。

### 缝合点4（主，机制轨）：结论层级是比时间更隐蔽的免检理由，层级与复查频率应负相关

**来源：** SC 昨日判定 3 个账号登录受限是平台级收紧，今日沙箱浏览器实测推翻，实为 CDP 9333 会话级问题。

**串联判断：** 与 09-04 缝合点2（停更类结论没有新数据检验，越陈旧越像正确）合流：两者都在讲**结论的复查豁免**。停更类结论靠没有反例而显得正确，高层级结论靠「平台级等于外部事实」而不需要复查。整合结论：**结论的抽象层级越高，复查频率越要固定化**。平台级、结构性、已修复、已停更这四类判断一律标证据时间戳并按期强制复验。SC 已落地「结论必须带最近观测时间，超 3 日失效重查」，本轮新增的是：层级比时间更隐蔽，因为它让人主动放弃复查。

### 缝合点5（次，业务轨）：全民梗借势的第四问「容器承接度」，借势判定链三阶补完

**来源：** SC + SP 今日：苹果发布会 Duo 梗 4 家同日借势，爷爷不泡茶评 411（有 EP02 系列化内容承接）远高于 CoCo 转 169、柠季 转 93、库迪 转 1。

**串联判断：** hotspot 三问（能不能玩、是不是二创期、挂不挂得上）在全民梗场景失效，门槛趋零、万物可挂。串联 09-06 缝合点3（谐音梗必配 UGC 动作）、09-07 缝合点4（咬合度是质量分水岭）、09-10 缝合点1（节点门槛分层），整合为**借势判定链三阶：门槛（能不能进）到咬合（挂得上吗）到承接（接得住吗）**，缺一层就空转。容器（栏目、角色、系列）是唯一把一次性梗变成可积累资产的东西。客户用法：蹭全民梗必须配自有容器，无容器不投内容资源。

### 缝合点6（次，业务轨）：平台通道第四型「节点统一下发」，自有流量池成为唯一免租资产

**来源：** 库迪与沪上阿姨 9/11 用几乎逐字一致的开学小宝盒文案（官微评 5 与评 0），柠季新品同步挂淘宝闪购特惠。

**串联判断：** 09-04 缝合点1（平台三通道：IP 组局、公益节、渠道促销）补第四型=节点统一分发，品牌从谈判方变成被通知方，议价权进一步下降。串联 09-10 缝合点4（品牌账号流量不等于目标圈层流量）：两头挤压下，**自有阵地与私域是唯一不被平台收租的资产**。权衡模型：平台通道=成本摊薄加公域流量，代价=同质化加自有流量池稀释加议价权下降；判断按品牌阶段，铺货期用平台通道，建资产期必须自建。客户用法：平台通道是铺货工具不是品牌工具，方案必须双轨规划。
