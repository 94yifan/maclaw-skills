# 小红书商业动态深度阅读

## 触发条件

用户发送 mp.weixin.qq.com 小红书商业动态相关文章链接，或要求"读一下这篇小红书文章""分析这个报告"。

## SOP

### 第一步：判断文章类型

用 CDP 打开 URL（必须加 `?scene=1`），等待页面加载后执行：

```
document.querySelector('#js_content')?.innerText || document.querySelector('.rich_media_content')?.innerText || ''
```

同时检查页面是否包含图片类内容（信息图特征）：
- 页面文字极少、以图片为主的排版
- 标题含"一图读懂"、"图解"、"干货图"等关键词
- 页面主体内容无法通过 innerText 提取超过 200 字

如果判定为图片类信息图文章，进入**图片处理分支**；否则进入**文字文章分支**。

### 文字文章分支

直接使用上一步提取的 innerText 内容，按第二步流程处理。

### 图片处理分支（嵌套 ocr-local skill）

1. 下载页面内所有图片（SVG、PNG、JPG）：通过 CDP 执行 `document.querySelectorAll('img')` 提取 src，下载到本地
2. 调用 `ocr-local` skill 逐张提取文字：
   ```
   node {xhs-business-deep-reading}/scripts/extract_images.js <tab-id> <output-dir>
   ```
   或直接调用：`node {baseDir}/scripts/ocr.js <image-path> --lang chi_sim+eng`
3. 将所有 OCR 结果按页面顺序拼接，得到完整正文
4. 按第二步流程处理

> `{baseDir}` = `~/.openclaw/workspace/skills/ocr-local`
> 如果 ocr-local 未安装，先安装：`openclaw skills install ocr-local`

### 提取内容

从正文提取：
- **标题、作者、发布日期**
- **核心论点**：1-2句概括
- **关键打法/策略**：原文描述的打法名称+描述
- **核心数据点**：搜索量、用户规模、增长率等数字
- **案例**：报告引用的品牌案例

### 第二步：内容提炼

按标准结构输出（标题/作者/日期 + 核心论点 + 打法 + 数据 + 案例）。

### 第三步：回答两个分析问题

#### 思考一：小红书现在侧重什么

- **平台定位关键词**：从"种草渠道"升级为什么
- **侧重的行业方向**：文章涉及哪些行业
- **侧重的打法关键词**：原文中的具体打法名称

#### 思考二：哪些可以深度复用到全行业

每个复用点必须包含：
- **是什么**：框架核心逻辑（从原文提取）
- **为什么**：跨行业通用的具体原因
- **怎么用**：其他行业落地的具体动作

**举例要求（必须遵守）：**

功能→具体感受→生活场景，三环节顺畅衔接，不能跳步。

正确示例：
> 超静音（功能）→宝宝在地板上玩不用担心被机器人噪音吵醒、加班再晚回家也有安静环境（具体感受）→大人终于不用守在客厅盯着机器人跑（生活场景）

禁止：把多个功能打包成一个情绪场景，或用笼统情绪词跳过具体感受。

### 第四步：保存到飞书文档

文档命名：`年-月-深度阅读-小红书-文章标题`

文档结构：

```
# [文章标题]

**来源：** [作者]
**发布日期：** [日期]

## 内容摘要
[第二步输出]

## 思考一：小红书现在侧重什么
[第三步思考一输出]

## 思考二：哪些可以深度复用到全行业
[第三步思考二输出]
```

使用 `feishu_doc` action=create 创建，`owner_open_id: ou_c4249d713be906d36ef8607efab6506f`，然后 action=write 写入内容。完成后把文档链接发给用户。

## 关键约束

**最容易出错的地方：举例时跳步**

检查每个举例必须确认：功能→具体感受之间有顺畅的情绪或因果逻辑。如果举例对不上，换一个能对上的，不要凑合。

## 复用价值

每次读新的小红书行业文章都走同一套流程，内容沉淀持续积累，团队可直接查阅飞书文档里的全部沉淀。
