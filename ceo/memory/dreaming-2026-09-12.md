## A. 执行错误

### A1（客户交付级，今日实际发生）：82MB 录音超过飞书机器人 30MB 入站上限，被系统静默丢弃——agent 与用户两侧零信号

**证据链：**
- `~/Library/Logs/openclaw/gateway.log` 原文两行：`15:31:56 received message … <media:document> (春光冉总第一次沟通0910.m4a)` → `15:32:00 [feishu] failed to download file media: Error: Media exceeds 30MB limit`
- 会话侧只收到 `<media:document> (春光冉总第一次沟通0910.m4a)` 一行占位符，**没有任何失败提示**

**我的处置过程（暴露问题）：** 收到占位符后，我用了约 3 分钟在文件系统里穷举——反复列 `media/inbound`、全盘 `find *.m4a -newermt`、查 openclaw.sqlite 的 `media_blobs` 表（表为空）、在会话 jsonl 里 grep `file_key`。**全部无果。** 最后靠 `grep -n "failed to download" gateway.log` 一行定位根因。
