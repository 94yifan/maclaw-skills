# 内容类型五分类分析

## 分析框架

对每个深度品牌，扫描各社媒平台（抖音/小红书/B站/微博）内容，按五类型归类：

1. 曝光型：观点强、争议大、易传播
2. 涨粉型：资源型/推荐型
3. 收藏型：步骤/SOP/模板，生命周期长
4. 转化型：展示结果/案例/收益，直接驱动购买
5. 人设型：故事/经历/踩坑复盘，建立人格认知

核心洞察：一次爆可能是运气，十次爆一定是规律。判断品牌内容增长系统的主导类型。

## 各品牌分析

### 缸鸭狗
主导类型：人设型（老字号故事）。缸鸭狗的内容资产几乎全部来自UGC——消费者自发在社交媒体分享名字梗和汤圆体验。品牌官方的主动内容产出极少。占比估计：人设型40%、曝光型（名字梗传播）30%、转化型（测评带货）20%、收藏型5%、涨粉型5%。增长系统判断：无系统性内容策略，增长依赖自然UGC的随机爆发。重复爆款倾向：低——名字梗只能红一次，没有持续内容产出能力。

### 沈大成
主导类型：转化型（探店测评）。沈大成的内容高度依赖南京东路旗舰店的到店体验分享，以小红书探店帖和大众点评评价为主。占比估计：转化型（探店+购买体验）50%、人设型（老字号历史）25%、曝光型（糕团高颜值出片）15%、收藏型5%、涨粉型5%。增长系统判断：强依赖门店到店流量转化内容，线上主动运营几乎为零。重复爆款倾向：中偏低——青团季有稳定的UGC爆发，但非季节期内容产出断崖。

### 知味观
主导类型：转化型（试吃测评+送礼推荐）。知味观的内容在五家竞品中是最有体系的——既有东坡肉和小笼包的产品测评内容，也有杭州特产送礼场景的内容。占比估计：转化型45%、人设型（百年杭州老字号）25%、曝光型（东坡肉话题）15%、收藏型10%、涨粉型5%。增长系统判断：有初步的内容矩阵但缺乏KOL投放和爆款策划。重复爆款倾向：中——东坡肉相关内容有稳定的自然流量，但未形成爆款方法论。

### 巴比食品
主导类型：品牌无内容策略。巴比食品的内容天然由5934家门店承载——每个门店就是最大的曝光触点，不需要线上内容引流。占比估计：品牌官方几乎不生产社媒内容，依赖本地生活博主的探店测评（转化型70%）和消费者的早餐分享（曝光型20%）。增长系统判断：无线上内容策略，增长引擎是门店扩张而非内容。重复爆款倾向：不适用。

### 桃李面包
主导类型：品牌不做内容。桃李的内容策略与巴比类似——依赖产品在终端货架的可见性替代内容获客。偶尔有早餐搭配类UGC产出（收藏型约60%）。增长系统判断：无线上内容系统。重复爆款倾向：不适用。

### 蒸笼头（本品）
主导类型：零内容产出。蒸笼头目前在社交媒体上的能见度完全依赖盒马消费者的自发UGC，品牌方未运营任何社媒账号。判断：这是最大的内容洼地——手工包制生产过程是天然的短视频爆款素材，当前价值为零浪费。建议策略：以人设型（手工人设）+曝光型（工厂制作过程）为双主线启动内容建设，预计6个月可达月度百万级曝光量。
