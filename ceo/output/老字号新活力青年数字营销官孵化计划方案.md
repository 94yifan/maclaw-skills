# 黄浦区"老字号·新活力"青年数字营销官孵化计划

## 完整执行方案（2026-2027年度）

**项目定位：** 以MCN化运营模式（非签约属性），为黄浦老字号打造青年数字营销人才孵化平台
**主办单位：** 黄浦区就业促进中心（建议联合区商务委、区文旅局）
**支持企业：** 曼拾（广告代理·项目支持方）、小红书等平台方、老字号企业、高校
**方案版本：** V1.0（2026年8月27日）

---

## 一、项目背景与机遇

### 1.1 老字号之困：强场景、强叙事，但传播断层

黄浦区拥有全国最密集的老字号资源带——南京东路、淮海路、豫园三大商圈集聚了邵万生、三阳南货、老大同、沈大成、新雅粤菜馆、杏花楼、培丽酱菜、茂昌眼镜、吴良材眼镜、老庙黄金、童涵春堂、大世界等一批中华老字号与上海老字号。这些品牌共同拥有两个被反复验证的禀赋：

- **强场景**：百年门店、非遗技艺、匠人现场、历史建筑，天然具备"内容空间"潜质；
- **强叙事**：每个品牌背后都有数十年乃至上百年的故事、工艺与城市记忆，天然具备"内容素材"富矿。

但老字号普遍面临同一个断层：**品牌资产与年轻消费者的连接方式没有更新**。货架还是那个货架，门店还是那个门店，但年轻人获取信息和做消费决策的方式已经全面迁移到内容平台。老字号不是没有故事，而是没有一支能把故事翻译成年轻人语言、把门店变成打卡场景的内容队伍。

### 1.2 青年之困：有才华、有热情，但缺场景、缺出口

上海高校毕业生规模持续处于高位，就业结构性矛盾突出——企业招不到"会做内容的人"，学生找不到"能发挥内容能力的工作"。大学生普遍具备内容创作热情与学习能力，但缺少三个东西：

- **缺实训场景**：没有真实品牌、真实门店、真实需求让他们练手；
- **缺作品集**：没有商业级作品，求职时简历苍白；
- **缺岗位通道**：不知道"内容营销"这个岗位方向，也不知道去哪应聘。

### 1.3 时代之机：AI工具爆发 + 内容电商成熟 + 国潮文化红利

三重外部变量叠加，让今年的破题条件比过去八年任何时候都成熟：

- **AI降低创作门槛**：AIGC文案、图片、视频工具链成熟，非传媒专业学生也能产出专业级内容，生源池从"专业学生"扩大到"全体大学生"；
- **内容电商成为品牌标配**：直播、短视频、种草已成为品牌经营的基础设施，老字号不是要不要做，而是必须有人帮它做；
- **国潮与文化消费红利**：Citywalk、非遗热、国货自信，年轻人正在主动走向老字号——缺的只是"内容翻译官"。

### 1.4 就促中心之基：八年品牌资产与已验证的方法论

黄浦区"老字号·新活力"创新创业专项行动自2017年5月首创首发，已沉淀为全国标杆：

- 入选联合国《上海手册》全球25个案例之一；
- 与7家老字号集团建立战略合作，建成星光色谷、邵万生、大世界演艺中心3家老字号公共创业实训基地；
- 累计发布老字号创新需求167项，组织创新创业活动171场，2万余人次参与，产生创新方案632个，促成51个创新合作对接意向；
- 赛事方法论成熟：中国好创意大赛辐射全国526所高校、6644件作品；2024年"中华杯"黄浦美食大赛530余名学生报名、360余组作品、17校宣发辐射近万名学生；
- **"AI+新媒体"创业陪跑计划已验证"培训+陪跑"模式**：三个月全流程陪跑（每两天日评、每周1V1复盘、每双周分享课），4家陪跑企业粉丝总量增长8.5%、活跃度提升4.6%、全渠道曝光超10万次。

**结论：体系完整、方法成熟、品牌响亮，唯一缺的是"从活动到人才资产"的沉淀闭环。** 过往赛事结束，作品归档，但人散了——学生没有持续成长通道，企业没有人才储备池，政府没有可追踪的就业成果。今年的"达人孵化"想法，恰好补上这一环。

### 1.5 破题方向：把"比赛+培训"升级为"选拔—孵化—就业"完整闭环

以MCN化运营模式（非签约属性），建设"老字号青年数字营销官孵化计划"：**大赛是入口（选拔+引流），孵化营是过程（培训+实战+陪跑），人才库与就业对接是出口（让大学生有班上）**。

## 二、项目定位与命名

### 2.1 一句话定位

> 以MCN化运营模式，为黄浦老字号打造青年数字营销人才孵化平台——就业导向、老字号焕新、AI赋能三位一体。

### 2.2 与MCN的本质区别：不是签约生意，是育人平台

本项目核心表达是"孵化器"，不是真正的签约主播MCN。差异用"三不、三有"说清楚：

| 维度 | 签约MCN | 本计划 |
|---|---|---|
| 关系 | 签约绑定、抽成 | 不签约、不抽成、不绑定 |
| 对象 | 现成主播/达人 | 零基础大学生 |
| 目标 | 商业变现 | 就业育人与品牌服务 |
| 赋能 | 流量扶持+商业分成 | 方法课程+真实场景+就业出口 |
| 沉淀 | 机构利润 | 青年人才库+老字号内容资产 |

**孵化的是"人"的能力，不是"主播"的生意。** 学生获得的是可迁移的数字营销职业技能与真实作品集，老字号获得的是可持续的内容服务队伍，政府获得的是可追踪的就业成果。

### 2.3 命名体系（建议）

保留并沿用母品牌资产，新项目作为子品牌生长在"老字号·新活力"之下：

- **母品牌**：黄浦区"老字号·新活力"创新创业专项行动（沿用，不动）
- **子项目全称**：「老字号·新活力」青年数字营销官孵化计划
- **项目简称**：老字号新声代
- **定位语**：以MCN化运营模式，孵化老字号数字营销人才
- **课程品牌**：老字号·新活力达人孵化课程（保留就促中心原想法中的课程名）
- **赛事品牌**：老字号新声代·青年数字营销达人赛

命名逻辑：不直接叫"MCN孵化"——MCN在公众认知中等同签约主播机构，与"不签约"的核心定位冲突，政府、高校、家长三方都容易误读。"数字营销官"五个字给出明确岗位指向，让学生看到名字就知道"参加完能干什么"；MCN概念降级为"运营模式"定语，保留其效率与专业性暗示，但规避身份歧义。

### 2.4 结构概念：入口—过程—出口

```
大赛（入口）——选拔有潜力学生，制造传播声量
    ↓
孵化营（过程）——课程培训 + 门店实战 + 导师陪跑
    ↓
人才库+就业对接（出口）——老字号就业/平台生态就业/代理公司就业/创业孵化
```

## 三、项目目标

### 3.1 总目标

建成一个可持续运营的黄浦老字号数字营销人才孵化平台：**让老字号有人可用，让大学生有班可上，让"老字号·新活力"品牌再上一个台阶。**

### 3.2 量化指标（建议值，最终与就促中心对齐）

**育人维度**
- 覆盖高校≥15所（含上海及长三角高校）
- 报名学生≥500人（对标2024年中华杯530人规模）
- 孵化课程结业≥100人
- 建成"老字号青年数字营销人才库"入库≥200人

**传播维度**
- 老字号参与≥10家，发布真实创新需求≥15项
- 学生产出可发布内容作品≥300件（含AI辅助创作）
- 赛事全程内容总曝光≥500万（平台统计口径）

**就业维度（核心KPI）**
- 达成实习/见习/就业对接≥50人
- 其中明确就业（含offer/入职）≥20人
- 就业跟踪周期：结业后3/6/12个月回访，形成就业成效报告

**品牌维度**
- 赛事成为"老字号·新活力"专项行动年度标杆活动
- 沉淀"门店内容空间"改造示范案例≥3个
- 形成可复制的"政府+平台+代理+高校+老字号"五方协同模式

## 五、比赛设计：老字号新声代·青年数字营销达人赛

### 5.1 设计原则

- **真实命题**：所有赛题来自老字号真实经营需求，作品直接服务企业经营，不做虚拟命题；
- **AI贯穿**：AI工具全程允许且鼓励，设AI应用专项赛道，呼应年度热点；
- **赛训一体**：比赛不是孤立的淘汰赛，而是与孵化营课程咬合的进阶路径——比到哪一关，课程跟到哪一层；
- **门店即考场**：决赛级考核在老字号真实门店完成，线下探店与线上实训同频。

### 5.2 赛制设计（四阶段）

**阶段一：报名海选（线上）**
- 报名条件：上海及长三角高校在校大学生（含毕业两年内青年），专业不限
- 提交内容：个人简历 + 一条自选主题的短视频或图文作品（1分钟以内）
- 评审方式：讲师团初筛，择优200人进入初赛
- 目的：低门槛广撒网，AI工具降低创作门槛后，非传媒专业学生也能拿出作品

**阶段二：初赛（线上命题创作）**
- 老字号企业发布创新需求命题（每家1-2题），选手任选其一创作
- 命题示例：
  - "用一条60秒视频讲活邵万生的百年酱香"
  - "给三阳南货设计一套中秋伴手礼的种草笔记"
  - "为沈大成设计一个年轻人愿意打卡的门店体验动线"
  - "用AI为老大同创作一支国潮风广告片"
- 评审方式：企业代表+讲师团打分，择优100人晋级孵化营
- 目的：检验内容创作能力与品牌理解力

**阶段三：复赛（孵化营+门店实战）**
- 100名晋级选手进入达人孵化课程（详见第六章），完成六大模块培训
- 实战考核：分组进驻老字号门店，完成三项任务——
  1. 门店探店内容制作（图文+短视频，真实发布）
  2. 门店实景直播模拟（考核话术、节奏、互动）
  3. 门店"内容空间"改造提案（针对门店动线、打卡点、Citywalk适配）
- 评审方式：四方评审团（企业+平台+代理+高校）打分+作品真实传播数据加权
- 择优30人晋级决赛
- 目的：真实场景检验，产出可直接发布的内容资产

**阶段四：决赛（路演+直播实战）**
- 形式：决赛日分两场——
  - 上午：个人路演（作品展示+商业价值陈述+评委问答）
  - 下午：老字号专场直播实战（30名选手分组为老字号品牌做一场真实直播）
- 评审：四方评审团现场打分
- 奖项：冠军1名、亚军2名、季军3名、单项奖4名（最佳创意/最佳AI应用/最佳直播表现/最佳人气）
- 荣誉：获奖者获颁证书+奖金+孵化资源包（导师陪跑、平台流量扶持、实习直通卡）
- 目的：巅峰对决即传播事件，决赛直播本身成为一场老字号直播节

### 5.3 赛道设计（四赛道，贯穿初赛至决赛）

| 赛道 | 内容方向 | 对应老字号需求 |
|---|---|---|
| A 品牌内容创作 | 图文/短视频种草，老字号故事年轻化表达 | 品牌焕新、年轻客群触达 |
| B 直播网创实战 | 门店实景直播、产品讲解、直播话术 | 直播渠道从0到1 |
| C AI+老字号创新应用 | AIGC广告片、数字人导览、AI门店体验 | 数字化升级、降本增效 |
| D 门店内容空间提案 | 门店改造为"内容空间"的提案（适配Citywalk动线） | 场景焕新、到店引流 |

选手可跨赛道提交作品，每人至多2个赛道；评审按赛道分别计分，决赛奖项按赛道+综合双轨评定。

### 5.4 评审机制

**四方评审团**（每个赛道3-5人）：
- 老字号企业代表（命题方，懂品牌与生意）
- 平台方运营专家（懂算法与流量）
- 代理公司总监（曼拾等，懂商业转化与内容方法论）
- 高校教授（懂学术规范与人才培养）

**评分维度**：创意性30% + 商业价值30% + 内容质量20% + 传播潜力20%
**传播数据加权**：进入复赛后的作品，其真实发布数据（播放/互动/转化）按10%-20%权重计入总分——让市场反馈参与打分，也倒逼学生理解"内容要服务效果"。

### 5.5 奖项与激励

- 奖金：冠军2万元、亚军1万元、季军5000元、单项奖3000元（建议值）
- 证书：就促中心+联合主办单位盖章的获奖证书（含金量高，可写入简历与综评）
- 孵化资源包：3个月导师陪跑、平台流量扶持（话题/活动位）、老字号实习直通卡、人才库优先推荐权
- 特殊激励：优秀作品获得真实投放机会（由曼拾等代理企业协助落地为真实商业投放，作品署名归学生）——这是其他大赛没有的差异化激励

## 六、培训体系：达人孵化课程

### 6.1 课程定位

不是普通讲座式培训，而是"理论+实操+陪跑"三位一体的MCN化孵化课程。吸收就促中心原想法精华——**"场景与IP融合、门店升级为内容空间、适配Citywalk、线下探店与线上实训同频"**——并升级为完整的六模块课程体系。

### 6.2 六大课程模块

**M1 老字号文化认知与商业逻辑（认知底座）**
- 老字号品牌地图：黄浦老字号的百年脉络与商业逻辑
- 非遗技艺与匠人故事：如何把工艺翻译成内容
- 场景叙事方法论：强场景如何变成强内容
- 授课：老字号品牌经营管理人员、非遗传承人、文化专家
- 形式：课堂+企业参访+名匠对话（呼应"名匠带徒"传统）

**M2 内容创作方法论（专业核心，曼拾主授）**
- 平台算法与流量逻辑：小红书/抖音/视频号的内容分发机制
- 种草方法论：KFS模型（KOL种草+KOC铺量+信息流放大）实战拆解
- 选题、文案、视觉、剪辑：从0到1产出商业级内容
- 数据复盘：用数据迭代内容
- 授课：曼拾核心团队（广告代理专业输出）+ 平台方运营专家
- 形式：课堂+workshop+作业批改

**M3 AI工具实战（时代热点，差异化王牌）**
- AIGC文案工具链：选题、脚本、标题的AI工作流
- AIGC图片/视频工具链：文生图、图生视频、数字人
- AI剪辑与提效：从10小时到1小时的内容生产流程
- AI应用边界与合规：内容标注、版权、平台AI规则
- 授课：AI行业专家 + 一线操盘手
- 形式：实操工作坊（人手一机，当场产出AI作品）

**M4 直播与短视频实操（技能硬核）**
- 直播间搭建与场景设计（老字号门店场景适配）
- 直播话术脚本：开场、讲解、逼单、互动
- 场控与复盘：数据看板、问题诊断
- 短视频完播率优化：钩子、节奏、封面
- 授课：MCN机构操盘手、头部达人、平台直播运营
- 形式：理论+门店实景直播演练（在邵万生、三阳南货等门店实战）

**M5 IP与人设打造（场景与IP融合）**
- 个人账号定位：我是谁、为谁做、做什么
- 内容人设设计：Citywalk探店人设、老字号青年体验官等
- 场景与IP融合：让门店成为人设的舞台
- IP商业化边界：接广、带货、就业的合规路径
- 授课：达人导师 + 曼拾策略团队
- 形式：1V1定位咨询 + 账号运营实战

**M6 职业化训练（就业直通，本项目灵魂）**
- 作品集打造：把课程成果整理成求职级作品集
- 简历与面试：数字营销岗位的面试要点
- 职场素养：从学生到职场人的第一课
- 老字号行业认知：在这个行业工作是什么体验
- 授课：就促中心首席创业指导师工作室 + 企业HR + 曼拾团队
- 形式：模拟面试 + 双选会实战

### 6.3 教学形式（升级版"AI+新媒体陪跑计划"）

借鉴并升级2023年已验证的"AI+新媒体"创业陪跑计划模式（每两天日评、每周1V1复盘、每双周分享课）：

- **三天线下集训营**：六大模块集中授课（M1-M3）+ 直播/探店实操启蒙
- **六周导师陪跑**：每两天一次作品日评、每周一次1V1复盘、每双周一次分享课——学员在陪跑期内完成个人账号冷启动
- **门店实战月**：分组进驻老字号门店，完成探店内容、直播演练、内容空间提案三项实战
- **线上课程平台**：录播课+直播课+资料库，支持非上海学生参与
- **结业考核**：学分制，完成全部模块+实战任务+作品集，颁发结业证书

### 6.4 证书体系（三层）

1. **结业证书**：《老字号青年数字营销官结业证书》（就促中心+老字号企业联合认证）——全员结业即发
2. **达人认证**：实战考核优秀者获《老字号青年数字营销达人认证》——进入人才库优先推荐
3. **获奖证书**：赛事获奖证书（政府背书，就业直通凭证）

## 七、宣导方案

### 7.1 传播主线与话题资产

- **核心话题**：#老字号新声代 #老字号青年数字营销官 #老字号Citywalk
- **传播主线**：不是"招人参赛"，而是"一场老字号与年轻人的双向奔赴"——让社会看到老字号在年轻化，让年轻人看到老字号的新机会
- **内容资产化**：赛事全程所有选手作品、花絮、导师金句、老字号故事均为可复用内容资产，赛事结束即沉淀为"老字号·新活力"的内容素材库

### 7.2 三阶段传播节奏

**阶段一：预热期（报名前2周）**
- 官宣海报与宣传片：老字号掌门人+非遗匠人+高校学生同框，制造期待
- 校园大使招募：每所合作高校招募2-3名校园大使，负责校内扩散（大使本身获得社会实践证明）
- 老字号门店话题预热：门店设置"新声代"主题物料，扫码了解赛事
- 政务新媒体发布：就业促进中心公众号/视频号首发

**阶段二：招募期（3-4周）**
- 高校渠道：就业办/团委官方发文、校园宣讲会（走进10余所高校，延续成熟打法）、社团合作、学生社群投放
- 平台渠道：小红书话题页运营、信息流扶持（平台方资源）、抖音挑战赛、美团本地生活活动位
- 门店渠道：老字号门店物料+店员话术引导（"在拍我们店的年轻人都能参加"）
- 内容激励：优秀报名作品提前获得展示位，制造"参赛即曝光"效应
- 关键机制：**报名即参与传播**——报名作品带话题发布，海选期即为赛事造势

**阶段三：赛程期（6-8周）**
- 赛事进程内容化：每阶段产出赛事花絮、选手故事、导师金句、老字号冷知识
- 门店实战阶段直播切片传播：探店vlog、直播高光时刻
- 决赛直播：老字号专场直播节（决赛日=传播峰值日）
- 成果展：决赛后举办"老字号新声代成果展"（优秀作品+人才库开放），邀请企业HR到场，兼作就业对接会

### 7.3 渠道矩阵与分工

| 渠道 | 主体 | 动作 |
|---|---|---|
| 高校渠道 | 就促中心+高校 | 官方发文、宣讲会、校园大使 |
| 平台渠道 | 小红书/抖音/美团 | 话题运营、流量扶持、活动位 |
| 政务渠道 | 就促中心 | 公众号、视频号、媒体报道 |
| 老字号渠道 | 老字号企业 | 门店物料、官号联动、员工转发 |
| 专业渠道 | 曼拾 | 行业社群、KOL/KOC资源、案例包装 |

## 八、就业转化机制（核心差异化——让大学生有班上）

### 8.1 全程人才建档

从报名起为每位学员建立数字档案：能力测评+课程成绩+实战表现+作品集+企业评价，结业自动入库，形成《黄浦区老字号青年数字营销人才库》。**人才库是本项目给政府的核心交付物**——它让"就业促进"从活动口号变成可持续运营的资产。

### 8.2 四条就业出口

**出口一：老字号企业就业（主出口）**
- 实习/见习直通：对接既有实训基地见习机制，结业学员优先进入老字号实习见习（已有17个岗位/13人见习的既往基础）
- 面试绿色通道：获奖者免初筛进入老字号企业面试
- 定向招聘：人才库按季度向老字号企业推送匹配人才

**出口二：平台生态就业**
- 平台方生态内岗位推荐：MCN机构、品牌服务商、内容制作公司、达人经纪
- 平台官方合作资源：小红书生态服务商名录对接

**出口三：代理公司就业（曼拾等）**
- 曼拾开放实习与初级岗位（内容策划、媒介执行、客户执行等）
- 行业联动：联合上海广告代理行业企业开放岗位

**出口四：创业孵化**
- 优秀学员创业项目可入驻老字号公共创业实训基地孵化（延续"孵化创业组织"既有模式）
- 创业指导：首席创业指导师工作室跟踪辅导

### 8.3 就业对接活动

- **结营双选会**：决赛后举办，老字号企业+平台生态企业+代理公司摆摊，学员路演作品集现场双选
- **人才库定向推送**：季度推送机制，人才库向合作企业开放查询
- **就业追踪**：结业后3/6/12个月回访，形成就业成效数据（就业率、岗位类型、薪资、留存），写入政府就业服务成效报告

### 8.4 就业数据闭环（项目灵魂）

```
报名建档 → 培训评估 → 实战考核 → 结业入库 → 双选对接 → 就业追踪(3/6/12月) → 成效报告 → 下一年度优化
```

就业数据不是赛后统计，而是全过程沉淀——这正是本项目与过往赛事最本质的区别。

## 十一、曼拾：作为支持企业的角色定位（专章）

### 11.1 定位

曼拾作为**项目支持方（广告代理侧）**参与，承担三重角色：**课程共建方、导师评委方、就业出口方**。曼拾是深耕小红书整合营销的专业代理机构（覆盖KFS、灵犀、聚光、蒲公英等平台产品），天然是"政府+平台+高校+老字号"四方之间的翻译器——既懂平台规则，又懂品牌生意，还懂内容方法论。

### 11.2 五大具体贡献

**1. 课程共建（专业输出）**
- 主导开发M2内容创作方法论模块：KFS模型、小红书种草实战、数据复盘方法论
- 提供真实操盘案例库：曼拾服务消费品牌的实战案例作为教学素材（脱敏处理）
- 联合开发AI内容工作流课程（M3）：把AIGC工具链做成可复制的标准流程

**2. 导师与评委**
- 逸凡及核心团队担任课程导师，参与全程陪跑辅导
- 担任赛事四方评审团评委（广告代理侧）
- 提供一对一职业咨询（数字营销方向）

**3. 就业出口**
- 开放实习与初级岗位：内容策划、媒介执行、客户执行、数据分析等方向
- 优秀学员优先录用，形成"孵化计划→曼拾实习→行业成长"通道
- 联动广告代理同业开放岗位资源

**4. 传播与落地支持**
- 赛事传播策略支持（宣发方案、话题运营、内容节奏）
- 帮助老字号把获奖方案落地为真实投放：学生作品→专业优化→真实上线（KFS执行），作品署名归学生——形成"方案到投放"的完整闭环，也让就促中心的赛事成果可见、可量化

**5. 项目长期共建**
- 参与项目年度迭代：基于就业追踪数据优化课程与赛制
- 共建"老字号数字营销案例库"：赛事优秀案例沉淀为黄浦老字号数字化营销的可复制资产

### 11.3 对曼拾的价值（互利逻辑）

曼拾不是单方赞助，而是多方共赢：
- **人才储备**：提前锁定经过实战检验的数字营销人才，降低招聘试错成本
- **客户关系**：深化与老字号企业、区政府的合作关系，打开老字号数字化营销服务市场
- **品牌背书**：参与政府标杆项目，提升曼拾在行业与客户中的专业公信力
- **方法论沉淀**：赛事中验证的内容方法论可反哺曼拾自身服务能力

## 十二、风险与保障

| 风险 | 应对 |
|---|---|
| 学生参与度不足 | 证书+奖金+就业直通三重激励；AI降低创作门槛扩大生源；校园大使渠道；与高校学分/综评联动 |
| 老字号配合度不足 | 区商务委背书动员；命题轻量化（企业只需出命题和门店场景，执行由秘书处承担）；成果反哺企业（作品+人才+传播曝光） |
| 内容合规风险 | AI内容标注规则前置培训；作品知识产权约定（学生署名、企业使用授权范围明确）；平台规则合规纳入课程 |
| 就业转化不及预期 | 保底机制：实训基地见习承接；数据透明：就业追踪如实呈现，不美化；目标分档（对接数/就业数/满意数） |
| 平台资源承诺落空 | 资源协议前置书面确认；多平台并行分散依赖；曼拾等代理方作为平台资源落地执行方 |
| 执行质量风险 | 第三方执行机构+工作组例会制度（周例会+里程碑评审）；关键节点成果验收 |
