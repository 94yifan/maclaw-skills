## 二、报告标准结构（固化版）

```
品牌概览模板（module_h）
  一、品牌概览 — 1.1基础信息(≥8维度表格) + 1.2品牌发展里程碑(≥8事件) + 1.3规模判断
  二、产品与品类矩阵 — 2.1核心品类(≥4品类表格) + 2.2定价带(≥6行) + 2.3品类结构
  三、渠道与供应链 — 3.1渠道演变路径(≥4阶段表格) + 3.2供应链能力(表格)

第一章：核心发现与咨询窗口（1-2页）
  - 核心发现（5-8条，每条=判断+数据锚点+战略含义）
  - 咨询窗口（1-2个）

第二章：行业格局与竞品总矩阵（2-3页）
  - Porter五力扫描 + 行业规模与增速 + 竞品总矩阵

第三章：竞品多维度扫描（8-15页）
  - 深度品牌五维扫描（每维1-3段，五维强制：市场渠道/品牌力/产品/趋势/人群）
  - 汇总品牌总述（每品牌一段五要素）
  - 参考品牌分析（核心信息+可比性判断）
  - 竞争模式总结

第四章：本品深度分析（4-8页）
  - 五维深度诊断（比第三章竞品基线更详细，≥1.5倍篇幅）
  - 趋势：已做趋势(含具体动作) + 可做趋势预判(赛道/营销/情绪)

第五章：咨询切入点与策略建议（2-3页）
  - 品牌层策略 + 集团层战略议题 + 咨询项目范围

第六章：创品策略（2-3页）
  - ≥10个方向，跨界借鉴型+原创型

附录：创始人研究（≥40行，≥3篇原生稿件）+ 数据核验表
```

## 三、五维模型强制展开标准

每个维度的子项要求（QA B-6/B-7 自动检查）：

**市场/渠道** — 营收数据+渠道结构+增长趋势+平台表现
**品牌力** — ①品牌力(定位叙事+营销资产+社媒四平台表现) ②组织力(治理/团队/经销商/架构)
**产品** — 核心爆款+SKU矩阵+定价带+评价关键词
**趋势** — ①已做趋势(具体产品/动作+捕获质量) ②可做趋势(赛道/营销/情绪三类预判)
**人群** — 核心用户画像+消费场景

## 四、QA 检查体系（34项，v1.5）

### A. 结构性检查（4项）
- A-1: 章节完整性 — 六章+附录缺一不可
- A-2: 深度品牌五维一致性 — 每个deep品牌必须包含全部五个维度
- A-3: 汇总品牌要素完整性 — 每品牌一段五要素
- A-4: 内容完整性 — 完整句子表达，非关键词碎片

### B. 内容检查（7项）
- B-1: 数据锚点覆盖率 — ≥60%段落含数字
- B-2: 结论先行 — 每段首句是可独立理解的判断句
- B-3: 段落结构 — 判断→数据→收尾
- B-4: 禁止AI腔 — 14项禁止短语命中=0
- B-5: 品类/渠道拆分 — 不同渠道分别陈述
- B-6: 品牌力子维度完整性 — 组织力+社媒5关键词≥3/5覆盖
- B-7: 趋势子维度完整性 — 已做趋势+可做预判均有

### C. 图表检查（6项）
- C-1/C-2: 图表存在性+顺序 — 4张mandatory，天猫→京东→斤价→回头客
- C-3/C-4: 标签完整性+标题规范性 — X/Y轴中文品牌名，含数据源+指标
- C-5/C-6: 图表嵌入位置+数据源标注

### D. 颗粒度检查（7项）
- D-1: 总行≥800
- D-2: 总字符≥60KB
- D-3: 核心发现≥5条
- D-4: 每个深度品牌五维≥30行
- D-5: 创始人≥40行
- D-6: 创品≥10个方向

### D. 交付检查（6项）
- D-1～D-5: 维度一致性、图表标签、数据完整、导航标题、ch5维度标注
- D-6: **版本号规范** — 文件命名「品牌中文名-行业-V数字.数字-日期.docx」

### E. docx标题结构（1项）
- E-1: Heading1≥2, Heading2≥3, Heading3≥5

## 五、版本号规则

**文件命名格式：** `品牌中文名-行业-V数字.数字-日期.docx`

**升降规则：**
- 整数升版（V1→V2→V3）= 结构改动：增删章节、补全缺失模块、输出结构调整
- 小数升版（V2.1→V2.2→V2.3）= 文字改动：修bug、改措辞、调数据、修格式

**检查点：** QA D-6自动检查 + docx_builder生成时打印验证

## 六、文风铁律

**硬性禁止（完本检查命中=0）：**
未查到、待验证、估计、大概、综合判断、推测、建议通过XX补充、需要说明的是、目前公开信息不足以判断、有待进一步确认、关键数据缺口、免责声明、本报告基于XX完成

**AI填充词禁止：** 当然、其实、本质上、整体而言、从某种意义上说、目前来看、这意味着、值得关注、众所周知

**写作格式：** 结论先行、自然段落、不起装饰符号（「」/""/''）、不星号破折号列表体

## 七、今天新增的约定（2026-07-21）

1. **Pipeline 执行铁律**：读到触发词→建config→跑pipeline.py→spawn Pro→QA→发群。零判断，零手工
2. **品牌概览模板**：三个表格章节（品牌概览/产品矩阵/渠道供应链），docx_builder 必须加载
3. **品牌力拆两层**：品牌力（定位+社媒）+ 组织力（治理/团队）
4. **趋势拆两段**：已做趋势 + 可做趋势（赛道/营销/情绪三类）
5. **Deep品牌自动合并**：ch3_competitor_scan.md 含摘要，deep_*.md 含完整五维，docx_builder 自动合并
6. **表格渲染**：python-docx Table API 替代 pipe 纯文本
7. **行内格式**：`**bold**` → Word 真粗体，不显示星号
8. **版本号规则**：整数=结构，小数=文字。QA D-6 + docx_builder验证
9. **发群强制**：生成后立刻发群，逸凡不Access电脑
10. **不新建独立MD文件**：复盘写进SKILL/SOUL/MEMORY/breat-skill，不额外创建日期文件
