# 3.2 汇总品牌速览

汇总品牌的作用是补全赛道光谱，让深度品牌之外的竞争主体也能进入对比视野。以下品牌按体量与合作关系分组，每个品牌一段，聚焦定位、渠道、产品与对本项目的参照价值。

卫龙食品是辣条第一股，2024年营收62.66亿元，同比增长28.6%，辣条业务收入26.67亿元、同比增长4.6%，魔芋爽贡献约30亿元，是典型的自主制造加量贩渠道增长派（evidence_tier：reported）。它的价值在于证明了用制造能力和大单品矩阵可以在零食赛道做出高增长，同时用第二曲线对冲单品老化。

甘源食品2024年营收22.57亿元，同比增长22.18%，净利润3.76亿元，以坚果炒货和豆类零食为主，主打自主制造与渠道下沉（evidence_tier：reported）。它的参照价值在于多品类零食平台如何用量贩渠道放大规模。

好巴食是豆干与休闲素食零食品牌，定位川味素食零食，渠道以商超与流通为主，是区域零食品牌全国化的样本。它的参照价值在于素食品类如何在卤味主导的赛道里找到差异化空间。

麻爪爪是川渝风味卤味零食品牌，主打即食凤爪与鸭副产品，线上内容与线下流通并行，属于凤爪赛道的区域竞争主体。它的参照价值在于同类凤爪品牌如何在口味差异化上做文章。

盛香亭是新中式热卤的代表，主打现制热卤，把卤味做成即食的热食体验，与预包装卤味形成场景区隔。它的参照价值在于现制卤味对预包装卤味的场景替代压力。

绝味食品是门店数量领先的休闲卤味连锁，门店规模超万家，但2025年出现首亏，正在收缩与提效（evidence_tier：reported）。它的参照价值在于线下连锁模式在零食化浪潮中的压力测试。

煌上煌是江西卤味连锁品牌，以酱卤禽类为核心，渠道以线下连锁和商超为主，是传统卤味上市企业之一。它的参照价值在于区域卤味品牌全国化扩张的难点。

紫燕食品以佐餐卤味为核心，主打夫妻肺片等佐餐场景，与休闲零食卤味形成场景互补。它的参照价值在于佐餐卤味与零食卤味的边界与协同。

久久丫是华东区域卤味连锁品牌，以鸭脖、禽类卤味为主，线下门店密集，是区域连锁的代表。它的参照价值在于区域密度对品牌壁垒的作用。

小鲜卤是新锐卤味零食品牌，主打鲜卤概念与短保产品，线上内容驱动，属于卤味零食的新势力。它的参照价值在于短保和鲜卤概念能否支撑差异化溢价。

良品铺子是高端零食集合品牌，以全品类零食平台为定位，渠道覆盖线上线下，是量贩渠道冲击下高端零食平台的转型样本。它的参照价值在于零食平台在面对量贩渠道时的价格与品类压力。

来伊份是上海起家的休闲零食连锁，以线下门店和自有品牌为核心，属于老牌零食连锁。它的参照价值在于老牌零食连锁如何在渠道变迁中守住基本盘。

百草味是线上起家的全品类零食品牌，后被并入大型食品集团，以电商销售为主，是线上零食品牌的代表。它的参照价值在于线上零食品牌在流量成本上升后的路径选择。

三只松鼠是零食全品类平台，2024年营收106.22亿元，同比增长49.30%，从线上向线下和量贩渠道扩张，是零食赛道体量最大的品牌之一（evidence_tier：reported）。它的参照价值在于平台级零食品牌如何用全渠道对冲单一渠道波动。

区域凤爪品牌是凤爪赛道里广泛存在的地方性中小品牌，通常依托本地流通和商超渠道经营，产品以泡椒或卤味凤爪为主，缺少品牌化运营和全国化能力。区域卤味零食品牌则是更宽泛的一类地方卤味零食企业，品类覆盖禽类、豆制品和素食卤味，优势在于本地口味和渠道，劣势在于规模与标准化。两者共同构成了赛道长尾，也构成了量贩渠道扩张中最容易被整合的产能来源。


## 参照品牌的模式归纳

把汇总品牌按模式归类，可以得到三组清晰的参照。第一组是自主制造加量贩渠道的增长派，包括卫龙食品、甘源食品，它们的共性是制造能力强、渠道下沉彻底、用多品类对冲单品风险。这一组是王小卤在成本与品质上的对标对象（evidence_tier：reported）。

第二组是零食平台派，包括良品铺子、来伊份、百草味、三只松鼠，它们的共性是全品类覆盖、渠道线上线下并行，规模大但品牌溢价薄。三只松鼠2024年营收106.22亿元、同比增长49.30%，说明平台级品牌在量贩和全渠道扩张下仍有强增长（evidence_tier：reported）。这一组是王小卤在品类扩张上的参照，也是它做卤味零食平台时会正面遭遇的对手。

第三组是卤味专业派，包括绝味食品、煌上煌、紫燕食品、久久丫、麻爪爪、盛香亭、小鲜卤，它们的共性是围绕卤味做深，或做连锁门店，或做现制热卤，或做短保鲜卤。这一组说明卤味品类内部的场景分化正在加剧，预包装、现制、佐餐三种场景各有玩家，王小卤要守住零食场景的心智，就必须在预包装零食这个位置持续做深，而不是贸然进入现制和佐餐场景。好巴食这类素食零食品牌则提供了差异化参照，说明在卤味主导的赛道里，素食和豆制品仍有独立空间。

## 对王小卤的直接参照价值

汇总品牌里，对王小卤最有直接参照价值的是三类。第一类是三只松鼠、良品铺子这类零食平台，它们展示了全品类平台在量贩和全渠道扩张下的机会与压力，是品牌做卤味零食平台时的远期参照。第二类是有制造底盘但内容能力偏弱的量贩派品牌，它们展示了制造能力的价值，也暴露了内容短板的代价，是品牌补制造课时的反向参照。第三类是绝味、周黑鸭这类卤味专业派，它们展示了卤味品类的场景边界，提示品牌不要贸然越过预包装零食的场景去竞争。

参照的意义在于少走弯路。品牌可以看到，纯靠内容和流量的品牌在流量红利消退后会遇到规模天花板，而纯靠制造和渠道的品牌在品质升级和品牌溢价上会受限。两类品牌的共同短板分别是制造和内容，而王小卤的优势恰好是内容。因此品牌最理性的路径，是守住内容优势的同时补齐制造短板，用两条腿走路的模式，而不是在单一维度上孤注一掷。

从赛道结构看，参照品牌的存在也提示了竞争的时间窗口。量贩渠道的红利仍在释放，但释放的速度会随渠道集中度上升而放缓。品牌在制造和渠道上补课的时点越早，越能享受到渠道红利的尾巴；补课越晚，越可能要付出更高的成本才能获得同样的份额。时点判断是品牌当前战略决策里不可忽视的变量。

## 汇总品牌的方法论价值

汇总品牌不只是补全赛道的信息，它的方法论价值在于提供模式参照。通过观察不同模式品牌的成败，品牌可以判断自己所在的模式是否还有空间，以及需要向哪些模式借鉴。增长派的成功说明制造和渠道的价值，传统派的困境说明模式和场景的重要性，平台派的扩张说明全品类的机会与代价，这些都是品牌做战略判断时的镜子。

方法论价值还体现在模式迁移的经验上。卤味赛道内还没有品牌完成从新锐线上派向制造能力派的成功迁移，这意味着品牌如果做成，会是一次模式迁移的示范；如果做不成，会暴露模式迁移的结构性障碍。品牌在迁移过程中积累的经验和能力，本身可能成为区别于同行的竞争优势。

从竞争格局看，汇总品牌的多样存在说明赛道尚未定型。一个定型的赛道会只剩下少数模式相似的头部玩家，而当前的卤味零食赛道仍有多种模式并存，说明赛道仍处于格局未定的阶段。格局未定意味着机会仍在，谁先完成关键能力的补课，谁就可能在新格局中占据更有利的位置（evidence_tier：reported）。
