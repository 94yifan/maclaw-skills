# 第1章 核心发现与咨询窗口

## 一、核心发现

瑞幸即享咖啡站在一个独特的位置上，它背靠中国最大的连锁咖啡品牌，却在一个由纯零售品牌主导的赛道里重新出发。它的核心矛盾是，手里握着预包装咖啡赛道里最稀缺的一张牌，即门店体系沉淀的爆款心智和国民认知，但要把这张牌在速溶、咖啡液、瓶装即饮三个品类上分别打出来，需要跨越的是三套完全不同的竞争结构（evidence_tier：mapped）。

核心发现一：瑞幸即享最大的资产是门店爆款心智，而这张牌远没有被充分使用。生椰拿铁、酱香拿铁、橙C美式这些门店爆款，已经把瑞幸和敢于创新、平价好喝、自带流量绑定在了一起，9.9元的心智更是把瑞幸和极致性价比划了等号。三顿半、永璞、隅田川没有瑞幸的国民级门店认知，雀巢、麦斯威尔只有传统速溶的老牌认知。瑞幸即享要做的是把这套门店心智系统化地迁移到货架上，但目前它还停留在浅尝辄止的阶段，没有一款产品真正把门店爆款的势能完整搬运到预包装（evidence_tier：mapped）。

核心发现二：三个品类的竞争结构完全不同，不存在一套打法通吃。冻干咖啡粉已经被三顿半用精品化重新定义，竞争的是精品化和性价比心智；咖啡液由永璞、隅田川先发占领，竞争的是便携和新鲜感；瓶装即饮由雀巢、星巴克双雄主导，竞争的是货架位置和渠道分销。瑞幸即享用同一套品牌资产同时切入三个品类，是机会也是风险，资源分散可能导致三块都做不透（evidence_tier：reported）。

核心发现三：瑞幸即享的强项和短板都异常清晰。强项是供应链的规模采购和门店流量入口，这是雀巢、三顿半都没有的结构性优势，2万多家门店本身既是流量入口也是消费场景，门店会员体系能直接触达海量咖啡消费者。短板是线下分销网络和电商内容运营，瓶装即饮要靠经销商铺货、电商要靠内容种草投流，这两块能力瑞幸的门店体系给不了，需要从零补起（evidence_tier：mapped）。

核心发现四：瑞幸即享的胜负手在于把门店爆款心智系统化地迁移到货架。生椰拿铁浓缩咖啡液、生椰拿铁瓶装即饮、酱香风味冻干粉，这些把门店国民级爆款做成预包装产品的方向，是瑞幸即享相对所有竞品的独有优势。这条心智迁移的路，是它最短也最顺的一条路，关键是要做得深、做得系统，而不是把门店爆款零散地搬几个过来（evidence_tier：mapped）。

核心发现五：三品类的资源聚焦与节奏排序，是瑞幸即享最先要拍板的战略问题。冻干、咖啡液、瓶装即饮三个品类的竞争强度和机会窗口完全不同，冻干粉被三顿半的精品化牢牢占据、咖啡液有永璞隅田川的先发优势、瓶装即饮被雀巢星巴克的重渠道壁垒挡着，瑞幸即享如果三线并进、平均用力，很可能三块都做不透。最合理的节奏是先把门店爆款心智最强的品类做深做透，打出一款能定义品类的大单品，再带动另外两个品类，而不是一开始就全面铺开（evidence_tier：mapped）。

## 二、咨询窗口

燃创咨询的切入机会集中在四个方向，按优先级排序：

第一，门店爆款心智的预包装化迁移。把生椰拿铁、酱香拿铁、橙C美式等门店国民级爆款，系统化地做成冻干粉、咖啡液、瓶装即饮三类产品，形成一套瑞幸即享独有的爆款预包装产品矩阵。这是瑞幸即享相对所有竞品最独特的优势，也是投入产出比最高的一条路。

第二，门店加货架的双渠道联动。把瑞幸2万多家门店作为预包装产品的展示、体验和转化场景，用门店的会员资产和App流量反哺预包装产品的销售，同时搭建线下分销和电商内容运营能力。这条双渠道联动是雀巢、三顿半都无法复制的结构性优势。

第三，9.9元心智在零售端的定价策略设计。门店的9.9元是现磨体验价，预包装产品的成本结构和定价逻辑不同，如何在守住平价心智和建立零售端合理价格体系之间找到平衡，是瑞幸即享进入预包装赛道最先要拍板的策略问题。

第四，三品类的资源聚焦与节奏排序。冻干、咖啡液、瓶装即饮三个品类的竞争强度和机会窗口不同，瑞幸即享需要明确先打哪一个、后打哪一个，避免三线并进导致资源分散。这是决定瑞幸即享能否在预包装赛道站稳的战略优先级问题。
