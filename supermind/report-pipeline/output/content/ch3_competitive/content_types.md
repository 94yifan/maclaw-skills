# 3.6 内容类型五分类分析

## 猫哆哩

猫哆哩在各社媒平台的内容策略处于品类教育阶段，五类型分布如下：

曝光型内容占比约60%。品牌主要的内容输出为猫哆哩酸角糕从原料到制成的过程展示、云南印象广告投放、以及用户自发分享的云南特产推荐。曝光型内容的传播面主要靠品类新鲜感和地域特色驱动，而非观点争议或社会话题，破圈效应有限。代表性内容为B站原料视频（播放量1529）和云南印象广告（播放量1989），数据体量小但品类教育价值高。

涨粉型内容占比约5%。猫哆哩几乎没有系统化的资源推荐型或盘点型内容，账号涨粉主要依靠品类独占的自然搜索流量而非内容价值。

收藏型内容占比约5%。品牌未建立步骤/SOP/模板类的结构化知识内容，在酸角知识科普方面有潜力但未开发。

转化型内容占比约20%。天猫京东产品详情页是主要的转化内容，抖音直播带货有一定转化但频次和规模有限。

人设型内容占比约10%。老派云南滋味的品牌定位具备人设内容的叙事基础，但品牌尚未将创始人故事、品牌历程系统地转化为内容资产。

内容增长系统判断：猫哆哩目前的内容增长系统处于萌芽阶段——品类独占的自然流量驱动增长，而非内容策略驱动增长。品牌最需要突破的是将品类教育转化为涨粉型内容（酸角科普/健康零食盘点/云南美食推荐），将品牌资产转化为收藏型内容（酸角食用指南/健康零食搭配/云南美食地图）。evidence_tier: mapped。

## 溜溜梅

溜溜梅的内容类型分布是四个深度品牌中最成熟的：

曝光型内容占比约35%。明星代言视频、品牌广告campaign、新品发布会是主要曝光内容。肖战和时代少年团的代言带来了巨大的自然曝光量，品牌无需刻意制作争议性内容即可获得超额曝光。

涨粉型内容占比约20%。以梅子零食推荐、青梅功效科普、零食测评盘点为主，明星效应的外溢也带来了大量新增粉丝。

收藏型内容占比约10%。梅冻的制作工艺揭秘、青梅的营养价值数据等具有一定的收藏价值，但不是品牌内容策略的重点。

转化型内容占比约30%。天猫京东直播带货、抖音购物车转化、新品首发促销是主要的转化内容，转化效率在食品行业中属于高水平。

人设型内容占比约5%。品牌以产品为中心，创始人杨帆的创业故事不是品牌叙事核心。

内容增长系统判断：溜溜梅的内容增长系统以明星流量为核心引擎，转化型和曝光型并重，是典型的流量驱动模式。重复爆款倾向：明星代言的视频内容反复获得高互动，明星效应+新品发布是最可靠的内容公式。内容风险在于，如果明星解约且没有新的流量抓手，品牌的内容体系会出现巨大空洞。evidence_tier: mapped。

## 齐云山南酸枣糕

齐云山的内容策略几乎是空白状态：

曝光型内容占比约70%。用户自发分享和淘宝京东详情页是品牌的主要曝光来源，品牌几乎没有主动制作的内容。

涨粉型内容占比约5%。无系统性内容运营。

收藏型内容占比约5%。无。

转化型内容占比约15%。电商详情页和促销页是最主要的转化内容，抖音直播覆盖极为有限。

人设型内容占比约5%。无。

内容增长系统判断：齐云山完全依靠产品力和认证背书自然增长，在内容端是完全不设防的状态。连续28年绿色食品认证这一最强资产没有被转化为任何有传播力的内容，是品牌最大的资源浪费。参考王小卤的品类教育路径，齐云山至少应该围绕南酸枣多酚、野生健康、深山食材三个叙事建立基础内容体系。evidence_tier: mapped。

## 品世

品世的内容策略与齐云山类似，几乎没有主动的内容运营：

曝光型内容占比约80%。绝大部分为用户自发分享，品牌方几乎不制作内容。

涨粉型/收藏型/人设型内容均接近零。

转化型内容占比约20%。电商详情页是最主要的转化内容。

内容增长系统判断：品世在内容端完全空白，品牌认知几乎全部依赖消费者对云南酸角的既有认知，没有任何主动的内容建设。evidence_tier: mapped。

## 四品牌内容对比总结

| 品牌 | 主导类型 | 内容增长系统 | 重复爆款倾向 | 内容发育度 |
|------|---------|------------|------------|-----------|
| 猫哆哩 | 曝光型(60%) | 品类自然流量 | 无 | 萌芽 |
| 溜溜梅 | 曝光型(35%)+转化型(30%) | 明星流量驱动 | 明星代言内容反复爆 | 成熟 |
| 齐云山 | 曝光型(70%) | 产品力自然增长 | 无 | 空白 |
| 品世 | 曝光型(80%) | 无 | 无 | 空白 |

核心洞察：酸角食品赛道的三个品牌（猫哆哩、齐云山、品世）在内容端都严重投入不足，这是品类教育严重滞后的直接原因。溜溜梅对内容的全方位投入（特别是明星代言带来的传播效率）是其在品牌声量上遥遥领先的核心原因。猫哆哩的内容缺口同时也是机会——品类独占地位意味着只要开始做内容，竞争优势会指数级放大。
