# 黄浦区"老字号·新活力"青年数字营销官孵化计划

## 完整执行方案（2026-2027年度）V2.0

**项目定位：** 以MCN化运营模式（非签约属性），为黄浦老字号打造青年数字营销人才孵化平台
**主办单位：** 黄浦区就业促进中心（建议联合区商务委、区文旅局）
**支持企业：** 曼拾（广告代理·项目支持方）、平台方、老字号企业、高校及多元企业生态
**方案版本：** V2.2（2026年8月27日修订：平台中立化、作品分档制、企业生态展开、小红书属地核心平台、课程双轨分档体系+种草学认证接入）

## 一、项目背景与机遇

### 1.1 老字号之困：强场景、强叙事，但传播断层

黄浦区拥有全国最密集的老字号资源带——南京东路、淮海路、豫园三大商圈集聚了邵万生、三阳南货、老大同、沈大成、新雅粤菜馆、杏花楼、培丽酱菜、茂昌眼镜、吴良材眼镜、老庙黄金、童涵春堂、大世界等一批中华老字号与上海老字号。这些品牌共同拥有两个被反复验证的禀赋：

- **强场景**：百年门店、非遗技艺、匠人现场、历史建筑，天然具备"内容空间"潜质；
- **强叙事**：每个品牌背后都有数十年乃至上百年的故事、工艺与城市记忆，天然具备"内容素材"富矿。

但老字号普遍面临同一个断层：**品牌资产与年轻消费者的连接方式没有更新**。货架还是那个货架，门店还是那个门店，但年轻人获取信息和做消费决策的方式已经全面迁移到内容平台与数字渠道。老字号不是没有故事，而是没有一支能把故事翻译成年轻人语言、把门店变成打卡场景的内容队伍。

### 1.2 青年之困：有才华、有热情，但缺场景、缺出口

上海高校毕业生规模持续处于高位，就业结构性矛盾突出——企业招不到"会做数字营销的人"，学生找不到"能发挥数字营销能力的工作"。大学生普遍具备内容创作热情与学习能力，但缺少三个东西：

- **缺实训场景**：没有真实品牌、真实门店、真实需求让他们练手；
- **缺作品集**：没有商业级作品，求职时简历苍白；
- **缺岗位通道**：不知道"数字营销"有哪些岗位方向，也不知道去哪应聘。

### 1.3 时代之机：AI工具爆发 + 数字营销成为品牌标配 + 国潮文化红利

三重外部变量叠加，让今年的破题条件比过去八年任何时候都成熟：

- **AI降低创作门槛**：AIGC文案、图片、视频工具链成熟，非传媒专业学生也能产出专业级内容，生源池从"专业学生"扩大到"全体大学生"；
- **数字营销成为品牌标配**：无论内容种草、直播带货还是效果投放，品牌都急需能落地执行的人；
- **国潮与文化消费红利**：Citywalk、非遗热、国货自信，年轻人正在主动走向老字号——缺的只是"数字营销翻译官"。

**平台策略：全平台通识 + 属地核心平台。** 课程与赛制按"全平台"设计——老字号被看到，可能发生在小红书、抖音、视频号、B站、美团、淘宝直播等任何阵地；学生的数字营销能力应是跨平台、可迁移的通识能力。平台资源接入上，以**小红书为核心平台**：小红书办公地与注册地均在黄浦区，是天然的属地合作伙伴，具备政策协同、资源直通、人才留区的独特条件；同时开放其他平台资源按作品需要接入。

### 1.4 就促中心之基：八年品牌资产与已验证的方法论

黄浦区"老字号·新活力"创新创业专项行动自2017年5月首创首发，已沉淀为全国标杆：

- 入选联合国《上海手册》全球25个案例之一；
- 与7家老字号集团建立战略合作，建成星光色谷、邵万生、大世界演艺中心3家老字号公共创业实训基地；
- 累计发布老字号创新需求167项，组织创新创业活动171场，2万余人次参与，产生创新方案632个，促成51个创新合作对接意向；
- 赛事方法论成熟：中国好创意大赛辐射全国526所高校、6644件作品；2024年"中华杯"黄浦美食大赛530余名学生报名、360余组作品、17校宣发辐射近万名学生；
- **"AI+新媒体"创业陪跑计划已验证"培训+陪跑"模式**：三个月全流程陪跑（每两天日评、每周1V1复盘、每双周分享课），4家陪跑企业粉丝总量增长8.5%、活跃度提升4.6%、全渠道曝光超10万次。

**结论：体系完整、方法成熟、品牌响亮，唯一缺的是"从活动到人才资产"的沉淀闭环。** 过往赛事结束，作品归档，但人散了——学生没有持续成长通道，企业没有人才储备池，政府没有可追踪的就业成果。今年的"达人孵化"想法，恰好补上这一环。

**黄浦独有的属地闭环优势：** 小红书（办公地与注册地均在黄浦区）叠加黄浦老字号集聚区、高校资源、就促中心就业服务体系，使本项目具备全国罕见的属地闭环——头部内容平台总部、老字号场景、青年人才、政府就业服务同处一区，平台资源可直通、学生就业可留区、老字号焕新可落地。这是其他城区难以复制的竞争壁垒，也是本项目区别于全国同类赛事的最强卖点。

### 1.5 破题方向：把"比赛+培训"升级为"选拔—孵化—就业"完整闭环

以MCN化运营模式（非签约属性），建设"老字号青年数字营销官孵化计划"：**大赛是入口（选拔+引流），孵化营是过程（培训+实战+陪跑），人才库与就业对接是出口（让大学生有班上）**。

## 二、项目定位与命名

### 2.1 一句话定位

> 以MCN化运营模式，为黄浦老字号打造青年数字营销人才孵化平台——就业导向、老字号焕新、AI赋能三位一体。

### 2.2 与MCN的本质区别：不是签约生意，是育人平台

本项目核心表达是"孵化器"，不是真正的签约主播MCN。差异用"三不、三有"说清楚：

| 维度 | 签约MCN | 本计划 |
|---|---|---|
| 关系 | 签约绑定、抽成 | 不签约、不抽成、不绑定 |
| 对象 | 现成主播/达人 | 零基础大学生 |
| 目标 | 商业变现 | 就业育人与品牌服务 |
| 赋能 | 流量扶持+商业分成 | 方法课程+真实场景+就业出口 |
| 沉淀 | 机构利润 | 青年人才库+老字号内容资产 |

**孵化的是"人"的能力，不是"主播"的生意。** 学生获得的是可迁移的数字营销职业技能与真实作品集，老字号获得的是可持续的内容服务队伍，政府获得的是可追踪的就业成果。

### 2.3 命名体系（建议）

保留并沿用母品牌资产，新项目作为子品牌生长在"老字号·新活力"之下：

- **母品牌**：黄浦区"老字号·新活力"创新创业专项行动（沿用，不动）
- **子项目全称**：「老字号·新活力」青年数字营销官孵化计划
- **项目简称**：老字号新声代
- **定位语**：以MCN化运营模式，孵化老字号数字营销人才
- **课程品牌**：老字号·新活力达人孵化课程（保留就促中心原想法中的课程名）
- **赛事品牌**：老字号新声代·青年数字营销达人赛

命名逻辑：不直接叫"MCN孵化"——MCN在公众认知中等同签约主播机构，与"不签约"的核心定位冲突，政府、高校、家长三方都容易误读。"数字营销官"五个字给出明确岗位指向，让学生看到名字就知道"参加完能干什么"；MCN概念降级为"运营模式"定语，保留其效率与专业性暗示，但规避身份歧义。

### 2.4 结构概念：入口—过程—出口

```
大赛（入口）——选拔有潜力学生，制造传播声量
    ↓
孵化营（过程）——课程培训 + 门店实战 + 导师陪跑
    ↓
人才库+就业对接（出口）——老字号就业/平台生态就业/代理机构就业/创业孵化
```

## 三、项目目标

### 3.1 总目标

建成一个可持续运营的黄浦老字号数字营销人才孵化平台：**让老字号真正被看到，让大学生有班可上，让"老字号·新活力"品牌再上一个台阶。**

### 3.2 量化指标（建议值，最终与就促中心对齐）

**育人维度**
- 覆盖高校≥15所（含上海及长三角高校）
- 报名学生≥500人（对标2024年中华杯530人规模）
- 孵化课程结业≥100人
- 建成"老字号青年数字营销人才库"入库≥200人

**传播维度**
- 老字号参与≥10家，发布真实创新需求≥15项
- 学生产出可发布内容作品≥300件（含AI辅助创作）
- 赛事全程内容总曝光≥500万（平台统计口径）

**就业维度（核心KPI）**
- 达成实习/见习/就业对接≥50人
- 其中明确就业（含offer/入职）≥20人
- 就业跟踪周期：结业后3/6/12个月回访，形成就业成效报告

**品牌维度**
- 赛事成为"老字号·新活力"专项行动年度标杆活动
- 沉淀"门店内容空间"改造示范案例≥3个
- 形成可复制的"政府+平台+专业机构+高校+老字号"多元协同模式

## 五、比赛设计：老字号新声代·青年数字营销达人赛

### 5.1 设计原则

- **真实命题**：所有赛题来自老字号真实经营需求，作品直接服务"老字号被看到"这一核心目标；
- **AI贯穿**：AI工具全程允许且鼓励，设AI应用专项奖励，呼应年度热点；
- **多形态参赛**：产出一份营销方案、做一次真实带货、写一组种草笔记——不同能力形态均可参赛，不设唯一作品标准；
- **分档竞技**：按作品形态与难度分档，各档独立评审、独立设奖，让不同起点的学生都能找到自己的位置；
- **赛训一体**：比赛与孵化营课程咬合——比到哪一关，课程跟到哪一层；
- **门店即考场**：实战考核在老字号真实门店/真实渠道完成，线下探店与线上实训同频。

### 5.2 赛制设计（四阶段）

**阶段一：报名海选（线上）**
- 报名条件：上海及长三角高校在校大学生（含毕业两年内青年），专业不限
- 提交内容：个人简历 + 一份自选方向的初试作品（笔记/短视频/方案提纲均可，形态不限）
- 评审方式：讲师团初筛，择优200人进入初赛
- 目的：低门槛广撒网，AI工具降低创作门槛后，非传媒专业学生也能拿出作品

**阶段二：初赛（按档命题创作）**
- 老字号企业发布真实创新需求命题（每家1-2题，见附录B），选手按所选档位（见5.3）任选命题创作：
  - 内容创作档：提交1-3条可直接发布的图文/短视频作品
  - 策略策划档：提交一份营销方案（结构见5.3）
  - 实战转化档：提交一份可执行的带货/投放计划书（实战放在复赛阶段）
- 评审方式：企业代表+讲师团按档位分别评审，择优100人晋级孵化营
- 目的：检验基本能力与品牌理解力，为分班培养提供依据

**阶段三：复赛（孵化营+分班实战）**
- 100名晋级选手进入达人孵化课程（详见第六章），按赛事档位与基础分层编班（对应通识营/进阶营/实战营课程档位）
- 实战考核（分班进行）：
  - 内容班：进驻老字号门店完成探店内容制作（真实发布），产出可传播内容资产
  - 策略班：围绕老字号命题产出完整营销方案并进行路演答辩
  - 实战班：完成真实直播带货或广告投放（真实转化数据计入评分）
- 评审方式：四方评审团（企业+平台+专业机构+高校）打分+真实数据加权
- 择优30人晋级决赛
- 目的：真实场景检验，产出可直接使用的商业级成果

**阶段四：决赛（分档竞技+直播实战）**
- 形式：决赛日分场进行——
  - 内容创作档决赛：作品展映+创作阐述
  - 策略策划档决赛：方案路演+评委质询
  - 实战转化档决赛：老字号专场直播实战（真实直播，转化数据实时计分）
- 评审：四方评审团现场打分，三档分别评定
- 奖项：各档设冠军1名、亚军2名、季军3名；另设单项奖（最佳创意/最佳AI应用/最佳直播表现/最佳人气）与全场总冠军（跨档综合评定）
- 荣誉：获奖者获颁证书+奖金+孵化资源包（导师陪跑、流量扶持、实习直通卡）
- 目的：巅峰对决即传播事件，决赛直播本身成为一场老字号直播节

### 5.3 档位设计：作品形态 × 实际难度评估（核心）

**档位一：内容创作力（入门档）——写笔记、拍视频、做探店**

| 维度 | 说明 |
|---|---|
| 作品形态 | 种草笔记/图文/短视频/探店vlog（1-3条），可含AI辅助创作 |
| 实际难度 | ★★☆☆☆（入门友好） |
| 时间投入 | 单条1-3天 |
| 技能门槛 | 基础内容创作+平台发布能力，AI工具可显著降低门槛 |
| 适合人群 | 全体学生，特别是非传媒专业、首次参赛者 |
| 评审侧重 | 选题与文案质量、画面呈现、真实传播数据（播放/互动） |
| 对老字号价值 | 直接可用的内容资产，作品真实发布即为品牌曝光 |

**档位二：策略策划力（进阶档）——产出一份完整的数字营销方案**

| 维度 | 说明 |
|---|---|
| 作品形态 | 营销方案书：品牌与市场诊断→目标人群洞察→传播策略→内容规划→渠道组合→预算分配→效果预估→执行节奏 |
| 实际难度 | ★★★☆☆（中等） |
| 时间投入 | 1-2周 |
| 技能门槛 | 市场分析、策略思维、方案撰写与表达；需要行业认知支撑 |
| 适合人群 | 商科/广告/市场营销专业，或有实习经验者 |
| 评审侧重 | 问题洞察是否准确、策略逻辑是否成立、商业可行性、路演答辩表现 |
| 对老字号价值 | 可执行的策略输入，方案落地后即成为品牌资产 |

**档位三：实战转化力（高阶档）——做一次真实的带货或投放**

| 维度 | 说明 |
|---|---|
| 作品形态 | 真实直播带货（单场）/短视频带货/广告投放实战，附真实转化数据与复盘报告 |
| 实际难度 | ★★★★☆（较高，但最值钱） |
| 时间投入 | 2-4周（含筹备、执行、复盘） |
| 技能门槛 | 直播表达/投流操作能力、数据敏感度、抗压能力 |
| 适合人群 | 有内容基础、敢于真实实战、愿意承受结果的学生 |
| 评审侧重 | 真实转化数据（GMV/ROI/转化率）+执行复盘质量 |
| 对老字号价值 | 直接可量化的销售与投放效果，是最硬的成果证明 |

**难度评估的实话实说（写给报名学生，也是赛制设计依据）：**
- 档位一：容易出量、难出彩——同质化竞争激烈，拼的是选题与细节；
- 档位二：容易空谈、难落地——方案要经得起"预算从哪来、谁来执行"的追问；
- 档位三：门槛最高、价值最大——真实数据不会说谎，但一份真实战报胜过十份漂亮方案。

**档位与奖项的关系：** 三档独立评审独立设奖，确保"写笔记的"不跟"做投放的"同场竞技；跨档另设全场总冠军，奖励综合能力突出的全能选手。学生可跨档报名（每人至多2档），课程阶段按档分班辅导。

### 5.4 评审机制

**四方评审团**（每个档位3-5人）：
- 老字号企业代表（命题方，懂品牌与生意）
- 平台方运营专家（懂算法与流量）
- 专业机构总监（曼拾等，懂商业转化与内容方法论）
- 高校教授（懂学术规范与人才培养）

**评分维度**（按档位加权）：
- 内容创作档：创意性30% + 内容质量30% + 传播数据20% + 品牌契合20%
- 策略策划档：洞察30% + 策略逻辑30% + 可行性25% + 答辩表现15%
- 实战转化档：转化数据40% + 执行质量30% + 复盘深度20% + 表达呈现10%

**真实数据加权**：复赛及以后的作品，真实发布数据（播放/互动/转化）按10%-20%权重计入总分——让市场反馈参与打分，倒逼学生理解"营销要服务效果"。

### 5.5 奖项与激励

- 奖金：各档冠军2万元、亚军1万元、季军5000元、单项奖3000元；全场总冠军另奖3万元（建议值）
- 证书：就促中心+联合主办单位盖章的获奖证书（含金量高，可写入简历与综评）
- 孵化资源包：3个月导师陪跑、平台流量扶持、老字号实习直通卡、人才库优先推荐权
- 特殊激励：优秀作品获得真实落地机会——方案类作品由专业机构协助落地为真实执行，带货类作品进入真实渠道投放，作品署名归学生。这是其他大赛没有的差异化激励。

## 六、培训体系：达人孵化课程

### 6.1 课程定位

不是普通讲座式培训，而是"理论+实操+陪跑"三位一体的MCN化孵化课程。吸收就促中心原想法精华——**"场景与IP融合、门店升级为内容空间、适配Citywalk、线下探店与线上实训同频"**——构建"通识型+专业化"双轨课程体系：

- **通识型课程**：面向全体学生，建立数字营销全景认知与基础能力，低门槛、广覆盖；
- **专业化课程**：面向有基础与明确职业意向的学生，深入方法论与实战技能，对接行业认证（含小红书"种草学"营销人才认证）。

课程按全平台逻辑设计，不绑定任何单一平台；小红书作为属地核心平台，其官方"种草学"认证体系直接接入课程（见6.3）。

### 6.2 课程档位体系（三档）

**档位一：数字营销通识营（通识型·入门）**

| 维度 | 说明 |
|---|---|
| 定位 | 零基础入门，全专业可学；建立数字营销全景认知+老字号文化底座+AI工具上手 |
| 适合人群 | 全体在校大学生（含非传媒商科专业） |
| 课时 | 约16-20课时（2天线下集训+8课时线上录播） |
| 课程内容 | ①数字营销全景图：内容种草/直播带货/效果投放/私域运营是什么、怎么选 ②老字号文化认知：品牌故事、非遗技艺、场景叙事（含门店参访） ③内容创作基础：选题、文案、视觉、剪辑入门 ④AI工具入门：AIGC文案/图片/视频工作流实操 ⑤小红书种草学通识：种草营销的底层逻辑与平台规则（官方通识内容） |

| 学完takeaway | 数字营销全景认知；AI工具链上手；1个个人账号冷启动；通识结业证书；具备参加赛事入门档（内容创作）的能力 |

**档位二：数字营销官进阶营（专业化·进阶）**

| 维度 | 说明 |
|---|---|
| 定位 | 掌握完整方法论与实战技能，对接行业认证，成为"能独立交付"的数字营销人才 |
| 适合人群 | 有基础的学生、通识营结业且考核优秀者、商科/传媒/设计专业学生 |
| 课时 | 约40课时（3天线下集训+4-6周导师陪跑+实战任务） |
| 课程内容 | ①种草营销方法论：小红书种草学认证课程（种草逻辑、内容策略、流量组合打法、数据复盘，官方认证体系） ②策略策划实战：品牌诊断、人群洞察、渠道组合、预算分配、方案撰写 ③直播带货实操：话术脚本、场控、门店实景直播演练 ④AI进阶应用：数字人、AI视频、投放辅助 ⑤IP与人设打造：账号定位、内容人设、商业化边界 ⑥职业化基础：作品集打造、简历面试 |

| 维度 | 说明 |

| 课程内容 | ①真实项目实战：围绕老字号真实命题完成真实直播/真实投放/真实方案落地（可选方向） ②商业数据复盘：ROI、转化率、复盘报告撰写 ③就业冲刺：作品集定稿、模拟面试、双选会实战 ④创业辅导：对有创业意向者提供入驻实训基地辅导 |
| 考核方式 | 真实商业成果（直播GMV/投放ROI/方案落地）+复盘答辩 |
| 学完takeaway | 真实商业战报（可写进简历的硬成果）；企业导师背书与推荐信；就业/实习offer（双选会直通）；老字号人才库高级认证；创业孵化资格 |

**三档关系：** 通识营→进阶营→实战营逐级进阶，也可按基础直接选档；与赛事档位（内容创作/策略策划/实战转化）对应衔接——课程学哪档，参赛比哪档，学赛一体。

### 6.3 小红书"种草学"营销人才认证接入

- **认证背景**：小红书官方营销学习平台"种草学"推出营销人才认证体系，是内容营销领域行业认可的能力凭证（具体认证名称与等级以平台官方最新体系为准，建议依托属地关系与小红书团队合作确认）
- **接入方式**：
  1. 通识营：引入种草学官方通识课程内容（线上学习），作为入门认知模块
  2. 进阶营：接入种草学认证课程+官方考试，通过者获官方认证证书——作为进阶营毕业硬指标之一
  3. 合作机制：依托小红书总部在黄浦的属地优势，争取官方讲师授课、考试费用优惠/补贴、认证直通通道（纳入政企合作框架）
- **认证价值**：行业认可的营销能力凭证，显著提升简历含金量；认证学员自动进入小红书生态就业推荐视野；与就促中心人才库联动，形成"官方认证+政府背书"双保险

### 6.4 教学形式（升级版"AI+新媒体陪跑计划"）

借鉴并升级2023年已验证的"AI+新媒体"创业陪跑计划模式（每两天日评、每周1V1复盘、每双周分享课）：

- **线下集训**：按档位分营——通识营2天、进阶营3天、实战营以项目制为主
- **六周导师陪跑**：每两天一次作品日评、每周一次1V1复盘、每双周一次分享课——学员在陪跑期内完成个人账号冷启动或方案打磨
- **门店实战月**：分档进驻老字号门店（内容班探店、策略班调研、实战班直播/投放）
- **线上课程平台**：录播课+直播课+资料库，支持非上海学生参与
- **结业考核**：学分制，完成全部模块+实战任务+作品集，颁发结业证书

### 6.5 证书体系（五层）

1. **通识结业证书**：《老字号青年数字营销官通识结业证书》（就促中心认证）——通识营结业即发
2. **进阶结业证书**：《老字号青年数字营销官结业证书》（就促中心+老字号企业联合认证）——进阶营结业即发
3. **小红书种草学认证**：官方营销人才认证证书（进阶营考核通过）——行业认可凭证
4. **达人认证**：实战营考核优秀者获《老字号青年数字营销达人认证》——人才库高级认证+就业直通
5. **获奖证书**：赛事获奖证书（政府背书，就业直通凭证）——参赛获奖另发

## 七、宣导方案

### 7.1 传播主线与话题资产

- **核心话题**：#老字号新声代 #老字号青年数字营销官 #老字号Citywalk
- **传播主线**：不是"招人参赛"，而是"一场老字号与年轻人的双向奔赴"——让社会看到老字号在年轻化，让年轻人看到老字号的新机会
- **内容资产化**：赛事全程所有选手作品、花絮、导师金句、老字号故事均为可复用内容资产，赛事结束即沉淀为"老字号·新活力"的内容素材库

### 7.2 三阶段传播节奏

**阶段一：预热期（报名前2周）**
- 官宣海报与宣传片：老字号掌门人+非遗匠人+高校学生同框，制造期待
- 校园大使招募：每所合作高校招募2-3名校园大使，负责校内扩散（大使本身获得社会实践证明）
- 老字号门店话题预热：门店设置"新声代"主题物料，扫码了解赛事
- 政务新媒体发布：就业促进中心公众号/视频号首发

**阶段二：招募期（3-4周）**
- 高校渠道：就业办/团委官方发文、校园宣讲会（走进10余所高校，延续成熟打法）、社团合作、学生社群投放
- 平台渠道：按合作平台资源位投放（话题页/活动位/信息流），覆盖小红书、抖音、视频号、B站、美团等
- 门店渠道：老字号门店物料+店员话术引导（"在拍我们店的年轻人都能参加"）
- 内容激励：优秀报名作品提前获得展示位，制造"参赛即曝光"效应
- 关键机制：**报名即参与传播**——报名作品带话题发布，海选期即为赛事造势

**阶段三：赛程期（6-8周）**
- 赛事进程内容化：每阶段产出赛事花絮、选手故事、导师金句、老字号冷知识
- 门店实战阶段直播切片传播：探店vlog、直播高光时刻
- 决赛直播：老字号专场直播节（决赛日=传播峰值日）
- 成果展：决赛后举办"老字号新声代成果展"（优秀作品+人才库开放），邀请企业HR到场，兼作就业对接会

### 7.3 渠道矩阵与分工

| 渠道 | 主体 | 动作 |
|---|---|---|
| 高校渠道 | 就促中心+高校 | 官方发文、宣讲会、校园大使 |
| 平台渠道 | 小红书（核心）+其他平台方 | 话题运营、流量扶持、活动位；属地官方合作通道 |
| 政务渠道 | 就促中心 | 公众号、视频号、媒体报道 |
| 老字号渠道 | 老字号企业 | 门店物料、官号联动、员工转发 |
| 专业渠道 | 曼拾等 | 行业社群、达人/KOC资源、案例包装 |

## 八、就业转化机制（核心差异化——让大学生有班上）

### 8.1 全程人才建档

从报名起为每位学员建立数字档案：能力测评+课程成绩+实战表现+作品集+企业评价，结业自动入库，形成《黄浦区老字号青年数字营销人才库》。**人才库是本项目给政府的核心交付物**——它让"就业促进"从活动口号变成可持续运营的资产。

### 8.2 四条就业出口

**出口一：老字号企业就业（主出口）**
- 实习/见习直通：对接既有实训基地见习机制，结业学员优先进入老字号实习见习（已有17个岗位/13人见习的既往基础）
- 面试绿色通道：获奖者免初筛进入老字号企业面试
- 定向招聘：人才库按季度向老字号企业推送匹配人才

**出口二：平台生态与数字营销行业就业**
- 平台方生态内岗位推荐：MCN机构、品牌服务商、内容制作公司、达人经纪、直播基地
- 数字营销行业企业联动：广告代理公司、电商代运营、MCN机构开放岗位

**出口三：专业机构就业（曼拾等）**
- 曼拾开放实习与初级岗位（内容策划、媒介执行、客户执行、数据分析等方向）
- 联动广告代理与营销服务行业企业开放岗位

**出口四：创业孵化**
- 优秀学员创业项目可入驻老字号公共创业实训基地孵化（延续"孵化创业组织"既有模式）
- 创业指导：首席创业指导师工作室跟踪辅导

### 8.3 就业对接活动

- **结营双选会**：决赛后举办，老字号企业+平台生态企业+专业机构摆摊，学员路演作品集现场双选
- **人才库定向推送**：季度推送机制，人才库向合作企业开放查询
- **就业追踪**：结业后3/6/12个月回访，形成就业成效数据（就业率、岗位类型、薪资、留存），写入政府就业服务成效报告

### 8.4 就业数据闭环（项目灵魂）

```
报名建档 → 培训评估 → 实战考核 → 结业入库 → 双选对接 → 就业追踪(3/6/12月) → 成效报告 → 下一年度优化
```

就业数据不是赛后统计，而是全过程沉淀——这正是本项目与过往赛事最本质的区别。

| 就业转化期 | 第17-20周 | 结营双选会、人才库上线、就业对接启动、成效初报 |

*注：如就促中心希望赶在2027年应届生春招前完成，可压缩至14-16周；如需覆盖毕业季，建议启动时间不晚于当年2月。*

## 十一、赛事带动企业生态：参与企业及其资源贡献（核心章节）

### 11.1 设计逻辑：企业不是来"当评委"的，是来"接入资源"的

赛事带动企业参与的价值，不止于评选。本方案把每一类参与企业都设计成**资源接入方**——企业带着真实资源入场（命题、场景、流量、岗位、工具、资金），换回四样东西：**品牌曝光、人才优先权、成果使用权、政企合作背书**。学生的作品、人才、传播声量，就是给企业的回报。

### 11.2 企业参与矩阵（除评选外，还能提供什么）

**1. 平台方（小红书为核心·办公地与注册地均在黄浦；抖音/视频号/B站/美团/淘宝直播等为协同）**
- 评选角色：平台运营专家评委
- 属地优势：小红书总部在黄浦，政企合作具备政策协同、资源直通、人才留区的基础——本项目区别于全国同类赛事的独特壁垒
- 还能提供：流量扶持（话题页/活动位/开屏）、平台规则与算法课程、官方认证背书、优秀作品平台官方活动位与商业化机会、生态内企业岗位推荐、内容审核绿色通道、平台校园合作资源

**2. 广告代理/数字营销机构（曼拾等）**
- 评选角色：策略与商业价值评委
- 还能提供：方法论课程与导师、真实项目落地执行（学生方案→专业优化→真实投放）、行业案例库、实习与就业岗位、部分投放预算资源

**3. MCN机构/达人经纪公司**
- 评选角色：内容与直播表现评委
- 还能提供：直播实操培训、达人孵化方法论、直播间与设备、供应链选品资源、签约与兼职合作机会（自愿原则，不强制）、直播复盘工具

**4. 老字号品牌企业（核心参与方）**
- 评选角色：命题方+品牌评委
- 还能提供：真实经营命题、门店场景（内容空间）、产品样品、品牌经营管理人员讲师、实习见习就业岗位、获奖作品落地应用、新品试吃试用

**5. 高校（生源与学术方）**
- 评选角色：学术评委
- 还能提供：生源组织、学分/综评认定、教学研究支持、师资与实验室资源、就业办渠道宣发

**6. 媒体与政务新媒体（传播方）**
- 评选角色：传播价值评委（可选）
- 还能提供：新闻报道、奖项背书、社会影响力放大、决赛直播传播

**7. 数据与技术服务商（工具方）**
- 评选角色：数据评审支持（可选）
- 还能提供：数据监测与复盘工具（赛事免费版）、行业数据报告、AI创作工具赞助（降低参赛门槛）、数字人技术支持

**8. 直播基地/产业园/供应链（场地与货品方）**
- 评选角色：实战支持（可选）
- 还能提供：直播间场地与设备、供应链与选品资源、仓储物流支持、实训基地联动（可纳入现有实训基地体系）

**9. 文旅与非遗机构（场景与内容方）**
- 评选角色：文化价值评委（可选）
- 还能提供：Citywalk线路资源、非遗文化内容素材、景区/街区联动场景、文化专家讲师

**10. 金融机构与创业服务机构（创业出口方）**
- 评选角色：创业项目评审（可选）
- 还能提供：创业扶持政策对接、创业贷款绿色通道、孵化器入驻资源、创业导师

**11. 职业技能认证/培训机构（认证方）**
- 评选角色：认证标准顾问（可选）
- 还能提供：职业技能等级证书合作、人社补贴培训资质对接、课程共建（把培训体系纳入正规认证体系）

### 11.3 企业权益设计（为什么愿意来）

| 权益 | 内容 |
|---|---|
| 冠名与联办 | 设立企业冠名奖（如"XX老字号创新奖"），联办单位署名 |

## 十二、曼拾：作为支持企业的角色定位（专章）

### 12.1 定位

曼拾作为**项目支持方（广告代理/数字营销专业机构）**参与，承担三重角色：**课程共建方、导师评委方、就业出口方**。曼拾是深耕数字营销整合服务的专业机构，服务覆盖内容种草、效果投放、直播电商等多个领域——天然是"政府+平台+高校+老字号"之间的翻译器：既懂品牌生意，又懂内容与方法论，还懂落地执行。

### 12.2 五大具体贡献

**1. 课程共建（专业输出）**
- 主导开发M2数字营销方法论模块：营销全景图、平台通识（中立视角）、策略到执行的完整方法论、内容生产标准、数据复盘
- 提供真实操盘案例库：曼拾服务消费品牌的实战案例作为教学素材（脱敏处理）
- 联合开发AI内容工作流课程（M3）：把AIGC工具链做成可复制的标准流程

**2. 导师与评委**
- 逸凡及核心团队担任课程导师，参与全程陪跑辅导
- 担任赛事四方评审团评委（专业机构侧）
- 提供一对一职业咨询（数字营销方向）

**3. 就业出口**
- 开放实习与初级岗位：内容策划、媒介执行、客户执行、数据分析等方向
- 优秀学员优先录用，形成"孵化计划→曼拾实习→行业成长"通道
- 联动广告代理与营销服务同业开放岗位资源

**4. 落地执行支持**
- 帮助老字号把获奖方案落地为真实执行：学生方案→专业优化→真实上线（内容/投放/直播均可）
- 作品署名归学生，让"方案到成果"完整闭环，也让就促中心的赛事成果可见、可量化

**5. 项目长期共建**
- 参与项目年度迭代：基于就业追踪数据优化课程与赛制
- 共建"老字号数字营销案例库"：赛事优秀案例沉淀为黄浦老字号数字化营销的可复制资产

### 12.3 对曼拾的价值（互利逻辑）

曼拾不是单方赞助，而是多方共赢：
- **人才储备**：提前锁定经过实战检验的数字营销人才，降低招聘试错成本
- **客户关系**：深化与老字号企业、区政府的合作关系，打开老字号数字营销服务市场
- **品牌背书**：参与政府标杆项目，提升曼拾在行业与客户中的专业公信力
- **方法论沉淀**：赛事中验证的方法论可反哺曼拾自身服务能力

## 十三、风险与保障

| 风险 | 应对 |
|---|---|
| 学生参与度不足 | 证书+奖金+就业直通三重激励；AI降低创作门槛扩大生源；分档制让不同起点的学生都有位置；校园大使渠道；与高校学分/综评联动 |
| 老字号配合度不足 | 区商务委背书动员；命题轻量化（企业只需出命题和门店场景，执行由秘书处承担）；成果反哺企业（作品+人才+传播曝光） |
| 档位三（实战转化）报名不足 | 实战班导师1V1护航降低心理门槛；提供直播间/设备/货品支持；明确"真实数据不等于必须盈利"的评分口径；设保底参与奖 |
| 内容合规风险 | AI内容标注规则前置培训；作品知识产权约定（学生署名、企业使用授权范围明确）；平台规则合规纳入课程 |
| 就业转化不及预期 | 保底机制：实训基地见习承接；数据透明：就业追踪如实呈现，不美化；目标分档（对接数/就业数/满意数） |
| 平台资源承诺落空 | 资源协议前置书面确认；多平台并行分散依赖；曼拾等专业机构作为平台资源落地执行方 |
| 执行质量风险 | 第三方执行机构+工作组例会制度（周例会+里程碑评审）；关键节点成果验收 |
