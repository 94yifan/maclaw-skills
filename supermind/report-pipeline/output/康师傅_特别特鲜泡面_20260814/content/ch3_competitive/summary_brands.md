# 汇总品牌速览

康师傅红烧牛肉面是康师傅的经典大单品，也是整个方便面品类的国民记忆锚点。它定位大众经典口味，价格锚定在3到5元，渠道表现是百万终端的全渠道覆盖，在品类里处于不可撼动的销量基本盘位置，核心人群是价格敏感的大众消费者。它是康师傅高端化的地基，任何新品都站在它建立的品牌信任之上 [报道层]。

统一来一桶是统一应对康师傅红烧牛肉面的大份量经典产品，定位高性价比大份量，价格带在4到8元，渠道与康师傅正面竞争，在三四线及下沉市场有稳定基本盘，核心人群是注重份量的男性年轻消费者。它是统一守住性价比防线、为汤达人高端化托底的战略棋子 [映射]。

白象汤好喝是白象逆袭的核心产品，定位真材实料浓汤面，价格带在4到8元，渠道上在传统经销网络和电商都有强劲动销，趋势上处于快速增长通道，核心人群是看重汤底品质和国货情绪的大众家庭。它是白象从民族情绪红利转向产品力沉淀的关键载体 [报道层]。

康师傅大汤王是康师傅守住3到5元性价比价格带的战略产品，定位大份量高性价比，价格带3到5元，渠道主打下沉市场和乡镇终端，趋势上承接的是平价基本盘的需求稳定，核心人群是对价格极度敏感的蓝领和家庭消费者。它证明康师傅在高端化的同时没有放弃基本盘，这种上下兼顾是它回旋余地的来源 [映射]。

趋势综述：四个汇总品牌共同指向一个判断——方便面竞争正在同时向两端发力，向上走高端化和健康化，向下守性价比和份量，中间地带的品牌最容易被挤压。康师傅是唯一在两端都有强势产品承接的品牌，这是它在这个K型分化格局里的独特优势。

人群综述：方便面的核心人群正在分化，价格敏感的大众家庭、注重品质的都市白领、健康意识觉醒的年轻人三类人群各自有不同的产品对应。谁能用产品矩阵同时覆盖这三类人群，谁就能在K型分化里占据最有利的位置。康师傅用大汤王守价格敏感人群、用合麵汤大师攻品质人群、用特别特鲜泡面打年轻健康人群，是三线并进的完整布局。这个布局的关键在于，三个产品线不是各自为战，而是共享康师傅的渠道和供应链底座，形成合力。
