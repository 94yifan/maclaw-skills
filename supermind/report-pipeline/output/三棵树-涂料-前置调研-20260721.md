## 1. 赛道概览

### 1.1 油漆/涂料行业整体

| 指标 | 数据 | 备注 |
|------|------|------|
| 2025年市场规模 | **4200-4300亿元** | 含工业涂料+建筑涂料 |
| 营收增速 | 3%-5% | 工业需求拉动 |
| 2025年产量 | 约3600万吨 | 增速1%-3%，传统溶剂型下降 |
| 行业利润 | 约280亿元 | 增速6%，毛利率在改善 |
| **CR5** | **约45%**（从38%升至45%） | 集中度显著提升，中小企业退出率+17% |
| 过去十年年均增速 | 4.7%-5.46% | 成熟行业特征 |
| 2024年（1-9月） | 产量2768万吨，收入2902亿 | 同比产量-5.12%，收入-1.79% |

**四大趋势**：绿色引领（水性/粉末涂料）、智能驱动（自清洁/隔热/防火）、功能突破（辐射制冷涂料600元/㎡）、集中发展（并购整合加速）

**头部格局**：立邦连续27年蝉联中国市场第一，2025年百强榜单中PPG、阿克苏诺贝尔、三棵树等紧随其后。

### 1.2 乳胶漆/建筑涂料（内墙漆）赛道

| 指标 | 数据 | 备注 |
|------|------|------|
| 建筑涂料占行业比重 | 约35%-40% | 估算约1500-1700亿元 |
| 零售端CR3 | 约40%-50% | 立邦+多乐士+三棵树 |
| 工程端竞争更分散 | CR5约25%-30% | 三棵树、亚士、立邦、嘉宝莉等混战 |
| **立邦TUC份额** | 25%（2023） | 2019年19%→2020年23%→2021年24%→2023年25% |
| 零售端增速 | 弱于工程端 | 新房交付下滑，存量翻新托底 |

**竞争格局特征**：
- **零售端**：立邦约25%、多乐士约12%-16%、三棵树约10%-12%（估算），三者合计约50%
- **工程端**：三棵树、立邦、亚士创能三足鼎立，三棵树在大型地产集采中份额领先
- **外资主导零售、内资主导工程**的二元格局在松动——三棵树零售端正在追赶

**关键趋势**：
- 新房装修需求见顶，**存量房翻新**接棒（年翻新需求5000万套）
- 重涂市场崛起，涂料行业具有"重涂属性"——每8-10年翻新周期
- 地产下行冲击工程渠道，三棵树等工程占比高的公司承压（2024年营收-3%）
- "高端化+服务化"是零售突围方向（立邦刷新服务、三棵树马上住）

- **差异化方向**：设计驱动、施工培训、空间解决方案

**关键观察**：
- 2024年营收微降（-3%）主要受地产下行影响（工程渠道承压）
- 2024年净利润暴增91%主要来自成本优化和产品结构升级
- **2025年是拐点**：营收转正增长+3.49%，净利润暴增133%，净利率从2.74%→6.19%大幅修复
- 扣非净利润仅约1亿+说明房地产坏账计提等非经常性损益仍在消化

### 3.2 业务与渠道结构

| 维度 | 描述 | 数据点 |
|------|------|--------|
| **主营品类** | 建筑涂料（乳胶漆/真石漆/艺术漆）、防水材料、基辅材 | 涂料占比约70%+ |
| **渠道结构** | 经销商+B端大地产工程+C端零售+电商（补充） | ⚠️ 大头在线下（经销商+工程） |
| **经销商网络** | 覆盖全国，深度下沉 | 乡镇级门店渗透领先 |
| **工程渠道** | 与恒大、万科等大型地产商长期合作 | 2024年地产下行冲击明显 |
| **零售品牌** | "三棵树 马上住"服务品牌 | 一站式涂刷服务 |
| **高端化** | 艺术漆5.0旗舰店 | 南京等地落地，2025年涂博会爆火 |
| **海外** | 开始"出走"海外 | 东南亚等市场布局初步 |

### 3.3 艺术漆业务亮点

- **2020年**：销售额突破1亿
- **2022年**：突破2亿，年均复合增长率超40%
- **2024年**：突破3亿
- **2025H1**：增长率高达43%，预计全年突破5亿

- 艺术漆5.0旗舰店：南京首店火爆，标志着渠道模式升级

### 4.3 经营理念与价值观

> "创业的时候，我们六个月卖不出一桶涂料，那时候大家比较相信外资品牌。我们不信邪，就想要做一桶中国人自己的涂料。经过20年的艰苦奋斗，我们终于成为了中国民族涂料的第一品牌，关键是打破了外资品牌对中国涂料市场的垄断，我们觉得蛮自豪的。"  
> ——洪杰，央广网/央视财经采访

核心经营理念提炼：

1. **"敬天爱人"**——核心价值观，累计捐赠超1亿元，覆盖教育、扶贫、环保
2. **"健康漆"定位**——差异化切入，强调环保品质
3. **"有使命有价值观的企业，才能走得更远"**——《闽商》杂志采访
4. **"尊重自然、爱护自然"**——总部大楼原计划20层主动缩减为十几层
5. **"永争第一"**——20周年庆典发言：以永争第一的精神做到世界涂料领导品牌
6. **民族品牌情怀**——打破外资垄断的使命感贯穿始终

## 5. 赛道框架建议（待逸凡确认）

基于前置调研数据，提供以下3个分析框架选项：

### 选项A：双赛道纵向对比框架

**逻辑**：分别对"乳胶漆/建筑涂料"和"艺术漆"两个赛道做独立竞品对比，最后做交叉分析。

- **Part 1**：乳胶漆/建涂赛道竞争分析（三棵树 vs 立邦·多乐士·嘉宝莉·亚士）
- **Part 2**：艺术漆赛道竞争分析（三棵树 vs 菲玛·卡百利·立邦米兰诺·嘉宝莉）
- **Part 3**：交叉洞察——三棵树从建涂延伸到艺术漆的"高维打低维"战略逻辑

**优势**：结构清晰，两条赛道的竞争逻辑天然不同（建涂比规模/渠道，艺术漆比品牌/设计/服务）  
**劣势**：可能割裂三棵树整体战略画像

### 选项B：战略叙事框架

**逻辑**：以三棵树"从民族涂料第一品牌到艺术漆高端化"为主线，对标不同阶段的竞争对手。

- **Part 1**：基本盘——建涂赛道如何守住+突破（vs 立邦/多乐士/嘉宝莉）
- **Part 2**：增长极——艺术漆赛道的追赶与领先（vs 菲玛/卡百利/立邦米兰诺）
- **Part 3**：护城河——渠道、品牌、产品三维分析
- **Part 4**：风险与隐忧——地产依赖、利润率、千亿目标差距

**优势**：故事性强，适合品牌咨询报告叙事  
**劣势**：需要更多内部数据支撑（如渠道利润率、单店模型等）

### 选项C：四维竞品矩阵框架

**逻辑**：从"规模×增速"和"大众×高端"两个维度构建竞品矩阵，四象限定位。

```
            高增速
              │
    菲玛      │  三棵树艺术漆
    卡百利    │  立邦米兰诺
              │
  ────────────┼──────────── 规模
              │
    巴德士    │  立邦
    美涂士    │  多乐士
              │  嘉宝莉
              │  三棵树建涂
            低增速
```

- **Part 1**：建涂象限——巨头肉搏（立邦/多乐士/三棵树/嘉宝莉/亚士）
- **Part 2**：艺术漆象限——群狼抢滩（菲玛/卡百利/三棵树/立邦米兰诺/蔻帝）
- **Part 3**：渠道力对比——经销商密度、单店产出、工程渗透率
- **Part 4**：品牌力对比——NPS、溢价能力、设计师口碑

**优势**：视觉化强，适合PPT呈现  
**劣势**：数据可得性挑战大（需要大量一手数据）
