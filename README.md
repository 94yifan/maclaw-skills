# MacLaw Skills

CEO分身Agent的Skill集合。每个Skill可按需安装到[OpenClaw](https://openclaw.ai)使用。

## Skills

### 🔮 ziwei-people-analysis — 紫微识人管人报告生成

输入命盘输出八层管理策略：驱动力排序、软肋预警、ROI最高的管理手段、沟通适配方式、学习成长路径、职业发展建议、合盘适配分析、场景化话术。

适用场景：团队成员入职/晋升评估、管理风格适配、团队关系诊断。

详阅：[ziwei-people-analysis/SKILL.md](ziwei-people-analysis/SKILL.md)
