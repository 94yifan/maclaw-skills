# 第1章 核心发现与咨询窗口

## 一、核心发现

CoCo都可是一家被市场严重低估、但正在快速失血的老牌现制茶饮企业。它创立于1997年，比蜜雪冰城早了整整两代创始周期，全球门店超过5000家，覆盖美国、日本、东南亚、欧洲等市场，是现制茶饮行业出海最早、覆盖最广的品牌之一。可回到中国大陆主场，蜜雪冰城已经冲到4万家以上，古茗、茶百道、沪上阿姨各自站稳8000到9000家，连后起的霸王茶姬都突破6000家，CoCo在大陆的门店规模被甩开了数量级的差距（evidence_tier：reported）。

核心发现一：CoCo的差距不是单点短板，而是产品代际没跨过、品牌势能老化、资本杠杆缺失三重叠加，导致它从行业先驱退化为存量老牌。产品上，珍珠奶茶和鲜芋系列是立身之本，但SKU老化、缺新爆款接棒，被霸王茶姬的国风鲜奶茶和喜茶的鲜果茶两头挤压；品牌上，消费者知道它是台湾老牌奶茶，却说不清它到底主打什么，门店几乎没有打卡和分享价值；资本上，CoCo长期对上市保持警惕、未引入资本杠杆，营收量级被头部拉开一个数量级（推算约9至18亿元，蜜雪冰城约248亿元，evidence_tier：speculation/reported）。

核心发现二：现制茶饮的竞争主轴已经从差异化营销升级为万店规模、供应链效率、品牌势能的三重战争。谁先建立品类定义权，谁就拥有定价权和用户心智。CoCo在这三个维度都不占优，唯一没有掉队的是供应链垂直整合这项老本行，2011年台湾塑化剂风波中幸免靠的正是这一点，但这项能力从未被产品化、品牌化（evidence_tier：reported）。

核心发现三：CoCo手里现成有一张几乎没人抢的牌，就是芋头。鲜芋系列是CoCo二十多年积累的招牌产品线，芋泥奶茶、鲜芋圆奶茶在华南华东有稳定忠实客群，而主流竞品里没有任何一家把芋头做成品牌级符号。这是CoCo重建差异化护城河成本最低、见效最快的切入点（evidence_tier：mapped）。

核心发现四：海外市场是CoCo被忽视的第二增长曲线。它是中国茶饮出海最早的一批，全球5000多家门店里相当比例在海外，这份全球化版图在同行里稀缺，蜜雪冰城出海晚得多，霸王茶姬、古茗的海外才刚起步。问题在于CoCo从未把海外当成战略来经营，只是顺其自然地存在（evidence_tier：reported）。

## 二、咨询窗口

燃创咨询的切入机会集中在四个方向，按优先级排序：

第一，用鲜芋系列重建差异化护城河。把定位从模糊的台式奶茶收窄到国民鲜芋鲜果茶饮，主推一到两款芋泥核心单品打透心智，做芋头供应链的深度绑定。这是投入远低于造新品牌、却能最快把模糊定位变清晰的一条路。

第二，把海外市场从被动存在升级为主动的第二增长曲线。梳理海外各市场单店模型和盈利结构，做北美、东南亚、日本重点市场的深度本地化和组织化运营，让海外成为独立贡献增长和利润的第二曲线，同时反哺国内品牌的高端化叙事。

第三，完成从创始人驱动到职业经理人体系的治理升级。洪肇水从1997年掌舵至今，决策集中稳健，这套模式早期帮CoCo避开了无数坑，如今成了组织瓶颈。引进关键岗位职业经理人、搭建总部中台能力，是承接万店级运营和资本市场治理要求的前提。

第四，上市与否是CoCo未来三年最该拍板的一个决定。头部竞品纷纷资本化用资本杠杆做大，CoCo长期警惕资本，若继续回避，规模差距只会越拉越大。这个问题不该再拖，需要尽快给一个明确答案。
